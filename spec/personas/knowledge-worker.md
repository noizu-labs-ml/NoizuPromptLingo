# Knowledge Worker Persona

## Profile
- **Name**: Generic Knowledge Worker
- **Role**: Professional (designer, analyst, writer, PM, etc.)
- **Primary Environment**: macOS
- **Secondary Environments**: iPad, iPhone (for reference)
- **Tools**: Productivity apps, browsers, communication tools, design tools

## Motivations
- Needs quick access to recently copied text and links
- Works across multiple applications constantly
- Values simplicity and ease of use over advanced features
- Wants reliability—clipboard history must not fail

## Pain Points
- Copying a link/email/URL and losing it before pasting
- Searching through multiple documents for that thing copied 10 minutes ago
- Switching apps and losing the clipboard buffer
- Email writer's block—need to reference recently copied information

## Goals
1. Quick access to recent clipboard items (Cmd+Shift+T)
2. Simple search to find items from the past hour
3. Different visual handling for links, phone numbers, addresses
4. Easy dismissal/paste workflow
5. Low friction—just works in background

## Usage Patterns
- Copies text, links, and simple data constantly
- May not care about code-specific features (JSON formatting, etc.)
- Uses keyboard but also uses mouse/trackpad frequently
- May work with images/screenshots occasionally

## Anti-Patterns (What to Avoid)
- Overly complex interfaces with too many options
- Keyboard-only workflows that ignore user might use mouse
- Heavy configuration requirements before basic features work
- Unreliable storage or sync that loses data

## Different from Developer Persona
- Less concern about "what" something is—just show it
- Less need for code-specific features
- May prioritize simple over configurable
- More likely to sync to mobile devices
