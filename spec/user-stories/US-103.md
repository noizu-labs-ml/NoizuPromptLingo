# US-103: Tag Entry In-Panel (T Key)

As a developer,
I want to press T on a highlighted entry to open the tag editor,
so that I can quickly tag entries without navigating to a separate menu.

## Scenario: Press T to open tag editor
Given a clipboard entry is highlighted in the history panel
When the user presses the T key
Then the tag editor form should appear for that entry
And existing tags should be displayed as removable chips

## Scenario: Add new tag via autocomplete
Given the tag editor is open
When the user types in the add tag field
Then previously used tags should appear as autocomplete suggestions
And pressing Enter or clicking adds the tag

## Scenario: Remove tag
Given tags are displayed on an entry
When the user clicks on a tag chip or presses Delete on focused tag
Then that tag should be removed from the entry
And the entry should update immediately

## Scenario: Bulk tag multiple entries
Given multiple entries are selected (Shift + arrow keys)
When the user presses T
Then the tag editor should open in bulk mode
And tags should be applied to all selected entries

## Scenario: Save tags with Enter
Given the tag editor is open
When the user presses Enter
Then tags should be saved and the editor should close
And the changes should be reflected in the entry display

## Scenario: Cancel tag editor
Given the tag editor is open
When the user presses Escape
Then the editor should close without saving changes
And original tags should be preserved

## Notes
- **Persona**: both
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Key conflict, multi-select edge cases
- **Dependencies**: US-016 (Filter History by Content Type) for tags
