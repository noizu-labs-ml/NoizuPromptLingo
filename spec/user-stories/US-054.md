# US-054: Prevent multiple app instances from running

As a knowledge-worker,
I want the application to prevent launching multiple instances,
so that my clipboard history doesn't get out of sync through duplicate processes.

## Scenario: Detect existing instance on startup
Given Smart Clipboard is already running
When I attempt to launch a second instance from Finder or Spotlight
Then the second instance should detect the running instance and exit immediately

## Scenario: Show warning on duplicate launch attempt
Given Smart Clipboard is already running
When I attempt to launch a second instance
Then a brief notification should appear indicating "Smart Clipboard is already running"

## Scenario: Focus existing instance instead of launching new one
Given Smart Clipboard is already running in the background
When I double-click the application icon
Then the existing instance should be brought to the foreground instead of launching a new process

## Scenario: Single instance enforcement during auto-start
Given auto-start is enabled and Smart Clipboard is already running
When macOS attempts to launch the app on login
Then the duplicate launch should detect the running process and exit without showing a popup or error

## Scenario: Check for stale lock after crash
Given Smart Clipboard was terminated ungracefully
When the app starts
Then it should check for a stale single-instance lock file and, if found, clean it up and proceed

## Scenario: Multiple user support per instance
Given two users are logged into macOS (via Fast User Switching)
When each user launches Smart Clipboard
Then each user should have their own instance monitoring their clipboard in their session

## Notes
- **Persona**: knowledge-worker
- **T-Shirt Size**: XS
- **Complexity**: low
- **Risks**: Stale lock files can prevent valid startup; need timeout detection
- **Dependencies**: None
