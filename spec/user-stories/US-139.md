# US-139: Copy Method Tracking

As a developer,
I want to track how clipboard content was copied (keyboard, menu, programmatic),
so that I can understand my clipboard usage patterns.

## Scenario: Detect keyboard copy
Given the user copies via Cmd+C
When the clipboard entry is created
Then the copy_method should be recorded as "keyboard"

## Scenario: Detect menu copy
Given the user copies via Edit > Copy menu
When the clipboard entry is created
Then the copy_method should be recorded as "menu"

## Scenario: Detect programmatic copy
Given an app copies to clipboard programmatically
When the clipboard entry is created
Then the copy_method should be recorded as "programmatic"

## Scenario: Display copy method in entry detail
Given an entry has copy_method recorded
When viewing entry details
Then the method should be displayed
And usage analytics should aggregate by method

## Notes
- **Persona**: developer
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Detection accuracy
- **Dependencies**: US-070 (Usage Statistics Dashboard)
