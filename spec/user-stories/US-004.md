# US-004: View Clipboard History

As a developer,
I want to see the last 10 clipboard entries in the popup,
so that I can quickly access recently copied items.

## Scenario: Display clipboard history list
Given the user has copied 5 different text items in the last hour
When the user opens the clipboard popup
Then the popup should display a list of the 5 most recent clipboard entries

## Scenario: Display history with item numbers
Given the clipboard popup is showing history
When the popup renders
Then each history item should be numbered (1-10) for quick reference

## Scenario: Display trimmed history items
Given the user has copied 15 different items
When the user opens the clipboard popup
Then the popup should display only the 10 most recent items

## Notes
- **Persona**: both
- **T-Shirt Size**: S
- **Complexity**: medium
- **Risks**: Performance with large history items
- **Dependencies**: US-001, US-002
