# US-149: Import from Other Clipboard Managers

As a developer,
I want to import clipboard history from other clipboard managers,
so that I can migrate to ClipStash without losing my history.

## Scenario: Import from Paste
Given the user has used the Paste app
When they select "Import from Paste"
Then ClipStash should read Paste's data store
And entries should be converted to ClipStash format

## Scenario: Import from CopyClip
Given the user has used CopyClip
When they select "Import from CopyClip"
Then ClipStash should read CopyClip's database
And entries should be imported with metadata preserved

## Scenario: Import from Maccy
Given the user has used Maccy
When they select "Import from Maccy"
Then ClipStash should read Maccy's storage
And entries should be imported

## Scenario: Import from Alfred Clipboard
Given the user has used Alfred's clipboard history
When they select "Import from Alfred"
Then ClipStash should read Alfred's clipboard data
And entries should be imported

## Scenario: Import from JSON/CSV
Given the user has exported clipboard data
When they select "Import from File"
Then JSON or CSV files should be parsed
And entries should be created from the file data

## Scenario: Deduplication on import
Given imported entries may duplicate existing ones
When import occurs
Then duplicates should be detected by content hash
And the user should be prompted to skip or merge

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Reverse engineering data formats, data loss during conversion
- **Dependencies**: US-036 (Export clipboard history as JSON), US-037 (Import clipboard history from JSON)
