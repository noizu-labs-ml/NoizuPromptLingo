# US-134: Preferences - LLM Tab

As a developer,
I want an LLM preferences tab,
so that I can configure LLM providers and API keys.

## Scenario: Open LLM preferences
Given the menu bar dropdown is open
When the user selects Preferences > LLM
Then the LLM tab should display with provider configurations

## Scenario: Add OpenAI provider
Given LLM preferences is open
When the user enters an OpenAI API key
Then the key should be stored securely in macOS Keychain
And the provider should appear in the list

## Scenario: Add Anthropic provider
Given LLM preferences is open
When the user enters an Anthropic API key
Then the key should be stored securely
And Claude models should become available

## Scenario: Configure Ollama local
Given LLM preferences is open
When the user enters the Ollama server URL
Then local models should be discovered
And the connection should be tested

## Scenario: Set default model per task
Given LLM preferences is open
When the user selects default models for: code, text, image
Then those models should be used when task type is inferred

## Scenario: View token budget and costs
Given LLM preferences is open
When viewing usage stats
Then total tokens used and estimated costs should be displayed
And budget alerts should be configurable

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: API key security, cost tracking accuracy
- **Dependencies**: US-098 (LLM Provider Configuration)
