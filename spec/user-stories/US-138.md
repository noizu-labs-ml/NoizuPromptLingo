# US-138: Source Document URL Detection

As a developer,
I want to detect the source document URL when copying content,
so that I can trace where clipboard entries originated.

## Scenario: Detect browser URL on copy
Given the user copies content from a web browser
When the clipboard entry is created
Then the browser's active tab URL should be captured via Accessibility API
And the URL should be stored as entry metadata

## Scenario: Detect file path on copy
Given the user copies content from a local file
When the clipboard entry is created
Then the file path should be captured
And the path should be stored as entry metadata

## Scenario: Display source URL in entry detail
Given an entry has a source URL
When viewing entry details
Then the source URL should be displayed as a clickable link
And clicking should open the source

## Scenario: No source detection available
Given the source app doesn't expose URL/path
When the clipboard entry is created
Then no source should be stored
And the entry should still function normally

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Accessibility API permissions, app compatibility
- **Dependencies**: US-002 (Popup Display Current Clipboard)
