# US-155: Multi-Select Paste

As a developer,
I want to select multiple entries and paste them concatenated,
so that I can combine related clipboard items in one action.

## Scenario: Select multiple entries
Given the history panel is open
When the user holds Shift and presses arrow keys
Then multiple entries should be selected
And the selection count should be displayed

## Scenario: Paste multiple entries
Given multiple entries are selected
When the user presses Enter or pastes
Then all selected entries should be concatenated
And the combined content should be pasted

## Scenario: Configure separator
Given multi-select paste is used
When the user configures a separator (newline, comma, custom)
Then entries should be joined with the separator
And the separator preference should persist

## Scenario: Multi-select with different types
Given entries of different types are selected (text, image)
When pasting
Then only text entries should be concatenated
And non-text entries should be skipped with a warning

## Scenario: Copy multiple to clipboard
Given multiple entries are selected
When the user chooses "Copy Selected"
Then the concatenated content should be copied to clipboard
And it should appear as a new entry

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Large content combination, type handling
- **Dependencies**: US-004 (View Clipboard History), US-006 (Paste Selected History Item)
