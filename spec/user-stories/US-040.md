# US-040: Log clipboard access by other applications

As a knowledge-worker,
I want to see log entries when other applications access the clipboard,
so that I can identify which apps are reading my clipboard content.

## Scenario: Log clipboard read access
Given another application reads the system clipboard
When the read operation occurs
Then an access log entry should be created with the timestamp, application name, and content type accessed

## Scenario: View clipboard access log
Given the access log contains entries from clipboard reads
When I navigate to the "Security" or "Audit" section in settings
Then I should see a chronological list of clipboard access events

## Scenario: Filter access log by application
Given the access log contains entries from multiple applications
When I apply a filter to show only a specific application
Then only clipboard access events from that application should be displayed

## Scenario: Configure access logging scope
Given I want to limit the scope of access logging
When I configure logging options to exclude certain applications (e.g., system services)
Then clipboard reads from excluded applications should not be logged

## Scenario: Export access log
Given the access log contains entries
When I click "Export Access Log"
Then a CSV or JSON file should be created with the clipboard access history

## Scenario: Clear access log
Given the access log contains older entries beyond the retention period
When I click "Clear Old Logs"
Then entries older than the configured retention period should be removed

## Notes
- **Persona**: both
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Access detection on macOS is limited by OS privacy controls; logging may impact performance
- **Dependencies**: US-018
