# US-045: High contrast mode support

As a user with visual impairments or visual preferences,
I want the clipboard popup to support macOS high contrast mode,
so that I can use the history popup with better visibility and reduced eye strain.

## Scenario: Popup adapts to system high contrast
Given macOS is configured with "Increase contrast" or high contrast accessibility mode enabled
When the clipboard history popup is opened
Then the popup should use high contrast colors for text, backgrounds, and borders

## Scenario: Popup adapts to reduce transparency option
Given macOS "Reduce transparency" accessibility option is enabled
When the clipboard history popup appears
Then the popup background should be opaque without transparency effects

## Scenario: Distinguish high contrast borders
Given high contrast mode is active
When I view clipboard items in the popup
Then selected items should have a clearly visible border or indicator that stands out against the background

## Scenario: Popup maintains readability with system colors
Given macOS "Differentiate without color" accessibility option is enabled
When I view the popup
Then UI elements should use shapes, borders, or indicators beyond just color differences

## Scenario: Settings UI respects high contrast
Given high contrast mode is enabled
When I open the settings window
Then the settings UI should use high contrast colors and reduced transparency

## Scenario: Popup updates for contrast changes
Given the clipboard history popup is open
When I toggle high contrast mode in macOS settings
Then the popup should immediately update its appearance to match (if still open)

## Notes
- **Persona**: knowledge-worker (with visual accessibility needs)
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Custom UI elements may need explicit high contrast variants
- **Dependencies**: None
