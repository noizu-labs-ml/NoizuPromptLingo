# US-043: VoiceOver support for popup menu

As a blind or low-vision user,
I want the clipboard popup menu to be compatible with VoiceOver,
so that I can navigate and use clipboard history without needing to see the screen.

## Scenario: VoiceOver announces popup title
Given VoiceOver is enabled
When I press the clipboard hotkey and the popup appears
Then VoiceOver should announce "Clipboard History" or a similar accessible title

## Scenario: VoiceOver reads clipboard items
Given the clipboard history popup is visible
When I navigate to a clipboard item using arrow keys or VoiceOver navigation
Then VoiceOver should read the content text, date/time, and source application of the item

## Scenario: VoiceOver indicates selected item
Given the clipboard history popup is visible with multiple items
When I navigate to a different item
Then VoiceOver should announce "Selected" when an item becomes focused

## Scenario: VoiceOver for copy confirmation
Given I select a clipboard item to paste
When I confirm the selection
Then VoiceOver should announce "Item copied to clipboard" to confirm the action

## Scenario: VoiceOver for search input
 given the clipboard history popup includes a search field
When I focus the search field
Then VoiceOver should announce it as a text field and allow typing without additional gestures

## Scenario: VoiceOver for menu actions
Given I right-click on a clipboard item or open the item menu
When VoiceOver is active
Then each menu action should have readable labels and VoiceOver should announce the available options

## Notes
- **Persona**: knowledge-worker (with accessibility needs)
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Accessibility must be tested early; SwiftUI components require specific accessibility labels
- **Dependencies**: None
