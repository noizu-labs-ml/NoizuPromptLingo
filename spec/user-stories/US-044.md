# US-044: Dynamic type sizing support

As a user with visual preferences or needs,
I want the clipboard popup UI to respect macOS Dynamic Type settings,
so that I can view clipboard items at a comfortable text size.

## Scenario: Popup adapts to system font size
Given I have increased the macOS Display font size to a larger setting
When I open the clipboard history popup
Then all text elements in the popup should scale to match the system font size setting

## Scenario: Popup adapts to system larger text accessibility
Given I have enabled "Larger Text" in macOS Accessibility settings
When I open the clipboard history popup
Then the text should appear at the specified larger scale while maintaining layout integrity

## Scenario: Popup adapts to smaller system text
Given I have decreased the macOS Display font size to a smaller setting
If larger text was previously selected
When I open the clipboard history popup
Then the text should scale down accordingly

## Scenario: Popup layout handles extreme sizes
Given I have set macOS font size to the maximum accessible size
When I open the clipboard history popup
Then the popup layout should remain usable with appropriate scrolling and without UI elements overlapping

## Scenario: Popup adapts while open
Given the clipboard history popup is open
When I change the macOS Display font size setting
Then the popup should update to reflect the new font size without requiring reopening

## Scenario: Settings UI respects Dynamic Type
Given I open the settings window
When the system font size is set to large or small
Then the settings UI should scale appropriately to remain legible and usable

## Notes
- **Persona**: knowledge-worker (with visual accessibility needs)
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Extreme font sizes may break layout; popup must fit on screen at all sizes
- **Dependencies**: None
