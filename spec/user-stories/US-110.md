# US-110: Long Press Format Picker

As a developer,
I want to hold Cmd+Shift+T Space to open a paste format picker,
so that I can select a custom format before pasting.

## Scenario: Long press opens format picker
Given a clipboard entry is selected
When the user holds Cmd+Shift+T Space for a threshold time (e.g., 200ms)
Then the format picker modal should appear
And the current format should be highlighted

## Scenario: Select format from picker
Given the format picker is open
When the user selects a format and releases the keys
Then the content should be pasted in the selected format

## Scenario: Short press uses default format
Given a clipboard entry is selected
When the user presses Cmd+Shift+T Space briefly
Then the entry should be pasted using the default format
And no picker should appear

## Scenario: Cancel format picker
Given the format picker is open
When the user presses Escape
Then the picker should close without pasting
And the panel should remain open

## Notes
- **Persona**: developer
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Threshold tuning, accidental long-presses
- **Dependencies**: US-108 (Paste Format Options)
