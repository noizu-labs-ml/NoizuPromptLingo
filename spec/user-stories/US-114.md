# US-114: Custom Regex Transform

As a developer,
I want to apply custom regex find/replace patterns at paste time,
so that I can transform clipboard content on-demand.

## Scenario: Create regex transform
Given the user wants to create a custom transform
When they define a regex pattern and replacement string
Then the transform should be saved with a name
And capture groups should be supported in replacement

## Scenario: Apply regex transform
Given a custom regex transform is configured
When the user selects "Paste with Transform: [_transform_name]"
Then the regex should be applied to the clipboard content
And the transformed result should be pasted

## Scenario: Regex transform preview
Given a regex transform is selected
When the transform preview is shown
Then the before/after change should be displayed
And the user can see exactly what will be pasted

## Scenario: Save frequently used transforms
Given the user has created regex transforms
When transforms are saved
Then they should appear in the transform menu
And the user can quickly reuse them

## Scenario: Multi-pass regex transforms
Given complex transformations need multiple regex rules
When configuring a custom transform
Then multiple regex patterns should be supported
And patterns should be applied in sequence

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Regex errors, invalid replacement strings, performance on large content
- **Dependencies**: US-108 (Paste Format Options)
