# US-136: Preferences - Privacy Tab

As a developer,
I want a Privacy preferences tab,
so that I can control what content is captured and stored.

## Scenario: Open Privacy preferences
Given the menu bar dropdown is open
When the user selects Preferences > Privacy
Then the Privacy tab should display

## Scenario: Exclude apps from monitoring
Given Privacy preferences is open
When the user adds apps to the exclusion list
Then clipboard changes from those apps should be ignored
And existing entries from excluded apps should be optional to delete

## Scenario: Auto-redact patterns
Given Privacy preferences is open
When the user defines regex patterns for sensitive data
Then matching content should be redacted before storage
And patterns should support: credit cards, passwords, API keys

## Scenario: Sensitive entry mode
Given Privacy preferences is open
When the user enables "Sensitive Entry Mode"
Then entries marked as sensitive should be excluded from sync
And they should auto-delete after a configurable period

## Scenario: Export/clear history
Given Privacy preferences is open
When the user chooses to export or clear history
Then the action should be confirmed
And clear should be irreversible

## Notes
- **Persona**: both
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Pattern false positives, data loss on clear
- **Dependencies**: US-021 (Exclude specific applications), US-034 (Privacy mode)
