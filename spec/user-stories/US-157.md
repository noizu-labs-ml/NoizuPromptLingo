# US-157: High Contrast Mode

As a user with visual impairments,
I want a high contrast mode for ClipStash,
so that I can see the interface more clearly.

## Scenario: Enable high contrast mode
Given the user opens appearance preferences
When they enable "High Contrast Mode"
Then the UI should switch to high contrast colors
And text and icons should have maximum contrast against backgrounds

## Scenario: Follow system high contrast
Given macOS high contrast is enabled
When ClipStash launches
Then high contrast mode should be automatically enabled
And the setting should track system preferences

## Scenario: High contrast color scheme
Given high contrast mode is active
When viewing any UI element
Then backgrounds should be black or white (no grays)
And text should be pure white on black or pure black on white

## Scenario: High contrast for badges
Given high contrast mode is active
When badges are displayed (usage count, type icons)
Then badges should use high contrast outlines
And colors should be distinguishable

## Notes
- **Persona**: both
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Color scheme maintenance
- **Dependencies**: US-045 (High contrast mode support)
