# US-146: Shortcuts.app Integration

As a developer,
I want ClipStash actions exposed to macOS Shortcuts,
so that I can automate clipboard operations in Shortcuts workflows.

## Scenario: Expose clipboard actions
Given ClipStash is installed
When the user opens Shortcuts.app
Then ClipStash actions should be available in the action library

## Scenario: "Get Clipboard History" action
Given the user creates a Shortcut
When they add the "Get Clipboard History" action
Then they can configure: limit, content type filter, search query
And the action should return entries as output

## Scenario: "Copy to Clipboard" action
Given the user creates a Shortcut
When they add the "Copy to Clipboard" action
Then text input should be added to clipboard history
And the entry should appear in ClipStash

## Scenario: "Paste from History" action
Given the user creates a Shortcut
When they add the "Paste from History" action
Then they can specify an entry ID or search query
And the content should be pasted to the active app

## Scenario: "Invoke Macro" action
Given the user creates a Shortcut
When they add the "Invoke Macro" action
Then they can select a macro and provide variables
And the expanded result should be available as output

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Shortcuts API limitations
- **Dependencies**: US-004 (View Clipboard History), US-074 (Macro Quick Insert Bar)
