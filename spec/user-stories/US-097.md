# US-097: LLM Snippet Output Editing

As a developer,
I want to edit generated LLM output before pasting,
so that I can fix errors or adjust the result without regenerating.

## Scenario: Edit output in preview
Given LLM output is displayed in preview
When the user presses E or clicks "Edit"
Then the output should become editable in a text field
And the original output should be preserved for comparison

## Scenario: Display diff view after edit
Given the user has edited the output
When the edit is complete
Then a diff view should show changes between original and edited output
And the user can review before confirming

## Scenario: Rate both original and edited output
Given the user has edited output
When submitting a rating
Then separate ratings should be recorded for original and edited outputs
And the rating form should indicate which version was rated

## Scenario: Paste edited output
Given the user has edited the output
When the user presses Cmd+Shift+T Space
Then the edited output should be copied to clipboard
And the invocation should be marked with a flag indicating manual editing occurred

## Scenario: Discard edits
Given the user has edited the output in preview
When the user chooses to discard edits
Then the preview should revert to the original LLM output
And no changes should be made

## Notes
- **Persona**: developer
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Losing original output, rating confusion between versions
- **Dependencies**: US-089 (Invoke LLM Snippet), US-090 (Rate LLM Snippet Output)
