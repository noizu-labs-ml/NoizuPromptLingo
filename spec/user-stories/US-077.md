# US-077: LLM-Assisted Macro Variable Fill

As a developer,
I want to press Cmd+Shift+T A to fill macro variables using LLM inference,
so that I can generate intelligent content without manual typing.

## Scenario: Open LLM fill prompt
Given the variable form is open with empty or partially filled variables
When the user presses Cmd+Shift+T A
Then an LLM fill interface should appear with the macro context

## Scenario: Prompt LLM for variable values
Given the LLM fill interface is open
When the user provides a natural language prompt describing their intent
Then the LLM should receive the prompt, macro template, and variable descriptions
And should return structured values for each variable

## Scenario: Populate variables from LLM response
Given the LLM has returned structured output
When the response is received
Then each variable field should be populated with the corresponding value
And the macro preview should update to reflect the filled values

## Scenario: User can edit LLM-filled values
Given variables have been populated by LLM
When the LLM fill completes
Then each variable field should remain editable
And the user can modify values before pasting

## Scenario: LLM fill with existing values as context
Given some variable fields are already filled
When the user invokes LLM fill
Then the LLM should receive existing values as context
And should generate values for unfilled variables

## Notes
- **Persona**: developer
- **T-Shirt Size**: L
- **Complexity**: high
- **Risks**: LLM API latency, rate limits, malformed responses
- **Dependencies**: US-073 (Macro Variable Types), US-075 (Macro Variable Form), US-068 (Semantic Search)
