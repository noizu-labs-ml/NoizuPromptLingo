# US-127: Image Edit and Annotate

As a knowledge worker,
I want to perform basic image editing (crop, annotate) on clipboard images,
so that I can modify screenshots before pasting.

## Scenario: Open image editor
Given an image entry is selected
When the user presses E to edit
Then a basic image editor overlay should appear

## Scenario: Crop image
Given the image editor is open
When the user draws a crop selection and confirms
Then the image should be cropped
And the cropped version should replace the original or create a new entry

## Scenario: Add annotation
Given the image editor is open
When the user adds arrows, boxes, or text annotations
Then the annotations should be rendered on the image
And the annotated image should be saved

## Scenario: Undo/redo in editor
Given edits have been made in the editor
When the user presses Cmd+Z / Cmd+Shift+Z
Then edits should be undone/redone
And edit history should be maintained during the session

## Notes
- **Persona**: both
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Editor complexity, undo stack management
- **Dependencies**: US-119 (Image Type Support), US-104 (Inline Edit Entry)
