# US-074: Macro Quick Insert Bar

As a developer,
I want to press Cmd+Shift+T M to open a macro quick-insert bar,
so that I can quickly select and insert macros without navigating through menus.

## Scenario: Open macro quick-insert bar
Given the application is running
When the user presses Cmd+Shift+T M
Then the macro quick-insert bar should appear
And the input field should be focused

## Scenario: Fuzzy search macros by slug
Given the macro quick-insert bar is open
When the user types a partial macro slug
Then matching macros should be filtered and displayed
And results should include slug, description, and tags

## Scenario: Navigate macro results with keyboard
Given macro search results are displayed
When the user presses arrow keys
Then the selection should move through the results
And the current selection should be highlighted

## Scenario: Select macro with Enter
Given a macro is selected in the quick-insert bar
When the user presses Enter
Then the macro should be selected for expansion
And if no variables need input, paste immediately
And if variables need input, open the variable form

## Scenario: Dismiss macro quick-insert bar
Given the macro quick-insert bar is open
When the user presses Escape
Then the quick-insert bar should close without pasting
And no changes should be made to the clipboard

## Notes
- **Persona**: both
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Fuzzy search performance, hotkey conflicts
- **Dependencies**: US-072 (Macroize Clipboard Entry), US-073 (Macro Variable Types)
