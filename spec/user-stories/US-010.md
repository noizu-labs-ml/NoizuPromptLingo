# US-010: Manually Clear History

As a privacy-conscious user,
I want to clear my clipboard history manually,
so that I can remove sensitive information from the history.

## Scenario: Clear all history
Given the application has clipboard history with multiple items
When the user selects the clear history option
Then all clipboard history items should be deleted

## Scenario: Clear history confirmation
Given the user selects the clear history option
When the application is about to delete all history
Then a confirmation dialog should be displayed

## Scenario: Cancel clear history
Given the clear history confirmation dialog is displayed
When the user cancels the operation
Then the clipboard history should remain unchanged

## Notes
- **Persona**: both
- **T-Shirt Size**: XS
- **Complexity**: low
- **Risks**: Accidental data loss if confirmation is dismissed
- **Dependencies**: US-008
