# US-076: Wrapper Variable Auto-Fill from Selection

As a developer,
I want wrapper-type macro variables to auto-fill with my currently selected text,
so that I can quickly wrap or transform snippets without extra typing.

## Scenario: Auto-fill wrapper variable from selection
Given the user has selected text in an application
When the user invokes a macro with a wrapper variable
Then the wrapper variable should be pre-filled with the selected text
And the macro preview should show the wrapped result

## Scenario: Wrapper variable with no selection falls back to text input
Given the user invokes a macro with a wrapper variable
When no text is currently selected
Then the wrapper variable should show as an empty text input
And the user can manually type the value

## Scenario: Paste wrapped result replaces selection
Given a macro with a wrapper variable has been previewed with selected text
When the user pastes the macro
Then the original selected text should be replaced with the wrapped output
And the cursor should be positioned after the pasted content

## Scenario: Multiple wrapper variables use same selection
Given a macro has multiple wrapper variables
When the user invokes the macro with selected text
Then all wrapper variables should be pre-filled with the same selection
And the template should use the selection in each placeholder

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Getting selection from other applications, handling empty selections
- **Dependencies**: US-073 (Macro Variable Types), US-075 (Macro Variable Form)
