# US-005: Navigate History with Arrow Keys

As a developer,
I want to use arrow keys to navigate through clipboard history,
so that I can select the desired item without using the mouse.

## Scenario: Navigate down through history
Given the clipboard popup is displaying history
When the user presses the down arrow key
Then the selection should move to the next item in the list

## Scenario: Navigate up through history
Given the clipboard popup is displaying history and an item other than the first is selected
When the user presses the up arrow key
Then the selection should move to the previous item in the list

## Scenario: Circular navigation
Given the clipboard popup is displaying history and the last item is selected
When the user presses the down arrow key
Then the selection should wrap around to the first item

## Notes
- **Persona**: both
- **T-Shirt Size**: S
- **Complexity**: medium
- **Risks**: None significant
- **Dependencies**: US-004
