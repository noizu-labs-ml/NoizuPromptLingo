# US-059: Favorites and Pinned Items Management

As a knowledge-worker,
I want to mark frequently-used clipboard items as favorites so they stay at the top of my history,
so that I can quickly access important text, snippets, or links I use repeatedly.

## Scenario: Mark item as favorite
Given the clipboard popup is displaying clipboard history
When the user presses the favorite shortcut (Cmd+F) or clicks the star icon on an item
Then the item should appear in a dedicated favorites section at the top of the list
And a star icon should appear next to the item

## Scenario: Unmark item as favorite
Given an item is marked as a favorite
When the user presses the favorite shortcut again or clicks the filled star icon
Then the item should be removed from favorites
And return to its normal chronological position in the history list

## Scenario: Favorites persist across sessions
Given the user has marked several clipboard items as favorites
When the application quits and relaunches
Then all favorites should be preserved and displayed at the top of the clipboard history

## Scenario: Favorites section with visual separation
Given the clipboard popup contains both favorites and regular history
When the popup is displayed
Then favorites should appear in a visually distinct section at the top
And a collapsible header should show the favorites section with count

## Scenario: Multiple items can be favorites
Given the clipboard contains many items
When the user marks multiple items as favorites
Then all favorites should appear in the favorites section sorted by most-recently-favorited
And the favorites count should accurately reflect the total

## Scenario: Limit on maximum favorites
Given the user attempts to add more than 50 favorites
When the user tries to mark the 51st item as a favorite
Then a prompt should appear showing "Maximum of 50 favorites reached"
And suggest removing an existing favorite to add the new one

## Scenario: Quick access favorites from menu bar
Given the user has marked items as favorites
When the user control-clicks or right-clicks the menu bar icon
Then a contextual menu should show the top 5 most recently used favorites as quick actions

## Scenario: Favorites sync across devices (future)
Given sync is configured and the user has favorites on one device
When a new clipboard item is marked as favorite on device A
Then the favorite status should sync to device B within 30 seconds

## Notes
- **Persona**: knowledge-worker
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Performance impact when favorites span many items; database schema changes needed; UI layout complexity with favorites section
- **Dependencies**: US-004 (clipboard history display), US-011 (keyboard selection), US-054 (local storage schema)
