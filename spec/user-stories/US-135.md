# US-135: Preferences - Sync Tab

As a developer,
I want a Sync preferences tab,
so that I can configure cross-device synchronization.

## Scenario: Open Sync preferences
Given the menu bar dropdown is open
When the user selects Preferences > Sync
Then the Sync tab should display

## Scenario: Configure sync server
Given Sync preferences is open
When the user enters the sync server URL
Then the connection should be tested
And sync should be initialized

## Scenario: Selective sync rules
Given Sync preferences is open
When the user configures which content types to sync
Then only selected types should be synchronized
And excluded types should remain local-only

## Scenario: Device management
Given Sync preferences is open
When viewing connected devices
Then a list of devices should be displayed
And devices can be removed or renamed

## Scenario: Encryption key management
Given Sync preferences is open
When the user views encryption settings
Then options to export/import keys should be available
And key rotation should be supported

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Key management complexity
- **Dependencies**: US-022 (Sync target configuration), US-025 (Encryption key setup)
