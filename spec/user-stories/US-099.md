# US-099: LLM Snippet Import and Export

As a developer,
I want to export snippets to share with others and import snippets from community libraries,
so that I can benefit from shared prompt engineering knowledge.

## Scenario: Export single snippet to file
Given a snippet is selected
When the user chooses to export
Then the snippet should be saved as JSON including: slug, name, description, system_prompt, variables, versions, tags

## Scenario: Export snippet with version history
Given a snippet has multiple versions
When exporting with history
Then all versions should be included in the export file
And invocation metadata should optionally be included

## Scenario: Import snippet from file
Given the user has a snippet export file
When they import the file
Then the snippet should be added to their library
And ID conflicts should be resolved with a rename prompt

## Scenario: Import from community library
Given a web-based snippet library is configured
When the user searches community snippets
Then results should display: name, description, author, rating, download count
And the user can preview before importing

## Scenario: Validate imported snippet format
Given an imported file is malformed
When the import process detects invalid JSON
Then an error should be displayed
And no changes should be made to the library

## Scenario: Bulk import multiple snippets
Given the user has multiple snippet files
When bulk importing
Then all valid snippets should be added
And invalid files should be reported separately

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: low
- **Risks**: Malicious imports, version conflicts, community content quality
- **Dependencies**: US-087 (Create LLM Snippet), US-096 (LLM Snippet Tags and Organization)
