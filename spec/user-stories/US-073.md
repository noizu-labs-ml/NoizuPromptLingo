# US-073: Macro Variable Types

As a developer,
I want to define different types of macro variables (text, wrapper, choice, number, date, llm, llm_transform),
so that macro behavior can be adapted to different use cases.

## Scenario: Create text variable
Given the user is defining a macro variable
When the variable type is set to "text"
Then the user should be able to enter free-form text at paste time

## Scenario: Create wrapper variable
Given the user is defining a macro variable
When the variable type is set to "wrapper"
Then the variable should auto-fill with currently selected text when macro is invoked
And should fallback to text input if nothing is selected

## Scenario: Create choice variable
Given the user is defining a macro variable
When the variable type is set to "choice"
Then the user should be able to define predefined options
And a dropdown should appear with those options at paste time

## Scenario: Create number variable
Given the user is defining a macro variable
When the variable type is set to "number"
Then the user should be able to enter numeric values with optional min/max constraints

## Scenario: Create date variable
Given the user is defining a macro variable
When the variable type is set to "date"
Then a date picker should appear at paste time
And the date should be formatted according to the macro's format string

## Scenario: Create llm variable
Given the user is defining a macro variable
When the variable type is set to "llm"
Then the field value should be generated by LLM inference
And the user should define a prompt for generation

## Scenario: Create llm_transform variable
Given the user is defining a macro variable
When the variable type is set to "llm_transform"
Then selected text should be passed through an LLM with a system prompt
And the transformed output should be inserted into the template

## Notes
- **Persona**: developer
- **T-Shirt Size**: L
- **Complexity**: high
- **Risks**: Validating input for each type, LLM integration latency
- **Dependencies**: US-072 (Macroize Clipboard Entry)
