# US-034: Privacy mode (disable history temporarily)

As a knowledge-worker,
I want to temporarily disable clipboard history recording,
so that sensitive information I copy is not saved without changing app settings.

## Scenario: Toggle privacy mode on
Given Smart Clipboard is running and recording is enabled
When I click the menu bar icon and select "Privacy Mode" or press a configurable hotkey
Then clipboard history recording should be immediately paused and a visual indicator should appear in the menu bar

## Scenario: Copy during privacy mode
Given privacy mode is enabled
When I copy something to the clipboard
Then the clipboard content should not be saved to the history

## Scenario: Toggle privacy mode off
Given privacy mode is enabled
When I click the menu bar icon again and deselect "Privacy Mode" or press the hotkey
Then clipboard history recording should resume and existing history should be accessible

## Scenario: Privacy mode persists across app restarts
Given privacy mode is enabled and I quit the application
When I relaunch Smart Clipboard
Then privacy mode should still be active and recording should remain disabled

## Scenario: Privacy mode indicator in popup
Given privacy mode is enabled
When I press the clipboard hotkey
Then the popup should show a message indicating "Privacy mode is active - history is not being recorded"

## Notes
- **Persona**: knowledge-worker
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: User may forget to re-enable; need clear indicators
- **Dependencies**: US-018
