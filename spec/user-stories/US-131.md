# US-131: Preferences - General Tab

As a developer,
I want a General preferences tab,
so that I can configure basic application settings.

## Scenario: Open General preferences
Given the menu bar dropdown is open
When the user selects Preferences > General
Then the General tab should display

## Scenario: Configure launch at login
Given General preferences is open
When the user toggles "Launch at Login"
Then the setting should be saved
And the LaunchAgent should be registered/unregistered

## Scenario: Set menu bar icon style
Given General preferences is open
When the user selects an icon style (monochrome, colored)
Then the menu bar icon should update immediately

## Scenario: Configure max history size
Given General preferences is open
When the user sets the maximum history entries
Then the limit should be applied to future captures
And existing entries beyond the limit should be pruned

## Scenario: Auto-cleanup rules
Given General preferences is open
When the user configures cleanup rules (e.g., delete after 30 days)
Then the rules should be saved
And cleanup should run according to schedule

## Notes
- **Persona**: both
- **T-Shirt Size**: M
- **Complexity**: low
- **Risks**: Preference persistence
- **Dependencies**: US-020 (Auto-start on login), US-009 (Configure Maximum History Size)
