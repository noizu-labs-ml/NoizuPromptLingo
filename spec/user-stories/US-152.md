# US-152: Clipboard Chains

As a developer,
I want to activate a "clipboard chain" mode where successive Cmd+V pastes a sequence of entries,
so that I can paste multiple related items in order.

## Scenario: Activate clipboard chain
Given the history panel is open with entries selected
When the user presses Cmd+Shift+T C
Then clipboard chain mode should be activated
And the selected entries should form the chain in order

## Scenario: Chain indicator
Given chain mode is active
When viewing the menu bar or panel
Then a chain indicator should show remaining items
And the next item to paste should be previewed

## Scenario: Paste next in chain
Given chain mode is active with N items
When the user presses Cmd+V
Then the next item in the chain should be pasted
And the chain position should advance

## Scenario: Complete chain
Given chain mode is active
When all items have been pasted
Then chain mode should automatically deactivate
And a completion notification should appear

## Scenario: Cancel chain
Given chain mode is active
When the user presses Escape
Then chain mode should be cancelled
And no further chain pastes should occur

## Scenario: Define chain order
Given multiple entries are selected
When activating chain
Then the chain order should follow selection order
And the user should be able to reorder before confirming

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Cmd+V interception, chain state management
- **Dependencies**: US-006 (Paste Selected History Item)
