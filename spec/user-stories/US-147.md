# US-147: AppleScript/JXA Dictionary

As a developer,
I want an AppleScript/JXA dictionary for ClipStash,
so that I can automate clipboard operations from scripts.

## Scenario: AppleScript clipboard commands
Given ClipStash is installed
When the user writes AppleScript
Then commands should be available: get history, search, copy, add

## Scenario: Get history via AppleScript
Given AppleScript is running
When the user executes `tell application "ClipStash" to get history`
Then clipboard entries should be returned as a list
And each entry should have properties: id, content, timestamp, type

## Scenario: Search via AppleScript
Given AppleScript is running
When the user executes `tell application "ClipStash" to search "query"`
Then matching entries should be returned

## Scenario: Add entry via AppleScript
Given AppleScript is running
When the user executes `tell application "ClipStash" to add "text"`
Then the text should be added to clipboard history

## Scenario: JXA (JavaScript for Automation) support
Given JXA is running
When the user accesses ClipStash via JXA
Then the same commands should be available
And the API should be idiomatic for JavaScript

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: AppleScript syntax complexity, JXA compatibility
- **Dependencies**: US-004 (View Clipboard History)
