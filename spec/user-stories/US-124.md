# US-124: Image Vector Embeddings

As a developer,
I want to generate CLIP vector embeddings for images,
so that I can search for visually similar images.

## Scenario: Generate CLIP embedding on capture
Given an image is captured
When the entry is created
Then a CLIP embedding should be generated asynchronously
And the vector should be stored in the vector index

## Scenario: Visual similarity search
Given images with embeddings exist
When the user selects an image and chooses "Find Similar"
Then visually similar images should be returned
And results should be ranked by cosine similarity

## Scenario: Text-to-image search
Given images with embeddings exist
When the user performs semantic search with text query
Then the CLIP text encoder should find matching images
And images semantically related to the query should appear

## Scenario: Embedding model selection
Given multiple embedding models are available
When configuring preferences
Then the user should be able to select the CLIP model variant
And re-indexing should be available when model changes

## Notes
- **Persona**: developer
- **T-Shirt Size**: XL
- **Complexity**: high
- **Risks**: Embedding computation time, storage for vectors, model size
- **Dependencies**: US-119 (Image Type Support), US-068 (Semantic Search)
