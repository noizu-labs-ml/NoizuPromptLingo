# US-128: Image Size Limit and Compression

As a developer,
I want large images to be automatically compressed or excluded,
so that clipboard history storage doesn't grow unbounded.

## Scenario: Compress large images on capture
Given an image larger than the size threshold is copied
When the entry is created
Then the image should be compressed to fit within limits
And the original should optionally be preserved

## Scenario: Configure max image size
Given the user opens storage preferences
When they set a max image size
Then images exceeding this size should be compressed or rejected
And a warning should be logged for rejected images

## Scenario: Exclude very large images
Given an image exceeds the maximum allowed size
When captured
Then the entry should store a placeholder with metadata
And the full image should not be stored

## Scenario: Image quality setting
Given images are being compressed
When the quality setting is configured
Then JPEG/WebP compression should use the specified quality level
And a balance between size and quality should be maintained

## Notes
- **Persona**: both
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Quality loss, storage calculation
- **Dependencies**: US-119 (Image Type Support)
