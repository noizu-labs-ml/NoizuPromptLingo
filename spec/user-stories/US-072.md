# US-072: Macroize Clipboard Entry

As a developer,
I want to convert any clipboard entry into a macro with a short slug and template,
so that I can reuse the content pattern with variable parts.

## Scenario: Create macro from selected entry
Given a clipboard entry is highlighted in the history panel
When the user creates a new macro by pressing M
Then a macro creation form should appear with the entry content pre-populated

## Scenario: Set macro slug
Given the macro creation form is open
When the user enters a short slug (e.g., "hc", "dbconn", "sig")
Then the slug should be saved as the identifier for the macro

## Scenario: Define template with variables
Given the macro creation form is open
When the user adds variable placeholders in the format {{variable_name}}
Then those placeholders should become editable macro variables

## Scenario: Save macro successfully
Given the user has defined a macro slug and template with variables
When the user saves the macro
Then the macro should be stored in the database with all defined variables
And the original entry should linked to the macro

## Notes
- **Persona**: both
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Slug conflicts, variable parsing errors, template validation
- **Dependencies**: US-004 (View Clipboard History)
