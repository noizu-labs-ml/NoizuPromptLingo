# US-018: Configuration UI for settings

As a developer,
I want to access a dedicated settings interface,
so that I can customize the application behavior to match my workflow.

## Scenario: Open settings interface
Given the Smart Clipboard application is running and the menu bar icon is visible
When I click on the menu bar icon and select "Settings" (or use Cmd+,)
Then a settings window should appear with a sidebar listing all configuration categories

## Scenario: Navigate between settings sections
Given the settings window is open and showing the General section
When I click on different category names in the sidebar
Then the main panel should display the options for that category without closing the window

## Scenario: Save settings changes
Given the settings window is open and I have modified one or more preferences
When I click "Save" or navigate away from the current section
Then the modified settings should be persisted to the application preferences and take effect immediately

## Notes
- **Persona**: both
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Settings changes may require app restart in some cases; needs clear feedback
- **Dependencies**: None
