# US-130: Menu Bar Sync Status

As a developer,
I want to see sync status in the menu bar,
so that I know if my clipboard is synchronized across devices.

## Scenario: Display sync status indicator
Given sync is configured
When viewing the menu bar
Then a status indicator should show: ✓ Synced, ⟳ Syncing, or ⚠ Sync Error

## Scenario: Sync status detail
Given the menu bar dropdown is open
When viewing the Sync section
Then it should show: last sync time, pending items count, connected devices

## Scenario: Sync error notification
Given a sync error occurs
When the user next opens the menu bar
Then the icon should show a warning badge
And the Sync section should display the error message

## Scenario: Force sync from menu bar
Given the menu bar dropdown is open
When the user clicks "Sync Now"
Then a manual sync should be triggered
And the status should update to "Syncing..."

## Notes
- **Persona**: both
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Status refresh timing
- **Dependencies**: US-023 (Display sync status in UI)
