# US-094: Regression Alerts for LLM Snippets

As a developer,
I want to be notified when a new snippet version scores significantly worse,
so that I can quickly catch and revert prompt regressions.

## Scenario: Automatic regression detection
Given a new snippet version receives ratings
When the average score drops below the previous version by a threshold (e.g., 0.5 points)
Then a regression alert should be triggered
And the alert should be displayed in the snippet details

## Scenario: Regression alert display
Given a regression has been detected
When viewing snippet details
Then a warning badge should appear next to the affected version
And the alert message should show the score difference

## Scenario: Regression dashboard summary
Given multiple snippets may have regressions
When viewing the overall LLM Snippet Library
Then a "Regressions" section should list snippets with detected issues
And the user can quickly identify problem prompts

## Scenario: Configure regression threshold
Given the user wants to adjust sensitivity
When in LLM snippet preferences
Then the regression threshold should be configurable (e.g., 0.3, 0.5, 1.0 point drop)
And minimum sample count before alerting should also be settable

## Scenario: Dismiss regression alert
Given a regression alert is displayed
When the user acknowledges or dismisses the alert
Then the alert badge should be removed
But the version history should preserve a note about the regression

## Scenario: Compare regression candidates
Given a regression is detected
When the user selects the regression alert
Then a comparison view should show the new vs old version performance
And the user can quickly see which prompts changed

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: False positives, alert fatigue, statistical insignificance with few samples
- **Dependencies**: US-091 (LLM Snippet Version History), US-093 (Eval Framework)
