# US-153: Expiring Entries

As a developer,
I want clipboard entries to auto-delete after a configurable time,
so that sensitive content doesn't persist in history.

## Scenario: Mark entry as expiring
Given an entry is selected
When the user sets an expiry time (e.g., 5 minutes, 1 hour)
Then the entry should be marked with an expiry timestamp
And a countdown should be visible

## Scenario: Auto-delete expired entry
Given an entry has an expiry time
When the current time passes the expiry
Then the entry should be automatically deleted
And the deletion should be logged

## Scenario: Per-app expiry rules
Given the user configures app-specific expiry
When content is copied from a configured app (e.g., 1Password)
Then entries from that app should auto-expire after the configured time

## Scenario: Visual indicator for expiring entries
Given an entry will expire soon
When viewing the history list
Then a visual indicator (clock icon, countdown) should show remaining time
And the indicator should update in real-time

## Scenario: Prevent paste of expired entry
Given an entry has expired but not yet deleted
When the user tries to paste it
Then an error should indicate the entry has expired
And the entry should be deleted immediately

## Notes
- **Persona**: both
- **T-Shirt Size**: M
- **Complexity**: low
- **Risks**: Timer accuracy, deletion race conditions
- **Dependencies**: US-017 (Delete Single History Item)
