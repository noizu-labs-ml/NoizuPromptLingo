# US-150: Export Formats (CSV, JSON, Archive)

As a developer,
I want to export clipboard history in multiple formats,
so that I can backup or analyze my clipboard data.

## Scenario: Export as JSON
Given clipboard history exists
When the user selects "Export as JSON"
Then all entries should be exported as a JSON array
And the format should match the import format

## Scenario: Export as CSV
Given clipboard history exists
When the user selects "Export as CSV"
Then entries should be exported as CSV with columns: id, content, timestamp, type, source_app
And the CSV should be UTF-8 encoded

## Scenario: Export as ClipStash Archive (.csa)
Given clipboard history exists
When the user selects "Export Archive"
Then a .csa file should be created
And the archive should include: entries, macros, snippets, settings
And the archive should be importable on another machine

## Scenario: Selective export
Given the user wants to export subset
When they select entries and choose "Export Selected"
Then only selected entries should be included
And format options should be available

## Scenario: Encrypted export
Given sensitive data exists
When the user exports with encryption
Then the export should be password-protected
And AES-256 encryption should be used

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: low
- **Risks**: Large export files, encryption key management
- **Dependencies**: US-036 (Export clipboard history as JSON)
