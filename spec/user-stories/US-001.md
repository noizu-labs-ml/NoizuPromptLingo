# US-001: Global Hotkey Activation

As a developer,
I want to press Cmd+Shift+T to open the clipboard manager,
so that I can quickly access my clipboard history without breaking my workflow.

## Scenario: User presses global hotkey
Given the application is running in the background
When the user presses Cmd+Shift+T
Then a clipboard popup window should appear

## Scenario: User presses global hotkey when already open
Given the clipboard popup window is already visible
When the user presses Cmd+Shift+T
Then the popup should be dismissed

## Notes
- **Persona**: both
- **T-Shirt Size**: S
- **Complexity**: medium
- **Risks**: Conflicts with other apps using same hotkey, macOS permissions
- **Dependencies**: US-000 (background process setup)
