# US-140: Target App Tracking on Paste

As a developer,
I want to track where clipboard entries are pasted,
so that I can understand usage patterns and improve suggestions.

## Scenario: Track paste target app
Given an entry is pasted
When the paste completes
Then the target app name should be recorded
And the entry's usage history should be updated

## Scenario: Track paste target document
Given an entry is pasted
When the target document can be detected
Then the document name or URL should be recorded
And this should inform future suggestions

## Scenario: Display paste targets in entry detail
Given an entry has been pasted multiple times
When viewing entry details
Then a list of paste targets should be displayed
And targets should show: app name, document, timestamp

## Scenario: App affinity for suggestions
Given an entry has been pasted to a specific app frequently
When the suggestion algorithm runs
Then entries with high affinity to the current app should rank higher

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Document detection accuracy, privacy concerns
- **Dependencies**: US-069 (Context-Aware Suggestions)
