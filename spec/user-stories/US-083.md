# US-083: Edit Existing Macro

As a developer,
I want to edit an existing macro's template and variables,
so that I can update and improve my macros over time.

## Scenario: Open macro editor
Given a macro is selected in the macro list
When the user presses E on the macro
Then the macro creation form should open with the macro's existing values populated

## Scenario: Update macro template
Given the macro editor is open
When the user modifies the template content
Then the changes should be preserved when saving
And existing variables in the template should be preserved

## Scenario: Add new variable to existing macro
Given the macro editor is open
When the user adds a new variable placeholder to the template
Then a variable definition should be created
And the user should configure the variable type and description

## Scenario: Remove variable from macro
Given the macro editor is open with existing variables
When the user removes a variable placeholder from the template
Then that variable should be removed from the macro definition
And the template should be updated

## Scenario: Macro edit preserves macroized entries
Given a macro already has generated entries in the history
When the macro is edited and saved
Then existing generated entries should remain linked to the macro
And new expansions should use the updated template

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: low
- **Risks**: Breaking existing references, variable validation after edit
- **Dependencies**: US-072 (Macroize Clipboard Entry)
