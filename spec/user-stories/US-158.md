# US-158: Reduced Motion and Animation Control

As a user sensitive to motion,
I want to reduce or disable animations in ClipStash,
so that the interface doesn't cause discomfort.

## Scenario: Enable reduced motion
Given the user opens appearance preferences
When they enable "Reduce Motion"
Then all animations should be replaced with instant transitions
And fade effects should be removed

## Scenario: Follow system reduce motion
Given macOS "Reduce Motion" is enabled
When ClipStash launches
Then reduced motion mode should be automatically enabled
And the setting should track system preferences

## Scenario: Configurable animation speed
Given the user wants some animation but slower
When they adjust the animation speed slider
Then animations should play at the selected speed
And instant mode should be available as an option

## Scenario: Panel open animation
Given reduced motion is enabled
When the panel opens
Then it should appear instantly without slide/fade
And focus should immediately move to the first entry

## Notes
- **Persona**: both
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: None
- **Dependencies**: US-046 (Reduced motion animation option)
