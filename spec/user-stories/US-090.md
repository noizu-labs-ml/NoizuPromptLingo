# US-090: Rate LLM Snippet Output

As a developer,
I want to rate the quality of generated snippet outputs (1-5 stars),
so that I can track which prompts work best and improve them over time.

## Scenario: Display rating prompt after generation
Given an LLM snippet has just generated output
When the output preview is displayed
Then a rating prompt should appear below the output
And the user should be invited to rate 1-5 stars

## Scenario: Submit star rating
Given the rating prompt is displayed
When the user clicks a star rating
Then the rating should be submitted to the database
And it should be associated with: snippet_id, version_number, invocation_timestamp

## Scenario: Optional notes with rating
Given the user is submitting a rating
When a notes field is available
Then the user can optionally add free-form feedback
And the notes should be saved with the rating record

## Scenario: Skip rating option
Given the rating prompt is displayed
When the user chooses to skip or closes the panel
Then the invocation should still be logged with a null rating
And the output should still be available for pasting

## Scenario: Average score calculation
Given a snippet has multiple rated invocations
When viewing the snippet details
Then an average score should be displayed (e.g., "avg: 4.2/5")
And the score should update in real-time as new ratings are submitted

## Scenario: Rating aggregation per version
Given a snippet has multiple versions with different prompts
When viewing version analytics
Then each version should show its own average score
And the current version's score should be highlighted

## Notes
- **Persona**: developer
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: User rating fatigue, misleading averages with few ratings
- **Dependencies**: US-089 (Invoke LLM Snippet)
