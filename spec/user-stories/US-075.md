# US-075: Macro Variable Form with Live Preview

As a developer,
I want to see a live preview of macro output as I fill in variable fields,
so that I know exactly what will be pasted before committing.

## Scenario: Open variable form for macro with variables
Given a macro with variables has been selected
When the macro requires user input for variables
Then a variable form should appear with all variable fields

## Scenario: Display variable information
Given the variable form is open
When a variable field is displayed
Then it should show the variable name, type, and description
And text fields should show default values if defined

## Scenario: Update live preview as user types
Given the variable form is open
When the user types into a variable field
Then the macro preview should update in real-time
And the preview should show the fully expanded template

## Scenario: Show preview of expanded macro
Given all variable fields are filled or have defaults
When the variable form is displayed
Then a preview section should show the final output
And the preview should reflect current field values

## Scenario: Paste from variable form
Given the user is satisfied with the macro preview
When the user presses Cmd+Shift+T Space
Then the expanded macro should be copied to the clipboard
And the panel should close

## Notes
- **Persona**: both
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Preview update performance on complex templates
- **Dependencies**: US-073 (Macro Variable Types), US-074 (Macro Quick Insert Bar)
