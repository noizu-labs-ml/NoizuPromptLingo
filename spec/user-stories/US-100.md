# US-100: Focus Search Bar with Hotkey

As a developer,
I want to press Cmd+Shift+T F to focus the search bar when the history panel is open,
so that I can quickly search without reaching for the mouse.

## Scenario: Focus search bar in history panel
Given the history panel is open
When the user presses Cmd+Shift+T F
Then the search bar input should receive keyboard focus
And any existing search query should be selected for editing

## Scenario: Focus search bar in macro bar
Given the macro quick-insert bar is open
When the user presses Cmd+Shift+T F
Then the search input should receive focus
And the user can immediately type to filter macros

## Scenario: Focus search bar in LLM library
Given the LLM Snippet Library is open
When the user presses Cmd+Shift+T F
Then the snippet search input should receive focus

## Scenario: Search bar already focused
Given the search bar already has keyboard focus
When the user presses Cmd+Shift+T F
Then the existing behavior should be maintained (select all text)

## Notes
- **Persona**: both
- **T-Shirt Size**: XS
- **Complexity**: low
- **Risks**: Hotkey conflict, focus state management
- **Dependencies**: US-001 (Global Hotkey Activation)
