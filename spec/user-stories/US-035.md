# US-035: Password protection for app access

As a knowledge-worker,
I want to password-protect access to my clipboard history,
so that unauthorized users cannot view my clipboard content even on my device.

## Scenario: Enable password protection
Given the settings window is open in the "Security" section
When I enable "Require password to access history" and set a password
Then the password should be stored in the macOS Keychain and protection should be active

## Scenario: Prompt for password on access
Given password protection is enabled
When I press the global hotkey to access clipboard history
Then a password prompt should appear and the history should not be displayed until the correct password is entered

## Scenario: Remember password for session
Given password protection is enabled and "Remember password for this session" is checked
When I enter the correct password
Then I should not be prompted again until the app is quit and relaunched or a configurable timeout period elapses

## Scenario: Disable password protection
Given password protection is enabled
When I disable "Require password to access history"
Then I should be prompted to enter the current password for confirmation, and upon success the protection should be removed

## Scenario: Limit password attempts
Given password protection is enabled and I am prompted for my password
When I enter an incorrect password
Then I should see an error message and after 3 failed attempts a cooldown period should be enforced

## Notes
- **Persona**: knowledge-worker
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Password management must be secure; user may lock themselves out
- **Dependencies**: US-018
