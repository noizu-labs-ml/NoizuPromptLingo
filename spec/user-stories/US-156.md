# US-156: VoiceOver Accessibility Support

As a visually impaired user,
I want full VoiceOver support for ClipStash,
so that I can use the application without sighted assistance.

## Scenario: VoiceOver announces panel open
Given VoiceOver is enabled
When the clipboard panel opens
Then VoiceOver should announce "Clipboard history panel, N entries"
And focus should move to the first entry

## Scenario: VoiceOver announces entry content
Given VoiceOver is enabled and an entry is selected
When the user navigates to an entry
Then VoiceOver should announce: content preview, timestamp, type
And additional details should be available via VO keys

## Scenario: VoiceOver navigation
Given VoiceOver is enabled
When the user navigates with VoiceOver commands
Then all interactive elements should be accessible
And the navigation order should be logical

## Scenario: VoiceOver for actions
Given VoiceOver is enabled and an entry is selected
When the user invokes the actions rotor
Then actions should include: Paste, Delete, Tag, Favorite, Macroize
And activating an action should work as expected

## Scenario: VoiceOver for search
Given VoiceOver is enabled
When the user focuses the search field
Then VoiceOver should announce "Search clipboard history"
And search results should be announced as they update

## Notes
- **Persona**: both
- **T-Shirt Size**: L
- **Complexity**: medium
- **Risks**: Accessibility compliance, VoiceOver API changes
- **Dependencies**: US-043 (VoiceOver support for popup menu)
