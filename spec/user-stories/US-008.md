# US-008: Clipboard History Persistence

As a developer,
I want my clipboard history to be saved and restored after app restarts,
so that I don't lose my copy history when I restart my Mac.

## Scenario: Save history on app exit
Given the application is running and has collected clipboard history
When the application is terminated (quit or crash)
Then the clipboard history should be saved to storage

## Scenario: Restore history on app launch
Given the application has previously saved clipboard history
When the application starts up
Then the saved clipboard history should be loaded and available

## Scenario: History remains after system restart
Given the application has saved clipboard history
When the operating system is restarted and the application launches
Then the saved clipboard history should be available

## Notes
- **Persona**: both
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Data corruption during writes, performance with large history
- **Dependencies**: US-004, US-061 (SQLite storage setup)
