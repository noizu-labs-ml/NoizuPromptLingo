# US-143: Menu Bar Analytics Summary

As a developer,
I want to see clipboard statistics in the menu bar,
so that I can understand my productivity at a glance.

## Scenario: Display weekly stats
Given the menu bar dropdown is open
When viewing the Stats section
Then it should show: "X items pasted this week, saving ~Y hours"

## Scenario: Calculate time saved
Given entries have been pasted
When calculating time saved
Then each paste should contribute estimated seconds saved
And the total should be displayed as human-readable time

## Scenario: Display storage stats
Given the menu bar dropdown is open
When viewing the Stats section
Then it should show: "X entries (Y MB)"

## Scenario: Display today's activity
Given the menu bar dropdown is open
When viewing the Stats section
Then it should show: "Today: X copies, Y pastes"

## Scenario: Analytics breakdown
Given the user wants detailed analytics
When they click "View Full Stats"
Then a detailed analytics panel should open
And it should show: top apps, top entries, usage trends

## Notes
- **Persona**: both
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Time saved estimation accuracy
- **Dependencies**: US-129 (Menu Bar Dropdown), US-070 (Usage Statistics Dashboard)
