# US-126: Image-to-Image Transformation

As a developer,
I want to transform images using LLM (image-to-image diffusion),
so that I can modify images via AI without leaving my clipboard workflow.

## Scenario: Create image-to-image macro
Given the user creates a macro with a wrapper variable
When the variable type is "image" and transform is set to "diffusion"
Then selected images should be processed through the model

## Scenario: Transform selected image
Given an image is selected in another app
When the user invokes an image-to-image macro
Then the selected image should be transformed
And the result should appear in preview

## Scenario: Style transfer transformation
Given a style transfer macro is configured
When the user applies it to an image
Then the image should be transformed to match the target style
And the user can adjust style strength

## Scenario: Image enhancement (upscaling, denoising)
Given an image enhancement macro is configured
When applied to a low-quality image
Then the enhanced result should be generated
And before/after comparison should be available

## Notes
- **Persona**: developer
- **T-Shirt Size**: L
- **Complexity**: high
- **Risks**: API costs, processing time, quality consistency
- **Dependencies**: US-076 (Wrapper Variable Auto-Fill), US-125 (Text-to-Image Generation)
