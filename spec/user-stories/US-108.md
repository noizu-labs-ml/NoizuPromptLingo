# US-108: Paste Format Options

As a developer,
I want to paste clipboard content in different formats (plain text, Markdown, HTML, RTF, code block, JSON, URL-encoded, Base64),
so that I can adapt clipboard content to the target application's requirements.

## Scenario: Paste as plain text
Given a rich-text clipboard entry is selected
When the user chooses "Paste as Plain Text"
Then all formatting should be stripped
And only the text content should be pasted

## Scenario: Paste as Markdown
Given an HTML clipboard entry is selected
When the user chooses "Paste as Markdown"
Then the HTML should be converted to Markdown format
And the markdown should be pasted

## Scenario: Paste as HTML
Given a plain-text clipboard entry is selected
When the user chooses "Paste as HTML"
Then the text should be wrapped in HTML paragraphs
And the HTML should be pasted

## Scenario: Paste as Rich Text (RTF)
Given content should retain formatting
When the user chooses "Paste as RTF"
Then the original RTF formatting should be preserved
And the RTF should be pasted

## Scenario: Paste as rendered image (HTML to image)
Given an HTML clipboard entry is selected
When the user chooses "Paste as Rendered Image"
Then the HTML should be rendered as an image
And the image should be pasted

## Scenario: Paste as code block
Given a code snippet clipboard entry is selected
When the user chooses "Paste as Code Block"
Then the content should be wrapped in markdown code block delimiters (```)
And the language should be auto-detected

## Scenario: Paste as JSON
Given a plain-text JSON string is selected
When the user chooses "Paste as JSON (escaped)"
Then the JSON should be properly escaped if needed
And formatted with proper indentation

## Scenario: Paste as URL-encoded
Given a string with special characters is selected
When the user chooses "Paste as URL-encoded"
Then the string should be percent-encoded
And the encoded string should be pasted

## Scenario: Paste as Base64
Given any clipboard content is selected
When the user chooses "Paste as Base64"
Then the content should be Base64-encoded
And the encoded string should be pasted

## Notes
- **Persona**: developer
- **T-Shirt Size**: L
- **Complexity**: medium
- **Risks**: Format conversion quality, detection accuracy
- **Dependencies**: US-006 (Paste Selected History Item)
