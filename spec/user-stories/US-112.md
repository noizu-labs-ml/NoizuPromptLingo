# US-112: RTF to Markdown Conversion

As a knowledge worker,
I want to convert RTF clipboard content to Markdown,
so that I can paste styled text from Word or other rich-text apps into markdown editors.

## Scenario: Convert RTF heading styles
Given RTF content with heading styles (e.g., "Heading 1", "Heading 2")
When converting to Markdown
Then headings should be converted to # and ## markdown syntax
And bold/italic styles within headings should convert to **/* markdown

## Scenario: Convert RTF character formatting
Given RTF content contains bold, italic, underline styles
When converting to Markdown
Then bold should become **, italic should become *
And underline should be dropped or converted to &lt;u&gt;

## Scenario: Convert RTF lists
Given RTF content contains ordered or unordered lists
When converting to Markdown
Then bullet lists should become - or * syntax
And numbered lists should become 1., 2., 3. syntax

## Scenario: Preserve RTF links
Given RTF content contains hyperlinks
When converting to Markdown
Then links should convert to [text](url) markdown syntax
And both displayed text and URL should be preserved

## Notes
- **Persona**: knowledge-worker
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: RTF parsing complexity, style mapping accuracy
- **Dependencies**: US-108 (Paste Format Options)
