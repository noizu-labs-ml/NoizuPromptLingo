# US-145: Alfred/Raycast Integration

As a developer,
I want ClipStash integration with launcher apps (Alfred, Raycast),
so that I can access clipboard history from my launcher workflow.

## Scenario: Install Alfred workflow
Given Alfred is installed
When the user installs the ClipStash Alfred workflow
Then clipboard history should be searchable from Alfred

## Scenario: Search history in Alfred
Given the Alfred workflow is installed
When the user invokes Alfred and types the trigger keyword
Then clipboard history should be searchable
And selecting an entry should paste it

## Scenario: Browse macros in Alfred
Given the Alfred workflow is installed
When the user searches macros via Alfred
Then macros should appear with their slugs
And selecting a macro should invoke it

## Scenario: Install Raycast extension
Given Raycast is installed
When the user installs the ClipStash Raycast extension
Then clipboard commands should be available in Raycast

## Scenario: Raycast commands
Given the Raycast extension is installed
When the user invokes ClipStash commands
Then commands should include: Search History, List Macros, Toggle Monitoring

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: API changes in Alfred/Raycast, extension approval
- **Dependencies**: US-004 (View Clipboard History), US-074 (Macro Quick Insert Bar)
