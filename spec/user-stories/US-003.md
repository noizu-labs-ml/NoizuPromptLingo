# US-003: Dismiss Popup with Escape Key

As a developer,
I want to dismiss the clipboard popup by pressing Escape,
so that I can quickly close the popup and return to my work without using the mouse.

## Scenario: Dismiss popup with Escape
Given the clipboard popup window is visible
When the user presses the Escape key
Then the popup should be dismissed and focus should return to the previous application

## Scenario: Escape when no popup is open
Given the clipboard popup window is not visible
When the user presses the Escape key
Then nothing should happen (no action should be triggered)

## Notes
- **Persona**: both
- **T-Shirt Size**: XS
- **Complexity**: low
- **Risks**: None significant
- **Dependencies**: US-001, US-002
