# US-120: Image Thumbnail Generation

As a developer,
I want image clipboard entries to display as thumbnails in the history list,
so that I can visually identify images without loading full-size versions.

## Scenario: Generate thumbnail on capture
Given an image is copied to clipboard
When the clipboard entry is created
Then a thumbnail should be generated at a standard size (e.g., 64x64 px)
And the thumbnail should be stored separately from the full image

## Scenario: Display thumbnail in history list
Given an image entry exists in history
When the history panel displays the entry
Then the thumbnail should be shown in the entry row
And the thumbnail should maintain aspect ratio

## Scenario: Thumbnail for very large images
Given an image larger than 10MB is copied
When generating thumbnail
Then the thumbnail should still be generated efficiently
And memory usage should be bounded

## Scenario: Animated GIF thumbnail
Given an animated GIF is captured
When generating thumbnail
Then the first frame should be used as the thumbnail
And the entry should display a "GIF" badge to indicate animation

## Notes
- **Persona**: both
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Memory usage, thumbnail storage
- **Dependencies**: US-119 (Image Type Support)
