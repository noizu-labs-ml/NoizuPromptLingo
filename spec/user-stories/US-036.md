# US-036: Export clipboard history as JSON

As a developer,
I want to export my clipboard history to a JSON file,
so that I can backup, analyze, or transfer my clipboard data.

## Scenario: Export entire history
Given I have a clipboard history with multiple items
When I click the menu bar icon and select "Export History" and choose a save location
Then a JSON file should be created containing all clipboard items with metadata (timestamp, content, source app)

## Scenario: Export filtered history
Given I have a clipboard history with multiple items
When I apply a filter (e.g., last 7 days, containing specific text) and select "Export Filtered History"
Then only the filtered clipboard items should be included in the exported JSON file

## Scenario: Export with sensitive content optional
Given I have clipboard items that include sensitive content (passwords, credit card numbers)
When I export history with "Exclude passwords and sensitive data" option enabled
Then the JSON file should exclude items flagged as sensitive or redact matching patterns

## Scenario: Validate exported JSON format
Given a JSON export file has been created
When I validate the JSON file structure
Then the file should be valid JSON with a top-level array or object containing clipboard items with standard metadata fields

## Scenario: Export progress indicator
Given I am exporting a large clipboard history
When the export is in progress
Then a progress indicator should show the number of items exported or a percentage complete

## Scenario: Export cancellation
Given an export is in progress
When I click "Cancel Export"
Then the export should be stopped gracefully and no file should be created

## Notes
- **Persona**: developer
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Export may contain sensitive data by default; file may be very large
- **Dependencies**: None
