# US-057: Welcome Wizard and Feature Discovery

As a knowledge-worker,
I want a guided first-run experience that introduces me to the application's key features,
so that I can understand how to use Smart Clipboard effectively without reading documentation.

## Scenario: First launch shows welcome wizard
Given the application is launched for the first time
When the user has no previous configuration data
Then a welcome wizard should appear with an overview of core features and a "Get Started" button

## Scenario: Welcome wizard dismisses after completion
Given the welcome wizard is displayed
When the user completes all wizard steps or clicks "Skip Tutorial"
Then the wizard should dismiss and the main app should launch normally
And a flag should be set to prevent the wizard from showing again

## Scenario: Progressive disclosure in main interface
Given the user has completed the welcome wizard
When the user opens the clipboard popup for the first few times
Then contextual hints and tooltips should highlight key shortcuts (Cmd+Shift+T, arrow keys, Enter)
And these hints should gradually fade out as the user demonstrates familiarity

## Scenario: Re-enable tutorial from settings
Given the user has previously completed the welcome wizard
When the user accesses preferences and selects "Show Welcome Tutorial"
Then the welcome wizard should reappear on next app launch
And existing user configuration should be preserved

## Scenario: Feature highlights in menu bar
Given the app is running and the user is new (first 7 days)
When the user interacts with the menu bar icon
Then a tooltip should suggest "Try Cmd+Shift+T to access your clipboard history"
And this suggestion should stop appearing after the user has used the hotkey 10+ times

## Scenario: Skip option always available
Given the welcome wizard is displayed
When the user clicks a "Skip" or "Not Now" button on any wizard step
Then the wizard should immediately dismiss with the current step remembered
And the user can resume the tutorial later from preferences

## Notes
- **Persona**: knowledge-worker
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Tutorial interruptions may annoy power users; need graceful degradation if tutorial data is missing; ensuring tutorial state persists correctly
- **Dependencies**: US-001 (global hotkey), US-004 (clipboard history display)
