# US-129: Menu Bar Dropdown

As a developer,
I want a menu bar dropdown with quick access to clipboard features,
so that I can access ClipStash without the global hotkey.

## Scenario: Open menu bar dropdown
Given the app is running
When the user clicks the menu bar icon
Then a dropdown menu should appear with sections for: Quick Actions, Stats, Browse, Settings

## Scenario: Quick Actions section
Given the menu bar dropdown is open
When viewing Quick Actions
Then options should include: Open History, Open Macros, Open LLM Snippets, Pause Monitoring

## Scenario: Statistics section
Given the menu bar dropdown is open
When viewing Stats
Then it should display: "Today: X copies, Y pastes" and "Storage: N entries (size MB)"

## Scenario: Browse section
Given the menu bar dropdown is open
When viewing Browse
Then quick links should include: Recent, Favorites, Tags, Macros, LLM Snippets

## Scenario: Dismiss menu bar dropdown
Given the menu bar dropdown is open
When the user clicks outside or presses Escape
Then the dropdown should close

## Notes
- **Persona**: both
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Menu bar space, dropdown positioning
- **Dependencies**: US-020 (Auto-start on login)
