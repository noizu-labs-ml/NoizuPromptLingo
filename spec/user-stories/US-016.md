# US-016: Filter History by Content Type

As a developer,
I want to filter my clipboard history by content type,
so that I can quickly find items of a specific type.

## Scenario: Filter to show only URLs
Given the clipboard history contains text, URLs, and images
When the user selects "URLs only" filter
Then only URL items should be displayed

## Scenario: Filter to show only images
Given the clipboard history contains text, URLs, and images
When the user selects "Images only" filter
Then only image items should be displayed

## Scenario: Clear content type filter
Given the clipboard history is filtered to show only URLs
When the user clears the content type filter
Then all items in history should be displayed

## Notes
- **Persona**: developer
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: None significant
- **Dependencies**: US-011, US-014
