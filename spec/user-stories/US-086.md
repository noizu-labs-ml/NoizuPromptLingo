# US-086: Macro Templates and Example Library

As a new user,
I want access to a library of template macros with common use cases,
so that I can quickly get started with macros without creating them from scratch.

## Scenario: Browse template library
Given the macro quick-insert bar is open
When the user selects "Templates" or "Examples"
Then a list of pre-built macro templates should be displayed
And each template should show: name, description, and use case

## Scenario: Preview template before adding
Given a template is selected in the library
When the user views template details
Then the full template content and variable definitions should be shown
And the user can review before adding to their library

## Scenario: Add template to personal library
Given a template is being viewed
When the user chooses to add it
Then a copy of the template should be created in the user's macro library
And the user can then customize and use it

## Scenario: Template categories
Given the template library contains many templates
When browsing the library
Then templates should be organized by category (e.g., Code, Email, SQL, HTML, Git)
And the user can filter by category

## Scenario: Template preview in format picker
Given the user is creating a new macro
When the template library is available
Then popular templates should be suggested as starting points
And the user can preview and adapt templates during macro creation

## Scenario: Community templates (optional)
Given a web service for macro templates is configured
When the user searches the community template library
Then additional templates from other users should be available
And the user can download and customize community templates

## Notes
- **Persona**: knowledge-worker
- **T-Shirt Size**: L
- **Complexity**: medium
- **Risks**: Template versioning, community content, maintaining template quality
- **Dependencies**: US-072 (Macroize Clipboard Entry), US-074 (Macro Quick Insert Bar)
