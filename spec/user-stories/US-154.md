# US-154: URL Preview Card

As a developer,
I want URL clipboard entries to show preview cards with title and favicon,
so that I can identify links without visiting them.

## Scenario: Display URL preview
Given a URL is copied to clipboard
When the entry is displayed in history
Then a preview card should show: page title, favicon, domain

## Scenario: Fetch URL metadata
Given a URL is captured
When the entry is processed in background
Then the page title and favicon should be fetched
And the data should be cached

## Scenario: Click to open URL
Given a URL entry is displayed
When the user clicks the preview card
Then the URL should open in the default browser

## Scenario: Handle URL fetch failure
Given a URL cannot be reached
When fetching metadata
Then a fallback display should show the raw URL
And no error should block the entry

## Scenario: URL preview for secure links
Given a URL requires authentication
When fetching metadata fails
Then only the domain should be displayed
And the raw URL should remain accessible

## Notes
- **Persona**: both
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Network requests, preview caching, privacy concerns
- **Dependencies**: US-014 (Detect and Display Content Type)
