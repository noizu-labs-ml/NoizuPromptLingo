# US-115: Custom LLM Transform

As a developer,
I want to use an LLM to transform clipboard content with custom prompts,
so that I can perform intelligent text transformations that regex can't handle.

## Scenario: Create LLM transform
Given the user wants a custom LLM transform
When they provide a system prompt (e.g., "Rewrite this in friendly tone")
Then the transform should be saved with a name
And the prompt should be configured for use

## Scenario: Apply LLM transform at paste
Given a custom LLM transform is configured
When the user selects "Paste with LLM Transform: [_transform_name]"
Then the clipboard content should be sent to the LLM with the system prompt
And the transformed output should replace the original content on clipboard
Then the transformed content should be pasted

## Scenario: LLM transform preview before paste
Given an LLM transform is selected
When the LLM returns the transformed result
Then a preview panel should show before/after comparison
And the user can edit the result before pasting

## Scenario: Reuse LLM transform prompts
Given LLM transforms have been created
When accessing the transform menu
Then custom LLM transforms should appear distinct from regex transforms
And the menu should indicate LLM transforms with an icon

## Scenario: LLM transform with context
Given an LLM transform is configured with a prompt
When the transform is applied
Then additional context can optionally be provided (e.g., target app name)
And the context should be included in the LLM call

## Notes
- **Persona**: developer
- **T-Shirt Size**: L
- **Complexity**: high
- **Risks**: LLM API latency, cost per transformation, quality consistency
- **Dependencies**: US-108 (Paste Format Options), US-078 (LLM Transform Variable Pipeline)
