# US-141: Usage Count Badge

As a developer,
I want to see usage counts on clipboard entries,
so that I can identify my most-used snippets at a glance.

## Scenario: Display usage count on entry
Given an entry has been pasted N times
When the entry is displayed in the history list
Then a usage badge should show "×N" (e.g., "×42")
And the badge should be subtle but visible

## Scenario: Increment usage count on paste
Given an entry is pasted
When the paste completes
Then the entry's usage count should be incremented
And the badge should update immediately

## Scenario: Sort by usage count
Given entries have varying usage counts
When the user sorts by "Most Used"
Then entries should be ordered by usage count descending
And ties should be broken by recency

## Scenario: Usage count filter
Given the user wants to find frequently used entries
When filtering by "Used > 5 times"
Then only entries meeting the threshold should be displayed

## Notes
- **Persona**: both
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Badge visual clutter
- **Dependencies**: US-004 (View Clipboard History)
