# US-039: Secure deletion of sensitive items

As a knowledge-worker,
I want to permanently delete sensitive clipboard items,
so that they cannot be recovered from the database.

## Scenario: Delete single item securely
Given I have a clipboard history with one or more items
When I right-click on a clipboard item and select "Secure Delete"
Then the item should be removed from the database and the storage space should be overwritten with random data

## Scenario: Secure delete confirmation
Given I select "Secure Delete" for one or more items
When the confirmation dialog appears
Then I should be warned that this action cannot be undone and asked to confirm

## Scenario: Secure delete multiple items
Given I have multiple clipboard items selected
When I select "Secure Delete" from the action menu
Then all selected items should be securely deleted and overwritten

## Scenario: Verify database contains no trace of deleted item
Given I have securely deleted a clipboard item
When I directly examine the raw database file
Then the original content should not be recoverable and the space should contain overwritten data

## Scenario: Clear all history securely
Given I want to remove all clipboard history
When I select "Clear All History Securely" from settings with confirmation
Then all clipboard items should be securely deleted and the database should be overwritten with random data

## Scenario: Secure deletion for favorites
Given a clipboard item is marked as a favorite
When I securely delete the item
Then the favorite should also be removed and not retained separately

## Notes
- **Persona**: knowledge-worker
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Overwriting data can cause database growth if not compacted; performance impact
- **Dependencies**: None
