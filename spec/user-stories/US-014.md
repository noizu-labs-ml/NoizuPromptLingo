# US-014: Detect and Display Content Type

As a developer,
I want to see what type of content each clipboard item is,
so that I can quickly identify code snippets, URLs, images, vs. plain text.

## Scenario: Display text content type indicator
Given the clipboard contains plain text "Hello World"
When the clipboard popup displays this item
Then a text content type indicator should be shown

## Scenario: Display URL content type indicator
Given the clipboard contains "https://example.com/api/v1/users"
When the clipboard popup displays this item
Then a URL content type indicator should be shown

## Scenario: Display image content type indicator
Given the clipboard contains an image
When the clipboard popup displays this item
Then an image content type indicator should be shown

## Scenario: Display file path content type indicator
Given the clipboard contains a file path "/Users/keith/Documents/file.txt"
When the clipboard popup displays this item
Then a file path content type indicator should be shown

## Notes
- **Persona**: both
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Incorrect type detection for edge cases
- **Dependencies**: US-004
