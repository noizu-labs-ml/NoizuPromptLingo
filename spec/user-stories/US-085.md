# US-085: Macro Export and Import

As a developer,
I want to export macros to a portable format and import macros from files,
so that I can share macros between devices and backup my macro library.

## Scenario: Export single macro to file
Given a macro is selected
When the user chooses to export the macro
Then the macro should be saved to a file with all its configuration
And the file format should include: slug, template, variables, tags, metadata

## Scenario: Export all macros to archive
Given the user has multiple macros
When the user chooses to export all macros
Then all macros should be bundled into a single archive file
And the archive should maintain macro organization and relationships

## Scenario: Import macro from file
Given the user has a macro export file
When the user imports the file
Then the macro should be added to their macro library
And a confirmation prompt should appear for slug conflicts

## Scenario: Handle slug conflicts on import
Given an imported macro has a slug that already exists
When the user begins the import
Then options should be presented: overwrite existing, rename imported, or skip
And the user's choice should be applied

## Scenario: Validate macro format on import
Given a macro file is being imported
When the file contains invalid macro definitions
Then validation errors should be displayed
And the import should fail gracefully without corrupting the library

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: File format compatibility, conflict handling, data loss during import
- **Dependencies**: US-072 (Macroize Clipboard Entry), US-083 (Edit Existing Macro)
