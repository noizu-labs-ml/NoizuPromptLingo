# US-033: Popup appears within 50ms of hotkey press

As a knowledge-worker,
I want the clipboard history popup to appear instantaneously after pressing the hotkey,
so that my workflow is not interrupted by perceptible lag.

## Scenario: Popup appears within 50ms of hotkey
Given Smart Clipboard is running and clipboard monitoring is active
When I press the global hotkey (Cmd+Shift+T)
Then the popup window should appear and be fully rendered within 50ms of the keypress

## Scenario: Popup appears with first frame ready
Given I have pressed the global hotkey
When the popup window is first displayed
Then the first frame should include the visible portion of clipboard history (not a blank window)

## Scenario: Smooth animation launch
Given the popup is configured to show an open animation
When I press the global hotkey
Then the animation should start and complete smoothly without stuttering within 50ms

## Scenario: Popup maintains responsiveness
Given the popup is displayed with a large clipboard history
When I navigate through the list using keyboard or mouse
Then the scrolling and selection should remain at 60fps without frame drops

## Scenario: Pre-render popup window
Given the app is running in the background
When no popup is currently displayed
Then a popup window instance should be pre-allocated and hidden, ready for instant display

## Scenario: Popup performance with many items
Given the clipboard history contains 1000+ items
When I press the global hotkey
Then the popup should still appear and be usable within 50ms by using virtualized rendering

## Notes
- **Persona**: knowledge-worker
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: 50ms is an aggressive target; SwiftUI rendering may add overhead during initial launch
- **Dependencies**: None
