# US-007: Click to Paste with Mouse

As a knowledge worker,
I want to click on a history item to paste it,
so that I can use the clipboard manager with my mouse/trackpad.

## Scenario: Click to paste item
Given the clipboard popup is displaying history
When the user clicks on a history item with the mouse
Then that item should be copied to the clipboard and the popup should be dismissed

## Notes
- **Persona**: both
- **T-Shirt Size**: XS
- **Complexity**: low
- **Risks**: None significant
- **Dependencies**: US-004
