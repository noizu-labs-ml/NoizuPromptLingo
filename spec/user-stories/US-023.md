# US-023: Display sync status in UI

As a knowledge-worker,
I want to see the current sync status at a glance,
so that I know whether my clipboard history is up to date across devices.

## Scenario: Display synced status in menu bar
Given sync is configured and has completed successfully
When I view the menu bar icon or menu
Then a green indicator or sync icon should show that the device is synced

## Scenario: Display unsynced changes in menu bar
Given I have made changes to clipboard history that have not yet synced
When I view the menu bar icon or menu
Then an orange or yellow indicator should show that unsynced changes are present

## Scenario: Display sync error in menu bar
Given sync is configured but has encountered an error
When I view the menu bar icon or menu
Then a red indicator should show that sync has failed

## Scenario: View detailed sync status in settings
Given the settings window is open in the "Sync" section
When I view the sync status area
Then I should see the last sync timestamp, sync status, and any applicable error messages

## Scenario: Click to view sync details
Given a sync status indicator is visible in the menu bar
When I click on the indicator
Then the popup menu should show last sync time and a "View Details" option

## Notes
- **Persona**: knowledge-worker
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Status indicators should be unobtrusive but informative
- **Dependencies**: US-022
