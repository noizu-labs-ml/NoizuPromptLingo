# US-015: Display Copy Timestamps

As a developer,
I want to see when each clipboard item was copied,
so that I can quickly identify recently copied items vs. older ones.

## Scenario: Display timestamp for text item
Given the user copied text "Hello World" 5 minutes ago
When the clipboard popup displays this item
Then a timestamp indicating "5 minutes ago" should be shown

## Scenario: Display timestamp in relative format
Given the user copied an item 2 hours ago
When the clipboard popup displays this item
Then a timestamp indicating "2 hours ago" should be shown

## Scenario: Display timestamp for older items
Given the user copied an item 3 days ago
When the clipboard popup displays this item
Then a timestamp indicating "3 days ago" should be shown

## Scenario: Display absolute timestamp on hover
Given the user hovers over a history item
When the cursor pauses on the item
Then the absolute timestamp (e.g., "2026-03-03 14:30:00") should be displayed

## Notes
- **Persona**: developer
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Localization of date/time formats
- **Dependencies**: US-004
