# US-084: Delete Macro

As a developer,
I want to delete a macro and manage its removal,
so that I can clean up unused or outdated macros.

## Scenario: Delete macro from list
Given a macro is selected in the macro list
When the user initiates a delete action
Then a confirmation dialog should appear
And the user should confirm to proceed with deletion

## Scenario: Macro deletion unlinks generated entries
Given a macro has generated clipboard entries
When the macro is deleted
Then the generated entries should remain in clipboard history
But the macro_id reference should be cleared
And entries become standalone clipboard entries

## Scenario: Delete macro with no confirmation for low-usage items
Given a macro has usage count of 0 or 1
When the user deletes the macro
Then a lightweight confirmation should be sufficient
And full confirmation dialog may be optional

## Scenario: Restore deleted macro
Given a macro was accidentally deleted
When using an undo or restore function
Then the macro should be restored with its original ID and configuration
And the restore should re-link to any generated entries

## Notes
- **Persona**: developer
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Accidental deletion, cascading effects on database references
- **Dependencies**: US-072 (Macroize Clipboard Entry), US-079 (Macro Generated Output Nesting)
