# Observational Studies

Structured observation for exploratory research when you can't or shouldn't intervene.

## When to Use

- You can't manipulate the independent variable (ethical, practical, or cost reasons)
- Exploring a problem space before forming hypotheses
- Understanding natural behavior without experimental interference
- Monitoring systems or user behavior as-is

## Types

| Type | Description | Example |
|------|-------------|---------|
| **Naturalistic** | Observe without any intervention | Watch how users navigate a site via analytics |
| **Participant** | Observer is part of the environment | Developer joins a team to understand workflow |
| **Structured** | Pre-defined categories for recording | Count specific behaviors in time windows |
| **Unstructured** | Open-ended field notes | Exploratory observation of a new system |

## Observation Protocol

```markdown
### Observation: [Subject/System]

**Observer:** [name]
**Period:** [start] to [end]
**Setting:** [where/what is being observed]
**Focus:** [what specifically are you watching for]

### Recording Method
- [ ] Tally sheet (counting specific behaviors)
- [ ] Time sampling (observe at fixed intervals)
- [ ] Event sampling (record when specific events occur)
- [ ] Continuous recording (everything in sequence)
- [ ] Video/screen recording (review later)

### Categories
| Code | Behavior/Event | Definition |
|------|---------------|-----------|
| [A] | [behavior name] | [precise definition] |
| [B] | [behavior name] | [precise definition] |
```

## Limitations

| Limitation | Implication | Mitigation |
|-----------|------------|-----------|
| **No causation** | Can only show association | Clearly label findings as correlational |
| **Observer effect** | Being watched changes behavior | Use unobtrusive measures when possible |
| **Selection bias** | Can't randomize | Document population carefully |
| **Confounding** | Unknown variables at play | Measure and report potential confounds |
| **Subjectivity** | Observer interpretation varies | Use structured categories; inter-rater reliability |
