## Weekly Cadence

### Balanced Multi-Stream (9-13 hrs/week)

```
Monday:    AI Templates — Research + ideation (2 hrs)
Tuesday:   AI Templates — Drafting + development (2 hrs)
Wednesday: Content — Keyword research + outline (1.5 hrs)
Thursday:  Content — Writing + editing (2 hrs)
Friday:    POD — Design generation batch (2 hrs)
Weekend:   Review metrics, plan next week (1 hr)
```

### Primary-Focused (5-8 hrs/week)

Allocate 70% to primary stream, 30% to secondary:

```
Mon-Wed:   Primary stream (4-5 hrs)
Thu-Fri:   Secondary stream (2-3 hrs)
Weekend:   Metrics review (30 min)
```

### Single-Stream Sprint (4-6 hrs/week)

```
Mon-Tue:   Research + ideation (2 hrs)
Wed-Thu:   Build + create (2 hrs)
Friday:    Launch prep + optimization (1 hr)
Weekend:   Metrics review (30 min)
```

## Agent Invocation Patterns

### Quick Ideation (5-10 minutes)

```
"Generate 5 AI template ideas for [niche]"
"Find trending dev topics for article ideas"
"Create POD concepts for [target audience]"
```

### Full Development (30-60 minutes)

```
"Develop AI template: [idea] — full scope and requirements"
"Write article abstract: [topic] with keyword research"
"Design POD product: [concept] with 5 prompt variations"
```

### Validation & Research (15-30 minutes)

```
"Validate template idea: [concept] — market size and competition"
"Keyword research for article: [topic]"
"Analyze top sellers in [POD niche]"
```

### Tracking Updates (5 minutes)

```
"Update tracker: launched [product] on [platform]"
"Log performance: [product] — [sales/views/revenue]"
"Review backlog and prioritize next items"
```

## Scaling Path

### Year 1: Build Foundation
- **Months 1-3:** Launch primary stream, validate product-market fit
- **Months 4-6:** Add secondary stream, optimize primary
- **Months 7-12:** Scale what works, add third stream if capacity allows

### Year 2+: Scale & Diversify
- **AI Templates:** Add SaaS tier ($29-99/mo subscriptions)
- **Content:** Paid community, courses, sponsorships
- **POD:** Expand winning designs to new niches, seasonal collections

### Revenue Scaling Triggers

| Trigger | Action |
|---------|--------|
| Single template hits $500/mo | Create template bundle, raise prices |
| 500 free subscribers | Launch paid tier ($5-10/mo) |
| 1 POD design > 50 sales/mo | Create variations, expand to new platforms |
| Total revenue > $2K/mo | Move to own site (lower fees) |
| Total revenue > $5K/mo | Consider paid ads, hire design help |

Based on the technical founder positioning:

| Area | Why It Works | Timeline to First $ |

| AI for Creative Pros | Low competition, can code real tools | 2-4 weeks |

2. **Creative Execution** — AI-assisted design at scale
3. **Problem-Solving** — Understand developer pain points firsthand
