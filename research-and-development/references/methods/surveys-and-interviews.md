# Surveys and Interviews

Qualitative and quantitative data collection from human participants.

## When to Use

- Understanding user preferences, opinions, or behaviors
- Exploring a problem space before designing experiments
- Gathering subjective data that can't be instrumented
- Validating quantitative findings with qualitative depth

## Surveys vs Interviews

| Factor | Survey | Interview |
|--------|--------|-----------|
| **Scale** | 30-1000+ respondents | 5-20 participants |
| **Depth** | Shallow, standardized | Deep, flexible |
| **Analysis** | Quantitative + basic qualitative | Thematic analysis |
| **Time per respondent** | 5-15 minutes | 30-60 minutes |
| **Best for** | Measuring frequency/prevalence | Understanding why |

## Survey Design

### Question Types

| Type | When to Use | Example |
|------|-------------|---------|
| **Likert scale** | Measuring agreement/satisfaction | "How satisfied are you? (1-5)" |
| **Multiple choice** | Categorical preferences | "Which feature do you use most?" |
| **Ranking** | Relative priority | "Rank these 5 features by importance" |
| **Open-ended** | Exploratory, unexpected insights | "What's the most frustrating part?" |
| **NPS** | Loyalty/satisfaction benchmark | "How likely to recommend? (0-10)" |

### Common Survey Mistakes

| Mistake | Example | Fix |
|---------|---------|-----|
| Leading questions | "How great is our new feature?" | "How would you rate this feature?" |
| Double-barreled | "Is it fast and reliable?" | Split into two questions |
| Too many questions | 50-question survey | 10-15 max; respect time |
| No "N/A" option | Forcing answers on irrelevant questions | Include "Not applicable" |
| Acquiescence bias | All positive-worded items | Mix positive and negative framing |

## Interview Design

### Semi-Structured Interview Protocol

```markdown
### Interview: [Topic]
**Duration:** [30-60 min]
**Participants:** [criteria]

#### Opening (5 min)
- Introduce yourself and the purpose
- Explain confidentiality and how data will be used
- Ask permission to record

#### Core Questions (20-40 min)
1. [Open question about their experience]
   - Probe: [follow-up if they mention X]
   - Probe: [follow-up if they mention Y]
2. [Question about specific behavior]
3. [Question about pain points]
4. [Question about ideal state]

#### Closing (5 min)
- "Is there anything else you'd like to share?"
- Thank them for their time
```

### Interview Analysis

1. Transcribe (or use detailed notes)
2. Code responses (tag themes)
3. Build affinity diagram (group related themes)
4. Count frequency of themes across participants
5. Select representative quotes for each theme

## Sampling

| Method | Description | When to Use |
|--------|-------------|-------------|
| **Random** | Every member has equal chance | Large, accessible population |
| **Stratified** | Random within defined subgroups | Need representation of key segments |
| **Convenience** | Whoever's available | Exploratory/pilot only |
| **Snowball** | Participants recruit others | Hard-to-reach populations |
| **Purposive** | Deliberately selected for criteria | Expert interviews, extreme cases |

## Response Rate Expectations

| Channel | Typical Rate | Good Rate |
|---------|-------------|-----------|
| Email to customers | 5-15% | 20%+ |
| In-app survey | 10-25% | 30%+ |
| Pop-up intercept | 2-5% | 10%+ |
| Paid panel | 40-60% | 70%+ |
