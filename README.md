# Meat Brains

**Domain:** meat-brains.therobotlives.com

## Project Idea

Reddit/Digg-style community for sharing, discussing, and voting on prompts and models. Meat Brains provides a social platform where AI practitioners share prompt engineering techniques, model configurations, and workflows. Users upvote effective prompts, discuss model capabilities, and collaboratively build a curated knowledge base of LLM best practices and emerging techniques.
