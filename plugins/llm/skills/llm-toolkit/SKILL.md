# llm-toolkit

Companion CLI vendored at `plugins/llm/llm-toolkit` (squash subtree of `the-robot-lives/llm-toolkit`). It is **not** one of this plugin's MCP servers.

```bash
cd plugins/llm/llm-toolkit
pnpm install
llm-toolkit recent
llm-toolkit search "query"
```
