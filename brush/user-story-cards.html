07 — User Story Cards

Generated during Sketch, executed during Ink. Each story links to a persona and includes acceptance criteria.

INK-001
MVPMarcus Chen
As a solo developer,
I want to paste my rough idea into a text field
so that the AI can help me structure it into a project plan.
Acceptance Criteria
  • Text area accepts freeform input of any length
  • Submitting triggers AI pitch refinement
  • User can edit the refined version
  • Pitch is saved and passed to next step
INK-002
MVPMarcus Chen
As a solo developer,
I want to review AI-generated personas
so that I can validate who I'm building for before writing stories.
Acceptance Criteria
  • AI generates 2-3 personas from the pitch
  • Each persona shows as an editable card
  • User can accept, edit, or reject each persona
  • User can add their own persona manually
INK-003
Jules Okafor
As an indie hacker,
I want to watch agents build my project story by story
so that I can approve each change before it merges.
Acceptance Criteria
  • Agent dashboard shows backlog with status
  • Live code diff as agents write
  • Acceptance criteria auto-check as implemented
  • Approve/reject per story
INK-004
Rina Patel
As a team lead,
I want to deploy the finished project with one click
so that my team can start iterating on a live product, not a doc.
Acceptance Criteria
  • Choose deployment target (Vercel/Railway/Fly)
  • Auto-provision database if needed
  • Deploy log streams in real-time
  • Live URL displayed on success
