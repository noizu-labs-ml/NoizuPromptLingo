# US-007: Satisfying Daily Core Loop

**As a** regular player
**I want to** complete a full daily cycle (wake, tend, gather, craft, trade/explore/socialize, rest) in 30-60 minutes
**So that** each session feels productive and I always log off with a sense of accomplishment

## Acceptance Criteria
- [ ] 15-minute session allows: check overnight activity, harvest garden, review marketplace sales
- [ ] 30-minute session allows: full morning routine + one focused activity (craft, trade, or explore)
- [ ] 60-minute session allows: full daily cycle with social interaction and market activity
- [ ] Session pacing has natural stopping points (no cliffhanger timers forcing continued play)
- [ ] Overnight activity log shows what happened while offline (sales, garden growth, faction events)
- [ ] "Plan Tomorrow" feature lets player queue priorities for next session

## Category
Core Gameplay

## Priority
Must

## Notes
- Unlike the original roguelite's tight 30-60 minute runs, TheRobotWars sessions are open-ended with natural stopping points.
- Offline progression is key: gardens grow, shops stay open (if agent-staffed), orders fill.
- See design/core-loop.md "Session Pacing" for full breakdown.
