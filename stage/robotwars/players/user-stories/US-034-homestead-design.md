# US-034: Designing Homestead Layout

**As a** Builder player
**I want to** customize my homestead layout (garden placement, building rotation, path routing, decoration)
**So that** my property reflects my personal style and feels like a place I built

## Acceptance Criteria
- [ ] Grid-based placement system for buildings, gardens, paths, and decorations
- [ ] Buildings can be rotated and positioned within plot boundaries
- [ ] Path routing connects buildings and creates walkable routes for visitors
- [ ] Decorative items from crafting and exploration can be placed as homestead decor
- [ ] Species-specific architectural variants (human cabin, synthetic bay, NEI server rack, fay treehouse)
- [ ] Other players visiting the homestead see the full custom layout
- [ ] Layout changes are free to make (no resource cost for rearranging)

## Category
Core Gameplay

## Priority
Should

## Notes
- The homestead layout is creative expression. It should be as satisfying as Stardew Valley's farm design.
- Rare building materials from distant biomes enable unique decorations unavailable in starter zones.
- See design/mechanics/secondary-mechanics.md "Homesteading" for building types and plot grid rules.
