## 4. Cross-Posting Strategy

When publishing the same content across platforms:

| Order | Platform | Timing | Adjustments |
|-------|----------|--------|-------------|
| 1 | Primary platform | Day 0 | Full optimization for this platform |
| 2 | Cross-post #1 | Day 3-7 | Set canonical URL to primary, adjust formatting |
| 3 | Cross-post #2 | Day 7-14 | Set canonical URL, adapt tone/length |

**Rules:**
- Always set canonical URL on cross-posts (SEO credit to original)
- Adjust title/tags for each platform's audience
- Adapt code examples and formatting to platform conventions
- Don't cross-post on the same day — spread for maximum discovery
