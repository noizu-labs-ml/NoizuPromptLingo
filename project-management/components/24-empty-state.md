# Empty State

| Field | Value |
|-------|-------|
| **ID** | `empty-state` |
| **Category** | Feedback & Indicators |
| **Used In** | 05-Projects Dashboard, 10-Story Curation, 25-Agent Dashboard |

## Description

Illustrated placeholder shown when a view has no content yet. Includes a primary CTA to create the first item and optional quick-start templates. Sets user expectations and reduces confusion.

## Size Variants

| Variant | Description |
|---------|-------------|
| **Compact** | Icon + single-line message + button |
| **Expanded** | Illustration + message + description + CTA + template cards |

## Props / Configuration

- `illustration` — Image or icon
- `title` — Heading (e.g., "No projects yet")
- `description` — Explanatory text
- `cta` — Primary action button
- `templates` — Optional quick-start template cards

## Interactions

- CTA click → navigates to creation flow
- Template cards → pre-fill creation with template data
