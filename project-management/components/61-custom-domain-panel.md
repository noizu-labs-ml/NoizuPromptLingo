# Custom Domain Config Panel

| Field | Value |
|-------|-------|
| **ID** | `custom-domain-panel` |
| **Category** | Domain-Specific |
| **Used In** | 12-Server Detail |

## Description

Panel for configuring custom domains: enter domain, view DNS instructions, verify DNS, manage TLS certificates.

## Size Variants

| Variant | Description |
|---------|-------------|

## Props / Configuration

- `currentDomain`
- `dnsInstructions`
- `verificationStatus`
- `tlsStatus`

## Interactions

- Enter custom domain
- View DNS CNAME/A instructions
- Click verify DNS
- Upload custom cert
- Toggle enforce custom domain only
