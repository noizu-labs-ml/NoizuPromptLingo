# Git Push Dialog

| Field | Value |
|-------|-------|
| **ID** | `git-push-dialog` |
| **Category** | Modals & Overlays |
| **Used In** | 13-MCP Jumpstart Generator |

## Description

Modal for pushing generated project to Git: create new repo or select existing, set visibility, execute push with progress.

| Variant | Description |
|---------|-------------|

## Props / Configuration

- `providers`
- `repositories`
- `onPush`
- `onCreateRepo`

## Interactions

- Select provider (GitHub/GitLab)
- Create new or select existing repo
- Set visibility
- Push with progress indicator
