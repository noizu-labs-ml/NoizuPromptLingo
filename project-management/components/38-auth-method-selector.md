# Auth Method Selector

| Field | Value |
|-------|-------|
| **ID** | `auth-method-selector` |
| **Category** | Input & Forms |
| **Used In** | 11-JustMCP Deploy Wizard |

## Description

Radio/card selector for authentication methods: API key, OAuth 2.1, mTLS, No-auth. Shows warnings for risky selections.

| Variant | Description |
|---------|-------------|

## Props / Configuration

- `options`
- `selected`
- `onSelect`
- `warnings`

## Interactions

- Select auth method
- View warning for no-auth with write ops
