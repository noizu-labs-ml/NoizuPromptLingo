# Redaction Policy Editor

| Field | Value |
|-------|-------|
| **ID** | `redaction-policy-editor` |
| **Category** | Input & Forms |
| **Used In** | 11-JustMCP Deploy Wizard |

## Description

Configure audit argument redaction rules: field patterns, redaction types (full, partial, hash), regex patterns for sensitive value detection.
