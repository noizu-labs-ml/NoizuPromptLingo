- **Simple**: Single-purpose display components (badges, icons, hints)
- **Complex**: Multi-field, stateful components (editors, forms, graphs)
- **Layout**: Structural wrapper components (grids, panels, split views)
- **Interactive**: User-driven components with significant state (dialogs, selectors)
