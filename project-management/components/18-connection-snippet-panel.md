# Connection Snippet Panel

| Field | Value |
|-------|-------|
| **ID** | `connection-snippet-panel` |
| **Category** | Domain-Specific |

## Description

Tabbed code snippets for connecting to an MCP server from different clients (Claude Desktop JSON, Python SDK, TypeScript SDK).
