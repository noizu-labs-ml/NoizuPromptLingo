# Status Badge

| Field | Value |
|-------|-------|
| **ID** | `badge` |
| **Category** | Feedback & Indicators |
| **Used In** | 01-Today Dashboard, 05-Inbox, 07-Mobile Capture, 13-Kanban Board, 15-Portfolio Dashboard, 23-Bug Detail, 32-Uptime Dashboard, 36-Status Page, 48-OKR Hierarchy, 53-Agent Team Dashboard, 64-Prompt Template Library |

## Description

Small label indicating type, source, methodology, or status with color coding

## Size Variants

| Variant | Description |
|---------|-------------|
| **Inline** | Colored text label |
| **Compact** | Pill-shaped badge with icon + text |

## Props / Configuration

- `label` — string
- `color` — theme color or status-derived
- `icon` — optional icon
- `size` — sm|md

## Interactions

- hover for tooltip if truncated
- click for related filter
