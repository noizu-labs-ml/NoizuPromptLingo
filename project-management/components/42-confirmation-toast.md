# Confirmation Toast

| Field | Value |
|-------|-------|
| **ID** | `confirmation-toast` |
| **Category** | Feedback & Indicators |
| **Used In** | Multiple screens |

## Description

Non-blocking toast notification for confirmations (link copied, action succeeded) and rate limit warnings.

| Variant | Description |
|---------|-------------|

## Props / Configuration

- `message`
- `type`
- `duration`
- `action`

## Interactions

- Auto-dismiss after duration
- Click action link
- Dismiss manually
