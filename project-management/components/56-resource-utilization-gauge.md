# Resource Utilization Gauge

| Field | Value |
|-------|-------|
| **ID** | `resource-utilization-gauge` |
| **Category** | Data Display |

## Description

Circular or bar gauge showing current CPU/memory usage as percentage of allocation with color thresholds (green/yellow/red).
