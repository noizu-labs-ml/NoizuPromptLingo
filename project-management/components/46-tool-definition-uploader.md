# Tool Definition Uploader

| Field | Value |
|-------|-------|
| **ID** | `tool-definition-uploader` |
| **Category** | Input & Forms |
| **Used In** | 03-Onboarding Wizard, 11-JustMCP Deploy Wizard |

## Description

Drag-and-drop file upload zone accepting .json, .yaml, .yml files up to 5MB. Auto-detects format and shows parsed preview.

## Interactions

- Click to browse
- View parsed preview
- See validation errors
