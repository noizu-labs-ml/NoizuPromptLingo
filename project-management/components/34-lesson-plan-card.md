# Lesson Plan Card

| Field | Value |
|-------|-------|
| **ID** | `lesson-plan-card` |
| **Category** | Cards & Tiles |
| **Used In** | 10-Education Portal |

## Description

Card for lesson plan templates showing title, description, download links (PDF/Google Doc), and pre-loadable fighter build JSON. Supports community submission.

## Size Variants

| Variant | Description |
|---------|-------------|
| Compact | Card with title and download links |

## Props / Configuration

- `title` — Lesson plan name
- `description` — Brief summary of the lesson plan
- `downloadLinks` — PDF and Google Doc URLs
- `preloadBuild` — Fighter JSON for preloading into classroom environment

## Interactions

- Download lesson plan (PDF or Google Doc)
- Preload fighter build directly into classroom session
- Submit custom lesson plan template to community
