# US-066: Family-Friendly Content Mode

**As a Dad Gamer,** I want to enable a family-friendly content filter so that my 9-year-old and I can play together without encountering inappropriate fighter names or cosmetics.

**Acceptance Criteria:**
- A toggle in Settings labeled "Family Mode" filters opponent fighter names against a profanity blocklist
- When Family Mode is on, cosmetic previews are limited to age-appropriate asset tags (no gore, horror, or mature themes)
- Fighter names submitted by users pass through a moderation queue before appearing in opponents' clients
- Family Mode setting is PIN-protected to prevent a child from disabling it

**Priority:** Should
