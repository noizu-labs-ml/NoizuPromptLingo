# INK-017: Auto-Assemble PRD from Sketch Artifacts

**As an** indie hacker,
**I want** the system to compile my pitch, personas, and user stories into a structured PRD,
**So that** I have a single document I can hand to a contractor or use to build it myself.

**Primary Persona:** Jules Okafor (#2)
**Phase:** Sketch
**Priority:** P0-Critical

**Acceptance Criteria:**
- [ ] After user stories are finalized, a "Generate PRD" action produces the document within 30 seconds
- [ ] The PRD includes sections for: Executive Summary, Target Personas, User Stories (grouped and prioritized), Scope Boundaries, and Open Questions
- [ ] All content traces back to artifacts created in Steps 1-3 with no hallucinated requirements
- [ ] The PRD is displayed in a formatted, readable view within the app
- [ ] The Sketch phase status updates to "PRD Generated" on the dashboard
