# US-022: Decision Overlay Toggle and Filtering

**As a Creator-Spectator,** I want to toggle the neural network decision overlay on and off and filter it by node type (perception, decision, action) so that I can capture clean screenshots and annotated screenshots for content creation.

**Acceptance Criteria:**
- Overlay has a single-tap toggle between hidden, full, and filtered modes
- Filter panel allows selecting any combination of node categories to display
- Filtered overlay state persists for the session and is reflected in screenshots taken within the app
- Exported images include a watermark-free option for creators with a linked account

**Priority:** Must
