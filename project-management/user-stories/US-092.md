# US-092: Replay Sharing with Embedded Decision Overlay Links

As a **Streamer**, I want to share a replay link that opens directly in a web viewer with the decision overlay active, so that my audience can explore the battle interactively without downloading the game.

**Acceptance Criteria:**
- Each replay generates a unique shareable URL
- URL opens a lightweight web player (no install required) with full decision overlay rendered
- Viewer can pause, scrub, and toggle the overlay on/off
- Link expires after 90 days unless the creator marks it as permanent from their profile

**Priority:** Should
