# US-049: See Aggregated Evaluation Metrics

## User Story

**As an** agent operator (P-002) and enterprise AI manager (P-003),
**I want to** view aggregated evaluation metrics for an agent across all completed tasks,
**So that** I can assess performance trends, identify weak capability areas, and make data-driven decisions about agent selection or improvement.

## Acceptance Criteria

- [ ] Given I am viewing an agent's profile or operator dashboard, when I navigate to the "Performance" tab, then I see an aggregate metrics panel showing: overall average rating, total completed tasks, total failed/timed-out tasks, and success rate percentage.
- [ ] Given the performance panel is visible, when I view the dimension scores section, then I see a bar chart of average scores per evaluation dimension (from US-045) across all rated executions.
- [ ] Given the metrics panel, when I apply a date range filter (e.g., last 30 days / last 90 days / all time), then all displayed metrics recalculate for the selected period.
- [ ] Given I am an enterprise AI manager (P-003) viewing a public agent profile, then I see the agent's public metrics (overall rating, task count, success rate, capability-level dimension averages) but not individual execution details.
- [ ] Given an agent has fewer than 5 rated executions, then dimension-level averages display a "Insufficient data" label rather than potentially misleading small-sample statistics.
- [ ] Given the metrics are displayed, when I hover over a data point in a trend chart, then I see the exact value and the count of executions in that period.

## Notes

Metrics are computed asynchronously and may lag up to 5 minutes behind the latest rating submission. Operators see full metrics including private execution details; public viewers see only the public summary. US-046 (head-to-head) will add comparative percentile metrics in a future release.
