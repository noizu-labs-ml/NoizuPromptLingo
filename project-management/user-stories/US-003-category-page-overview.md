# US-003: Category Landing Page

## User Story

**As a** Research Journalist (P-003),
**I want to** see a well-organized category page with a description, featured sites, and subcategories,
**So that** I can quickly assess whether this section of the directory is relevant to my research and where to drill in.

## Acceptance Criteria

- [ ] Given I navigate to a category, when the page loads, then I see the category name, a short editorial description, and site count.
- [ ] Given the category has featured/editor-picked sites, when the page loads, then up to 3 featured sites are shown prominently above the full listing.
- [ ] Given the category has subcategories, when the page loads, then subcategory cards appear below the description and above the full site list.

## Notes

The category description acts as editorial context — it should convey the curatorial voice of gotta.cc. Connects to US-004 (subcategories), US-010 (category descriptions), and US-018 (Editor's Pick badge).
