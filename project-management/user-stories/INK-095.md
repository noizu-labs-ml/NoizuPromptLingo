# INK-095: Export to GitHub Repository

**As an** indie hacker ready to ship,
**I want to** push my Ink output directly to a new or existing GitHub repository,
**So that** I can immediately start iterating on the generated code in my normal workflow.

**Primary Persona:** Jules Okafor (#2)
**Phase:** Platform
**Priority:** P2-Medium

**Acceptance Criteria:**
- [ ] Publish phase includes a "Push to GitHub" action (requires connected GitHub account)
- [ ] User can choose to create a new repository or push to an existing one
- [ ] For existing repos, the user selects a branch and is warned about overwrite risks
- [ ] The push includes a generated README referencing the noizu.ink project and phase history
- [ ] A commit message is auto-generated with a link back to the noizu.ink project
- [ ] If the GitHub connection is not configured, the action prompts the user to connect in settings
