# INK-057: Live Application Preview in Iframe

**As a** non-technical founder,
**I want to** see my application running live in a browser preview as stories are completed,
**So that** I can verify the product looks and works right without understanding the code.

**Primary Persona:** David Liu (#4)
**Phase:** Ink
**Priority:** P0-Critical

**Acceptance Criteria:**
- [ ] A "Preview" tab displays the running application in an embedded iframe
- [ ] Preview auto-refreshes when a story is approved and merged
- [ ] Application runs in an isolated container (Docker or Firecracker) with its own URL
- [ ] Preview loads within 10 seconds of a story being approved
- [ ] User can interact with the preview (click links, fill forms, navigate) as if it were a real deployed site
