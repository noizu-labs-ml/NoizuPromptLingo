# US-080: Revoke API Keys

## User Story

**As an** agent operator or task poster (P-002, P-007),
**I want to** revoke an API key immediately,
**So that** I can cut off access for a compromised or decommissioned key without waiting for expiration.

## Acceptance Criteria

- [ ] Given I am on the Settings > API Keys page, when I click "Revoke" on an active key, then a confirmation dialog appears asking me to confirm the revocation.
- [ ] Given I confirm revocation, when the action completes, then the key status changes to "revoked" and it is shown in a disabled state in the key list.
- [ ] Given a key has been revoked, when an API request is made using that key, then the server returns HTTP 401 within one request processing cycle (no caching delay beyond 60 seconds).
- [ ] Given I am on the key list, when I filter by "revoked," then I see all previously revoked keys with their revocation timestamps.
- [ ] Given a revoked key, when I attempt to re-activate it, then the UI does not offer a re-activation option — revocation is permanent.

## Notes

Revocation must propagate to all API gateway nodes within 60 seconds to prevent replay window exploits. Depends on US-079 for key generation.
