# US-026: Screenshot Export with UI Skin Options

**As a Creator-Spectator,** I want to export replay frames and graph editor views with selectable UI skin themes (light, dark, minimal) so that my content looks polished and consistent across Reddit posts and Discord embeds.

**Acceptance Criteria:**
- Export dialog offers three UI skin presets: Dark (default), Light, Minimal (graph-only, no chrome)
- Exported PNG is at minimum 1080x1920 resolution for portrait and 1920x1080 for landscape
- Export does not include player usernames unless the exporting user opts in to credit display
- Export action is reachable from within any replay frame and from the graph editor canvas

**Priority:** Could
