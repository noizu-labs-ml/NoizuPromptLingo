# INK-051: Fork Project to Local Development

**As a** solo developer,
**I want to** export the full generated codebase as a Git repository I can clone and develop locally,
**So that** I can continue building in my own IDE and toolchain whenever I outgrow the browser environment.

**Primary Persona:** Marcus Chen (#1)
**Phase:** Ink
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] A "Fork to Local" button generates a Git repository URL (GitHub, GitLab, or downloadable .tar.gz)
- [ ] The exported repo includes full commit history from all agent and manual work
- [ ] README.md is generated with setup instructions (install deps, env config, run locally)
- [ ] Export includes the Dockerfile and docker-compose.yml so the project runs identically locally
- [ ] After forking, the user can optionally continue using noizu.ink agents via a CLI bridge or disconnect entirely
