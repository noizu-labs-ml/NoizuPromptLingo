# US-072: Switch Control Full-App Navigation

**As an Accessibility Advocate,** I want every interactive element in the app to be reachable via Switch Control's item scan mode so that I can play without any touch gestures.

**Acceptance Criteria:**
- All buttons, tabs, and list items have a defined `accessibilityActivationPoint` within the element bounds
- Custom gesture recognizers (swipe-to-dismiss, long-press) have a Switch Control-compatible alternative (e.g., a labeled button)
- Focus order follows a logical top-to-bottom, left-to-right reading order on every screen
- No interactive element is hidden behind a modal overlay that traps Switch Control focus

**Priority:** Must
