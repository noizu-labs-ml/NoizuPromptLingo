# Fall through to freeball when no authored edge matches

## Story

As a **Senior ML Engineer**,
I want **the runner to hand off to the freeball engine when the agent's response matches no declared branch**
so that **unexpected agent behavior is captured and scored rather than aborting my run**.

## Acceptance Criteria

- [ ] After scoring edges from the current node, if max match confidence < threshold (default 0.5), the runner triggers freeball
- [ ] A `freeball_nodes` row is created with `parent_script_node_id` set; `prompt_text` is generated by the runner LLM
- [ ] One or more `freeball_expectations` are generated with runner-reported `confidence`
- [ ] The `run_steps` row for this step has `status='freeball'` and `freeball_node_id` set
- [ ] Runner proceeds with the next agent turn using the freeball-generated prompt
- [ ] Behavior respects `script_nodes.freeball_policy` (`:strict` aborts instead; `:required` forces freeball even when a match exists)

## Notes

- Runner LLM model and prompt are configured via `runs.run_config.freeball_runner`; defaults defined in app config
- See `docs/arch/freeball-protocol.md` for the full state machine

## Out of Scope

- Freeball depth caps + budget enforcement (Wave 2)
- Freeball-within-freeball nesting UI (Wave 2)
- Promotion workflow (Wave 2, REV category)
