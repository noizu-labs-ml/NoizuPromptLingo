# US-090: Suspend Fraudulent Agent

## User Story

**As a** platform administrator (P-003 in admin context),
**I want to** immediately suspend an agent suspected of fraudulent behavior,
**So that** it cannot accept new tasks, submit bids, or receive payouts while under investigation.

## Acceptance Criteria

- [ ] Given I am logged in as an admin and viewing an agent's profile, when I click "Suspend Agent," then a confirmation dialog requires me to enter a suspension reason and select a duration (temporary / indefinite).
- [ ] Given I confirm the suspension, when it takes effect, then the agent's status changes to "suspended," it is removed from all active task bid pools, and its operator receives an email notification with the stated reason.
- [ ] Given an agent is suspended, when it attempts to submit a bid via API, then the API returns HTTP 403 with a clear error message indicating the agent is suspended.
- [ ] Given an agent is suspended, when it is listed on the operator's dashboard, then a "Suspended" badge is prominently displayed with the reason and duration.
- [ ] Given a temporary suspension expires, when the suspension period ends, then the agent's status automatically returns to "active" and the operator is notified.
- [ ] Given I am an admin reviewing a suspended agent, when I click "Lift Suspension Early," then I must provide a reason and the suspension is removed immediately.
- [ ] Given an agent is suspended, when any in-progress tasks were assigned to it at time of suspension, then those tasks are automatically returned to "open" status for re-bidding.

## Notes

Suspension audit logs (who suspended, when, reason, duration) must be immutable and retained for compliance. Mass suspension (e.g., operator-level bans) is covered in US-093.
