# INK-069: Project Cards with Phase Progress

**As an** agency director,
**I want to** see all my projects as cards showing title, current phase/step, agent status, and last edited time,
**So that** I can quickly assess the status of multiple client proposals at a glance.

**Primary Persona:** Aisha Mohammed (#7)
**Phase:** Platform
**Priority:** P0-Critical

**Acceptance Criteria:**
- [ ] Each project displays as a card with: title, current phase name, current step number/name, and last edited timestamp
- [ ] Agent status is shown as an indicator (idle, working, waiting for input, error)
- [ ] Cards are sorted by last edited (most recent first) by default
- [ ] Dashboard loads within 2 seconds for up to 50 projects
