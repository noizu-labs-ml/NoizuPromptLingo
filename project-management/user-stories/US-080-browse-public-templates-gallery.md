# US-080: Browse public mockup templates gallery

## User Story

**As a** Startup Founder (P-004),
**I want to** browse a gallery of publicly available mockup templates,
**So that** I can start from a proven pattern rather than generating from a blank prompt.

## Acceptance Criteria

- [ ] Given I navigate to the Templates section, when the page loads, then I see a grid of public templates organized by category (wireframe, architecture, diagram)
- [ ] Given I am viewing the templates gallery, when I click a template, then I see a preview with a description and a "Use this template" button
- [ ] Given I click "Use this template", when the action completes, then a new mockup is created in my workspace pre-populated with the template's content and prompt

## Notes

Templates are curated by platform admins or promoted from community-saved templates (US-081). Gallery is accessible to unauthenticated users for browsing; creation requires authentication.
