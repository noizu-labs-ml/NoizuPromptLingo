# US-057: Behavioral Analytics Diff Between Training Runs

As an **AI Researcher**, I want to compare the action-frequency distributions and decision entropy of two training runs side by side so that I can quantify behavioral drift caused by hyperparameter changes and determine which configuration produces more generalizable strategies.

**Acceptance Criteria:**
- "Compare Runs" tool available in Training Gym history
- Side-by-side view shows: action distribution bar charts, mean decision entropy, reward curve overlay
- Delta values (absolute and percentage change) shown for each metric
- Comparison exportable as PNG or CSV

**Priority:** Should
