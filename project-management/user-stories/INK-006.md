# INK-006: AI-Refined Pitch

**As a** non-technical founder,
**I want** the AI to rewrite my rough idea into a clear, structured pitch,
**So that** I can see my vision articulated in a way investors and collaborators would understand.

**Primary Persona:** David Liu (#4)
**Phase:** Sketch
**Priority:** P0-Critical

**Acceptance Criteria:**
- [ ] After submitting the raw pitch, the AI generates a refined version within 10 seconds
- [ ] The refined pitch includes a one-line value proposition, a target audience summary, and a core problem statement
- [ ] The original pitch and the refined pitch are displayed side by side for comparison
- [ ] The user can accept the refined pitch, edit it manually, or request a new variation
- [ ] At least one AI-generated variation must be accepted or edited before proceeding to Step 2
