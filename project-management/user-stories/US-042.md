# US-042: Multiple Fighter Slot Management

As a **Competitive Grinder**, I want to own and switch between at least four active fighter slots so that I can test multiple strategic archetypes simultaneously and hedge my ranking across different meta builds.

**Acceptance Criteria:**
- Players can unlock up to 4 additional slots via Fighter Pass
- Each slot maintains independent ELO, training history, and graph version
- Slot dashboard shows per-fighter stats at a glance (ELO, wins, last match date)
- Switching active fighter for ranked queue takes no more than 2 taps

**Priority:** Must
