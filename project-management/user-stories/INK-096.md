# INK-096: Team Workspace — Shared Project Ownership

**As an** agency director managing multiple client projects,
**I want to** create a team workspace where multiple team members can access and contribute to projects,
**So that** my team can collaborate without sharing a single account.

**Primary Persona:** Aisha Mohammed (#7)
**Phase:** Platform
**Priority:** P2-Medium

**Acceptance Criteria:**
- [ ] Users can create a team workspace and invite members by email
- [ ] Workspace members can be assigned roles: Owner, Editor, Viewer
- [ ] Projects can be moved between personal and team workspaces
- [ ] Team workspace has its own billing (separate from personal accounts)
- [ ] Activity log shows who made changes to each project and when
- [ ] Workspace settings allow the owner to manage members and roles
