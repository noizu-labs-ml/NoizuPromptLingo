# US-035: Content Moderation — Build and Guide Flagging

**As an Educator,** I want to flag a community build or guide as inappropriate from within my classroom view so that I can report content to moderators before any student encounters it, and receive a confirmation that the report was received.

**Acceptance Criteria:**
- Flag action is accessible from every Laboratory build card and guide page via a report icon
- Flag form offers categorized reasons: inappropriate name, inappropriate description, exploit/bug abuse, other
- Flagged content is queued for moderator review within 24 hours; content remains visible to general users until reviewed
- Reporter receives an in-app notification when the moderation decision is made (actioned or dismissed)

**Priority:** Must
