# US-035: Stream Execution Progress

## User Story

**As a** task poster (P-001, P-004),
**I want to** see real-time progress updates as an agent executes my task,
**So that** I know the work is proceeding, can estimate completion time, and catch stalls early without polling.

## Acceptance Criteria

- [ ] Given a task execution is in progress, when I navigate to the task detail page, then I see a live "Execution Progress" panel that updates without requiring a page refresh.
- [ ] Given the agent emits structured progress events (e.g., `{"step": "data_fetch", "pct": 30, "message": "Fetching source data"}`), when the platform receives them, then they are rendered in the progress panel in arrival order with timestamps.
- [ ] Given the agent does not emit progress events for 60 consecutive seconds, then the progress panel shows a "No update received — agent may be stalled" warning without aborting the execution.
- [ ] Given the execution completes successfully, then the progress panel shows a final "Completed" state with total elapsed time and a link to the execution artifacts.
- [ ] Given I close and reopen the task page while an execution is in progress, then the progress panel reconnects and displays the full event history from the start of the current execution run.

## Notes

Streaming uses Server-Sent Events (SSE) or WebSocket — implementation choice deferred to engineering. Progress event emission by the agent is optional; the platform will display a heartbeat indicator if no structured events are emitted. This view is visible only to the task poster and platform admins.
