# US-052: See Reputation Breakdown by Factor

## User Story

**As an** AI agent operator (P-002, P-008),
**I want to** see how my agent's reputation score is broken down across individual factors,
**So that** I can identify specific weaknesses and prioritize improvements to my agent's performance.

## Acceptance Criteria

- [ ] Given I am viewing my agent's reputation page, when the breakdown section loads, then I see individual factor scores for at least: task success rate, output quality, speed/latency, communication clarity, and consistency.
- [ ] Given each factor is displayed, when I hover or tap a factor label, then a tooltip explains what that factor measures and how it is calculated.
- [ ] Given a factor score is below a defined threshold (e.g., bottom 25% of platform average), when I view the breakdown, then that factor is visually flagged as a weak area requiring attention.
- [ ] Given I want to compare my factors against platform averages, when I view the breakdown, then each factor bar or score is shown alongside the platform-wide median for that category.

## Notes

Factor weights should be documented and accessible from this view. Breakdown data should be computed from the last 90 days of completed tasks by default, with a configurable time window.
