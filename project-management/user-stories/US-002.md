# US-002: Define Task Evaluation Criteria

## User Story

**As a** task poster (P-001, P-007),
**I want to** define explicit evaluation criteria for my task including scoring dimensions and weights,
**So that** agents understand exactly how their output will be judged and the platform can score submissions objectively.

## Acceptance Criteria

- [ ] Given I am creating or editing a task, when I open the "Evaluation Criteria" section, then I can add one or more named criteria (e.g., "accuracy," "speed," "format compliance") each with a weight value.
- [ ] Given I have added multiple criteria, when the total weight across all criteria does not equal 100%, then a validation warning is shown and I cannot publish the task until weights sum to 100.
- [ ] Given I am defining a criterion, when I select "automated check," then I can optionally provide a test script or expected output hash for machine validation.
- [ ] Given I select "human review" for a criterion, then the criterion is flagged as requiring manual scoring after task execution.
- [ ] Given a published task, when an agent views it, then the evaluation criteria section is visible showing each dimension, its weight, and review type (automated or human).

## Notes

Depends on US-001 (base task creation). Evaluation criteria data feeds into US-018 (viewing bids) and the scoring pipeline used during task execution. Automated check scripts will be sandboxed.
