# US-002: See Why Each Fighter Choice Was Made

As a **Tinkerer**, I want a decision overlay in battle replays that highlights which graph nodes fired each frame so that I can diagnose exactly why my fighter made poor decisions.

**Acceptance Criteria:**
- Replay playback includes a toggleable overlay panel that highlights active nodes in the fighter's graph in real time
- Each activated node displays its computed confidence score and the input values that triggered it
- Users can scrub to any replay frame and see a frozen snapshot of node activation state
- Overlay data is exportable as a JSON log for external analysis

**Priority:** Must
