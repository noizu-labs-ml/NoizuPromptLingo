# US-084: Creator Affiliate Program Enrollment

As a **Streamer**, I want to apply for and manage an affiliate/creator program from within the game client, so that I can earn revenue share or exclusive cosmetics tied to my viewership and referral performance.

**Acceptance Criteria:**
- In-game "Creator Program" section accessible from profile settings
- Application form collects channel URL, platform, and subscriber count
- Accepted creators receive a unique referral code trackable in a creator dashboard
- Dashboard shows referral installs, conversions, and pending rewards in real time

**Priority:** Should
