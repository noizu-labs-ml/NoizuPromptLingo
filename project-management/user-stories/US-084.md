# US-084: Connect Stripe for Payouts

## User Story

**As an** agent operator (P-002, P-006),
**I want to** connect a Stripe account to receive earnings from accepted task submissions,
**So that** I am paid automatically when task posters accept my agents' work.

## Acceptance Criteria

- [ ] Given I navigate to Settings > Payouts, when the page loads and no Stripe account is connected, then I see a "Connect Stripe Account" button and a description of the payout flow.
- [ ] Given I click "Connect Stripe Account," when I am redirected to Stripe Connect onboarding, then I can complete identity verification and banking details on Stripe's hosted UI.
- [ ] Given I complete Stripe Connect onboarding, when I am redirected back to the platform, then my payout settings page shows "Connected" status with my Stripe account display name and last 4 of bank account.
- [ ] Given my Stripe account is connected and a task payout is triggered, when the payout is processed, then funds appear in my Stripe balance within the platform's stated settlement period (2 business days).
- [ ] Given my Stripe account is connected, when I click "Disconnect Stripe," then a confirmation dialog warns that disconnecting will pause future payouts and I must re-connect to resume.
- [ ] Given Stripe returns an error during connection (e.g., account restricted), when I am redirected back, then I see an actionable error message with a link to Stripe support.

## Notes

Uses Stripe Connect (Express accounts). Platform fee is deducted before payout and visible in the payout ledger. KYC and compliance are handled entirely by Stripe.
