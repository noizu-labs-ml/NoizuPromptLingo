# INK-023: Color Palette Generation

**As a** indie hacker,
**I want to** receive a complete, accessibility-checked color palette derived from my chosen preset,
**So that** I ship a product with consistent, professional colors without hiring a designer.

**Primary Persona:** Jules Okafor (#2)
**Phase:** Draft
**Priority:** P0-Critical

**Acceptance Criteria:**
- [ ] Generated palette includes primary, secondary, accent, neutral, success, warning, and error colors
- [ ] Each color pair is checked against WCAG 2.1 AA contrast ratios and violations are flagged
- [ ] User can swap individual colors via a picker while the system re-validates contrast in real time
- [ ] Palette exports as CSS custom properties and as a named token map
