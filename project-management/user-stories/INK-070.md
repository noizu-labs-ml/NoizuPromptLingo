# INK-070: Phase Progress Indicators

**As a** UX designer,
**I want to** see a visual progress indicator on each project card showing which phases are complete, in progress, or locked,
**So that** I can understand at a glance how far along my design-to-code projects are.

**Primary Persona:** Sofia Reyes (#5)
**Phase:** Platform
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] Progress indicator shows all 4 phases (Sketch, Draft, Ink, Publish) as distinct segments
- [ ] Completed phases are filled/green, current phase is highlighted/blue, future phases are gray/locked
- [ ] Current step within the active phase is indicated (e.g., "Step 7 of 10")
- [ ] Locked phases due to subscription tier show a lock icon with upgrade tooltip
