# US-033: Combat Skill Progression — Narration Depth Unlocks

**Persona:** Tyler — Sighted MMO refugee, wants player agency
**Priority:** P1
**Epic:** Combat — Progression

## Story
As Tyler, I want my combat skill ranks to unlock richer narration detail and new tactical options so that progression feels meaningful through expanding prose depth, not just numerical stat increases.

## Acceptance Criteria
- [ ] Each combat skill has 5 ranks; each rank unlocks at least one new narration variant or tactical option
- [ ] Rank-up announced in assertive live region with prose that reflects the character's growing mastery: "Your grip on the blade has settled — Longshot rank 3 unlocked."
- [ ] Rank 1–2: functional narration (what happened). Rank 3–4: contextual narration (how and why). Rank 5: mastery narration (subtle detail, opponent reactions, environmental reads)
- [ ] Skill progression panel fully keyboard navigable, showing rank, XP progress, next-rank requirement, and preview of unlocked narration sample
- [ ] XP gain announced as polite update after each combat: "Longshot: +12 XP (340/500)"
- [ ] Rank 5 skills unlock a visible combat style title displayed (and announced) in the player's public profile
- [ ] Skill tree dependencies narrated: "Whirlwind requires Blade Mastery rank 3 — you are at rank 2."
- [ ] Skill preview shows a sample narration at the next rank before committing XP

## Notes
Tyler is motivated by agency and visible progression. The narration depth unlock is the key differentiator from visual MMOs — the reward for leveling up is a better story, not just bigger numbers. The rank 5 mastery narrations should be individually crafted (not templated) and feel like lore fragments about the technique's history or philosophy. This requires content production pipeline coordination.
