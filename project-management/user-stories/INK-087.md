# INK-087: Guided Project Type Selection

**As a** CS instructor setting up a project for my students,
**I want to** select a project type (web app, API, mobile, static site) at the start of Sketch,
**So that** the wizard tailors its questions and outputs to the kind of project I'm building.

**Primary Persona:** Tom Brennan (#6)
**Phase:** Platform
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] First step of Sketch presents a project type selector with at least 4 categories
- [ ] Each category displays a brief description and an icon
- [ ] Selecting a type adjusts subsequent wizard fields (e.g., mobile projects ask about platforms; APIs skip UI questions)
- [ ] A "Not sure yet" option is available that uses a general-purpose question flow
- [ ] Project type can be changed later from project settings without losing existing Sketch data
