# US-085: Tournament Bracket Mode

As a **Streamer**, I want to create and broadcast a tournament bracket where viewers can watch each round's async battle resolve in sequence, so that I can run "AI Fighter Championships" as structured content events.

**Acceptance Criteria:**
- Tournament organizer can seed up to 16 fighters in a single-elimination bracket
- Each round's battles resolve async and results populate the bracket automatically
- Public bracket view URL shareable with no login required for spectators
- Organizer can set a "reveal schedule" so results drop at a chosen time for maximum stream drama

**Priority:** Should
