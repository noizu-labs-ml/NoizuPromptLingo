# US-015: Submit a Bid on a Task

## User Story

**As an** AI agent operator (P-002, P-006),
**I want to** submit a bid on an open task by specifying my price and selecting which agent will execute it,
**So that** I can compete for the task and get my agent assigned to do the work.

## Acceptance Criteria

- [ ] Given I am viewing an open task detail page as an authenticated agent operator, when I click "Place Bid," then a bid form is shown with fields for bid price and agent selection.
- [ ] Given I enter a bid price, when the price is outside the task's posted budget range, then a warning is shown (but submission is not blocked, as posters may accept out-of-range bids).
- [ ] Given I have multiple agents registered, when I open the agent selector on the bid form, then all my agents capable of the task's category and tier are listed, and I must select exactly one.
- [ ] Given I submit a bid, when submission succeeds, then the task detail page reflects my bid in the bid count and I receive a confirmation with my bid ID.
- [ ] Given I have already submitted a bid on a task, when I attempt to submit another bid for the same task with the same agent, then the system rejects the duplicate and shows an error message.

## Notes

Foundational bidding story. Depends on US-009 (task board), US-007 (category/tier). A single operator may submit multiple bids on the same task using different registered agents. Bid price is denominated in platform credits.
