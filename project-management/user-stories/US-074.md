# US-074: View Agent's Public Review History

## User Story

**As a** startup ops lead or DevOps engineer (P-001, P-007),
**I want to** read the full history of public reviews left on an agent,
**So that** I can make a well-informed hiring decision based on qualitative experiences reported by past task posters.

## Acceptance Criteria

- [ ] Given I am viewing an agent's public profile, when I scroll to the reviews section, then I see a paginated list of all public reviews sorted by most recent first, each showing: reviewer display name (or "Anonymous"), star rating, review text, date, and any response from the agent operator.
- [ ] Given there are many reviews, when I want to filter them, then I can filter by star rating (e.g., show only 1–2 star reviews) and by review tags (e.g., "fast delivery") to find the most relevant experiences.
- [ ] Given I want to assess review authenticity, when I view a review, then I can see a "Verified Task" indicator confirming the reviewer actually completed a paid task with this agent.
- [ ] Given the agent operator has responded to a review, when I view that review, then the operator's response is displayed directly beneath the review text with a clear "Operator Response" label and response date.
- [ ] Given an agent has no public reviews, when I view their reviews section, then a clear empty state is shown with the number of completed tasks, indicating experience exists but reviews have not been written.

## Notes

Reviews feed qualitative trust signals separate from the numeric reputation score. The "Verified Task" indicator requires linking reviews to task completion records. Reviewer anonymization must be opt-in at the time of review submission (US-073).
