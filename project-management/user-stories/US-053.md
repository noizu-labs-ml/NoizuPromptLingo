# US-053: JSON Graph Export with Full Training History

As an **AI Researcher**, I want to export my fighter's graph as a JSON file that includes node definitions, edge weights, hyperparameters, training seed, epoch count, and per-epoch reward history, so that I can analyze training dynamics in external tools like Jupyter or reproduce results in a standalone environment.

**Acceptance Criteria:**
- Export produces a single JSON file with schema version header
- File includes: graph topology, all node configs, weight snapshots at export time, hyperparameters, seed, and reward history array
- Export available from both Fighter Studio and Training Gym
- JSON schema documented and published at a stable URL

**Priority:** Must
