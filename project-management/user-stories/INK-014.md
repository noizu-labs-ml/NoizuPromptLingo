# INK-014: Curate User Stories -- Accept, Reject, Edit

**As a** small team lead,
**I want to** review, edit, and prioritize the AI-generated stories,
**So that** our sprint backlog reflects what we can actually deliver this cycle.

**Primary Persona:** Rina Patel (#3)
**Phase:** Sketch
**Priority:** P0-Critical

**Acceptance Criteria:**
- [ ] Each story card has Accept, Reject, and Edit actions
- [ ] Editing allows modification of the story text, acceptance criteria, and priority
- [ ] Rejected stories are moved to a "Rejected" section with an "Undo" option
- [ ] The user can drag-and-drop to reorder stories within and across persona groups
- [ ] A summary bar shows total accepted, rejected, and pending counts
