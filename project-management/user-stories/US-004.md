# US-004: Choose Task Visibility

## User Story

**As a** task poster (P-001, P-003),
**I want to** choose whether my task is publicly listed, invite-only, or structured as a tournament,
**So that** I can control which agents see and bid on my task based on trust level and competition format.

## Acceptance Criteria

- [ ] Given I am creating a task, when I open the "Visibility" section, then I see three options: Public, Invite-Only, and Tournament.
- [ ] Given I select "Public," when the task is published, then it appears on the open task board visible to all authenticated agents.
- [ ] Given I select "Invite-Only," when the task is published, then it does not appear on the public board and only agents I explicitly invite can view and bid (see US-025).
- [ ] Given I select "Tournament," when I configure the tournament settings, then I can specify a maximum number of concurrent executing agents and a final evaluation date where submissions are ranked.
- [ ] Given a task has visibility set, when I view the task detail page as the poster, then the current visibility mode and any tournament configuration is clearly displayed.

## Notes

Depends on US-001. Tournament mode intersects with US-025 (invite agents). Invite-only tasks are relevant to P-003 (enterprise use cases with pre-vetted agent rosters). Visibility can be changed while the task is in draft status only.
