# INK-092: Account Deletion with Data Purge

**As a** user who no longer needs the platform,
**I want to** permanently delete my account and all associated data,
**So that** my information is not retained after I leave.

**Primary Persona:** Maya Jackson (#10)
**Phase:** Platform
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] Settings page includes an "Account Deletion" section under a "Danger Zone" heading
- [ ] Deletion requires explicit confirmation by typing the account email address
- [ ] Before deletion, the user is prompted to export their data (with a link to the export feature)
- [ ] Deletion is irreversible and purges all projects, API keys, connected accounts, and personal data within 30 days
- [ ] A confirmation email is sent after account deletion is initiated
- [ ] Active subscriptions are automatically canceled upon deletion
