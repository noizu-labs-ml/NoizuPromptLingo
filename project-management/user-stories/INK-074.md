# INK-074: Subscription Tier Display and Comparison

**As a** non-technical founder,
**I want to** see a clear comparison of subscription tiers with plain-language descriptions of what each tier unlocks,
**So that** I can choose the right plan without needing to understand technical jargon.

**Primary Persona:** David Liu (#4)
**Phase:** Platform
**Priority:** P0-Critical

**Acceptance Criteria:**
- [ ] Pricing page shows all 4 tiers side-by-side: Free ($0), Pro ($19/mo), Builder ($49/mo), Launch ($99/mo)
- [ ] Each tier lists unlocked phases in plain English (e.g., "Plan your project" not "Sketch phase access")
- [ ] Current tier is highlighted with a "Current Plan" badge
- [ ] Feature comparison table shows project limits, phase access, and compute allocation per tier
- [ ] Annual billing option is displayed with per-month savings highlighted
