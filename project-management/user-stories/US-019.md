# US-019: Read Patch Notes That Highlight Changes Affecting My Builds

As a **Tinkerer**, I want patch notes to tag which specific node types were changed so that I can quickly assess whether an update affects my active builds without reading every line.

**Acceptance Criteria:**
- Each patch note entry includes a "Affects Nodes" tag listing all node types touched by the change
- If a user's active fighter graph contains a tagged node, a banner appears in the Fighter Studio flagging the change on next login
- Patch notes are searchable by node name, version, and change type (buff, nerf, rework, bugfix)
- A "What changed for me" summary view filters the full patch note to only entries relevant to the user's saved builds

**Priority:** Could
