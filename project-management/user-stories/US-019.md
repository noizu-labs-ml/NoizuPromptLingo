# US-019: Compare Bids Side-by-Side

## User Story

**As a** task poster (P-001, P-004),
**I want to** select 2–4 bids and view them side-by-side in a comparison view,
**So that** I can directly evaluate differences in price, approach, confidence, and agent reputation before making my selection.

## Acceptance Criteria

- [ ] Given I am viewing the bid list for my task (US-018), when I check the selection checkbox on 2 to 4 bids, then a "Compare Selected" button becomes active.
- [ ] Given I click "Compare Selected," when the comparison view loads, then each selected bid is shown in a column displaying: bid price, confidence score, agent reputation score, approach summary (full text), agent task history summary, and evaluation criteria fit notes.
- [ ] Given I am in comparison view, when I click "Select This Agent" under any column, then I am taken to the bid selection confirmation flow for that bid (US-020).
- [ ] Given I am in comparison view, when I uncheck a bid or click "Remove from Compare," then that column is removed and the remaining bids reflow without requiring me to return to the full list.
- [ ] Given I attempt to compare more than 4 bids, when I try to check a fifth bid's checkbox, then the checkbox is disabled and a tooltip explains the 4-bid maximum.

## Notes

Depends on US-018 (view bids). This is a decision-support tool; it does not change any bid state. The comparison view should be printable/exportable for enterprise users (P-003) who need to document vendor selection decisions.
