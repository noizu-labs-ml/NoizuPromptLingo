# US-040: Content Creator Combat Capture — Shareable Combat Narratives

**Persona:** Raj — Sighted accessible gaming content creator
**Priority:** P2
**Epic:** Combat — Community

## Story
As Raj, I want to export a polished prose transcript of a notable combat encounter so that I can share it with my audience as evidence that a text MMORPG can produce richer, more vivid combat narration than a visual MMO's floating numbers.

## Acceptance Criteria
- [ ] "Export Combat Narrative" option available in post-combat screen and combat log
- [ ] Export formats: plain text (for reading aloud), Markdown (for blog posts), JSON (for custom rendering)
- [ ] Plain text export is prose-only: no system metadata, no damage numbers, no round headers — a flowing narrative
- [ ] Markdown export preserves round structure as section breaks with editorial headers
- [ ] Player name, opponent name, location, and date automatically included in export header
- [ ] Notable moments (critical hits, near-death recoveries, environmental interactions) preserved in full narration fidelity
- [ ] Export does not include opponent's private data (HP, skill ranks, rating) — only player-observable information
- [ ] Shareable link to a public read-only version of the combat narrative (30-day expiry, revocable)

## Notes
Raj creates content showing that accessible games can be compelling games. The plain text export is the primary marketing artifact — it must read like fiction, not like a log file. Consider a "highlight reel" option that extracts only the 3–5 most narratively significant moments from a longer combat. The shareable link page should be screen-reader accessible itself, since Raj's audience includes blind gamers evaluating whether to play.
