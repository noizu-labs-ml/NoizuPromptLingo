# INK-061: Automated Code Review Summary

**As a** solo developer,
**I want to** receive an automated code review summary that highlights issues by severity (critical, warning, info),
**So that** I can quickly triage what needs fixing before deploying my weekend prototype.

**Primary Persona:** Marcus Chen (#1)
**Phase:** Publish
**Priority:** P0-Critical

**Acceptance Criteria:**
- [ ] Code review runs automatically when user enters Step 11
- [ ] Results are grouped by severity: critical (blocking), warning (recommended), info (optional)
- [ ] Each issue links to the specific file and line number in the code viewer
- [ ] Critical issues display a clear "must fix before deploy" indicator
- [ ] User can re-run the review after making changes
