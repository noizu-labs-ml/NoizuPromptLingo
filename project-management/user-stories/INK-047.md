# INK-047: Pause Agent Work and Edit Code Manually

**As a** solo developer,
**I want to** pause the AI agent mid-story, open a code editor, make manual changes, and resume agent work,
**So that** I can fix nuanced logic that the agent struggles with without losing the agent's progress.

**Primary Persona:** Marcus Chen (#1)
**Phase:** Ink
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] A "Pause Agent" button halts the current Coder Agent within 5 seconds
- [ ] Paused state opens a browser-based code editor (Monaco/CodeMirror) with the full project file tree
- [ ] User edits are saved to the project container and visible in the file tree
- [ ] "Resume Agent" re-starts the Coder Agent, which detects manual changes and continues from the current state
- [ ] Manual edits are attributed to the user in the commit history, distinct from agent commits
