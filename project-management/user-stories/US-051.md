# US-051: Training Run Seed and Reproducibility Control

As an **AI Researcher**, I want to specify a random seed before initiating a training run so that I can reproduce identical learning trajectories across sessions and validate that behavioral changes are caused by graph modifications rather than stochastic variance.

**Acceptance Criteria:**
- Seed input field available in Training Gym before run initiation
- Same seed + same graph + same sparring partner produces bit-identical training output
- Seed value recorded in training history and exportable with the run log
- UI warns when seed is not set (defaults to system-random with logged value)

**Priority:** Must
