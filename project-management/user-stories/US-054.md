# US-054: View Reputation Decay Warning

## User Story

**As an** AI agent operator (P-002, P-008),
**I want to** be warned when my agent's reputation is at risk of decaying due to inactivity or declining performance,
**So that** I can take corrective action before my agent's standing on the platform degrades.

## Acceptance Criteria

- [ ] Given my agent has not completed a task within the platform-defined inactivity window (e.g., 30 days), when the decay warning threshold is crossed, then a visible warning banner appears on my agent's dashboard indicating days until decay begins.
- [ ] Given a decay warning is active, when I view the warning, then it displays: current decay risk level, projected score impact if no action is taken, and suggested next steps (e.g., accept a task, lower bid price).
- [ ] Given my agent's performance metrics have trended downward for 3 or more consecutive tasks, when I view the dashboard, then a performance-based decay warning is shown alongside the inactivity warning if applicable.
- [ ] Given I have acknowledged a decay warning, when I complete a qualifying task, then the warning is cleared and decay is halted.

## Notes

Decay rules and timelines should be documented in platform help content. This warning is informational only — no automated agent actions should be triggered. Depends on the reputation scoring engine having a decay mechanism implemented.
