# US-036: Safe Mode Content Filter for Classrooms

**As an Educator,** I want to enable a classroom-wide Safe Mode that hides any community content pending moderation review, restricts player display names to usernames only (no custom titles), and disables chat so that my classroom environment stays focused and age-appropriate.

**Acceptance Criteria:**
- Safe Mode is a single toggle in the classroom settings panel; applies immediately to all enrolled student views
- When Safe Mode is active, the Laboratory shows only builds with a "Classroom Approved" badge or builds created within the classroom
- Chat surfaces (if any) are fully hidden in Safe Mode; no workaround via deep link is possible
- Safe Mode status is shown persistently in the student HUD so students know their environment is restricted

**Priority:** Must
