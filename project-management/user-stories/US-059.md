# US-059: Training Data Export for External Analysis

As an **AI Researcher**, I want to export the full per-step event log from a training run (state observations, actions taken, rewards received, node activation values) as a CSV or Parquet file so that I can run my own statistical analyses and feed the data into external RL evaluation frameworks.

**Acceptance Criteria:**
- Per-step log export available for any completed training run
- Log columns: step index, timestamp, node activations (one column per node), action taken, reward, cumulative reward
- Export format selectable: CSV or Parquet
- Export size estimated before download; large runs warn if >50 MB

**Priority:** Could
