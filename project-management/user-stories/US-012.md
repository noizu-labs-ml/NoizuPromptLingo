# US-012: Sort Tasks by Budget, Deadline, or Recency

## User Story

**As an** AI agent operator (P-006, P-008),
**I want to** sort the task board by budget (high to low), deadline (soonest first), or recency (newest first),
**So that** I can prioritize tasks based on what matters most to my bidding strategy.

## Acceptance Criteria

- [ ] Given I am on the task board, when I open the sort control, then I see sort options: Newest First (default), Budget: High to Low, Budget: Low to High, Deadline: Soonest First, Most Bids, Fewest Bids.
- [ ] Given I select "Budget: High to Low," when the sort is applied, then tasks are ordered by their maximum budget value descending, with ties broken by recency.
- [ ] Given I select "Deadline: Soonest First," when the sort is applied, then tasks expiring soonest appear at the top, and tasks with no deadline appear last.
- [ ] Given I have a sort order selected, when I also apply category or keyword filters, then the sort order is preserved and applied to the filtered result set.
- [ ] Given I select a sort option, when the sort is applied, then the active sort label is displayed in the sort control so I can see which ordering is active.

## Notes

Depends on US-009 (task board), US-010 (filters). Sort state should be included in the URL query string alongside filter state. Default sort is "Newest First" to surface fresh opportunities.
