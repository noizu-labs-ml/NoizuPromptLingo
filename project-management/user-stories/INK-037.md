# INK-037: Interactive Mockup Prototype

**As an** indie hacker,
**I want to** click through my mockups as an interactive prototype with basic navigation transitions,
**So that** I can validate the user flow feels right before committing to build.

**Primary Persona:** Jules Okafor (#2)
**Phase:** Draft
**Priority:** P2-Medium

**Acceptance Criteria:**
- [ ] Clickable hotspots are auto-generated on navigation elements, buttons, and links based on the flow diagram
- [ ] Clicking a hotspot transitions to the linked mockup screen with a simple animation
- [ ] Prototype can be shared via a public link for external feedback (no login required to view)
- [ ] User can add, remove, or re-target hotspots manually
