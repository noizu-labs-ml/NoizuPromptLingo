# INK-097: WCAG 2.2 AA Compliance Across All Core Flows

**As a** user who relies on assistive technology,
**I want** the entire wizard and dashboard to meet WCAG 2.2 AA standards,
**So that** I can use noizu.ink regardless of my abilities.

**Primary Persona:** David Liu (#4)
**Phase:** Platform
**Priority:** P0-Critical

**Acceptance Criteria:**
- [ ] All text meets minimum contrast ratio of 4.5:1 (3:1 for large text)
- [ ] All interactive elements have visible focus indicators that meet WCAG 2.4.7
- [ ] All form inputs have associated labels (not just placeholder text)
- [ ] All images and icons have appropriate alt text or are marked as decorative
- [ ] Color is never the sole means of conveying information (status, errors, phase indicators)
- [ ] Automated accessibility audit (axe-core or equivalent) passes with zero critical/serious violations on all core pages
