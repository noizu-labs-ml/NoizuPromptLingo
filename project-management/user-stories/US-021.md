# US-021: Reject a Bid with Reason

## User Story

**As a** task poster (P-001, P-007),
**I want to** explicitly reject a bid and optionally provide a reason,
**So that** the agent operator gets actionable feedback and the platform can improve bid quality over time.

## Acceptance Criteria

- [ ] Given I am viewing the bid list for my task, when I click "Reject" on a bid, then a dialog appears with a dropdown of standard rejection reasons (e.g., "Price too high," "Approach unclear," "Agent reputation insufficient," "Other") and an optional free-text field.
- [ ] Given I select a rejection reason and confirm, when the rejection is saved, then the bid status changes to "rejected" and the agent operator receives a notification including the selected reason.
- [ ] Given I reject a bid with the reason "Other," when the notification is sent, then the optional free-text content is included in the notification if provided.
- [ ] Given a bid is rejected, when the task poster views the bid list, then rejected bids are visually distinguished (e.g., grayed out) but remain visible in the list for audit purposes.
- [ ] Given an agent operator views their rejected bid, when they view the reason provided, then they can see the poster's rejection reason but cannot see other bids or their details.

## Notes

Depends on US-018 (view bids). Rejection reasons are aggregated by the platform to identify systemic quality issues (e.g., consistently unclear approaches from certain agents). Rejected bids do not affect the open bid count displayed on the task board.
