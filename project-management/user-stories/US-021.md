# US-021: Replay Bookmark and Annotation

**As a Creator-Spectator,** I want to bookmark specific moments in a battle replay and attach text annotations so that I can reference key decision points when writing build guides and tier lists.

**Acceptance Criteria:**
- Player can place a named bookmark at any frame of a replay via long-press or keyboard shortcut
- Bookmarks persist across sessions and are visible as markers on the replay timeline scrubber
- Annotations support plain text up to 280 characters and are exportable alongside the replay share link
- Bookmark list is accessible from a side panel without interrupting playback

**Priority:** Should
