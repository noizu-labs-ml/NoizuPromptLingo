# US-040: Training Analytics Heatmap Export for Assignments

**As an Educator,** I want to export a student's training analytics heatmap — showing which decision nodes fired most frequently across a training run — as an image and as raw frequency data so that students can submit it as evidence of understanding in a lab report.

**Acceptance Criteria:**
- Heatmap export is available from the Training Analytics panel for any completed training session
- Image export renders the fighter's node graph with node activation frequency encoded as a color gradient (cool-to-warm)
- Raw frequency data exports as CSV with columns: node_id, node_type, node_label, activation_count, activation_percentage
- Both export types are accessible to the educator for any student within their classroom, not just the student's own account

**Priority:** Should
