# US-035: Research and Track Keywords

## User Story

**As the** Growth Operator (P-005),
**I want to** research candidate keywords from a seed topic and save the ones I want to keep,
**So that** I have a vetted keyword list I can reuse across ad copy and landing page generation for a campaign.

## Acceptance Criteria

- [ ] Given a campaign or market segment and a seed topic, when I trigger keyword research, then the system returns a list of candidate keywords and lets me select which ones to save.
- [ ] Given saved keywords exist for a campaign, when I open the campaign detail view, then the tracked keyword list is visible, with controls to add or remove individual keywords.
- [ ] Given a keyword is already tracked for a campaign, when I attempt to add that identical keyword again, then it is not duplicated in the tracked list.

## Notes

Often run alongside competitor research (US-034); saved keywords are natural input to ad copy generation (US-030).
