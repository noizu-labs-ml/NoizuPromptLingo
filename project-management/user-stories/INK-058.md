# INK-058: Device Switcher for Responsive Preview

**As a** UX designer,
**I want to** toggle the preview between desktop, tablet, and mobile viewport sizes,
**So that** I can verify responsive behavior matches my design specs across breakpoints.

**Primary Persona:** Sofia Reyes (#5)
**Phase:** Ink
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] Device switcher toolbar offers at least: Desktop (1440px), Tablet (768px), Mobile (375px)
- [ ] Switching devices resizes the iframe to the selected viewport width with a device frame overlay
- [ ] Custom viewport dimensions can be entered manually
- [ ] Current device selection persists across story approvals and page refreshes
- [ ] A side-by-side mode shows two viewports simultaneously for comparison
