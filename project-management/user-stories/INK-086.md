# INK-086: Progressive Feature Disclosure Across Phases

**As a** UX designer who is new to the platform,
**I want** advanced features to appear only after I've used the basics,
**So that** I'm not overwhelmed by options I don't understand yet.

**Primary Persona:** Sofia Reyes (#5)
**Phase:** Platform
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] During Sketch, only core inputs are visible; advanced options (constraints, tech stack preferences) are collapsed under an "Advanced" toggle
- [ ] Draft phase reveals design-related controls (export to Figma spec, style preferences) only after at least one Sketch is completed
- [ ] Ink phase reveals BYOK and deployment configuration only after at least one Draft is completed
- [ ] Feature unlock moments include a brief tooltip explaining the newly available capability
- [ ] Users who have completed projects on other accounts (detected via connected accounts) can skip progressive disclosure
