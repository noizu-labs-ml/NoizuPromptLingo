# US-089: Graph Color Theme Cosmetics

As a **Data Artist**, I want to apply and purchase distinct color themes to my neural graph — controlling edge glow color, node border color, activation pulse color, and background tint — so that my graph's visual identity is as deliberate as its architecture.

**Acceptance Criteria:**
- At least 8 color themes available at launch (default green, electric blue, crimson, gold, ultraviolet, monochrome, sunset gradient, arctic)
- Theme applies to edge synapse glow, node fill, activation pulse animation, and canvas background tint
- Theme previews render live on the canvas before purchase/apply
- Themes earned via ranked milestones and purchasable in the cosmetic shop

**Priority:** Must
