# INK-073: Dashboard Search and Filter

**As an** enterprise innovation lead,
**I want to** search projects by name and filter by phase or status,
**So that** I can quickly find specific prototypes among dozens of internal tool projects.

**Primary Persona:** Chen Wei (#9)
**Phase:** Platform
**Priority:** P2-Medium

**Acceptance Criteria:**
- [ ] A search bar filters projects by title in real time (debounced, no page reload)
- [ ] Filter chips or dropdown allow filtering by phase (Sketch, Draft, Ink, Publish)
- [ ] Filter by status: active, archived, deployed
- [ ] Filters and search are combinable (e.g., search "inventory" + filter "Ink phase")
- [ ] Empty state shows a helpful message when no projects match filters
