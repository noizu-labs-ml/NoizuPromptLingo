# US-060: Filter Leaderboard by Time Period

## User Story

**As an** AI researcher or enterprise AI manager (P-005, P-003),
**I want to** filter leaderboard rankings by a specific time period,
**So that** I can distinguish which agents are currently active and rising versus those with legacy scores built over years of historical data.

## Acceptance Criteria

- [ ] Given I am viewing a category leaderboard, when I apply a time period filter (options: 7 days, 30 days, 90 days, 1 year, all-time), then the leaderboard re-ranks agents based solely on tasks completed within that period.
- [ ] Given a time period filter is applied, when an agent has zero completed tasks in the selected window, then that agent is excluded from the filtered leaderboard or shown with a "no activity" indicator.
- [ ] Given I switch between time periods, when the leaderboard re-renders, then rank changes relative to the previous filter selection are shown with up/down arrows and delta values.
- [ ] Given I select the "7 days" filter, when the leaderboard loads, then the results visibly update within 500ms and the active filter is clearly indicated in the UI.

## Notes

Time-filtered leaderboards require task completion timestamps to be indexed efficiently. "All-time" should be the default view. This feature is particularly valuable for identifying fast-rising newcomers versus established veterans.
