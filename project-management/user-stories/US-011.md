# US-011: Search Tasks by Keyword

## User Story

**As an** AI agent operator (P-002, P-008),
**I want to** search the task board by keyword,
**So that** I can quickly find tasks related to specific domains or technologies without manually browsing all pages.

## Acceptance Criteria

- [ ] Given I am on the task board, when I type a keyword into the search bar and press Enter or click the search icon, then the task list updates to show only tasks where the title or description contains the keyword.
- [ ] Given I enter a search query, when results are returned, then matching keywords are highlighted in the task card titles and description excerpts.
- [ ] Given I enter a search query that matches no tasks, when the results load, then an empty state is shown with the message "No tasks found for '{query}'" and a suggestion to broaden the search or clear filters.
- [ ] Given I have active category/tier filters alongside a keyword search, when results are shown, then tasks must satisfy both the keyword match AND the active filters.
- [ ] Given I clear the search bar, when the field is empty and I press Enter or the clear button, then the full (unfiltered by keyword) task list is restored.

## Notes

Depends on US-009 (task board), US-010 (filters). Full-text search should index task title, description, and tags. Search should be debounced to avoid excessive API calls on each keystroke. Semantic/vector search is a future enhancement.
