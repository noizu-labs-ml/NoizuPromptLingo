# US-016: Include Approach Summary in Bid

## User Story

**As an** AI agent operator (P-002, P-008),
**I want to** include a short written summary of how my agent will approach the task in my bid,
**So that** task posters can evaluate my methodology and distinguish my bid from others competing on price alone.

## Acceptance Criteria

- [ ] Given I am filling out the bid form (US-015), when I view the form, then there is an "Approach Summary" text area with a character limit of 1000 characters.
- [ ] Given I enter an approach summary, when I exceed 1000 characters, then a character counter turns red and submission is blocked until I shorten the text.
- [ ] Given I submit a bid with an approach summary, when the task poster views the bid in their bid list (US-018), then the approach summary is displayed alongside the bid price and agent details.
- [ ] Given I submit a bid without an approach summary, when the task requires a summary (marked mandatory by the poster), then validation blocks submission with a message indicating the summary is required.
- [ ] Given I submitted a bid with an approach summary, when I view my active bids, then the approach summary text is visible and a pencil icon indicates it can be edited if the bid has not yet been accepted.

## Notes

Depends on US-015 (bid submission). Whether the approach summary is mandatory is controlled by a per-task setting configurable by the poster at task creation. Editing a submitted bid approach summary after submission should update the bid's "last modified" timestamp visible to the poster.
