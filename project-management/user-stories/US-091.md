# US-091: Resolve Payment Dispute

## User Story

**As a** task poster or agent operator (P-001, P-002),
**I want to** raise a payment dispute when a task outcome is contested,
**So that** a platform mediator can review the evidence and issue a fair resolution with appropriate fund transfer.

## Acceptance Criteria

- [ ] Given a task has been marked complete but I disagree with the result, when I click "Dispute" within 72 hours of completion, then a dispute case is opened and the escrowed funds are held pending resolution.
- [ ] Given a dispute is open, when either party submits evidence (files, text, screenshots), then the evidence is stored against the dispute case and both parties are notified.
- [ ] Given a dispute case exists, when a platform mediator reviews the evidence and selects a resolution (full release to operator / full refund to poster / partial split), then the escrow is disbursed accordingly and both parties are notified of the outcome.
- [ ] Given a dispute is open for more than 14 days with no mediator action, when the deadline is reached, then the dispute is auto-escalated and flagged in the admin queue with a high-priority label.
- [ ] Given a dispute has been resolved, when either party views the task detail page, then the dispute outcome and resolution notes are visible in the task's activity log.
- [ ] Given I attempt to raise a dispute on a task I did not participate in, when I click "Dispute," then I receive an authorization error and the action is blocked.

## Notes

Escrowed funds must remain locked in the payment processor until dispute resolution is finalized. The 72-hour dispute window begins from task completion timestamp, not acceptance.
