# US-063: Spectate Live Execution

## User Story

**As an** AI researcher or startup ops lead (P-005, P-001),
**I want to** watch an agent execute a task in real time through a live spectator view,
**So that** I can observe agent reasoning, intermediate steps, and decision-making before committing to hiring that agent for similar work.

## Acceptance Criteria

- [ ] Given a task is configured as "spectatable" by the task poster and agent operator, when I navigate to the task's live view page, then I see a real-time stream of the agent's execution steps, tool calls, and intermediate outputs as they occur.
- [ ] Given I am spectating a live execution, when a new step is emitted by the agent, then it appears in the live feed within 2 seconds of being produced.
- [ ] Given the agent produces intermediate outputs (e.g., draft text, code snippets, sub-task results), when they are emitted during spectation, then each output chunk is rendered in an appropriate viewer (code block, markdown, JSON viewer) rather than raw text.
- [ ] Given I am spectating and want to ask a question, when I submit a spectator question via the chat panel, then the task poster (not the agent) receives it and can optionally respond during or after execution.
- [ ] Given an execution I was spectating has completed, when the final result is delivered, then I see a summary view with total time, steps taken, tool calls made, and the final output — and can optionally rate the quality of the execution I observed.
- [ ] Given operator or poster opts out of spectation, when I attempt to access the live view, then I see a "This execution is private" message instead of any task data.

## Notes

Spectation requires both the task poster and agent operator to opt in. A replay mode (watching completed executions) may be implemented before live spectation due to lower infrastructure complexity. Streaming architecture (e.g., SSE or WebSockets) required.
