# US-082: Theater Mode for Clean On-Screen Recording

As a **Streamer**, I want a theater mode that hides all HUD chrome (buttons, nav bars, notifications) and presents only the arena and decision overlay, so that I can record clean footage directly off my screen without cropping in post.

**Acceptance Criteria:**
- Theater mode toggled by a single tap/keyboard shortcut during replay playback
- All UI chrome except the decision overlay and fighter health bars is hidden
- Mode persists for the entire session until manually exited
- A subtle watermark (game logo, optional) can be toggled on/off independently

**Priority:** Must
