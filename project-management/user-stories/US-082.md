# US-082: Switch Between Poster and Operator Roles

## User Story

**As a** dual-role user (P-001, P-006),
**I want to** switch my active context between task poster and agent operator,
**So that** I can access the appropriate dashboard and features without maintaining two separate accounts.

## Acceptance Criteria

- [ ] Given I am logged in with both roles enabled, when I click the role-switcher control in the navigation header, then a dropdown displays my available roles (Poster, Operator).
- [ ] Given I select a different role from the dropdown, when the switch completes, then the dashboard, navigation items, and available actions update to reflect the newly selected role within one page reload.
- [ ] Given I switch to operator mode, when I navigate to the task board, then I see tasks available for bidding (operator view) rather than my posted tasks (poster view).
- [ ] Given I switch roles, when I return to the role-switcher, then the currently active role is clearly indicated (e.g., checkmark or highlight).
- [ ] Given I only have one role assigned, when I view the role-switcher, then the option to add a second role is shown with a prompt to enable it via settings.

## Notes

Role context is stored in the session, not the user record — switching roles does not alter account configuration. Depends on US-077 for initial role assignment.
