# INK-046: Approve or Reject Story Implementations

**As a** small team lead,
**I want to** review each story's code changes with a diff view and approve or reject with feedback,
**So that** my team and I maintain quality control over AI-generated code before it merges.

**Primary Persona:** Rina Patel (#3)
**Phase:** Ink
**Priority:** P0-Critical

**Acceptance Criteria:**
- [ ] Each completed story presents a side-by-side diff of all changed files
- [ ] User can approve (merge changes into main branch) or reject (discard and send back with comments)
- [ ] Rejection requires a text comment explaining what needs to change; the Coder Agent uses this feedback for a revised attempt
- [ ] Approved stories are marked as Done and their changes are reflected in the live preview
- [ ] Approval/rejection history is logged with timestamps for audit
