# US-069: VoiceOver Live Regions for Battle State

**As an Accessibility Advocate,** I want the live battle replay screen to announce state changes via VoiceOver live regions so that I can follow the fight without watching the animation.

**Acceptance Criteria:**
- Fighter health changes, round transitions, and the final outcome are announced via `UIAccessibilityPostNotification` (announcement type)
- Announcements use plain language (e.g., "Round 2 begins. Your fighter has 60% health.")
- Live region updates do not interrupt mid-sentence; they queue politely
- A setting allows the user to reduce announcement verbosity to outcome-only

**Priority:** Must
