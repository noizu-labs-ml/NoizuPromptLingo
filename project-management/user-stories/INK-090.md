# INK-090: Connected Accounts — GitHub and Google

**As a** product manager who uses GitHub for everything,
**I want to** connect my GitHub account so I can push Ink output directly to a repo,
**So that** I don't have to manually copy files between noizu.ink and my team's workflow.

**Primary Persona:** Kevin Tanaka (#8)
**Phase:** Platform
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] Settings page includes a "Connected Accounts" section with GitHub and Google integrations
- [ ] Each integration shows connection status and the connected account identity (username/email)
- [ ] OAuth flow handles connect, disconnect, and re-authorization gracefully
- [ ] Disconnecting an account warns the user about features that will become unavailable
- [ ] Connected GitHub account enables the "Push to GitHub" export option in Publish phase
