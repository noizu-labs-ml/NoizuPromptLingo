# US-008: Complete a Guided Tutorial That Ends With a Working Fighter

As a **Curious Casual**, I want a step-by-step onboarding tutorial that walks me through placing nodes and connecting them so that I leave with a functional fighter ready to enter my first battle.

**Acceptance Criteria:**
- Onboarding is triggered automatically on first launch and skippable after step 2
- The tutorial guides the user through 5 steps: placing a perception node, a decision node, an action node, connecting them, and deploying to battle
- At completion, the user receives a Starter Template fighter with a contextual explanation of what each node does
- A contextual help button persists after onboarding that re-opens the relevant tutorial step for the section the user is viewing

**Priority:** Must
