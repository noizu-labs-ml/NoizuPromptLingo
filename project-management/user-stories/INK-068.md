# INK-068: Post-Deploy Confirmation and Monitoring Link

**As a** content creator,
**I want to** see my live URL and a link to a monitoring dashboard immediately after deploy succeeds,
**So that** I can share my project with my audience and know where to check if something goes wrong.

**Primary Persona:** Maya Jackson (#10)
**Phase:** Publish
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] On successful deploy, a prominent card displays the live URL with a "Visit Site" button
- [ ] Live URL is copyable with a single click for sharing on social media
- [ ] A monitoring dashboard link is provided showing uptime, response time, and error rate
- [ ] Post-deploy card includes quick links: "Share", "View Logs", "Redeploy", "Return to Dashboard"
- [ ] If deploy fails, the card shows the failure reason and a "View Logs" action instead
