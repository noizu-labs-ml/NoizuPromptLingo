# US-028: Classroom Sandbox Mode

**As an Educator,** I want to create a classroom sandbox where my students join under a class code, fight only within the sandbox, and cannot encounter content from the general ranked population so that I can control the learning environment.

**Acceptance Criteria:**
- Educators can create a named classroom with a join code from a dedicated Education portal
- Students who join the classroom are isolated to intra-class battles unless the educator explicitly enables open-ladder access
- Sandbox matches do not affect global ranked ladder standings
- Educator dashboard shows all enrolled students, their fighter builds, and recent match history

**Priority:** Must
