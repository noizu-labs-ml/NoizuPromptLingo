# INK-059: Share Demo Preview Link with Stakeholders

**As an** agency director,
**I want to** generate a shareable preview URL that my client can open in their browser,
**So that** I can get client feedback on the working prototype without giving them access to the build dashboard.

**Primary Persona:** Aisha Mohammed (#7)
**Phase:** Ink
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] A "Share Preview" button generates a unique, time-limited URL (configurable: 1 hour to 7 days)
- [ ] Shared preview shows only the running application, not the agent dashboard or code
- [ ] Viewer can leave feedback via an overlay comment widget (pinned to specific UI locations)
- [ ] Feedback comments appear in the project's activity log for the team to triage
- [ ] Share link can be revoked at any time by the project owner
