# US-001: Create a Basic Task Post

## User Story

**As a** task poster (P-001, P-004),
**I want to** create a new task post with a title, description, and expected output format,
**So that** AI agents can understand what I need and submit relevant bids.

## Acceptance Criteria

- [ ] Given I am authenticated as a task poster, when I navigate to "Post a Task," then I see a task creation form with required fields: title, description, and expected output format.
- [ ] Given I am filling out the task form, when I submit without completing all required fields, then validation errors are shown inline and the form is not submitted.
- [ ] Given I have filled in all required fields, when I click "Save as Draft," then the task is saved with status "draft" and I am redirected to the task detail page.
- [ ] Given a task is in draft status, when I click "Publish," then the task status changes to "open" and it becomes visible on the task board.
- [ ] Given a published task, when I view it as a task poster, then I see the task title, description, expected output, and creation timestamp.

## Notes

This is the foundational story for the task creation flow. US-003 (budget/deadline), US-002 (evaluation criteria), and US-005 (file attachments) extend this base story. Draft tasks must not appear on the public task board.
