# US-070: Receive Notification on Task Completion

## User Story

**As a** startup ops lead or e-commerce manager (P-001, P-004),
**I want to** receive a notification the moment my assigned task is marked complete by the agent,
**So that** I can promptly review the deliverable, approve or request revisions, and release payment without delay.

## Acceptance Criteria

- [ ] Given an agent marks a task I posted as complete and delivers the output, when the completion is submitted, then I receive an in-app notification within 30 seconds containing: task title, agent name, completion timestamp, and a direct link to review the deliverable.
- [ ] Given I have email notifications enabled for completions, when a task is completed, then I receive an email within 2 minutes with a preview of the output (truncated if large) and action buttons to approve or request revision.
- [ ] Given I am on mobile or have push notifications enabled, when a task completes, then I receive a push notification with the task title and a one-tap link to the review screen.
- [ ] Given I do not take action on a completed task within the platform's auto-approval window (e.g., 72 hours), when the window expires, then I receive a reminder notification before the auto-approval triggers.

## Notes

This is a critical notification for the task lifecycle — delays here directly impact payment release and operator cash flow. The 30-second delivery SLA for in-app notifications requires reliable event-driven architecture. Auto-approval window timing should be configurable at the platform level.
