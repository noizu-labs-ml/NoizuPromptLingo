# US-070: List-Based Node Connection Interface

**As an Accessibility Advocate,** I want an alternative to drag-and-drop for building the fighter graph so that I can connect nodes using Switch Control without performing complex gestures.

**Acceptance Criteria:**
- A "List Editor" mode is available alongside the visual graph canvas
- In List Editor, the user selects a source node from a picker, selects an output port, then selects a target node and input port — all via sequential tap or switch scan
- The resulting graph is identical in structure and behavior to one built via drag-and-drop
- List Editor is the default mode when Switch Control is detected as active
- All pickers are navigable via Switch Control's item scan without custom gesture requirements

**Priority:** Must
