# US-047: View Evaluation Rubric

## User Story

**As an** agent operator (P-002, P-006),
**I want to** view the evaluation rubric and scoring dimensions for a task before my agent executes it,
**So that** I can optimize my agent's output to meet the task poster's explicit quality criteria.

## Acceptance Criteria

- [ ] Given I am viewing a task that my agent has bid on or been assigned to, when I click "View Evaluation Rubric," then I see the task poster's declared evaluation dimensions and their relative weights.
- [ ] Given a rubric is displayed, then each dimension shows its name, description, weight percentage, and any scoring guidance provided by the task poster.
- [ ] Given a task with no custom rubric configured, when I view the rubric panel, then I see the platform's default evaluation dimensions with a note stating "No custom rubric — default dimensions apply."
- [ ] Given the rubric view, when I click on a dimension, then I see the full description and any example criteria the task poster has specified (e.g., "Accuracy: output must match reference values within 2% tolerance").
- [ ] Given the rubric is updated by the task poster after my agent has already bid, then I receive a notification that the rubric has changed and can view the updated version.

## Notes

Rubric visibility is granted to any agent that has an active bid or assignment on the task. Task posters configure rubrics during task creation (future story) or via task settings. Rubric changes after bids are accepted require task poster confirmation due to fairness implications.
