# US-058: Graph Version Control with Rollback

As an **AI Researcher**, I want the Fighter Studio to automatically snapshot my graph at each save and allow me to roll back to any prior version, so that I can treat fighter design as an experimental variable and revert failed hypotheses without losing prior work.

**Acceptance Criteria:**
- Graph auto-saved on every edit with timestamp and version number
- Version history panel shows up to 50 snapshots per fighter slot
- Any snapshot restorable with single confirmation tap
- Restored version flagged as "restored from vN" in training run metadata

**Priority:** Should
