# INK-084: Primary CTA — Start First Project Free

**As a** content creator who has never used a dev tool before,
**I want to** click a single button and immediately begin creating my first project,
**So that** I experience value before being asked to commit or pay.

**Primary Persona:** Maya Jackson (#10)
**Phase:** Platform
**Priority:** P0-Critical

**Acceptance Criteria:**
- [ ] A prominent "Start your first project — free" CTA is visible above the fold
- [ ] Clicking the CTA initiates sign-up (or skips to project creation if already authenticated)
- [ ] No credit card is required for the free tier
- [ ] After sign-up, the user lands directly in the Sketch phase wizard — not a dashboard
- [ ] CTA is repeated in at least one additional location on the landing page (e.g., after pricing)
