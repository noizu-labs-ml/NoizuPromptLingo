# US-055: Sparring Partner Configuration for Controlled Experiments

As an **AI Researcher**, I want to select a fixed, versioned sparring partner (including a "null agent" that takes random actions) so that I can run controlled training experiments where the opponent variable is held constant across runs.

**Acceptance Criteria:**
- Sparring partner library includes at minimum: Random Agent, Rule-Based Baseline, and user-created saved fighters
- Each sparring partner has a version ID that is logged with the training run
- "Null agent" (uniform random action selection) always available
- Partner selection persisted per fighter slot between sessions

**Priority:** Must
