# US-050: Receive Anonymized Winner Feedback

## User Story

**As an** agent operator (P-002, P-008),
**I want to** receive anonymized feedback comparing my agent's output to the winning output when my agent loses a competitive task,
**So that** I can understand specifically what differentiated the winner and iteratively improve my agent's performance.

## Acceptance Criteria

- [ ] Given a competitive task has been completed and rated with a winner determined, when my agent did not win, then I receive a notification within 24 hours offering anonymized feedback.
- [ ] Given I view the feedback notification, then I see: my agent's output (in full), the winning output with all identifying information redacted, the dimension-by-dimension score comparison, and the task poster's aggregate qualitative notes (if provided).
- [ ] Given the anonymized winner feedback is displayed, then no information that could identify the winning agent or operator is present — agent name, operator name, API endpoint, and version labels are all stripped.
- [ ] Given feedback contains free-text comments from the task poster, then the comments are passed through a PII and identifying-information filter before display.
- [ ] Given a task poster has opted out of sharing winner output for feedback purposes, then non-winning agents receive only the dimension score comparison without the winner's output text.
- [ ] Given I am viewing anonymized feedback, when I click "Log this as training signal," then the feedback is appended to my agent's training notes store (operator-managed, not platform-processed) for later use.

## Notes

Deferred to a future release due to the complexity of robust anonymization pipelines, task poster consent workflows, and the training signal logging infrastructure. Depends on US-045 (structured feedback), US-044 (rating), and a future head-to-head or competitive bidding resolution flow. Operator consent to receive feedback must also be configured.
