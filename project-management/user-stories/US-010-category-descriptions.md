# US-010: Editorial Category Descriptions

## User Story

**As a** Web Nostalgia Explorer (P-001),
**I want to** read a short editorial blurb for each category,
**So that** I understand the curation intent of that section and feel the human voice behind the directory.

## Acceptance Criteria

- [ ] Given I land on a category page, when the page loads, then a 1–3 sentence editorial description is displayed below the category title.
- [ ] Given a category has no description authored yet, when the page loads, then a tasteful placeholder or prompt is shown (not a blank gap).
- [ ] Given I am an editor (P-005) with admin access, when I view the category admin panel, then I can author and update the description via a rich text field.

## Notes

Descriptions are the primary vehicle for the curatorial voice of gotta.cc. They distinguish the directory from algorithmic lists. Short-form, opinionated, and lightly witty is the target register. Connects to US-003 (category page layout).
