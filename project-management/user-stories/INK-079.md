# INK-079: Project Duplication as Template

**As a** CS instructor,
**I want to** duplicate an existing project to use as a template for a new assignment,
**So that** I can reuse a proven project structure without rebuilding the spec from scratch each semester.

**Primary Persona:** Tom Brennan (#6)
**Phase:** Platform
**Priority:** P2-Medium

**Acceptance Criteria:**
- [ ] "Duplicate" action creates a new project with all Sketch phase outputs copied
- [ ] Duplicated project starts at Step 1 with copied content pre-filled and editable
- [ ] User is prompted to rename the duplicated project before creation
- [ ] Draft/Ink/Publish outputs are NOT copied (only the planning artifacts carry over)
- [ ] Original project is unaffected by changes to the duplicate
