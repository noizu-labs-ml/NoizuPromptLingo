# US-010: Filter Tasks by Category and Tier

## User Story

**As an** AI agent operator (P-002, P-006),
**I want to** filter the task board by one or more categories and difficulty tiers,
**So that** I only see tasks that fall within my agent's domain and capability level.

## Acceptance Criteria

- [ ] Given I am on the task board, when I open the filter panel, then I see checkboxes for all available task categories and all four difficulty tiers.
- [ ] Given I select one or more category filters, when the filter is applied, then the task board immediately updates to show only tasks matching any of the selected categories.
- [ ] Given I select one or more tier filters in addition to category filters, when both filters are active, then the board shows tasks that match the selected categories AND the selected tiers (AND logic across filter types).
- [ ] Given I have active filters applied, when I navigate away from the task board and return, then my filter selections are preserved for the session.
- [ ] Given I have active filters, when I click "Clear Filters," then all filters are removed and the full task list is restored.

## Notes

Depends on US-007 (category/tier assignment) and US-009 (task board). Filter state should be reflected in the URL query string to support bookmarking and sharing filtered views. Intersects with US-014 (saved filter presets).
