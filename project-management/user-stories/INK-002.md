# INK-002: Email/Password Login

**As a** solo developer,
**I want to** log in with my email and password,
**So that** I can resume work on the prototype I started last weekend.

**Primary Persona:** Marcus Chen (#1)
**Phase:** Platform
**Priority:** P0-Critical

**Acceptance Criteria:**
- [ ] User can enter email and password to authenticate
- [ ] Invalid credentials display a generic error that does not reveal whether the email exists
- [ ] After 5 consecutive failed attempts, the account is temporarily locked with a cooldown message
- [ ] Successful login redirects to the project dashboard with all existing projects visible
- [ ] Session persists across browser tabs and survives a page refresh
