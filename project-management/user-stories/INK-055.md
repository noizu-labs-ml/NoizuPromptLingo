# INK-055: File Tree with Change Indicators

**As a** solo developer,
**I want to** see the project file tree with visual indicators showing which files were added, modified, or deleted by the current story,
**So that** I can quickly assess the scope and impact of each agent's changes.

**Primary Persona:** Marcus Chen (#1)
**Phase:** Ink
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] File tree panel shows the full project directory structure
- [ ] Files added in the current story are marked with a green "A" indicator
- [ ] Files modified in the current story are marked with a yellow "M" indicator
- [ ] Files deleted in the current story are marked with a red "D" indicator
- [ ] Clicking any file opens it in a read-only viewer (or the editor if the agent is paused)
