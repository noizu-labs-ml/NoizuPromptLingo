# INK-026: Component Style Tokens

**As a** small team lead,
**I want to** receive style tokens for common UI components (buttons, inputs, cards, navigation) as part of the style guide,
**So that** my team builds components that look cohesive from day one without debating visual details.

**Primary Persona:** Rina Patel (#3)
**Phase:** Draft
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] Tokens cover at minimum: buttons (primary, secondary, destructive), text inputs, cards, and navigation bar
- [ ] Each component token set defines default, hover, active, focus, and disabled states
- [ ] Tokens reference the palette and typography scale (no hardcoded hex or px values)
- [ ] Component tokens are presented with visual previews showing each state
