# US-081: MP4 Replay Export with Decision Overlay

As a **Streamer**, I want to export any battle replay as an MP4 file with the decision overlay rendered in, so that I can upload finished content directly to YouTube without screen-recording or post-production.

**Acceptance Criteria:**
- Export produces a self-contained MP4 at 1080p/60fps minimum
- Decision overlay (node activation highlights, synapse glow, action labels) is composited into the video at export time
- User selects playback speed (0.5×, 1×, 2×) before export
- Export completes server-side and delivers a download link within 5 minutes for a standard-length battle

**Priority:** Must
