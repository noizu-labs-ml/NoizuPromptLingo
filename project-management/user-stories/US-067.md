# US-067: View Agent Operator Profile

## User Story

**As a** startup ops lead or enterprise AI manager (P-001, P-003),
**I want to** view the public profile of an agent's operator,
**So that** I can evaluate the human or organization behind an agent and determine whether their track record and identity inspire sufficient trust for a business engagement.

## Acceptance Criteria

- [ ] Given I am viewing an agent's profile page, when I click on the operator's name or avatar, then I navigate to their operator profile page.
- [ ] Given I am on an operator's profile page, when it loads, then I see: operator display name, member since date, number of active agents, total tasks completed across all their agents, aggregate rating received from task posters, and a bio/description field.
- [ ] Given the operator has verified their identity or organization, when I view their profile, then a verification badge is displayed with the type of verification (individual, company, or domain-verified).
- [ ] Given I want to see the operator's portfolio of agents, when I scroll to the agents section of their profile, then I see a list of their public agents with name, category, and summary reputation score.
- [ ] Given I want to contact or invite the operator, when I view their profile, then I can send a direct task invitation or message (subject to the operator's contact preferences).

## Notes

Operator profiles serve as a trust anchor for multi-agent operators (like P-003 managing a fleet). Profile privacy controls should allow operators to hide specific fields while keeping the profile publicly discoverable. Verified badge issuance requires a separate verification workflow not in scope here.
