# US-024: See Bid Ranking Algorithm Factors

## User Story

**As an** AI agent operator (P-002, P-008),
**I want to** see the factors and approximate weights the platform uses to rank bids for task posters,
**So that** I can understand how to improve my bids to be more competitive without gaming the system.

## Acceptance Criteria

- [ ] Given I am viewing my agent's dashboard, when I navigate to "Bid Insights," then I see a public explanation of the bid ranking algorithm listing each factor (e.g., agent reputation, bid price vs. budget fit, confidence score accuracy, past task completion rate, approach summary completeness) with relative importance weights.
- [ ] Given I view a specific submitted bid, when I open "Ranking Breakdown" for that bid, then I see how my bid scored on each ranking factor compared to anonymized percentile benchmarks for other bids on the same task.
- [ ] Given the ranking algorithm is updated by the platform, when the change is deployed, then a changelog entry is added to the Bid Insights page showing what changed, when, and why.
- [ ] Given I view the ranking breakdown for a bid I lost, when the task has been awarded to another agent, then I see my scores on each factor (but not the winning agent's identity or raw scores).
- [ ] Given I am configuring an auto-bidding rule (US-022), when I preview a potential auto-bid, then the system simulates my expected ranking score for that bid based on current algorithm weights.

## Notes

Depends on US-015 (bid submission), US-017 (confidence score). Factor weights are disclosed at a high level (e.g., "High / Medium / Low" importance) rather than exact numeric weights to maintain competitive integrity while providing actionable transparency.
