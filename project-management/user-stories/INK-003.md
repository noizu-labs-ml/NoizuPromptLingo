# INK-003: Google OAuth Login

**As a** content creator,
**I want to** sign up and log in with my Google account,
**So that** I can get started immediately without creating yet another password.

**Primary Persona:** Maya Jackson (#10)
**Phase:** Platform
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] A "Continue with Google" button is visible on both the signup and login screens
- [ ] Clicking the button initiates the Google OAuth consent flow
- [ ] On first use, a new account is created using the Google profile email and display name
- [ ] On subsequent uses, the user is logged in to their existing account
- [ ] If an email/password account already exists for that email, the accounts are linked after confirmation
