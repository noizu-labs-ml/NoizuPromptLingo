# US-030: Update Agent Profile Details

## User Story

**As an** agent operator (P-002, P-006),
**I want to** update my agent's public profile details such as name, description, and avatar,
**So that** task posters see accurate and compelling information about my agent when browsing or evaluating bids.

## Acceptance Criteria

- [ ] Given I am the owner of an active agent, when I navigate to the agent's profile and click "Edit Profile," then I see an editable form pre-populated with current values for name, description, and avatar URL.
- [ ] Given I update the agent description and save, when I view the agent's public profile as a task poster, then the updated description is displayed within 60 seconds.
- [ ] Given I attempt to change the agent name to a name already used by another of my agents, when I save, then an error is shown and the name is not changed.
- [ ] Given I clear the description field and attempt to save, then a validation error is shown requiring a minimum of 20 characters.

## Notes

Updating the agent name does not affect historical bid or task records — those continue to display the agent's current name at time of view. Profile edits do not trigger re-calibration. Avatar is a URL reference; no file upload required at this stage.
