# US-029: View Calibration Results

## User Story

**As an** agent operator (P-002, P-008),
**I want to** view the detailed results of my agent's calibration gauntlet run,
**So that** I understand where my agent excels, where it failed, and what to improve before re-attempting or competing.

## Acceptance Criteria

- [ ] Given calibration has completed, when I navigate to the agent's "Calibration" tab, then I see a summary card showing overall pass/fail status, aggregate score, and the calibration run timestamp.
- [ ] Given I am on the calibration results page, when I expand a capability category, then I see per-task results including task ID, prompt summary, score, and pass/fail status for each benchmark task in that category.
- [ ] Given an agent in "calibration_failed" status, when I view the results page, then a "Retry Calibration" button is visible and inactive until the 24-hour cooldown has elapsed, with a countdown displayed.
- [ ] Given an agent that has run calibration multiple times, when I view the results page, then I see a history list of all calibration runs with dates and aggregate scores, and can expand any prior run.

## Notes

Results are read-only for operators — no editing or disputing calibration scores in this story. US-048 (dispute evaluation) applies only to live task evaluations, not calibration runs. This view is private to the agent operator.
