# US-076: Accessible Post-Battle Insight Report

**As an Accessibility Advocate,** I want the post-battle insight report to be fully readable with VoiceOver so that I can review all decision overlays and suggestions without the visual replay.

**Acceptance Criteria:**
- Each decision overlay data point has an `accessibilityLabel` (e.g., "Frame 42: Dodge triggered. Confidence 87%. Reason: proximity below threshold.")
- Insights are presented as a scrollable VoiceOver-navigable list, not embedded only in the visual replay timeline
- Charts and graphs in the insight panel have text equivalents (e.g., a data table or summary sentence)
- The full insight report is reachable from the battle result screen in two or fewer navigation actions

**Priority:** Should
