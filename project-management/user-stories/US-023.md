# US-023: Build Metadata Stats Panel

**As a Creator-Spectator,** I want to view a build's win rate, loss rate, and matchup breakdown against the top 10 most-used archetypes so that I can produce data-backed tier lists without relying on guesswork.

**Acceptance Criteria:**
- Each published build displays aggregate win/loss/draw rates updated within 24 hours of new ranked matches
- Matchup breakdown shows performance split by opponent archetype with sample size indicated
- Stats panel is accessible from the Laboratory build card without entering the Fighter Studio
- Data is downloadable as CSV for offline analysis

**Priority:** Should
