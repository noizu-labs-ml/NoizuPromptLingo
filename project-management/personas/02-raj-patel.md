## Bio

Raj works full-time as a backend engineer but is building toward independence through side projects. He has a half-finished developer tool (CLI for database migrations) and is starting an AI-powered code review service. He's overwhelmed by context-switching between his day job commitments and side-project momentum. His personal life (fitness goals, apartment search, relationship commitments) competes for the same limited evening hours.

## Goals

1. **Unified personal + side-project tracking** — see day-job obligations, side-project tasks, and personal commitments in one view so he can make honest tradeoff decisions
2. **Agent-assisted momentum** — when he gets 90 minutes to work on a side project, he wants an agent to have already triaged issues, updated docs, and prepared a "here's where you left off" briefing
3. **OKRs for life transition** — track his path from employee to founder with concrete key results (MRR targets, launch dates, savings milestones)
4. **Low-ceremony project management** — no sprints, no velocity charts; just a kanban board and a smart inbox

## Frustrations

- **Fragmented attention:** Day job uses Jira; personal uses Apple Reminders; side projects live in GitHub Issues (poorly)
- **Lost momentum:** Every side-project session starts with 20 minutes of "where was I?"
- **No unified goals view:** His OKRs (ship v1 by Q3, save $20K, exercise 3x/week) live in a Google Doc he checks monthly
- **GitHub Issues is not a PM tool:** No personal items, no agent support, no methodology views, no context linking

## Behaviors

- Works on side projects in focused 1-2 hour blocks, 4-5 evenings per week
- Tracks habits in a physical notebook (would switch to digital if it was in the same tool as his tasks)
- Deploys side projects via GitHub Actions; monitors manually (checks logs when he remembers)
- Prefers mobile for personal task capture; desktop for project work
- Watches YouTube productivity content; follows the "building in public" community

## Job to Be Done

> "I need to see my full picture — job commitments, side projects, personal goals — in one place, with AI that keeps my side projects moving even when I can't touch them for a few days."

## Key Scenarios

1. **Evening work session:** Opens Today view on laptop. Planner agent shows: "Side project: 2 issues triaged, 1 PR from coder agent ready for review. Day job: nothing due until Thursday. Personal: gym done, apartment viewing tomorrow at 6pm." Raj reviews the PR and merges.
2. **Mobile capture:** Waiting for coffee, has an idea for the CLI tool. Quick-captures from phone. Item lands in inbox for later triage.
3. **Monthly OKR review:** Planner agent generates: "MRR: $0 (target: $500 by Q3). CLI tool: 60% to v1. Savings: $14K/$20K. Exercise: 2.8x/week (target: 3x)." Raj adjusts priorities.

## Product Implications

- **Free tier is the entry point** — personal todos + 1 project is exactly his starting need
- **Mobile capture is critical** for this persona's workflow
- **Agent "session prep"** (here's where you left off) is a killer feature for intermittent builders
- **No methodology enforcement** — he wants kanban, not sprint ceremonies
- **OKR as life dashboard** is core to retention (emotional investment in the tool)
