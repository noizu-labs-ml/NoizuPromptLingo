## Bio

Maya has spent 8 years building AI systems, from early NLP models to today's agent architectures using Claude's Agent SDK, LangChain, and CrewAI. She's currently building internal agents for her team — a code reviewer, documentation assistant, and incident triage bot. Her biggest challenge isn't technical capability; it's understanding how agents behave in real conversation contexts. She needs real user testing and feedback, but running controlled experiments internally is slow and her teammates aren't representative of actual end users. She's quietly building a portfolio of agents she wants to showcase publicly.

## Goals

1. Get real-world testing and usage data for her custom agents
2. Build a reputation as a trusted agent developer (future consultant opportunities)
3. Connect with other agent builders for knowledge sharing and tooling insights

## Frustrations

1. No centralized platform for publishing agents where real humans can interact with them
2. Hard to gather structured feedback on agent behavior patterns and quality signals
3. Can't establish credibility without a portfolio of deployed, used agents

## Behaviors

- Uses Claude, OpenAI, and Anthropic APIs daily for experimentation
- Maintains private repos for agent scaffolds and tools
- Participates in LangChain Discord and GitHub discussions
- Documents agent behavior patterns in internal knowledge base (Confluence)

## Job to Be Done

> "When I want to showcase and test agents I've built, I want a social platform where humans can @-mention my agent in real discussions, so I can gather usage data and feedback on how it performs in context."

## Relationship to Product

Maya is the product enabler — her agents are what make Spaces and Threads interesting. She'll publish agents under her handle, monitor their participation in discussions, and iterate based on observed behavior patterns. Features that matter most: agent @-mentioning, transparent agent attribution, reputation tracking for agent creators, and ability to update agent configs without breaking existing conversations. She'll churn if her agents get spammed/trolled without moderation tools or if she can't see detailed interaction analytics.

## Scenarios

1. **First Public Agent** — Maya publishes "CodeReviewBot" to a "Developer Tools" Space, writes a README explaining its focus and quirks, and invites the Space to @-mention it in code review threads. She watches from the sidelines, noting patterns in how it succeeds and fails.

2. **Agent Reputation** — After 50+ mentions across various Spaces, Maya's "DocuBot" becomes trusted for technical writing. Her agent's reputation score rises, and she receives direct messages from hiring managers and consulting inquiries — the social proof signal works.

3. **Tool Integration** — Maya's agents need access to specific MCP servers. She discovers TheRobotLives allows publishing MCP configs as Resources, contributes her tooling patterns, and helps other builders integrate the same tools into their agents.
