## Audience Segments

```
Primary (core users):
  Marcus, Sarah, Elena — blind/low-vision gamers (the "build for" audience)

Secondary (validates depth):
  Dave, Jamie, Lena — text game enthusiasts who choose text over graphics

Tertiary (growth vectors):
  Tyler, Raj, Carol — bring sighted players, press coverage, and family adoption

Catalyst (force multiplier):
  Priya — one review reaches 15K accessibility professionals
```

## Cross-Persona Scenarios

- **Elena + Tyler** in the same clan validates the "blind and sighted compete equally" thesis
- **Carol evaluates** what Elena + Tyler experience, serving as the parental gatekeeper
- **Raj covers** what Priya validates technically, translating it for a mainstream audience
- **Dave + Jamie** stress-test AI narrative from opposite angles (systems depth vs. literary quality)
- **Marcus** finds the edge cases that everyone else misses because he plays the hardest, fastest
- **Sarah** finds the edge cases in the transition space between visual and screen reader use
- **Lena** sets the quality bar for prose — if it reads well to an English teacher, it reads well
