# Lena Vasquez — Concept Artist

**Type:** Primary  
**Age:** 33 | **Location:** Los Angeles, CA  
**Occupation:** Concept artist at mid-size game studio  
**Platform:** MacBook Pro M4 Max, Cintiq Pro 27  

> "I need to go from rough to refined fast. Charcoal for blocking, paint for finish — in one tool."

## Goals

- Block out compositions quickly with charcoal/pastel, then paint over with oils or acrylics
- Use mixed media in a single painting (charcoal underdrawing + acrylic finish)
- Produce 3-5 concept variations per day for art director review
- Realistic material transitions (charcoal under acrylic looks different than charcoal under oil)

## Frustrations

- Switching between apps (Photoshop for paint, Procreate for sketch) breaks flow
- No tool handles cross-media interaction (fixative on charcoal, glazing over dried acrylic)
- Performance tanks on 4K canvas with many layers in existing tools
- Can't get the dry-brush-on-textured-canvas effect that concept art relies on

## Usage Context

- Fast iteration: 20-minute thumbnails, 2-hour hero frames
- Works at 4K resolution for production deliverables
- Needs all five media types available simultaneously
- Often works with reference images tiled alongside canvas

## Key Features She'd Use

- Multi-media support (charcoal, pastel, acrylic, oil)
- Cross-media physics (deposition rejection, fixative)
- 4K canvas performance at 60 FPS
- Fast layer management with media-aware compositing

## Design Implications

- Media selector must be fast-access (toolbar or shortcut, not buried in menus)
- Performance at 4K is non-negotiable (~2.5 GB memory budget)
- Layer panel needs media-type indicators per layer
- Must support large canvas sizes without degradation
