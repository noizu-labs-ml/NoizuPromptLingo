# Persona Library Modal

| Field | Value |
|-------|-------|
| **ID** | `persona-library-modal` |
| **Type** | Modal |
| **Category** | Persona Management |
| **User Stories** | US-055 |

## Description

Modal overlay for browsing and importing personas from the built-in starter library. Shows curated personas with name, tone tag, description, and sample preamble.

## Key Components

- **Starter persona list** — Name, tone tag, description, sample system preamble preview
- **Import button** — Deep-copies selected persona into user's org
- **Preview panel** — Full details of selected persona

## Interactions

- Browse starter personas
- Preview full details
- Import into organization (creates independent copy)

## Navigation

- Accessible from: Persona List (Import from Library button)
- Links to: Persona Detail (after import)
