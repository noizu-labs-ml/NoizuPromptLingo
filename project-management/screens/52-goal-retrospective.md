# Goal Retrospective

| Field | Value |
|-------|-------|
| **ID** | `goal-retrospective` |
| **Type** | Primary |
| **Category** | Goals & OKRs |
| **User Stories** | US-075 |

## Description

AI-generated cycle retrospective with quantitative analysis of achievements and misses, pattern recommendations for next cycle, score distributions, and agent ROI analysis.

## Key Components

- **Achievements list** — Goals met or exceeded with contributing factors
- **Misses analysis** — Goals missed with root cause analysis
- **Pattern recommendations** — AI suggestions for next cycle based on patterns
- **Score distributions** — Histogram of scores across all OKRs
- **Agent cost/contribution** — ROI analysis of agent involvement in goal achievement
- **Annotation editor** — Add team reflections and context

## Interactions

- Review AI-generated analysis
- Add team annotations and context
- Accept suggestions for next cycle planning
- Compare with previous cycle retrospectives
- Export for leadership reporting

## Navigation

- Accessible from: Goals nav (end-of-cycle), OKR Scoring (completion)
- Links to: OKR Hierarchy (next cycle), Agent Performance Dashboard
