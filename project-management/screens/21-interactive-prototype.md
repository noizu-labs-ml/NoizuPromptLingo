## Description

Clickable prototype generated from approved mockups with navigation hotspots and animated transitions. Supports public sharing for stakeholder preview.

## Key Components

- **Prototype Canvas** — Mockup with clickable hotspot overlays on nav/buttons/links (INK-037)
- **Hotspot Editor** — Add/remove/re-target clickable regions (INK-037)
- **Transition Animations** — Slide/fade between linked screens (INK-037)
- **Share Link Generator** — Public URL for prototype viewing without auth (INK-037)

## Interactions

- Click hotspots to navigate between mockup screens
- Edit mode: add hotspots by drawing regions, set target screen
- Preview mode: experience as end-user would
- Generate shareable link for external stakeholders

## Navigation

- Accessible from: Mockup Viewer toolbar
- Links to: Export, Share link (external)
