# Organization Usage Dashboard

| Field | Value |
|-------|-------|
| **ID** | `org-usage-dashboard` |
| **Type** | Dashboard |
| **Category** | Organization Management |
| **User Stories** | US-064 |

## Description

Aggregated org-wide metrics: deployment counts, invocation volumes, resource consumption, team activity, plan limit indicators.

## Key Components

- **SummaryMetricCards**
- **InvocationTrendChart**
- **ResourceConsumptionTable**
- **TeamActivityRanking**
- **PlanLimitIndicator**
- **DateRangeSelector**

## Interactions

- Select time window
- Drill down to server analytics
- Export report (CSV/PDF)
- View plan usage vs limits
