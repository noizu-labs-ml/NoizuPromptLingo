# Appearance Settings

| Field | Value |
|-------|-------|
| **ID** | `appearance-settings` |
| **Type** | Settings |
| **Category** | Settings & Preferences |
| **User Stories** | US-083 |

## Description

Theme selection (Bold, Enterprise, Minimal, Nocturne) with live preview swatches.

## Key Components

- **ThemeSelector**
- **ThemePreviewSwatch**

## Interactions

- Select theme
- Instant preview
- Auto-detect dark mode preference

## Navigation

- Settings -> Appearance
