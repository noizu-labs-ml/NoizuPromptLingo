# Prompt Annotations Panel

| Field | Value |
|-------|-------|
| **ID** | `prompt-annotations` |
| **Type** | Modal |
| **Category** | Prompt Archival & Versioning |
| **User Stories** | US-093 |

## Description

Structured annotation form for prompt versions capturing effectiveness notes, failure mode documentation, recommended contexts for use, and author attribution.

## Key Components

- **Annotation form** — Structured fields for effectiveness and context notes
- **Failure mode links** — Link to specific failure examples
- **Context fields** — When to use/not use this prompt version
- **Author attribution** — Who wrote the annotation
- **Search integration** — Annotations searchable in Knowledge Search

## Interactions

- Add annotations to any prompt version
- Link to specific failure examples for context
- Document when to use vs avoid
- Annotations appear in search results
- View all annotations for a prompt version

## Navigation

- Triggered from: Prompt Timeline (annotate action)
- Links to: Prompt Timeline, Knowledge Search
