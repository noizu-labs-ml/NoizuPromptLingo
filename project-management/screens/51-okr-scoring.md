# OKR End-of-Cycle Scoring

| Field | Value |
|-------|-------|
| **ID** | `okr-scoring` |
| **Type** | Storyboard |
| **Category** | Goals & OKRs |
| **User Stories** | US-073 |

## Description

End-of-cycle scoring workflow with AI-suggested scores based on progress data, historical comparison with past cycles, self vs lead assessment views, and calibration analysis.

## Key Components

- **KR score inputs** — Score each key result (0.0–1.0 or custom scale)
- **Auto-suggested values** — AI-suggested scores based on measured progress
- **Historical trend chart** — Scores for this OKR across past cycles
- **Agent analysis panel** — AI commentary on performance factors
- **Self vs lead assessment** — Compare self-assessment with manager view
- **Archive action** — Archive scored OKRs for historical record

## Flow Steps

1. **AI pre-scores** — Agent suggests scores based on data
2. **Self-assess** — Individual scores their own KRs
3. **Lead review** — Manager reviews and adjusts if needed
4. **Calibrate** — Compare assessments and resolve gaps
5. **Archive** — Lock scores and archive the cycle
