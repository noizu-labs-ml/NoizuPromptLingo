# Agent Output Rating (Inline)

| Field | Value |
|-------|-------|
| **ID** | `agent-output-rating` |
| **Type** | Modal |
| **Category** | Agent Evaluation |
| **User Stories** | US-096 |

## Description

Inline thumbs up/down rating widget on every agent output with optional free-text feedback field. Accessible via keyboard shortcut from any screen where agent output is displayed.

## Key Components

- **Thumbs up/down buttons** — Quick binary quality rating
- **Optional feedback field** — Free-text for additional context
- **Keyboard shortcut trigger** — Rate without leaving keyboard flow
- **Context capture** — Automatically captures what was rated and its context

## Interactions

- Rate agent output with one click or keyboard shortcut
- Optionally add text feedback
- Rating and context automatically captured
- Aggregated ratings feed into Eval Dashboard
- Rating appears inline on agent output

## Navigation

- Triggered from: Any agent output display (inline widget)
- Feeds into: Eval Dashboard, Agent Performance Dashboard
