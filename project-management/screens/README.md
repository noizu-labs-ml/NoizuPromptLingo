## Screen Types

- **primary** — Full-page views accessible from main navigation
- **dashboard** — Aggregation/metrics views with charts and cards
- **settings** — Configuration panels (typically under a settings section)
- **modal** — Overlays/dialogs triggered from other screens
- **storyboard** — Multi-step flows/wizards with sequential progression
