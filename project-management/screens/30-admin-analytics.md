# Admin Analytics Dashboard

| Field | Value |
|-------|-------|
| **ID** | `admin-analytics` |
| **Type** | Dashboard |
| **Category** | Admin & Moderation |

## Description

Platform-wide aggregate metrics: total servers, invocations, latency, error rates, resource utilization across the fleet.

## Key Components

- **AggregateMetricCards**
- **FleetTimeSeriesChart**
- **ErrorHotspotDrilldown**
- **TimeRangeSelector**
- **ExportButton**

## Interactions

- Select time range
- Drill into anomalies
- Filter by org/status/surface
- Export data
