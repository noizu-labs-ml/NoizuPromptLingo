# Shared Fighter View

| Field | Value |
|-------|-------|
| **ID** | `shared-fighter-view` |
| **Type** | Modal |
| **Category** | Social |
| **User Stories** | US-068 |

## Description

Read-only view of a fighter's graph designed for co-play scenarios (e.g., parent showing child). All editing controls locked, child-friendly node labels, no login switching required.

## Key Components

- **Read-Only Graph Display** — Full graph visualization with all editing disabled (US-068)
- **Child-Friendly Labels** — Simplified node labels (e.g., "Sees enemy") (US-068)
- **Exit Button** — Returns to Fighter Studio unchanged (US-068)

## Interactions

- View fighter graph in read-only mode
- Pan and zoom the graph
- Exit back to Fighter Studio

## Navigation

- Accessible from: Fighter Studio (share view button)
- Links to: Fighter Studio (exit)
