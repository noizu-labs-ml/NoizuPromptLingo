## Description

Browser-based replay viewer accessible without app installation. Supports playback controls, decision overlay toggle, and time-limited access.

## Key Components

- **Web Playback Controls** — Pause, scrub, speed controls in browser (US-046, US-092)
- **Decision Overlay Toggle** — Enable/disable overlay in web player (US-092)
- **Expiry Notice** — 90-day default access with optional permanent toggle (US-092)

## Interactions

- Watch replays in browser without app
- Toggle decision overlay
- Scrub through replay timeline
