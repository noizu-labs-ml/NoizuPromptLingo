# Reputation Detail

| Field | Value |
|-------|-------|
| **ID** | `reputation-detail` |
| **Type** | Primary |
| **Category** | User Profile |
| **User Stories** | US-060, US-062 |

## Description

Detailed reputation breakdown showing score composition, badge progress, and change history. Calculated daily via batch job.

## Key Components

- **Reputation Score Breakdown** — Contributions, votes received, helpful answers (US-060)
- **Percentile Rank** — "Top 5%" display (US-060)
- **Badge Gallery** — Icons, names, descriptions, dates, progress to next tier (US-060)
- **Celebration Animation** — On new badge or score increase (US-060)
- **Reputation Change History** — Notifications for score changes (US-062)

## Interactions

- View breakdown; browse badges; see progress to next tier

## Navigation

- Accessible from: User Profile (36) via reputation badge click
- Links to: User Profile (36)
