# User Settings

| Field | Value |
|-------|-------|
| **ID** | `user-settings` |
| **Type** | Settings |
| **Category** | User Settings |
| **User Stories** | US-006, US-010, US-012, US-017, US-019, US-082 |

## Description

Central settings screen for user preferences spanning capture shortcuts, notification channels, calendar integrations, habit defaults, review schedules, and display preferences. Aggregates settings that appear across multiple features.

## Sections

### General
- **Display name and avatar** — User identity
- **Timezone** — For scheduling and deadlines
- **Theme** — Light/dark/system mode
- **Language** — Interface language

### Capture & Input
- **Quick capture shortcut** — Configure global keyboard shortcut (US-006)
- **Voice capture language** — Speech-to-text language preference (US-010)
- **Default inbox behavior** — Where captured items go by default

### Notifications
- **Notification channels** — Enable/disable in-app, email, Slack, mobile push
- **Agent notification preferences** — Per-category notification rules (US-082)
- **Digest frequency** — Daily/weekly notification digest settings
- **Quiet hours** — Suppress notifications during specified hours

### Calendar & Scheduling
- **Calendar integration** — Connect Google/Outlook calendars (US-017)
- **Time blocking defaults** — Default block duration, working hours
- **Morning planning trigger** — Auto-show or manual trigger

### Habits & Reviews
- **Default habit schedule** — Default days/frequency for new habits (US-012)
- **Weekly review day** — Which day to generate weekly review (US-019)
- **Streak grace period default** — Default grace period for new habits

### Integrations
- **Connected accounts** — OAuth connections (calendar, email, Slack)
- **API keys** — Personal API key management
- **Webhook endpoints** — Personal webhook URLs

## Navigation

- Accessible from: User avatar menu, Main nav (settings)
- Links to: Agent Notification Settings, Calendar integration, Connected accounts
