# Wireframe Gallery

| Field | Value |
|-------|-------|
| **ID** | `wireframe-gallery` |
| **Type** | Primary |
| **Category** | Draft Phase |
| **User Stories** | INK-028, INK-031 |

## Description

AI generates wireframes from accepted user stories, mapping each story to a screen layout. Displays wireframes in a gallery with story cross-references and responsive variant toggles.

## Key Components

- **Wireframe Grid** — Gallery of generated wireframe thumbnails linked to user stories (INK-028)
- **Story Mapping Labels** — Per-wireframe tag showing which user story it implements (INK-028)
- **Viewport Toggle** — Desktop/Tablet/Mobile (1280/768/375px) variant switcher (INK-031)
- **Breakpoint Notes** — Per-wireframe responsive reflow annotations (INK-031)

## Interactions

- Click wireframe thumbnail to open in Wireframe Editor
- Viewport toggle shows responsive variants inline
- Story labels link back to Story Curation
- Regenerate button per wireframe

## Navigation

- Accessible from: Style Guide Revision completion
- Links to: Wireframe Editor, Navigation Flow Diagram
