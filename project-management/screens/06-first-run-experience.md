# First Run Experience

| Field | Value |
|-------|-------|
| **ID** | first-run-experience |
| **Type** | Dashboard |
| **Category** | Onboarding |
| **User Stories** | US-005 |

## Description

Empty state screen for new users with no universes, featuring guided onboarding.

## Key Components

- **Hero CTA** — Prominent "Create Your First Universe" button (US-005)
- **Workflow Summary Cards** — 3-step journey: Create → Write → Explore (US-005)
- **Empty State Illustration** — Visual showing what's possible (US-005)
- **Sidebar CTA** — Minimal version persists until first universe (US-005)
- **Tour Offer Banner** — Optional guided tour invitation (US-007)

## Interactions

- Displays when user has zero universes
- Hero CT A starts Universe Creation Wizard
- Dismissible CTA persists in sidebar until first universe
- Once universe created, replaced by actual dashboard content
- Tour banner appears after first universe creation

## Navigation

- Accessible from: Post-profile-setup
- Links to: Universe Creation Wizard, Onboarding Tour (optional)
