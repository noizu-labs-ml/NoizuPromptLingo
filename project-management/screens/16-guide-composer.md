# Guide Composer

| Field | Value |
|-------|-------|
| **ID** | `guide-composer` |
| **Type** | Primary |
| **Category** | Community |
| **User Stories** | US-025 |

## Description

Rich text editor for authoring and publishing build guides with inline images and attached graph JSON. Published guides appear in the Laboratory.

## Key Components

- **Rich Text Editor** — Text editor with inline image embedding (US-025)
- **Graph JSON Attachment** — Attach fighter graph, version-locked at publish time (US-025)
- **Publish Controls** — Publish to Laboratory with archetype/rank tagging (US-025)

## Interactions

- Write and format guide content
- Embed images and attach fighter graphs
- Preview before publishing
- Publish to Laboratory

## Navigation

- Accessible from: Laboratory, Creator Dashboard
- Links to: Laboratory (published view), Creator Dashboard
