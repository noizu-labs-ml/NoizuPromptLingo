## Description

Searchable history of completed and archived items. Full-text search, date and project filters, and restore capability. Provides completion statistics and trends.

## Key Components

- **Search bar** — Full-text search across all archived items
- **Filter panel** — Filter by project, date range, item type, tags
- **Item list with metadata** — Archived items showing completion date, project, tags
- **Restore action** — Move item back to active state
- **Bulk actions** — Multi-select for bulk restore or permanent delete
- **Completion stats** — Summary metrics (items completed this week/month/year)

## Interactions

- Search with instant results
- Filter narrows visible items
- Click to view archived item detail
- Restore returns item to its source list/project
- Permanent delete available (with confirmation)

## Navigation

- Accessible from: Main nav, "View Archive" from any list
- Links to: Item detail, source project/list
