# Prompt Template Library

| Field | Value |
|-------|-------|
| **ID** | `prompt-template-library` |
| **Type** | Primary |
| **Category** | Prompt Archival & Versioning |
| **User Stories** | US-091, US-092 |

## Description

Shared prompt templates organized by category with fork capability, sharing with permission controls, upstream update indicators, and usage notes.

## Key Components

- **Template list** — All shared prompt templates with metadata
- **Category tabs** — Organize by task type (triage, review, analysis, etc.)
- **Fork action** — Create personal copy of a shared template
- **Share dialog** — Share with specific users/teams with permission levels
- **Permission levels** — View, use, edit, admin per template
- **Upstream update indicator** — Badge when the source template has been updated
- **Usage notes** — Community notes on template effectiveness

## Interactions

- Browse templates by category
- Fork to create personal copy
- Share with granular permissions
- Get notified when upstream template updates
- Merge upstream changes into forked copy
- Add usage notes and tips

## Navigation

- Accessible from: Prompt management nav, Agent configuration
- Links to: Prompt Timeline, Agent settings
