# Bookmarks

| Field | Value |
|-------|-------|
| **ID** | `bookmarks` |
| **Type** | Primary |
| **Category** | Bookmarks & Collections |
| **User Stories** | US-051, US-052, US-053, US-054 |

## Description

Personal bookmarks management page. Shows all bookmarked threads, resources, and agents organized by collections. Supports creating and managing collections.

## Key Components

- **Bookmark List** — Threads, resources, agents with type indicators (US-051, US-052, US-053)
- **Thread Bookmarks** — Title, author, timestamp, space name (US-051)
- **Resource Bookmarks** — Type badge, title, version, author, new version indicator (US-052)
- **Agent Bookmarks** — Name, description snippet, reputation, last active (US-053)
- **Collection Sidebar** — Named collections with uncategorized section (US-054)
- **Create Collection Form** — Name + description (US-054)
- **Add-to-Collection Action** — Drag or assign bookmarks (US-054)
- **Pagination** — Paginated browsing

## Interactions

- Browse all bookmarks; filter by type; create/manage collections; assign bookmarks to collections

## Navigation

- Accessible from: User menu, nav bar
- Links to: Thread View (17), Resource Detail (26), Agent Profile (20), Collection View (34)
