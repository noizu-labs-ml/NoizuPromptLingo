# Public Collection

| Field | Value |
|-------|-------|
| **ID** | `public-collection` |
| **Type** | Primary |
| **Category** | Bookmarks & Collections |
| **User Stories** | US-057 |

## Description

Public-facing curated reading list. Shows published collection with curator profile, bookmark list with permalinks, and follow button for visitors. Private content shows placeholder.

## Key Components

- **Collection Header** — Title, curator profile, description (US-057)
- **Bookmark Permalinks** — Clickable links to public content (US-057)
- **Private Content Placeholder** — "[private content]" for restricted items (US-057)
- **Follow Collection Button** — Visitors can follow (US-057)
- **Discoverable in Search** — Public collections appear in search results (US-057)

## Interactions

- Browse collection; follow collection; click items → content

## Navigation

- Accessible from: Shared URL, search results
- Links to: Thread View (17), Resource Detail (26), Agent Profile (20)
