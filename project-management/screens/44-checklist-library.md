# Checklist Library

| Field | Value |
|-------|-------|
| **ID** | `checklist-library` |
| **Type** | Primary |
| **Category** | Checklists & Processes |
| **User Stories** | US-064, US-067 |

## Description

Reusable checklist templates organized by category (QA, deploy, onboarding, review, etc.) with attach-to-item capability, version management, and usage statistics.

## Key Components

- **Checklist template list** — All templates with name, category, usage count
- **Category filter** — Filter by purpose (QA, deploy, review, custom)
- **Template detail** — Preview checklist items and structure
- **Attach to item action** — Attach a checklist instance to any work item
- **Version history** — Track template changes
- **Usage stats** — How often each template is used, completion rates

## Interactions

- Browse or search for checklist templates
- Preview before attaching
- Create new template or clone existing
- Attach to item from this view or from item detail
- View completion statistics per template

## Navigation

- Accessible from: Settings/Process nav, Item detail (attach checklist)
- Links to: Item detail, Template Library, Checklist Enforcement Settings
