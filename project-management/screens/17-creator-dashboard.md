# Creator Dashboard

| Field | Value |
|-------|-------|
| **ID** | `creator-dashboard` |
| **Type** | Dashboard |
| **Category** | Creator |
| **User Stories** | US-025, US-084, US-094 |

## Description

Dashboard for content creators showing guide/build metrics, affiliate program management, and public profile configuration.

## Key Components

- **Content Metrics** — View counts, saves, comments for published guides and builds (US-025)
- **Affiliate Program Panel** — Application form, referral code, installs/conversions/pending rewards (US-084)
- **Public Profile Controls** — Per-section visibility toggles for public profile (US-094)
- **Published Content List** — All guides and builds with edit/delete actions (US-025)

## Interactions

- View metrics across all published content
- Apply for and manage affiliate program
- Configure public profile visibility
- Edit or manage published content

## Navigation

- Accessible from: Profile, Laboratory
- Links to: Guide Composer, Laboratory, Public Profile
