# Public Profile

| Field | Value |
|-------|-------|
| **ID** | `public-profile` |
| **Type** | Primary |
| **Category** | Social |
| **User Stories** | US-094 |

## Description

Public-facing player profile page at aifighter.com/u/{username} showing ranked stats, top builds, and recent replays. Configurable via Creator Dashboard.

## Key Components

- **Ranked Stats Display** — Tier badge, W/L record (US-094)
- **Top Builds Showcase** — Top 3 fighter builds with previews (US-094)
- **Recent Replays List** — Last 5 replay cards linking to web viewer (US-094)
- **Visibility Controls** — Per-section toggles (owner-only) (US-094)

## Interactions

- View player's ranked stats and top builds
- Watch recent replays via web viewer
- Owner can toggle section visibility

## Navigation

- Accessible from: Laboratory (creator credit), Leaderboard, Direct URL
- Links to: Battle Replay Viewer (web), Laboratory builds
