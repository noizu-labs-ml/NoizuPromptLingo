# Season Summary

| Field | Value |
|-------|-------|
| **ID** | `season-summary` |
| **Type** | Primary |
| **Category** | Competitive |
| **User Stories** | US-048 |

## Description

End-of-season reward summary showing peak rank, final ELO, record, cosmetics earned, and exportable summary card. Historical archive of past seasons.

## Key Components

- **Season Summary Card** — Peak rank, final ELO, W/L record, cosmetics earned (US-048)
- **Summary Export** — PNG export at 1080x1080 for social sharing (US-048)
- **Past Seasons Archive** — Scrollable list of previous season summaries (US-048)

## Interactions

- View current/past season summaries
- Export summary as shareable image
- Browse historical season data

## Navigation

- Accessible from: Ranked Arena, Profile
- Links to: Profile, Cosmetic Collection
