# Documentation Health Dashboard

| Field | Value |
|-------|-------|
| **ID** | `docs-health-dashboard` |
| **Type** | Dashboard |
| **Category** | Documentation & Wiki |
| **User Stories** | US-060 |

## Description

Overall documentation freshness scores, coverage gap analysis, stale document alerts, trend over time, and automatic review task creation for outdated content.

## Key Components

- **Freshness score** — Aggregate documentation freshness percentage
- **Coverage gap list** — Areas of code/features without documentation
- **Stale docs queue** — Documents flagged as potentially outdated
- **Trend chart** — Documentation health over time
- **Review task creation** — Create work items to update stale docs

## Interactions

- Click stale docs to navigate and review
- Create tasks directly from gap/stale lists
- Configure staleness thresholds
- View trends to track documentation investment
- Assign review tasks to team members

## Navigation

- Accessible from: Documentation nav, Portfolio Dashboard
- Links to: Wiki pages (stale docs), Task creation, Documentation settings
