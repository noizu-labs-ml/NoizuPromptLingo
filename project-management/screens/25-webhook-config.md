# Webhook Configuration

| Field | Value |
|-------|-------|
| **ID** | `webhook-config` |
| **Type** | Settings |
| **Category** | Settings & Preferences |
| **User Stories** | US-100 |

## Description

Create and manage webhook endpoints for real-time tool invocation events. View delivery log and retry status.

## Key Components

- **WebhookCreationForm**
- **EventTypeSelector**
- **WebhookList**
- **DeliveryLogTable**
- **SecretDisplay**

## Interactions

- Create webhook with event subscriptions
- Set signing secret
- View delivery history
- Retry failed deliveries

## Navigation

- Settings -> Webhooks
