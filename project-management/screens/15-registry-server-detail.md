## Description

Detailed public-facing page for an MCP server: tool schemas, version history, compatibility matrix, health chart, trust score breakdown, reviews, share options, star/favorite.

- **ServerHeader**
- **ToolSchemaTree**
- **VersionHistoryTimeline**
- **CompatibilityMatrix**
- **HealthTimeSeriesChart**
- **TrustScoreBreakdown**
- **ReviewsList**
- **ReviewForm**
- **StarButton**
- **ShareMenu**
- **DeprecationBanner**
- **AccessRequestButton**
- **ReportButton**
- **IntegrationSnippets**
- **VerifiedBadge**

## Interactions

- Expand tool schemas
- Browse version history
- View compatibility matrix
- Star/unstar server
- Write/edit review
- Share link/embed
- Request access (private)
- Report server
- Copy integration snippet
