# Content Moderation Queue

| Field | Value |
|-------|-------|
| **ID** | `content-moderation-queue` |
| **Type** | Dashboard |
| **Category** | Moderation |
| **User Stories** | US-035, US-079 |

## Description

Moderation queue for reviewing flagged content (builds, guides, community cosmetics). Shows categorized reports and enables approve/reject decisions.

## Key Components

- **Report Queue List** — Flagged items with report category and count (US-035)
- **Report Detail Panel** — Original content, report reasons, reporter info (US-035)
- **Moderation Actions** — Approve/reject with notification to reporter and content owner (US-035)
- **Moderation Status Badges** — Pending/Approved/Rejected badges on community submissions (US-079)
- **Content Rating Tags** — Classification tags on moderated content (US-079)

## Interactions

- Review flagged content
- View report details and categorization
- Approve or reject content
- View moderation history

## Navigation

- Accessible from: Admin menu
- Links to: Laboratory (source content), User profiles
