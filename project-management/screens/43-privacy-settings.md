## Description

Privacy configuration panel. Controls profile visibility, information sharing, and follower permissions with immediate effect and cached data invalidation.

## Key Components

- **Profile Visibility Toggle** — Public / Logged-in-only (US-073)
- **Show Join Date Toggle** — (US-073)
- **Show Reputation Toggle** — (US-073)
- **Show Spaces List Toggle** — (US-073)
- **Allow Following Toggle** — (US-073)
- **Restricted Profile Notice** — Displayed on profile when restricted (US-073)

## Interactions

- Toggle privacy settings; changes take effect immediately with 5-min cache invalidation
