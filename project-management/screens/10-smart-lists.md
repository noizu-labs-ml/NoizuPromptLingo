## Description

Auto-filtered views defined by rule combinations over tags, status, dates, projects, and custom fields. Smart lists update dynamically — they are saved queries, not static collections.

## Key Components

- **Rule builder** — Visual query builder with field/operator/value rows
- **AND/OR logic nesting** — Combine rules with boolean operators
- **Live item list** — Real-time results matching current rules
- **Save as smart list action** — Persist query as a named list
- **Sidebar entry** — Saved smart lists appear in navigation sidebar

## Interactions

- Build rules visually (no query language needed)
- Preview results in real-time as rules change
- Save to sidebar for quick access
- Edit rules of existing smart lists
- Share smart list definitions with team

## Navigation

- Accessible from: Main nav sidebar, "Create Smart List" action
- Links to: Item detail, Project views
