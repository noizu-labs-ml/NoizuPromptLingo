# Prompt Version Comparison

| Field | Value |
|-------|-------|
| **ID** | `prompt-comparison` |
| **Type** | Primary |
| **Category** | Prompt Archival & Versioning |
| **User Stories** | US-089 |

## Description

Side-by-side diff of two selected prompt versions with performance delta metrics (eval scores, error rates, user ratings) and auto-generated impact summary.

## Key Components

- **Side-by-side diff** — Two versions displayed with additions/deletions highlighted
- **Performance metrics panel** — Score comparison for both versions
- **Auto-generated summary** — AI-written summary of what changed and its impact
- **Version selector** — Pick any two versions to compare
- **Export report action** — Export comparison as PDF/markdown

## Interactions

- Select two versions to compare
- View diff with syntax highlighting
- Review performance impact of changes
- Export comparison for review meetings
- Navigate to either version's full timeline

## Navigation

- Accessible from: Prompt Timeline (compare action)
- Links to: Prompt Timeline, Eval Dashboard
