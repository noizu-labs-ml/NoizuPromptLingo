# Settings

| Field | Value |
|-------|-------|
| **ID** | `settings` |
| **Type** | Settings |
| **Category** | System |
| **User Stories** | US-020, US-054, US-066, US-074, US-080 |

## Description

Application settings including accessibility options (color vision modes, reduced motion, haptic feedback), family-friendly content mode, and AI model documentation access.

## Key Components

- **Color Vision Mode Selector** — Default/Deuteranopia/Protanopia/Tritanopia/High Contrast (US-020)
- **Reduced Motion Toggle** — Disables animations, enables crossfades and frame-step views (US-074)
- **Haptic Battle Feedback Toggle** — Enables haptic-only battle feedback patterns (US-080)
- **Family Mode Toggle** — PIN-protected toggle for content filtering (US-066)
- **AI Model Documentation Link** — Navigation to technical model documentation page (US-054)

## Interactions

- Select color vision mode
- Toggle reduced motion
- Toggle haptic feedback
- Enable/disable family mode with PIN
- Navigate to AI model documentation

## Navigation

- Accessible from: Home (settings icon), any screen via global nav
- Links to: AI Model Documentation, Accessibility Help
