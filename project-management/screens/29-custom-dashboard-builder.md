# Custom Dashboard Builder

| Field | Value |
|-------|-------|
| **ID** | `custom-dashboard-builder` |
| **Type** | Dashboard |
| **Category** | Results & Dashboards |
| **User Stories** | US-130 |

## Description

Drag-and-drop dashboard editor for assembling custom metric views from a palette of widgets. Dashboards are org-scoped and shareable by URL.

## Key Components

- **Widget palette** — Trend chart, heatmap, cohort table, run list, metric card widgets
- **Grid canvas** — Drag-drop layout area
- **Widget config** — Per-widget filter configuration (script, agent, persona, date range)
- **Save/Publish** — Save dashboard with name
- **Clone action** — Duplicate existing dashboard

## Interactions

- Drag widgets from palette to grid
- Configure each widget with filters
- Rearrange and resize widgets
- Save and share by URL
- Clone existing dashboards

## Navigation

- Accessible from: Global sidebar (Dashboards section)
- Links to: Run Detail (from widget drill-through), Run List (from list widgets)
