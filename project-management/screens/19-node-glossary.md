# Node Glossary

| Field | Value |
|-------|-------|
| **ID** | `node-glossary` |
| **Type** | Modal |
| **Category** | Education |
| **User Stories** | US-031 |

## Description

In-app glossary panel providing definitions, analogies, and external links for each node type. Searchable and browseable by category.

## Key Components

- **Glossary Entry** — Definition, analogy, external learning link per node (US-031)
- **Category Browser** — Browse by Perception/Decision/Action/Training (US-031)
- **Search Bar** — Full-text search across glossary entries (US-031)
- **Assigned Reading Flag** — Educator-set flag indicating required reading (US-031)

## Interactions

- Open from info icon on any node in Fighter Studio
- Search glossary entries
- Browse by category
- Follow external learning links

## Navigation

- Accessible from: Fighter Studio (node info icon), Education Portal
- Links to: External learning resources
