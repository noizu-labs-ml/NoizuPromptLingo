# Publisher Dashboard

| Field | Value |
|-------|-------|
| **ID** | `publisher-dashboard` |
| **Type** | Dashboard |
| **Category** | Social & Publishing |
| **User Stories** | US-057, US-072, US-074 |

## Description

Publisher-specific view showing published servers, usage statistics, adoption funnel, verification status, and publishing wizard.

## Key Components

- **PublishedServerList**
- **UsageStatisticsChart**
- **AdoptionFunnelChart**
- **VerificationStatusCard**
- **PublishWizard**

## Interactions

- View per-server analytics
- Publish new server to registry
- Toggle visibility (listed/unlisted)
- Request verification
- Export usage data

## Navigation

- Dashboard -> Publisher Dashboard
