# Team Management

| Field | Value |
|-------|-------|
| **ID** | `team-management` |
| **Type** | Settings |
| **Category** | Organization |
| **User Stories** | US-089 |

## Description

Organization member management panel for org admins. Supports inviting via email, role assignment, and revocation.

## Key Components

- **Member List** — Current org members with roles (US-089)
- **Invite Member Form** — Email input, role selector (Member/Admin/Editor) (US-089)
- **Invitation Email System** — Automated invite emails (US-089)
- **Revocation Confirmation** — Remove member with confirmation (US-089)
- **Duplicate Invite Error** — Prevent re-inviting existing members (US-089)

## Interactions

- Invite members; assign roles; revoke access; manage invitations

- Accessible from: Organization Profile (44) for admins
- Links to: User Profile (36)
