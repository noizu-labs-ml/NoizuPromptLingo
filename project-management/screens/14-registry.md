# Registry Search & Browse

| Field | Value |
|-------|-------|
| **ID** | `registry` |
| **Type** | Primary |
| **Category** | Registry & Discovery |
| **User Stories** | US-051, US-052, US-053, US-099 |

## Description

Global MCP registry with keyword search, category browsing, and faceted filtering. Shows server cards with health, trust score, and category badges.

## Key Components

- **GlobalSearchBar**
- **CategoryGrid**
- **ServerCardList**
- **FacetedFilterPanel**
- **InfiniteScrollLoader**
- **SearchHighlighter**

## Interactions

- Keyword search with instant results
- Browse by category
- Apply metadata filters
- Infinite scroll pagination
- Click server card for detail

## Navigation

- Global nav -> Registry -> Server Detail Page
