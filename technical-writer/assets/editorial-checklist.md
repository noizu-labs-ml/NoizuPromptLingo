## Pass 1: Structural (Organization & Flow)

- [ ] Opening answers "what is this?" within first 3 lines
- [ ] Sections in logical order for the reader's journey
- [ ] No missing sections for the doc type
- [ ] No redundant or repeated content
- [ ] Progressive disclosure: simple before complex
- [ ] Headers are descriptive (scanning headers tells the story)
- [ ] Every section earns its place
- [ ] Appropriate length for the content
- [ ] Cross-references point to real content

**Notes:** _______________

---

## Pass 2: Accuracy (Technical Correctness)

- [ ] Code examples run without modification
- [ ] CLI flags match `--help` output
- [ ] File paths exist
- [ ] URLs resolve
- [ ] Version numbers are current
- [ ] Environment assumptions stated
- [ ] Output examples match actual output
- [ ] Error messages are real (not invented)
- [ ] API endpoints match implementation
- [ ] Configuration keys are valid

**Notes:** _______________

---

## Pass 3: Clarity (Readability)

- [ ] Every sentence understood on first read
- [ ] Jargon defined on first use
- [ ] No ambiguous pronouns
- [ ] Active voice throughout
- [ ] Answers front-loaded in paragraphs
- [ ] Short paragraphs (3-4 sentences max)
- [ ] Scannable structure (headers, bullets, tables)
- [ ] Examples for every concept
- [ ] No unnecessary words
- [ ] Concrete values, not "configure appropriately"
- [ ] No "simply," "just," "easily," "obviously"

**Notes:** _______________

---

## Pass 4: Consistency (Terminology & Formatting)

- [ ] Same term for same concept throughout
- [ ] Consistent capitalization
- [ ] Consistent code fence style and language tags
- [ ] Consistent list style (all bullets or all numbers)
- [ ] Correct header hierarchy (no skipped levels)
- [ ] Voice matches context
- [ ] Tense consistency (present tense for current behavior)
- [ ] Formatting conventions followed (bold, code, italic)

**Notes:** _______________

---

## Pass 5: Mechanics (Grammar & Polish)

- [ ] No spelling errors
- [ ] Grammar correct
- [ ] Punctuation consistent
- [ ] Markdown renders correctly
- [ ] No trailing whitespace
- [ ] Blank lines around fences, headers, lists
- [ ] All links work (internal and external)
- [ ] Images have alt text (if present)
