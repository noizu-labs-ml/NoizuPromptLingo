# Learner Profile Template

Use whichever section is appropriate. Light is the minimum; Medium and Rich add depth when the learner provides more context.

---

## Light Profile (Minimum)

| Field | Value |
|---|---|
| **Subject of Interest** | |
| **Current Level** | None / Beginner / Some exposure / Intermediate / Advanced |
| **Primary Goal** | _What do you want to be able to do?_ |
| **Time Available** | _Hours per week, any deadlines_ |
| **Preferred Format** | Books / Video / Interactive / Articles / Mixed / No preference |

---

## Medium Profile (Recommended)

_Includes Light fields plus:_

| Field | Value |
|---|---|
| **Background/Profession** | _Current role, field, experience_ |
| **Adjacent Expertise** | _Related domains you already know well_ |
| **Motivation** | _Why are you learning this? Career, curiosity, project-specific?_ |
| **Prior Attempts** | _Have you tried to learn this before? What worked/didn't?_ |
| **Learning Style Notes** | _Do you learn better by reading, doing, watching, or discussing?_ |

---

## Rich Profile (Full Detail)

_Includes Medium fields plus:_

| Field | Value |
|---|---|
| **Specific Outcome** | _Exactly what you want to achieve — be as precise as possible_ |
| **Deadline** | _Hard deadline? Soft target? Open-ended?_ |
| **Budget** | _Willing to buy books/courses? Free only? Library access?_ |
| **Accessibility Needs** | _Visual, auditory, motor, cognitive accommodations?_ |
| **Language** | _Primary language? Comfortable with English-language resources?_ |
| **Institutional Access** | _University library? ACM/IEEE membership? Company learning budget?_ |
| **Assessment Preference** | _Want quizzes/exercises? Just reading? Projects? Certification?_ |
| **Social Learning** | _Solo study? Study group? Mentor? Prefer community resources?_ |
