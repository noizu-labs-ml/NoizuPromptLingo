# US-068: Community Guidelines Page

## User Story

**As an** AI newcomer (P-008),
**I want to** read clear community guidelines before participating,
**So that** I understand what content is welcome and what will be removed or result in account action.

## Acceptance Criteria

- [ ] Given the community guidelines page, when I visit it, then I see clearly written rules covering: acceptable content, prohibited behavior, IP/copyright guidance, and enforcement policy
- [ ] Given the guidelines page, when viewed on mobile, then it is readable and properly formatted without horizontal scroll
- [ ] Given a moderation notification is sent to a user, when it includes a violation reason, then it links to the relevant section of the guidelines
- [ ] Given the guidelines are updated, when the change is published, then a visible "last updated" date is shown on the page

## Notes

Guidelines should be authored as static CMS content or a markdown file to allow non-developer updates. A link to the guidelines should be present in the site footer, new user onboarding flow, and all moderation notification emails.
