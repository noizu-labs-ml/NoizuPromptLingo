# Data Model

## VolumeLayer (32 bytes, all FP16)

Swift struct (`Models/VolumeLayer.swift`) mirrored byte-for-byte in MSL (`Shaders/ShaderHeader.swift`).

| Field | Type | Purpose |
|-------|------|---------|
| color_r/g/b | half | Absorption color (not reflectance) |
| color_o | half | Opacity |
| depth | half | Paint thickness (drives impasto normals) |
| wetness | half | Current moisture level |
| viscosity | half | Flow resistance |
| hardness | half | Dried/cured state |
| velocity_x/y | half | Flow direction |
| surface_tension | half | Cohesion force |
| age | half | Time since deposition |
| gloss | half | Specular intensity |
| substance_type | half | Medium identifier |
| flags | half | Bitfield (reserved) |
| _padding | half | Alignment to 32 bytes |

## Buffer Layout

Layer-major: `buffer[pixelIndex + layer * (width * height)]`

- 8 layers per pixel -> 256 bytes per pixel
- 1080p (2048x1536): ~563 MB volume buffer
- 4K: ~2.5 GB

## Supporting Structs

| Struct | Size | Purpose |
|--------|------|---------|
| SimParams | 16B | Canvas dimensions, layer count, timestep |
| RenderParams | 12B | Canvas dimensions, layer count |
| LightParams | 16B | Light direction vector + ambient intensity |
| ViewParams | 40B | Zoom, pan, rotation, canvas/drawable dimensions |

## Canvas Properties Texture

`rgba16Float` at canvas resolution. Procedurally generated by `canvasInit` kernel.

| Channel | Property | Range |
|---------|----------|-------|
| R | Absorbency | 0-1 |
| G | Roughness | 0-1 |
| B | Porosity | 0-1 |
| A | Sizing | 0-1 |
