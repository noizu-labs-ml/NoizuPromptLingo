# US-062: Session-Resumable Fighter Studio

**As a Dad Gamer,** I want the Fighter Studio to auto-save my graph edits every few seconds so that I can close the app instantly without losing work.

**Acceptance Criteria:**
- Edits are persisted locally and synced to server within 5 seconds of any change
- On relaunch, the Studio opens to the last edited fighter graph, not a home screen
- A visual indicator shows "Saved" / "Saving" in the top bar
- No explicit "Save" action is required from the user

**Priority:** Must
