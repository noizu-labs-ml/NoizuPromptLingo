# US-020: Use the App Comfortably With Color Vision Deficiency

As a **Tinkerer** (and any player), I want colorblind-safe palette options for heatmaps and decision overlays so that the visual data is interpretable regardless of color vision.

**Acceptance Criteria:**
- Settings includes a Color Vision Accessibility option with modes: Default, Deuteranopia, Protanopia, Tritanopia, and High Contrast
- Selected mode applies consistently to all heatmap, overlay, and graph editor color coding throughout the app
- In colorblind modes, pattern fill (hatching, dots) supplements color to encode data for users who cannot distinguish hues
- The selected mode persists across sessions and syncs across devices linked to the same account

**Priority:** Should
