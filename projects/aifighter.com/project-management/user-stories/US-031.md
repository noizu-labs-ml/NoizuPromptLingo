# US-031: Node Concept Glossary Integration

**As an Educator,** I want each node type in the graph editor to link to a plain-language glossary entry explaining the underlying neural network concept so that students learn vocabulary while building without needing a separate reference.

**Acceptance Criteria:**
- Every node type has an info icon that opens an in-app glossary panel without navigating away
- Glossary entries include: plain-language definition, a real-world analogy, and a "learn more" link to a curated external resource (e.g., 3Blue1Brown, Wikipedia)
- Glossary is searchable by term and browsable by category (Perception, Decision, Action, Training)
- Educator can flag glossary entries as "assigned reading" within their classroom, adding a visual indicator on the node

**Priority:** Should
