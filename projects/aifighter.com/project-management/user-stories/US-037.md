# US-037: Archetype Comparison Side-by-Side View

**As a Creator-Spectator,** I want to open two builds in a split-screen comparison view showing their node graphs side by side with win rate differentials highlighted so that I can illustrate matchup analysis in my build guides visually.

**Acceptance Criteria:**
- Comparison view is accessible from any two build cards in the Laboratory by selecting "Compare"
- Side-by-side layout displays both graphs at the same zoom level with shared node types color-synced
- Win rate differential between the two builds (head-to-head and vs. meta) is displayed below each graph
- Comparison view can be exported as a single wide image for use in content

**Priority:** Could
