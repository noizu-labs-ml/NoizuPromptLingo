# US-046: Replay Export for Content Creation

As a **Competitive Grinder**, I want to export battle replays as MP4 or shareable link with decision overlays rendered in, so that I can post breakdown videos to YouTube and TikTok without needing third-party screen capture.

**Acceptance Criteria:**
- Export option available on any replay; produces MP4 at 1080p/30fps
- Decision overlay (node activations, confidence values) rendered into the export
- Shareable link generates a web-hosted replay viewable without app install
- Export queue completes within 3 minutes per replay

**Priority:** Should
