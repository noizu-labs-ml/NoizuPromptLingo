# US-049: Fighter Win-Rate Breakdown by Opponent Tier

As a **Competitive Grinder**, I want to see my fighter's win rate segmented by opponent ELO band (e.g., ±100, ±200, ±300 ELO) so that I can identify soft spots in my design against specific skill levels.

**Acceptance Criteria:**
- Win rate table displayed per fighter slot, broken into ELO delta bands
- Minimum sample size of 5 matches required before a band is shown
- Hovering/tapping a band shows recent matches in that range
- Data updates within 5 minutes of match resolution

**Priority:** Could
