# US-027: Tier List Builder Tool

**As a Creator-Spectator,** I want a built-in tier list builder that lets me drag published build archetypes into S/A/B/C/D tiers and export the result as a shareable image so that I can publish tier lists without using external tools.

**Acceptance Criteria:**
- Tier list builder is accessible from the Laboratory tab with up to 30 build cards per list
- Archetypes can be searched and added from the full published build catalog
- Finished tier list exports as a single image with tier labels, build names, and thumbnail icons
- Lists can be saved as drafts and re-edited; published lists link back to individual build pages

**Priority:** Could
