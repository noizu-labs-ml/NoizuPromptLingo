# US-078: VoiceOver-Navigable Fighter Template Gallery

**As an Accessibility Advocate,** I want the fighter template gallery to be fully navigable with VoiceOver so that I can browse and select starting configurations without sighted assistance.

**Acceptance Criteria:**
- Each template card's `accessibilityLabel` includes: template name, style tag (e.g., "Aggressive," "Defensive"), and node count
- Selecting a template announces a confirmation prompt before applying it to the fighter
- Gallery supports VoiceOver swipe navigation (next/previous element) without requiring custom gesture recognizers
- Search and filter controls in the gallery are labeled and reachable in the standard focus order

**Priority:** Should
