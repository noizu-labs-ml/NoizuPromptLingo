# US-071: Non-Color State Indicators on Graph Nodes

**As an Accessibility Advocate,** I want node states in the graph editor to be communicated with shapes and labels in addition to color so that I can distinguish states without relying on the four semantic colors.

**Acceptance Criteria:**
- Active nodes display a filled circle icon alongside the synapse-green border
- Error/conflict nodes display a triangle warning icon alongside the combat-pink border
- Inactive nodes display a dash icon alongside their default border
- All state icons include an `accessibilityLabel` describing the state (e.g., "Active," "Configuration error," "Inactive")
- No state information is conveyed by color alone

**Priority:** Must
