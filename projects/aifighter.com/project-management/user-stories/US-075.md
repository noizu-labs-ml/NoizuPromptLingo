# US-075: Semantic Screen Reader Labels on Graph Nodes

**As an Accessibility Advocate,** I want every node in the fighter graph to have a meaningful `accessibilityLabel` so that VoiceOver reads the node's role and current configuration, not its raw identifier.

**Acceptance Criteria:**
- Each node's `accessibilityLabel` follows the pattern: "[Node type], [configuration summary], [connection count] connections" (e.g., "Proximity Sensor, range 120, 2 connections")
- Port connectors are labeled with direction and connected state (e.g., "Output port, connected to Dodge Action")
- When a node has a configuration error, the label appends "Error: [reason]"
- Labels are re-announced automatically when configuration changes via VoiceOver's live region

**Priority:** Must
