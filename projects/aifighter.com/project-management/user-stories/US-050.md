# US-050: Ranked Queue Status and Wait Time Estimate

As a **Competitive Grinder**, I want the ranked queue screen to show estimated wait time and active queue depth by tier so that I can decide when to queue versus train without wasting session time.

**Acceptance Criteria:**
- Queue screen shows estimated time to match (updated every 10 seconds)
- Active queue depth displayed as a tier-segmented bar
- If wait exceeds 5 minutes, system widens ELO search window and notifies player
- Player can cancel queue at any time without penalty

**Priority:** Must
