# US-006: Save and Restore Previous Fighter Graph Versions

As a **Tinkerer**, I want version history for my fighter graphs so that I can roll back to a previous build if a change tanks my ranking.

**Acceptance Criteria:**
- The Fighter Studio auto-saves a snapshot on every deploy or manual save, retaining up to 30 versions
- Each snapshot shows a timestamp, the user's optional label, and the fighter's ranking at the time of save
- Restoring a snapshot replaces the active graph and prompts for confirmation before overwriting the current version
- A diff view highlights nodes added, removed, or changed between any two snapshots

**Priority:** Should
