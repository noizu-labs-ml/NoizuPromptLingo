# US-016: Understand Why I Was Matched Against This Opponent

As a **Tinkerer**, I want to see basic matchmaking metadata (MMR delta, rank tier of opponent) before a battle resolves so that I can assess the stakes and understand the system's fairness.

**Acceptance Criteria:**
- The battle confirmation screen shows the opponent's rank tier and an approximate MMR band (not exact score)
- After the match resolves, the result screen shows exact MMR gained or lost and the opponent's pre-match MMR
- A "How Matchmaking Works" link on the result screen opens a plain-language explanation of the ranking algorithm
- Repeat matches against the same opponent within 24 hours are flagged so the user is aware

**Priority:** Should
