# US-054: Honest AI Model Documentation

As an **AI Researcher**, I want the app to clearly document what computational model underlies the "neural net" fighter (e.g., policy gradient, Q-learning, fixed rules with learned weights), so that I can assess whether the system is genuinely learning or using a simplified approximation that would invalidate research use.

**Acceptance Criteria:**
- "About the AI Model" page accessible from Settings, written at graduate level
- Page describes: learning algorithm family, update frequency, what "nodes" map to computationally, and known limitations
- No marketing language that overstates model capability
- Model version tracked and included in all JSON exports

**Priority:** Must
