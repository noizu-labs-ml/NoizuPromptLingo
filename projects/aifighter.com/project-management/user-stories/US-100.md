# US-100: Node Annotation Labels for Graph Storytelling

As a **Data Artist**, I want to add freeform text annotation labels to individual nodes or edge groups in my graph, so that I can publish annotated graphs that communicate the design intent of each component as a readable visual story.

**Acceptance Criteria:**
- Annotation labels attach to a node or edge and move with it
- Label text supports up to 80 characters
- Labels are visible in the gallery view and included in SVG/PNG exports
- Labels can be toggled hidden during actual battle simulation (annotations are cosmetic only)

**Priority:** Should
