# US-003: Share Fighter Builds Without Revealing Core Logic

As a **Tinkerer**, I want to publish my fighter graph to the Laboratory with optional node obfuscation so that I can share my work with the community without giving away my competitive edge.

**Acceptance Criteria:**
- When sharing, the user can mark specific node subgraphs as obfuscated; obfuscated nodes render as black boxes in other users' views
- The shared build is importable and runnable by others but obfuscated internals cannot be inspected or cloned
- Full (non-obfuscated) shares are also supported as an opt-in setting
- Shared builds link back to the creator's profile with an optional credit byline

**Priority:** Must
