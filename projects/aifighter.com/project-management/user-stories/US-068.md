# US-068: Shared Fighter Viewing for Co-Play

**As a Dad Gamer,** I want to show my fighter's graph to my child in a read-only "spectator" view so that we can discuss the design together without accidentally editing it.

**Acceptance Criteria:**
- A "Share View" mode is accessible from the fighter profile that locks all editing controls
- In Share View, nodes are labeled with child-friendly descriptions (e.g., "Sees enemy" instead of "PerceptionNode::proximity")
- Share View can be entered without account switching or a second login
- Exiting Share View returns to the normal Studio without any changes

**Priority:** Could
