# US-033: Student Tournament Bracket

**As an Educator,** I want to run a single-elimination tournament bracket among my classroom students, seeded by their in-class ranking, so that I can use competitive play as a motivating culminating activity for a unit.

**Acceptance Criteria:**
- Educator creates a tournament from the classroom dashboard with configurable bracket sizes (8, 16, 32 students)
- Tournament matches resolve asynchronously on the server the same way ranked arena matches do, producing full replays
- Bracket display updates in real time and is viewable by all classroom members on a shared read-only link
- Educator can pause, reset, or manually advance bracket positions to handle absences or disqualifications

**Priority:** Should
