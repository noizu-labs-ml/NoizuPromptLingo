# US-097: Graph Versioning and Visual Diff

As a **Data Artist**, I want to save named versions of my graph and view a visual diff between any two versions — highlighting added, removed, or repositioned nodes and edges — so that I can treat graph evolution as a design process with intentional revision history.

**Acceptance Criteria:**
- "Save version" creates a named snapshot of the current graph state including node positions and color theme
- Visual diff overlays two versions on the canvas: green for additions, red for removals, yellow for moved nodes
- Up to 20 versions retained per graph
- Versions can be restored or branched into a new graph

**Priority:** Should
