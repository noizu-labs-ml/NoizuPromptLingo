# US-015: Search Nodes by Name or Function While Editing

As a **Tinkerer**, I want a search bar in the node palette that filters nodes by name or functional tag so that I can find the exact node I need without scrolling through the full library.

**Acceptance Criteria:**
- A search input at the top of the node palette filters results in real time as the user types
- Search matches on node name, category, and functional tags (e.g., "range", "dodge", "memory")
- Recent and favorited nodes appear in a pinned section at the top of the palette regardless of search state
- Pressing Escape or tapping outside clears the search and restores the full palette

**Priority:** Must
