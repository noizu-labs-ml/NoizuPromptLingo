# US-001: Access 20+ Node Types in the Graph Editor

As a **Tinkerer**, I want access to at least 20 distinct node types (perception, decision, and action categories) in the Fighter Studio so that I can express nuanced fighter logic beyond basic templates.

**Acceptance Criteria:**
- The node palette contains a minimum of 20 unique node types, organized by category (Perception, Decision, Action, Utility)
- Each node displays a tooltip with description, input/output pin types, and a link to documentation
- Nodes added to the canvas connect only to compatible pin types; incompatible connections are rejected with a clear error
- Node count is visible in a status bar so the user knows their graph complexity at a glance

**Priority:** Must
