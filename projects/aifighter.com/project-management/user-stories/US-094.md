# US-094: Streamer Dashboard with Viewer-Facing Stats

As a **Streamer**, I want a public streamer dashboard page showing my win rate, current ranked tier, most-used fighter builds, and recent replays, so that viewers can follow my AI Fighter journey between streams and I can link it in my channel description.

**Acceptance Criteria:**
- Public profile URL formatted as `aifighter.com/u/{username}`
- Displays: ranked tier badge, W/L record, top 3 published fighter builds, last 5 replays
- Replays on the dashboard are clickable and open the web replay viewer
- Profile owner can toggle individual sections visible/hidden

**Priority:** Should
