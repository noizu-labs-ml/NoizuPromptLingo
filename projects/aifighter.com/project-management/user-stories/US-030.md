# US-030: Training Data Export for Coursework

**As an Educator,** I want to export a student's fighter training session data — inputs, outputs, reward signals, epoch-by-epoch loss curves — as a structured JSON or CSV file so that students can analyze it as part of a machine learning assignment.

**Acceptance Criteria:**
- Training export is available from the Training Gym session history for any completed session
- Export formats: JSON (full fidelity, nested) and CSV (flattened, one row per epoch)
- Exported file includes metadata: session date, fighter name, total epochs, final validation accuracy equivalent metric
- Bulk export of all sessions for a class is available to the educator from the classroom dashboard

**Priority:** Must
