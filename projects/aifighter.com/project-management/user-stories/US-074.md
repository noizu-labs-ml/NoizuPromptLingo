# US-074: Reduced Motion Support

**As an Accessibility Advocate,** I want the game to respect iOS `prefers-reduced-motion` so that flashing animations and rapid transitions do not trigger my motion sensitivity.

**Acceptance Criteria:**
- When `UIAccessibility.isReduceMotionEnabled` is true, all non-essential animations are replaced with instant transitions or simple crossfades
- Battle replays in reduced-motion mode show a frame-by-frame step view instead of continuous animation
- The fighter graph editor uses opacity changes instead of sliding/bouncing for node feedback
- No animation plays for longer than 500ms or at a rate faster than 3 frames per second in reduced-motion mode

**Priority:** Must
