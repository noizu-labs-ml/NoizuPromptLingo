# US-088: High-Resolution Graph Export (SVG and PNG)

As a **Data Artist**, I want to export my neural graph as an SVG or high-resolution PNG, so that I can use it as a design asset, print it, or share it as standalone visual art independent of the game.

**Acceptance Criteria:**
- SVG export preserves vector paths for all edges and node shapes
- PNG export available at 2×, 4×, and 8× canvas resolution
- Export includes the graph's current color theme (edge glow, node fills)
- Background can be set to transparent, solid black, or the current arena theme background

**Priority:** Must
