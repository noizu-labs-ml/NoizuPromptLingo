# US-093: Graph Alignment and Distribution Tools

As a **Data Artist**, I want alignment and distribution controls (align left, distribute vertically, center on canvas) that I can invoke manually when I want geometric precision in my layouts, so that I can produce graphs with compositional intentionality without losing positional freedom.

**Acceptance Criteria:**
- Alignment toolbar appears when two or more nodes are selected
- Actions: align left edge, align right edge, align top, align bottom, center horizontally, center vertically, distribute horizontally, distribute vertically
- All alignment is non-destructive and undoable
- Tools do not activate automatically — only on explicit user invocation

**Priority:** Should
