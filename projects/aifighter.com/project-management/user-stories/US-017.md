# US-017: Export My Fighter Graph as a File and Import on Any Device

As a **Tinkerer**, I want to export my fighter graph as a portable file and import it on any device so that I can back up my work and collaborate offline with teammates.

**Acceptance Criteria:**
- Fighter Studio includes an Export button that produces a `.aifighter` JSON file download
- An Import button accepts `.aifighter` files and validates schema compatibility before loading
- Exported files include graph metadata (version, node count, author) but exclude server-side training weights by default; a separate option includes weights for full portability
- Importing a build that conflicts with the current fighter prompts the user to save or discard the active graph first

**Priority:** Should
