# US-091: Training Heatmap as Downloadable Art Print

As a **Data Artist**, I want to export my fighter's training heatmap as a high-resolution image suitable for printing, so that I can frame the data visualization as physical art.

**Acceptance Criteria:**
- Heatmap export available as PNG at minimum 3000×3000px resolution
- Color gradient of the heatmap reflects the graph's active color theme
- Optional overlay of fighter name and training epoch range as metadata text
- Download accessible from the Training Gym's heatmap view

**Priority:** Could
