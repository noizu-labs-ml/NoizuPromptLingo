# US-087: Manual Node Positioning in the Graph Editor

As a **Data Artist**, I want to freely drag and position every node on the neural graph canvas without the editor snapping or auto-arranging them, so that I can compose graphs as intentional visual layouts rather than functional diagrams.

**Acceptance Criteria:**
- Drag-to-position works for all node types (perception, decision, action)
- No auto-layout or snap-to-grid behavior unless explicitly enabled by the user
- Optional snap-to-grid toggle available but off by default
- Node positions are saved as part of the graph and restored exactly on reload

**Priority:** Must
