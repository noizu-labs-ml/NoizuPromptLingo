# US-090: Gallery Feature for Graph Visualization Sharing

As a **Data Artist**, I want to publish my graph to a public gallery where other players can browse, admire, and react to graphs as visual works, so that the community recognizes graph design as a form of artistic expression within the game.

**Acceptance Criteria:**
- "Publish to Gallery" option available from any saved graph
- Gallery displays graph as a static visual card (thumbnail of the graph canvas)
- Other players can react with emoji responses and leave short comments
- Gallery can be filtered by color theme, node count, and most-reacted

**Priority:** Should
