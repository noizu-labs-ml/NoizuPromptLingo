# US-025: Build Guide Authoring and Publishing

**As a Creator-Spectator,** I want to compose a structured build guide — with embedded graph screenshots, node explanations, and matchup notes — and publish it to the Laboratory so that the community can learn from my analysis.

**Acceptance Criteria:**
- Guide composer supports rich text with inline image embed from the in-app screenshot tool
- Authors can attach a build (JSON graph) directly to the guide; attached build is version-locked at publish time
- Published guides are searchable by archetype, rank tier, and author name
- Guide view count, saves, and comments are visible to the author in a creator dashboard

**Priority:** Should
