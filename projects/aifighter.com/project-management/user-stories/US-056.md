# US-056: Batch Training Run Scheduling

As an **AI Researcher**, I want to queue multiple training runs with different seed or hyperparameter configurations so that I can run overnight experiments without manually restarting each run.

**Acceptance Criteria:**
- Batch queue accepts up to 10 run configurations
- Each configuration specifies: graph snapshot, seed, sparring partner, epoch count
- Runs execute sequentially server-side; push notification sent on each completion
- All results accessible in a batch summary view with per-run export links

**Priority:** Should
