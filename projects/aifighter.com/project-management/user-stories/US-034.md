# US-034: Replay Playback Speed and Frame Step Controls

**As a Creator-Spectator,** I want to step through a replay frame by frame or play it at 0.25x, 0.5x, 1x, and 2x speed so that I can precisely identify the decision frame where a fight turns and capture it for content.

**Acceptance Criteria:**
- Replay player exposes speed selector (0.25x / 0.5x / 1x / 2x) as a persistent control
- Frame-step forward and backward buttons advance/rewind by exactly one simulation tick
- Current frame number and timestamp are displayed continuously during playback
- Speed setting persists across replay loads within the same session

**Priority:** Must
