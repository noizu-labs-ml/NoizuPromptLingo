# US-004: Review Node Activation Heatmaps After a Match

As a **Tinkerer**, I want a post-battle analytics screen showing a heatmap of node activation frequency across the full match so that I can identify underused or overloaded parts of my graph.

**Acceptance Criteria:**
- After every ranked or training match, an analytics screen is available showing a heatmap overlay on the fighter graph
- Node color intensity corresponds to activation frequency (cold = never fired, hot = fired >80% of frames)
- Users can filter the heatmap by match phase (opening, midgame, closing)
- Heatmap data is retained for the last 50 matches and browsable via a match history list

**Priority:** Should
