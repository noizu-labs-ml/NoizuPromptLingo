# US-047: Per-Match Detailed Stat Breakdown

As a **Competitive Grinder**, I want a post-match analytics screen showing frame-by-frame action accuracy, decision latency distribution, and opponent pattern exploitation rate so that I can identify exactly where my fighter's logic is losing.

**Acceptance Criteria:**
- Post-match screen shows: actions per second, decision confidence histogram, and top-3 node activations by frequency
- Opponent pattern exploitation score (0-100) calculated and displayed
- Downloadable CSV of match event log available per match
- Data persists for at least 90 days

**Priority:** Should
