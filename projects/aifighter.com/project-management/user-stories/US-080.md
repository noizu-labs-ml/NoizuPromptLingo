# US-080: Haptic-Only Battle Feedback Option

**As an Accessibility Advocate,** I want critical battle events to be communicated via haptic feedback so that I can perceive outcomes without relying on visual animations or audio.

**Acceptance Criteria:**
- A "Haptic Battle Feedback" toggle in Accessibility Settings maps key events to distinct haptic patterns: hit landed (light tap), round end (double tap), match win (success notification haptic), match loss (warning haptic)
- Haptics fire even when the device is in silent mode
- Haptic patterns are documented in the in-app Help screen with plain-language descriptions
- The setting defaults to on when `UIAccessibility.isReduceMotionEnabled` is true

**Priority:** Could
