# US-039: Replay Share Link with Decision Overlay Preset

**As a Creator-Spectator,** I want to generate a share link for a specific replay that includes my current overlay filter settings and a start timestamp so that Discord and Reddit readers land exactly at the moment I want them to see.

**Acceptance Criteria:**
- Share link encodes: replay ID, start frame, overlay filter preset (node category selections), and playback speed
- Opening the link on any device begins playback at the specified frame with the specified overlay state
- Share links are valid for 90 days from generation; a warning is shown if the replay will expire within 7 days
- Link preview (Open Graph metadata) shows a still frame thumbnail of the specified start frame

**Priority:** Should
