# US-052: Loss Curve and Weight Update Visualization

As an **AI Researcher**, I want a technical details panel in the Training Gym that displays per-epoch loss curves, reward signal over time, and a heatmap of weight update magnitudes across graph nodes, so that I can assess convergence behavior and identify dead or saturated nodes.

**Acceptance Criteria:**
- Technical panel toggled via "Research Mode" setting
- Loss curve rendered as line chart; updates in real time during training
- Reward-per-episode plotted alongside loss on shared time axis
- Node weight update heatmap rendered on the graph canvas with color scale legend

**Priority:** Must
