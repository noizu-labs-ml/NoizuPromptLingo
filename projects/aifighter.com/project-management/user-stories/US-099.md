# US-099: Tournament Bracket Embed for External Streams

As a **Streamer**, I want to embed a live tournament bracket as an overlay source (OBS browser source URL) in my stream, so that viewers can see bracket progression in real time as I cast each round.

**Acceptance Criteria:**
- Each tournament generates a unique browser-source URL formatted for OBS/Streamlabs
- Bracket updates live as round results resolve (no manual refresh)
- Overlay is styled with the game's neural pathway visual identity (dark background, green synapse lines)
- Overlay dimensions configurable: 16:9 full-screen or 4:3 sidebar panel

**Priority:** Should
