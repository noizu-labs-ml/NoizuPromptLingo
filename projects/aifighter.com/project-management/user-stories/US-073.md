# US-073: 48px Minimum Touch Targets

**As an Accessibility Advocate,** I want every tappable element to meet the 48×48pt minimum touch target size so that I can activate controls reliably with limited motor precision.

**Acceptance Criteria:**
- All buttons, links, and interactive icons have a minimum tap area of 48×48pt (enforced in the design system token)
- Small decorative icons that are not interactive have `isAccessibilityElement = false`
- Touch targets that are visually smaller than 48pt use invisible padding to reach the minimum (no visual change required)
- An automated accessibility audit (e.g., Xcode Accessibility Inspector) passes with zero touch-target violations on every screen

**Priority:** Must
