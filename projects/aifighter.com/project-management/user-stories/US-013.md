# US-013: Join a Clan and Access Shared Build Resources

As a **Curious Casual**, I want to join a clan and access a shared build library maintained by clan members so that I can learn from more experienced players and feel part of a community.

**Acceptance Criteria:**
- Players can create or join clans of up to 50 members via invite code or open search
- Clan leaders and officers can publish builds to the Clan Library, visible only to members
- The Clan Library lists builds with creator name, archetype tag, and a brief description
- A clan activity feed shows recent battles, rank promotions, and new builds from members

**Priority:** Could
