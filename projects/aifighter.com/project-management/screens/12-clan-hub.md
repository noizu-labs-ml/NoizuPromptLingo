# Clan Hub

| Field | Value |
|-------|-------|
| **ID** | `clan-hub` |
| **Type** | Primary |
| **Category** | Social |
| **User Stories** | US-013 |

## Description

Clan management center with member roster, shared build library, and activity feed. Players can join clans to access shared fighter builds.

## Key Components

- **Clan Search/Join** — Search clans or join by invite code (US-013)
- **Member Roster** — Up to 50 members with roles and status (US-013)
- **Clan Library** — Shared builds with creator, archetype, and description (US-013)
- **Activity Feed** — Recent clan activity (joins, builds shared, match results) (US-013)

## Interactions

- Search for clans or enter invite code
- View member roster and activity
- Browse and fork clan library builds
- Share own builds to clan library

## Navigation

- Accessible from: Home, Profile
- Links to: Fighter Studio (fork build), Laboratory
