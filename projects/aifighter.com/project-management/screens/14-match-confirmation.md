# Match Confirmation

| Field | Value |
|-------|-------|
| **ID** | `match-confirmation` |
| **Type** | Modal |
| **Category** | Competitive |
| **User Stories** | US-016, US-044 |

## Description

Pre-battle confirmation showing opponent details including rank tier, approximate MMR band, and smurf detection indicators.

## Key Components

- **Opponent Info Card** — Rank tier, approximate MMR band, fighter archetype (US-016)
- **Accelerated Placement Badge** — Visual indicator for flagged smurf accounts (US-044)
- **Matchmaking Info Link** — "How Matchmaking Works" explainer (US-016)
- **Repeat Match Indicator** — Flag for recently played opponents (US-016)

## Interactions

- Review opponent information before battle
- View matchmaking explanation
- Accept or decline match

## Navigation

- Accessible from: Ranked Arena (queue match found)
- Links to: Battle Replay Viewer (after resolution), Matchmaking Info
