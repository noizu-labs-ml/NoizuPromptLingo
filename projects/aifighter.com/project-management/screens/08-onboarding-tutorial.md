# Onboarding Tutorial

| Field | Value |
|-------|-------|
| **ID** | `onboarding-tutorial` |
| **Type** | Storyboard |
| **Category** | Onboarding |
| **User Stories** | US-008, US-064 |

## Description

5-step guided tutorial introducing new players to fighter building, culminating in a working starter fighter. Emphasizes no energy system or daily streaks.

## Key Components

- **Step Progress Indicator** — 5-step progress tracker with current step highlighted (US-008)
- **Guided Walkthrough Overlay** — Contextual instructions overlaid on Fighter Studio (US-008)
- **Skip Button** — Option to skip tutorial at any step (US-008)
- **Starter Template Receipt** — Confirmation screen showing received starter fighter (US-008)
- **Contextual Help Button** — Persistent help button available after tutorial (US-008)
- **No-FOMO Copy** — Onboarding messaging about no energy/streaks (US-064)

## Interactions

- Follow step-by-step guidance through Fighter Studio
- Skip tutorial at any point
- Receive starter fighter template
- Access contextual help post-tutorial

## Navigation

- Accessible from: First app launch, Settings (replay tutorial)
- Links to: Fighter Studio, Template Gallery
