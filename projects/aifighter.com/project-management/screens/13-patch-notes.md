# Patch Notes

| Field | Value |
|-------|-------|
| **ID** | `patch-notes` |
| **Type** | Primary |
| **Category** | System |
| **User Stories** | US-019, US-045 |

## Description

Searchable patch notes with per-node change details, plain-language summaries, and personalized "What changed for me" filtered view. Includes upcoming change previews.

## Key Components

- **Patch Entry List** — Chronological entries with "Affects Nodes" tags (US-019)
- **Personal Impact Filter** — "What changed for me" view showing only changes affecting user's builds (US-019)
- **Node Search** — Search by node name, version, or type (US-019)
- **Upcoming Changes Preview** — Preview list with old vs. new behavior per node (US-045)
- **Season Changelog Archive** — Historical changelog list by season (US-045)
- **Push Notification Opt-in** — Notification preferences for patch releases (US-045)

## Interactions

- Browse and search patch notes
- Filter to changes affecting own builds
- Preview upcoming balance changes
- Browse historical changelogs
- Configure patch notification preferences

## Navigation

- Accessible from: Home (news feed), Settings, Fighter Studio (affected banner)
- Links to: Fighter Studio (affected node), Node Glossary
