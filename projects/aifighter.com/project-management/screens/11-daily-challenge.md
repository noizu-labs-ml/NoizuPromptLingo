# Daily Challenge

| Field | Value |
|-------|-------|
| **ID** | `daily-challenge` |
| **Type** | Primary |
| **Category** | Engagement |
| **User Stories** | US-018 |

## Description

Daily challenge screen showing the current challenge with 24-hour expiry countdown, progress tracking, and streak bonus indicators.

## Key Components

- **Challenge Card** — Current challenge description with 24-hour expiry countdown (US-018)
- **Progress Tracker** — Visual progress toward challenge completion (US-018)
- **Streak Bonus Display** — 3/7/30-day streak indicators with multiplier (US-018)
- **Reward Display** — Cosmetic currency earned from completing challenges (US-018)

## Interactions

- View current challenge and time remaining
- Track progress toward completion
- Collect rewards upon completion
- View streak history and bonuses

## Navigation

- Accessible from: Home
- Links to: Fighter Studio, Training Gym, Ranked Arena (depending on challenge type)
