# Education Portal

| Field | Value |
|-------|-------|
| **ID** | `education-portal` |

## Description

Educator-facing portal for creating classrooms, managing students, running tournaments, exporting data, and accessing lesson plans. Includes COPPA safeguards and safe mode controls.

## Key Components

- **Classroom Creation Form** — Class name, join code display, student roster (up to 35) (US-028, US-038)
- **Student Roster** — Student list with fighter build viewer and match history (US-028)
- **Educator Dashboard** — Overview of all classrooms with activity metrics (US-028)
- **Tournament Bracket Manager** — Create 8/16/32-player brackets with pause/reset/advance (US-033)
- **Lesson Plan Library** — 5+ template cards with PDF/Google Doc downloads and JSON preloads (US-032)
- **Training Data Export** — Session list with JSON/CSV format selector and bulk export (US-030, US-040)
- **Student Heatmap Viewer** — Educator access to any student's training heatmap (US-040)
- **Safe Mode Controls** — Toggle safe mode, "Classroom Approved" badge system (US-036)
- **COPPA Consent Flow** — Age gate, consent form, activation confirmation (US-029)
- **.edu Email Verification** — Free tier verification input and manual request form (US-038)

## Interactions

- Create and manage classrooms with join codes
- View student builds and match histories
- Create and manage tournament brackets
- Browse and download lesson plan templates
- Export student training data
- Toggle safe mode for classroom content filtering
- Process student account consent
- Verify educator email for free access

## Navigation

- Accessible from: Home (educator role), Settings
- Links to: Classroom Dashboard, Tournament Bracket, Lesson Plan Library, Training Data Export
