# Template Gallery

| Field | Value |
|-------|-------|
| **ID** | `template-gallery` |
| **Type** | Primary |
| **Category** | Discovery |
| **User Stories** | US-009, US-078 |

## Description

Browse and deploy competitive starter templates tagged by playstyle with win rate badges. Fully accessible via VoiceOver navigation.

## Key Components

- **Template Cards** — Cards with playstyle tags, weekly win rate badges, node count (US-009, US-078)
- **One-Tap Deploy Button** — Instantly deploy template to fighter slot (US-009)
- **Strategy Explanation Modal** — Detailed breakdown of template strategy (US-009)
- **Fork Button** — Create editable copy in Fighter Studio (US-009)
- **Search & Filter Bar** — Filter by playstyle (Aggressive/Defensive/Balanced/Evasive) (US-009)
- **Accessible Card Labels** — VoiceOver labels with name, style, node count (US-078)

## Interactions

- Browse templates by playstyle tag
- Preview strategy explanation before deploying
- Deploy or fork a template
- Search and filter templates

## Navigation

- Accessible from: Home, Onboarding (final step), Fighter Studio
- Links to: Fighter Studio (fork), Ranked Arena (deploy)
