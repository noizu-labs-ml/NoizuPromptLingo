# Cosmetic Shop

| Field | Value |
|-------|-------|
| **ID** | `cosmetic-shop` |
| **Type** | Primary |
| **Category** | Monetization |
| **User Stories** | US-005, US-089 |

## Description

Cosmetics-only store for purchasing graph color themes, visual effects, and other non-gameplay-affecting items. Emphasizes fair play — no pay-to-win.

## Key Components

- **Theme Store Grid** — Purchasable graph color themes with live preview (US-089)
- **Cosmetics-Only Indicator** — Clear messaging that purchases don't affect gameplay (US-005)
- **Ranked Milestone Unlocks** — Themes unlockable through ranked play (US-089)
- **Purchase Flow** — Standard purchase confirmation dialog (US-089)

## Interactions

- Browse available cosmetics
- Preview themes on graph canvas
- Purchase or unlock via milestones
- Apply purchased cosmetics

## Navigation

- Accessible from: Home, Fighter Studio (theme picker)
- Links to: Fighter Studio (apply theme)
