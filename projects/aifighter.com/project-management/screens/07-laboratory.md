## Description

Community hub for sharing, discovering, and analyzing fighter builds. Includes build library, replay theater, guide publishing, tier list tools, graph gallery, and content moderation.

## Key Components

- **Build Card Grid** — Community builds with creator, archetype, description, win rate stats (US-003, US-023)
- **Build Stats Panel** — Win/loss/draw rates, matchup breakdown by archetype, CSV download (US-023)
- **Replay Theater Feed** — Curated replay feed with Top/New/Featured tabs, upvotes (US-024)
- **Guide Browser** — Published build guides searchable by archetype/rank/author (US-025)
- **Tier List Builder** — Drag-and-drop S/A/B/C/D rows with build cards, export as image (US-027)
- **Archetype Comparison View** — Split-screen node graph with shared zoom and win rate diff (US-037)
- **Graph Gallery** — Published graph visualizations with emoji reactions and comments (US-090)
- **Featured Spotlight** — Weekly community-voted spotlight card with full-res graph (US-098)
- **Report Flag Button** — Categorized report form on every build card and guide (US-035)
- **Research Note Field** — 2000-char methods/research note on uploads (US-060)
- **Lineage Panel** — Fork attribution showing original author chain (US-060)
- **Share Settings** — Subgraph obfuscation toggle, black-box node rendering (US-003)

## Interactions

- Browse, search, and filter community builds
- View detailed build stats and matchup data
- Watch curated replays in theater mode
- Read and search build guides
- Create and publish tier lists
- Compare archetypes side-by-side
- Publish graph visualizations to gallery
- Vote on weekly spotlight
- Report inappropriate content
- Share builds with optional obfuscation
