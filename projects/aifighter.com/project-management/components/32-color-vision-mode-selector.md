# Color Vision Mode Selector

| Field | Value |
|-------|-------|
| **ID** | `color-vision-mode-selector` |
| **Category** | Input & Forms |
| **Used In** | 09-Settings |

## Description

Accessibility setting for selecting color vision mode. Applies pattern-fill supplements globally to heatmaps and overlays.

## Size Variants

| Variant | Description |
|---------|-------------|
| Compact | Dropdown selector |

## Props / Configuration

- `mode` — `Default` | `Deuteranopia` | `Protanopia` | `Tritanopia` | `High Contrast`
- `patternFills` — Boolean enabling supplemental patterns alongside color coding

## Interactions

- Select mode from dropdown
- Preview changes before applying
- Apply mode globally across all heatmaps and overlays
