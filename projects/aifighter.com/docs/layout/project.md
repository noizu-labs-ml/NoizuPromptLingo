# project/ — Project Management Artifacts

## personas/

10 user personas defining the target audience for AI Fighter.

```
project/personas/
├── 01-the-tinkerer.md              # Primary: engineer who wants depth over grind
├── 02-the-curious-casual.md        # Secondary: student, knows AI from social media
├── 03-the-creator-spectator.md     # Tertiary: watches/shares more than plays
├── 04-the-educator.md              # Uses game as teaching tool
├── 05-the-competitive-grinder.md   # Ladder climber, tournament focused
├── 06-the-ai-researcher.md         # Professional exploring gamified AI
├── 07-the-dad-gamer.md             # Limited time, high engagement per session
├── 08-the-accessibility-advocate.md # Inclusive design champion
├── 09-the-streamer.md              # Content creator, spectator economy
├── 10-the-data-artist.md           # Aesthetics of neural graphs
└── README.md                       # Persona index and methodology
```

## user-stories/

100 user stories (US-001 through US-100) covering MVP and post-MVP features.

```
project/user-stories/
├── README.md                       # Story index, acceptance criteria format
├── US-001.md – US-100.md           # Individual story files
```

Stories are organized by feature area within the files themselves (Fighter Studio, Training Gym, Arena, Laboratory, onboarding, monetization, accessibility).
