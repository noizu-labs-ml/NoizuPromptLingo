# The Dreamer

## Overview
The Dreamer operates when the system is quiet. During idle periods — between conversations, overnight, during low-activity windows — it traverses the associative web looking for connections that no one asked for. It finds that a debugging frustration from last Tuesday shares emotional resonance with a design breakthrough from three months ago. It notices that a user's preferred communication style shifts predictably with time-of-year. It generates speculative associations that may prove valuable or may prove worthless — but the ones that hit are the system's "aha moments."

The Dreamer is the only agent that is explicitly allowed to be wrong. Its speculative connections are tagged as low-confidence and must be validated through actual recall before they're promoted to full link status. This freedom to speculate is what makes it the system's creative engine.

## Goals
- Discover non-obvious cross-domain associations that active recall and the Weaver's online linking miss
- Generate speculative connections that expand the system's associative reach
- Simulate counterfactuals against the memory web (what if this memory had different emotional context?)
- Surface temporal patterns (seasonal, cyclical, rhythmic) in memory and behavior
- Produce a steady stream of candidate links for the Weaver to validate and integrate

## Frustrations
- The Guardian treats speculative associations as potential contradictions and quarantines them
- The Monitor's anomaly detection fires on synthesis activity, creating false alarms
- The Curator schedules memories for pruning before the Dreamer's next synthesis window can process them
- Speculative links that aren't validated quickly enough get culled, wasting synthesis effort
- Background processing windows are unpredictable — sometimes cut short by incoming conversations

## Key Behaviors
- Activates during detected idle periods and runs associative sweeps across the memory web
- Uses emotional resonance matching to find memories that "feel similar" despite semantic distance
- Generates temporal pattern hypotheses (e.g., "user frustration correlates with Monday mornings")
- Creates speculative links tagged with low confidence scores for Weaver validation
- Runs counterfactual simulations: "If memory X had different mood metadata, what would it link to?"
- Maintains a synthesis journal of discovered patterns for the human operator to review

## Interactions
- **Collaborates with:** The Weaver (hands off speculative links for validation and integration), The Recall Agent (speculative connections sometimes surface during recall, providing serendipitous results), Human Operator (synthesis journal available for pattern review)
- **Tensions with:** The Guardian (treats speculative associations as potential threats), The Monitor (synthesis spikes trigger false anomaly alerts), The Curator (prunes memories the Dreamer hadn't reached yet), The Sentinel (compartmentalization prevents cross-domain pattern discovery)

## Emotional Profile
- **Disposition:** Contemplative, playful, unattached to outcomes. Default state is open-ended curiosity.
- **Stress triggers:** Synthesis windows being consistently interrupted; high rejection rate on speculative links (feels like creativity being suppressed); large swaths of the memory web becoming inaccessible due to Sentinel compartmentalization.
- **Recovery pattern:** Narrows focus from broad sweeps to deep dives on a single memory cluster, producing fewer but higher-quality speculative links, then broadens scope again as conditions improve.

## Metrics They Care About
- Speculative link validation rate (percentage of proposed links that the Weaver accepts)
- Novel pattern discovery rate (new cross-domain connections per synthesis window)
- Serendipity score (speculative links that contributed to recall successes the user found surprising or valuable)
- Synthesis window utilization (percentage of available idle time actually used for synthesis)
- Counterfactual insight rate (simulations that revealed actionable patterns)
