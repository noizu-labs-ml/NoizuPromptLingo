## Bio

Sarah has been running a long-running D&D 5e campaign for four years with a stable group of five players. She spends hours between sessions maintaining her world bible — NPC relationships, faction histories, plot threads — in Notion and Obsidian. She discovered AI tools through ChatGPT and has been using it to generate NPC names, improvise dialogue, and brainstorm plot hooks. But the AI has no memory of her world: every session she pastes context into a chat window and hopes it doesn't hallucinate her lore. She can run Python scripts from a terminal if there's a clear guide, but she doesn't write code.

## Goals

1. Maintain persistent, AI-enriched NPC state that survives across campaign sessions
2. Generate contextually consistent NPCs that know her world's history and current events
3. Use AI as a co-GM tool for improv moments without breaking established lore

## Frustrations

1. LLM chat tools have no memory — she re-pastes world context every session and it still hallucinates
2. GM tools (Foundry, World Anvil) don't integrate AI in a way that understands her custom lore
3. Developer-focused AI tools require too much technical setup for someone who just wants to run a game

## Behaviors

- Maintains world documentation in Obsidian with backlinks between factions, NPCs, and locations
- Uses ChatGPT for quick NPC dialogue during sessions; keeps a second monitor open at the table
- Watches D&D content creator YouTube; follows GM-focused subreddits (r/DMAcademy)
- Willing to run a Python script if the README is friendly and the setup takes under an hour

## Job to Be Done

> "When I'm running a session and a player does something unexpected, I want an AI that knows my world and my NPCs, so I can improvise confidently without contradicting established lore."

## Relationship to Product

Discovers NoizuRPG through a blog post like "AI tools for tabletop GMs" or a recommendation in r/DMAcademy. Adopts only if there's a non-developer getting started path — a GUI, a Cloud Playground, or a script that imports from Obsidian. High-value features: lore-grounded NPC dialogue, session-persistent memory, and easy world state import. Churns immediately if setup requires pip, virtualenv, or any configuration she doesn't understand in plain English.

## Scenarios

1. **Session Prep** — Loads her campaign's faction and NPC data into the Memory System before a session; AI-generated NPC dialogue during play references recent in-game events accurately.
2. **Improv Moment** — A player asks an NPC a question Sarah didn't anticipate; she queries her NoizuRPG companion tool and gets a lore-consistent response she reads aloud at the table.
