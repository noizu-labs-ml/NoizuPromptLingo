Code Blocks

The hero element of the documentation. Large, readable, with syntax highlighting and copy support.

python quickstart.py
1234 5678 9101112 13 
from noizurpg import World, Character, NarrativeEngine
from noizurpg.providers import Anthropic

world = World("The Ashward Chronicles")
kael  = Character("Kael Ashward")
kael.stats.set(str=12, dex=14, int=16)

engine = NarrativeEngine(
    llm=Anthropic("claude-sonnet-4-5-20250514"),
    world=world
)

await engine.narrate(kael, "enter the guild hall")

from noizurpg import Dialogue, DialogueContext

# Build a typed dialogue tree with LLM-driven branches
dialogue = Dialogue(
    speaker=venn,
    listener=kael,
    context=DialogueContext(
        location="guild_hall",
        tone="suspicious",
        knowledge_gate="northern_pass_report"
    )
)

result = await engine.run_dialogue(dialogue)
print(result.transcript)

Alerts & Callouts

Tip
Set your ANTHROPIC_API_KEY environment variable and NarrativeEngine will pick it up automatically — no configuration needed.
Note
World state is serialized as JSON by default. For large worlds with many characters, consider using MemoryStore compression to keep context windows manageable.
Warning
QuestTree is in Beta. The node resolution API may change before v1.0. Pin your dependency to avoid breaking changes.
Danger
Never commit API keys to source control. Use environment variables or a secrets manager. NoizuRPG will never log your API key, but third-party plugins may.
