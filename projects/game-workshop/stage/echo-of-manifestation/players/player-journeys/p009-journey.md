# Echo of Manifestation — Player Journey: P-009 (Liam O'Connor)

**Persona:** The Dedicated F2P Advocate
**Focus:** Fair monetization, community building, challenge runs

## Predicted Journey

### Phase 1: Advocacy (Pre-purchase through Run 5)
- Buys the game at full price specifically because of the premium model
- Immediately begins documenting runs for Discord communities
- Champions the game as proof that horror games don't need microtransactions
- Creates initial chimera strategy guides and essence route maps
- Becomes the game's most vocal organic promoter

### Phase 2: Skill Expression (Runs 6-20)
- Attempts challenge runs: no-transmute runs (survive using only scavenged items)
- Attempts no-divination runs (blind transmutation)
- Attempts speedruns, documenting best times
- Creates detailed essence route maps for community sharing
- Develops chimera strategy guides focusing on evasion techniques

### Phase 3: Community Leadership (Runs 21+)
- Becomes a recognized community resource creator
- Organizes challenge run competitions in Discord
- Provides feedback on balance and fairness
- Documents every chimera's evasion patterns for no-transmute runs
- Creates video guides for the Transcend ending

### Key Friction Points
- Any perceived unfairness in difficulty will be scrutinized through the "skill should be the only currency" lens
- If chimeras cannot be reliably evaded through skill alone, the core premise feels violated
- Will be sensitive to any post-launch monetization changes
- Community expectations may create pressure for content updates
