# US-038: Contributing Distributed Compute

**As a** player
**I want to** opt-in to contributing my device's processing power to the platform's distributed compute network
**So that** I earn passive SPARK income while playing, and my participation literally powers the world's AI agents

## Acceptance Criteria
- [ ] Opt-in toggle in settings with clear explanation of what compute contribution means
- [ ] Contribution meter shows: compute provided, SPARK earned, current contribution rate
- [ ] SPARK earnings from compute are passive (earned while playing, no extra effort)
- [ ] Device performance impact is configurable: low/medium/high contribution levels
- [ ] Contribution creates a virtuous cycle: more players = more compute = more capable AI = more interesting world
- [ ] Contribution statistics visible in player profile as a community contribution metric
