# US-003: Tutorial Quest Chain

**As a** new player
**I want to** complete a guided tutorial that teaches me gathering, crafting, trading, and socializing through natural gameplay rather than text walls
**So that** I understand the core loop within my first session without feeling lectured

## Acceptance Criteria
- [ ] Community Mentor NPC (Compass) introduces itself within 30 seconds of homestead claiming
- [ ] Tutorial covers: planting seeds, watering, gathering resources, crafting a basic item, selling at marketplace, talking to an NPC
- [ ] Each tutorial step is a mini-quest with a small Credit reward
- [ ] Tutorial completion unlocks the "Good Neighbor" quest line from Mayor Voss
- [ ] Player can skip the tutorial at any point (with confirmation dialog)
- [ ] Tutorial adapts to species: NEIs skip food/sleep steps, Fay tutorial includes territory communion, Synthetics include maintenance check
- [ ] Compass NPC remembers struggling players and offers follow-up help in later sessions

## Category
Onboarding

## Priority
Must

## Notes
- Compass is a first-party Community Mentor agent with dampened personality evolution to stay friendly.
- The tutorial should feel like "a helpful neighbor showing you around" not "a game teaching you mechanics."
- See platform/AGENT-SYSTEM.md, Appendix C for Compass personality profile.
