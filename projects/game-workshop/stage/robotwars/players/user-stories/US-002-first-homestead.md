# US-002: Claiming First Homestead

**As a** new player
**I want to** claim a starter cottage plot in my species' home biome and place my first workbench within the first 10 minutes of gameplay
**So that** I have a physical anchor in the world and can immediately begin crafting

## Acceptance Criteria
- [ ] Tutorial guides the player to an available 4x4 cottage plot
- [ ] Plot claiming takes a single interaction (no currency cost for the first plot)
- [ ] Cottage spawns with species-appropriate dwelling variant (human cabin, synthetic bay, NEI server rack, fay treehouse)
- [ ] Basic workbench is placed automatically with a prompt to use it
- [ ] Garden with 4 crop slots is available immediately
- [ ] Storage shed is present with starter inventory (basic seeds, one tool, starter materials)
- [ ] Player receives a notification explaining homestead evolution path (Cottage -> Workshop -> Campus -> District)

## Category
Onboarding

## Priority
Must

## Notes
- The homestead is the player's most visible progression marker. First impressions matter.
- Species variants provide immediate identity reinforcement.
- See design/meta-loop.md "Homestead Evolution" for the full progression path.
