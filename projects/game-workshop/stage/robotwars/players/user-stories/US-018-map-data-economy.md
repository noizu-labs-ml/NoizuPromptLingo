# US-018: Selling Exploration Map Data

**As an** Explorer player
**I want to** map biomes by physically traveling through them and sell my map data as a commodity
**So that** exploration has direct economic value and I can build a reputation as a cartographer

## Acceptance Criteria
- [ ] Map data is generated automatically as the player explores unmapped territory
- [ ] Map data types with different values: basic biome map (low, indefinite), resource node locations (medium, seasonal), hidden location coordinates (high, one-time), frontier territory map (very high, short shelf life), danger assessment (medium, weekly refresh)
- [ ] Map data can be listed on the marketplace as an Information Good
- [ ] Subscription model available: other players can subscribe to an explorer's map updates
- [ ] Map accuracy and completeness are tracked; higher-quality data sells for more
- [ ] Explorer reputation builds with consistent, accurate map production

## Category
Economy

## Priority
Should

## Notes
- The best explorers are known across the world. Captain Senna Roth is the narrative exemplar.
- Frontier maps have short shelf life because the Frontier changes as others explore.
- See design/mechanics/secondary-mechanics.md "Map Data Economy" for the full data type table.
