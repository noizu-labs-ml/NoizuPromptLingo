# Spacing & Layout Tokens

| Field | Value |
|-------|-------|
| **ID** | `spacing-layout-tokens` |
| **Type** | Primary |
| **Category** | Draft Phase |
| **User Stories** | INK-025, INK-026 |

## Description

Generates spacing scale, grid specification, and component-level style tokens. Visualizes the spacing rhythm and shows per-component state previews (button, input, card, nav).

## Key Components

- **Spacing Scale Ruler** — Visual representation of spacing values (4px, 8px, 12px, 16px, etc.) (INK-025)
- **Grid Specification** — Columns, gutter, max-width diagram (INK-025)
- **Component Token Previews** — Button, Input, Card, Nav in default/hover/active/focus/disabled states (INK-026)
- **Token Export** — CSS/Tailwind export preview (INK-025)

## Interactions

- Spacing values are editable with live preview update
- Grid spec shows responsive behavior per breakpoint
- Component previews toggle between states on hover/click
- "Accept" advances to Style Guide Revision

## Navigation

- Accessible from: Typography Scale
- Links to: Style Guide Revision
