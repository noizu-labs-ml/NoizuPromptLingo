# Wireframe Editor

| Field | Value |
|-------|-------|
| **ID** | `wireframe-editor` |
| **Type** | Primary |

## Description

Interactive editor for wireframe annotation and modification. Supports pinned text annotations, drag-resize of layout blocks, and export configurations for different audiences (clients, students).

## Key Components

- **Wireframe Canvas** — Full wireframe with layout region blocks (INK-030)
- **Annotation Pins** — Click-to-add text annotations pinned to regions (INK-030)
- **Drag-Resize Handles** — Layout block manipulation controls (INK-030)
- **Export Config Panel** — Client presentation (logo/footer/branding) or educational (callouts/principles) modes (INK-032, INK-033)

## Interactions

- Click canvas to add annotation pin with text
- Drag handles to resize layout blocks
- Add/remove placeholder components
- Export panel configures output for different audiences
- Branded deck builder for client presentations (INK-032)
- Educational callout mode with complexity toggle (INK-033)
