# Typography Scale

| Field | Value |
|-------|-------|
| **ID** | `typography-scale` |
| **Type** | Primary |
| **Category** | Draft Phase |
| **User Stories** | INK-024 |

## Description

Generates a typography system (h1-h6, body, caption, label) with font pairing and responsive breakpoint variants. Users preview rendered type at each scale level.

## Key Components

- **Type Scale Preview** — h1-h6 + body/caption/label rendered at actual sizes (INK-024)
- **Font Pairing Display** — Selected heading + body font combination (INK-024)
- **Responsive Breakpoint Table** — Size values at each breakpoint (INK-024)
- **Token Export** — CSS/Tailwind token preview (INK-024)

## Interactions

- Font pairing is editable via dropdown selector
- Type scale entries show responsive values
- "Accept" advances to Spacing & Layout Tokens

## Navigation

- Accessible from: Color Palette Editor
- Links to: Spacing & Layout Tokens
