# INK-024: Typography Scale Generation

**As a** product manager,
**I want to** receive a typographic scale (font families, sizes, weights, line heights) that pairs well with my color palette,
**So that** engineering receives an unambiguous type spec they can implement directly.

**Primary Persona:** Kevin Tanaka (#8)
**Phase:** Draft
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] Scale includes heading levels (h1-h6), body, caption, and label styles
- [ ] Font pairing is selected from freely licensable typefaces (Google Fonts or system fonts)
- [ ] Responsive breakpoints are defined for each size step
- [ ] Output includes concrete CSS or design token values, not vague descriptions
