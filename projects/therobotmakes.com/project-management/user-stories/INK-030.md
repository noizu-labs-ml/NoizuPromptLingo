# INK-030: Wireframe Annotation and Editing

**As a** small team lead,
**I want to** annotate wireframes with comments and move or resize layout regions,
**So that** I can adjust the AI output before sharing it with my team as the approved layout spec.

**Primary Persona:** Rina Patel (#3)
**Phase:** Draft
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] User can add text annotations pinned to specific regions of a wireframe
- [ ] User can drag to reposition and resize layout blocks within the wireframe
- [ ] User can add or remove placeholder components (e.g., add a sidebar, remove a hero section)
- [ ] All edits are saved and reflected in downstream mockup generation
