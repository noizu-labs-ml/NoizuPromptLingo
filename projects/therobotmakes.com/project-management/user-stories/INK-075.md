# INK-075: Subscription Upgrade Flow

**As a** UX designer,
**I want to** upgrade my subscription from within the app when I hit a phase gate (e.g., trying to enter Ink phase on Pro),
**So that** I can continue my design-to-code workflow without leaving the project context.

**Primary Persona:** Sofia Reyes (#5)
**Phase:** Platform
**Priority:** P0-Critical

**Acceptance Criteria:**
- [ ] When a user attempts to enter a locked phase, a contextual upgrade modal appears (not a redirect to a separate page)
- [ ] Modal shows only the relevant upgrade options (current tier and above)
- [ ] Payment is processed via Stripe with support for credit card and common payment methods
- [ ] After successful upgrade, the user is returned to exactly where they were and the phase unlocks immediately
- [ ] Downgrade option is accessible from account settings with clear explanation of what access will be lost
