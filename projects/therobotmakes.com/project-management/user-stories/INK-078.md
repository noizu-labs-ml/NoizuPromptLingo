# INK-078: Project Resume from Any Step

**As a** product manager,
**I want to** close a project and resume it later from exactly where I left off, with all prior work and agent context preserved,
**So that** I can work on specs across multiple sessions without losing progress.

**Primary Persona:** Kevin Tanaka (#8)
**Phase:** Platform
**Priority:** P0-Critical

**Acceptance Criteria:**
- [ ] Clicking "Continue" on a project card opens it at the exact step and state where it was last active
- [ ] All prior step outputs (PRD, designs, code, review results) are preserved and accessible
- [ ] Agent context from previous sessions is restored so the AI remembers prior decisions
- [ ] Resume works across devices (state is server-persisted, not local storage)
- [ ] A project timeline/breadcrumb shows all completed steps for easy navigation to prior work
