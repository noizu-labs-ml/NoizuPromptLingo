# INK-036: Mockup Approval Gate

**As an** enterprise innovation lead,
**I want to** formally approve or reject each mockup screen with status tracking,
**So that** I have documented sign-off before the project moves to the Ink (Build) phase.

**Primary Persona:** Chen Wei (#9)
**Phase:** Draft
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] Each mockup screen has an explicit status: Pending, Approved, Needs Revision, or Rejected
- [ ] User can add a rationale note when marking a screen as Needs Revision or Rejected
- [ ] The Draft phase cannot advance to Ink until all screens are Approved or explicitly skipped
- [ ] An approval summary report is generated showing status of each screen and any revision notes
