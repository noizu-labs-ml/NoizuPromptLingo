# INK-021: AI-Recommended Style Preset

**As a** non-technical founder,
**I want to** receive an AI-recommended style preset based on my product type and target audience,
**So that** I get a professional visual direction without needing design expertise.

**Primary Persona:** David Liu (#4)
**Phase:** Draft
**Priority:** P0-Critical

**Acceptance Criteria:**
- [ ] AI analyzes the approved PRD (product type, audience, tone) and recommends a ranked list of style presets
- [ ] Each recommendation includes a brief rationale explaining why it fits the product
- [ ] User can accept the top recommendation with a single click or browse alternatives
- [ ] Recommendation accounts for industry norms (e.g., fintech skews Corporate Enterprise, consumer apps skew Playful)
