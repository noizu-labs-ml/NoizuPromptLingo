# INK-053: Real-Time Agent Activity Dashboard

**As a** content creator building in public,
**I want to** see a live dashboard showing what each agent is doing right now (which file, which story, what action),
**So that** I can screenshot and share my "AI is building my app" progress with my audience.

**Primary Persona:** Maya Jackson (#10)
**Phase:** Ink
**Priority:** P0-Critical

**Acceptance Criteria:**
- [ ] Dashboard displays active agents with their current status (Idle, Working, Waiting for Approval)
- [ ] Each active agent shows: current story, current file being edited, elapsed time on current task
- [ ] Live code diff streams in real time as the Coder Agent writes (character-by-character or chunk-by-chunk)
- [ ] Terminal output panel shows agent commands (install, test, lint) with live stdout/stderr
- [ ] Dashboard auto-updates without page refresh via WebSocket or SSE
