# INK-080: Project Archiving and Read-Only Sharing

**As a** small team lead,
**I want to** archive completed projects and share a read-only link with stakeholders,
**So that** my team can reference past project specs and deployed artifacts without cluttering the active dashboard.

**Primary Persona:** Rina Patel (#3)
**Phase:** Platform
**Priority:** P2-Medium

**Acceptance Criteria:**
- [ ] "Archive" moves a project off the main dashboard into an "Archived" tab/filter
- [ ] Archived projects are read-only — no edits or agent actions can be triggered
- [ ] Archived projects can be restored to active status at any time
- [ ] "Share" generates a read-only URL that non-authenticated viewers can access
- [ ] Shared link displays all project phases and outputs but hides sensitive data (env vars, API keys)
- [ ] Share links can be revoked by the project owner
