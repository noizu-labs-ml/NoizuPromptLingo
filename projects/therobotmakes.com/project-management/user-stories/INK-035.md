# INK-035: Mockup Revision Workflow

**As a** UX designer,
**I want to** request targeted revisions to specific mockup screens using natural language or visual markup,
**So that** I can iterate on visual details without regenerating the entire set.

**Primary Persona:** Sofia Reyes (#5)
**Phase:** Draft
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] User can select a region of a mockup and describe a change (e.g., "make this CTA button larger and green")
- [ ] AI regenerates only the affected screen, preserving approved screens
- [ ] Before/after comparison is shown for each revision
- [ ] Revision count and history are tracked per screen so the user can revert
