# INK-022: Manual Style Preset Selection

**As a** UX designer,
**I want to** browse and select from the full catalog of style presets (Minimal Tech, Corporate Enterprise, Consumer Playful, Editorial, Bold Expressive, Nocturne),
**So that** I can apply my own design judgment rather than relying solely on the AI recommendation.

**Primary Persona:** Sofia Reyes (#5)
**Phase:** Draft
**Priority:** P0-Critical

**Acceptance Criteria:**
- [ ] All six presets are displayed with live visual previews (color swatches, type samples, spacing rhythm)
- [ ] User can switch between presets and see the preview update in real time
- [ ] Selected preset is applied as the foundation for the generated style guide
- [ ] User can change their selection at any point before finalizing the style guide
