# INK-008: Resume an In-Progress Pitch

**As a** solo developer,
**I want to** close my browser and pick up my pitch exactly where I left off,
**So that** I can work on my weekend project in short bursts without losing progress.

**Primary Persona:** Marcus Chen (#1)
**Phase:** Sketch
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] All pitch content, including drafts and AI refinements, is auto-saved on every change
- [ ] Returning to the project loads the exact state the user last saw, including cursor position in text fields
- [ ] The dashboard shows a "Last edited" timestamp for each project
- [ ] Projects in the Pitch step display a clear "Continue" action distinct from "Start New"
- [ ] No data is lost if the browser crashes or the tab is closed unexpectedly
