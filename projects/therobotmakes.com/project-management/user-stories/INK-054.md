# INK-054: Story Backlog Kanban View

**As a** product manager,
**I want to** see all stories in a Kanban board (Queued, In Progress, In Review, Done, Rejected),
**So that** I have the same project visibility I use with my engineering teams.

**Primary Persona:** Kevin Tanaka (#8)
**Phase:** Ink
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] Stories are displayed in a Kanban board with columns: Queued, In Progress, In Review, Done, Rejected
- [ ] Cards show story title, priority badge, assigned agent, and acceptance criteria progress (e.g., 2/4 passing)
- [ ] Clicking a card opens the story detail view with diff, review comments, and criteria checklist
- [ ] Board updates in real time as agents move stories through stages
- [ ] User can filter by priority, agent type, or story tag
