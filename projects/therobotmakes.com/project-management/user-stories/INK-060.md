# INK-060: Demo Snapshot and Comparison

**As a** content creator,
**I want to** take before/after snapshots of the preview at different story milestones,
**So that** I can create build-in-public progress threads showing the app evolving story by story.

**Primary Persona:** Maya Jackson (#10)
**Phase:** Ink
**Priority:** P2-Medium

**Acceptance Criteria:**
- [ ] A "Snapshot" button captures a full-page screenshot of the current preview at desktop, tablet, and mobile viewports
- [ ] Snapshots are labeled with the story ID and timestamp and stored in a gallery view
- [ ] A comparison mode shows two snapshots side by side with a slider overlay to highlight differences
- [ ] Snapshots can be downloaded as PNG or shared via a public gallery link
- [ ] Auto-snapshot is optionally triggered after each story approval for a complete build timeline
