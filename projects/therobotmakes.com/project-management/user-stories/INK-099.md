# INK-099: Screen Reader Support for Agent Status Updates

**As a** visually impaired user running the Ink phase,
**I want** real-time agent status updates to be announced by my screen reader,
**So that** I know what the system is doing without relying on visual indicators.

**Primary Persona:** David Liu (#4)
**Phase:** Platform
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] Agent status messages use ARIA live regions (`aria-live="polite"`) to announce updates
- [ ] Phase transitions (e.g., "Moving from Draft to Ink") use `aria-live="assertive"`
- [ ] Progress indicators convey percentage or step count via `aria-valuenow` / `aria-valuetext`
- [ ] Error states are announced immediately with descriptive messages (not just icon changes)
- [ ] Loading spinners have `aria-label` descriptions (e.g., "Generating code, please wait")
- [ ] The agent activity log is navigable as a list with screen reader-friendly semantics
