# INK-071: Quick Actions on Project Cards

**As an** indie hacker,
**I want to** access quick actions (continue, duplicate, export, archive, view demo) directly from each project card,
**So that** I can manage my projects without navigating into each one individually.

**Primary Persona:** Jules Okafor (#2)
**Phase:** Platform
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] Each card has a "Continue" primary action that resumes at the last active step
- [ ] A menu (kebab or dropdown) exposes: Duplicate, Export, Archive, View Demo, Delete
- [ ] "View Demo" is only available for projects that have reached the Ink phase or later
- [ ] Quick actions execute with a confirmation dialog for destructive actions (archive, delete)
