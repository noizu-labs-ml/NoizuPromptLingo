# INK-089: BYOK — Bring Your Own API Key Management

**As a** solo developer who already pays for API access,
**I want to** add my own API keys to reduce Ink phase costs,
**So that** I can use my existing provider accounts instead of paying noizu.ink's markup.

**Primary Persona:** Marcus Chen (#1)
**Phase:** Platform
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] Settings page includes an "API Keys" section where users can add, edit, and delete provider keys
- [ ] Supported providers are listed with status indicators (configured / not configured)
- [ ] Keys are stored encrypted and are never displayed in full after initial entry (masked with last 4 characters)
- [ ] A "Test Key" button validates that the key works before saving
- [ ] When a BYOK key is configured, the Ink phase displays estimated cost savings compared to platform-provided usage
- [ ] If a BYOK key fails during Ink execution, the system surfaces a clear error with a link to key settings
