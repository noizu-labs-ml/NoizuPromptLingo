# INK-005: Describe a New Project Idea

**As an** indie hacker,
**I want to** describe my product idea in a few sentences,
**So that** the system can help me shape it into something I can ship for revenue.

**Primary Persona:** Jules Okafor (#2)
**Phase:** Sketch
**Priority:** P0-Critical

**Acceptance Criteria:**
- [ ] User can create a new project and enter a free-text pitch of 2-3 sentences
- [ ] The input field accepts between 20 and 500 characters
- [ ] The pitch is saved as a draft immediately so progress is never lost
- [ ] A clear "Next" action advances the user to AI refinement
- [ ] The project appears in the dashboard with a "Sketch: Pitch" status badge
