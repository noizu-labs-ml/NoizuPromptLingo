# INK-001: Email/Password Signup

**As a** non-technical founder,
**I want to** create an account with my email and a password,
**So that** I can save my project ideas and return to them later.

**Primary Persona:** David Liu (#4)
**Phase:** Platform
**Priority:** P0-Critical

**Acceptance Criteria:**
- [ ] User can enter email, password, and password confirmation to create an account
- [ ] Password must meet minimum strength requirements (8+ chars, mixed case, number)
- [ ] A verification email is sent upon signup and the account is not active until verified
- [ ] Duplicate email addresses are rejected with a clear error message
- [ ] After verification, the user is redirected to the project dashboard
