# INK-066: Environment Configuration

**As a** non-technical founder,
**I want to** configure environment variables, custom domain, and database connection through a guided form with plain-English labels,
**So that** I can set up my production environment without understanding technical infrastructure.

**Primary Persona:** David Liu (#4)
**Phase:** Publish
**Priority:** P0-Critical

**Acceptance Criteria:**
- [ ] Environment variables are presented with human-readable labels and descriptions (e.g., "Payment Secret Key" not "STRIPE_SECRET_KEY")
- [ ] Required vs. optional variables are clearly distinguished
- [ ] Custom domain setup includes step-by-step DNS instructions with provider-specific guidance
- [ ] Database provisioning offers a managed option (auto-provision) alongside manual connection string entry
- [ ] Sensitive values are masked after entry and stored encrypted
