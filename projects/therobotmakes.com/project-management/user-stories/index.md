## MVP Scope Recommendation

A minimal viable product should cover all P0 stories (~22), giving:
- Auth (signup/login)
- Sketch phase core (pitch, personas, stories, PRD)
- Draft phase core (style preset, colors, wireframes, mockups)
- Ink phase core (scaffold, agent dev, approve/reject, dashboard, preview)
- Publish phase core (code review, security scan, deploy, env config)
- Dashboard (project cards, new project)
- Billing (tier display, upgrade flow)
- Landing page (animated demo, pricing, CTA)
- Onboarding (wizard-as-onboarding)
- Accessibility (WCAG 2.2 AA)
