# INK-048: Auto-Check Acceptance Criteria During Development

**As a** product manager,
**I want to** see acceptance criteria automatically validated as the agent implements each story,
**So that** I know at a glance whether the implementation actually meets the requirements I defined.

**Primary Persona:** Kevin Tanaka (#8)
**Phase:** Ink
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] Each acceptance criterion is displayed as a checklist item alongside the story during development
- [ ] Tester Agent runs automated checks (unit tests, integration tests, visual assertions) mapped to each criterion
- [ ] Criteria that pass are marked with a green check; failures show a red X with a brief explanation
- [ ] User can manually override a criterion's status (mark as passed/failed) with a note
- [ ] Story cannot be auto-approved unless all acceptance criteria pass or are manually overridden
