# INK-098: Full Keyboard Navigation for Wizard and Dashboard

**As a** power user who prefers keyboard navigation,
**I want to** complete all wizard steps, navigate the dashboard, and trigger exports using only the keyboard,
**So that** I can work efficiently without switching between mouse and keyboard.

**Primary Persona:** Marcus Chen (#1)
**Phase:** Platform
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] All wizard steps can be completed using Tab, Shift+Tab, Enter, Space, and Arrow keys
- [ ] Focus order follows a logical reading sequence on every page
- [ ] Modal dialogs trap focus and return focus to the trigger element on close
- [ ] Skip-to-content links are available on all pages
- [ ] Keyboard shortcuts are documented in an accessible help panel (opened via `?` key)
- [ ] No keyboard traps exist anywhere in the application
