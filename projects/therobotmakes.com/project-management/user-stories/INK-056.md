# INK-056: Agent Activity Log and Error Reporting

**As a** small team lead,
**I want to** see a chronological log of all agent actions, decisions, and errors across all stories,
**So that** I can diagnose issues and understand why an agent made a particular implementation choice.

**Primary Persona:** Rina Patel (#3)
**Phase:** Ink
**Priority:** P2-Medium

**Acceptance Criteria:**
- [ ] Activity log displays timestamped entries for: story started, file created/modified, test run, test passed/failed, story submitted for review
- [ ] Error entries are highlighted in red and include the full error message and stack trace
- [ ] Each log entry links to the relevant story and file
- [ ] Log is filterable by agent type (Coder, Tester, Reviewer, Design), story, and severity
- [ ] Log is exportable as JSON or CSV for external analysis
