# INK-062: Test Coverage Report

**As a** product manager,
**I want to** see a test coverage report showing which features have automated tests and which do not,
**So that** I can communicate confidence levels to my engineering team before handoff.

**Primary Persona:** Kevin Tanaka (#8)
**Phase:** Publish
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] Test coverage percentage is displayed as an overall score and per-module breakdown
- [ ] Untested code paths are visually highlighted in a coverage map
- [ ] Report distinguishes between unit tests, integration tests, and e2e tests
- [ ] Coverage report is exportable as PDF or Markdown for team sharing
