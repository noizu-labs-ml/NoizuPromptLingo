# INK-072: New Project Entry Point

**As a** CS instructor,
**I want to** start a new project from the dashboard with a prominent "+ New Project" button,
**So that** I can quickly generate a new project spec for an upcoming class assignment.

**Primary Persona:** Tom Brennan (#6)
**Phase:** Platform
**Priority:** P0-Critical

**Acceptance Criteria:**
- [ ] A "+ New Project" button is always visible on the dashboard (card-style element or fixed button)
- [ ] Clicking it begins the Sketch phase (Step 1) for a new project
- [ ] If the user has reached their project limit (Free tier: 3), the button shows an upgrade prompt instead
- [ ] New project appears on the dashboard immediately in a "draft" state
