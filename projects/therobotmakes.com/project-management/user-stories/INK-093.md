# INK-093: Shareable Read-Only Project Links

**As a** small team lead,
**I want to** share a read-only link to my project with my team,
**So that** they can review the spec and designs without needing noizu.ink accounts.

**Primary Persona:** Rina Patel (#3)
**Phase:** Platform
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] Each project has a "Share" button that generates a unique read-only URL
- [ ] The shared view displays all completed phase outputs (Sketch spec, Draft designs, Ink code, Publish artifacts)
- [ ] Viewers do not need to create an account or log in
- [ ] The project owner can revoke or regenerate the share link at any time
- [ ] Shared links display a "Built with noizu.ink" footer with a CTA to create their own project
