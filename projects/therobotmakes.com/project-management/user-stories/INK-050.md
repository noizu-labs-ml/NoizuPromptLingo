# INK-050: Rollback an Agent's Changes Per Story

**As a** solo developer,
**I want to** revert all code changes from a specific story's implementation with one click,
**So that** I can undo a bad agent attempt without manually hunting through commits.

**Primary Persona:** Marcus Chen (#1)
**Phase:** Ink
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] Each completed or approved story has a "Rollback" action in the story detail view
- [ ] Rollback reverts all commits associated with that story and moves it back to Queued status
- [ ] Dependent stories that were built on top of the rolled-back story are flagged for re-review
- [ ] A confirmation dialog warns the user about downstream impacts before executing
- [ ] Rollback history is preserved so the user can re-apply the reverted changes if needed
