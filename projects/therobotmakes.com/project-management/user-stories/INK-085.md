# INK-085: Wizard-as-Onboarding — First Sketch Flow

**As a** solo developer creating my first project,
**I want** the Sketch wizard itself to teach me how the platform works through contextual prompts,
**So that** I learn by doing instead of reading a tutorial I'll skip anyway.

**Primary Persona:** Marcus Chen (#1)
**Phase:** Platform
**Priority:** P0-Critical

**Acceptance Criteria:**
- [ ] First-time users entering Sketch see inline contextual tips explaining each input field
- [ ] Tips are dismissible individually and collectively ("Don't show tips again")
- [ ] The wizard pre-fills an example project idea as placeholder text to demonstrate expected input
- [ ] Completing the first Sketch triggers a brief celebration moment and a prompt to continue to Draft
- [ ] No separate tutorial, onboarding modal, or video is required to understand the core flow
