# INK-094: Multi-Format Export from Any Phase

**As a** UX designer,
**I want to** export my Draft output in multiple formats (Markdown, PDF, Figma spec),
**So that** I can bring noizu.ink artifacts into my existing design and documentation tools.

**Primary Persona:** Sofia Reyes (#5)
**Phase:** Platform
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] Each completed phase displays an "Export" menu with format options relevant to that phase
- [ ] Sketch phase supports: Markdown, PDF
- [ ] Draft phase supports: Markdown, PDF, HTML, Figma spec (structured JSON)
- [ ] Ink phase supports: ZIP (full code), GitHub repo push, Markdown summary
- [ ] Publish phase supports: ZIP (deployment bundle), Markdown changelog
- [ ] Exported files include metadata headers (project name, phase, export date, noizu.ink version)
