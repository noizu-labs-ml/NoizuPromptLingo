# INK-088: Empty State Dashboard with Quick-Start Prompt

**As a** non-technical founder who just signed up,
**I want** the dashboard to guide me toward creating my first project instead of showing an empty list,
**So that** I know exactly what to do next.

**Primary Persona:** David Liu (#4)
**Phase:** Platform
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] When a user has zero projects, the dashboard displays an illustrated empty state with a clear "Create your first project" CTA
- [ ] The empty state includes a one-sentence explanation of what a project is in noizu.ink
- [ ] At least one example project template is offered as a quick-start option ("Try this example")
- [ ] After the first project is created, the empty state is replaced by the standard project list
- [ ] The empty state is visually consistent with the landing page brand and tone
