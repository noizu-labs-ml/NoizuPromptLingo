# INK-004: Password Reset

**As a** small team lead,
**I want to** reset my forgotten password via email,
**So that** I can regain access to the project specs my team depends on.

**Primary Persona:** Rina Patel (#3)
**Phase:** Platform
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] A "Forgot password?" link is visible on the login screen
- [ ] User enters their email and receives a reset link within 60 seconds
- [ ] The reset link expires after 1 hour and can only be used once
- [ ] User can set a new password that meets the same strength requirements as signup
- [ ] After resetting, the user is logged in and all active sessions on other devices are invalidated
