# INK-042: Select and Customize Tech Stack Before Scaffolding

**As a** non-technical founder,
**I want to** choose from recommended tech stacks presented in plain English (e.g., "Fast web app with database" rather than "Next.js + Postgres"),
**So that** I make an informed infrastructure decision without needing to understand framework differences.

**Primary Persona:** David Liu (#4)
**Phase:** Ink
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] System presents 2-3 recommended stack options derived from the PRD, each with a plain-English summary of tradeoffs (speed, cost, scalability)
- [ ] Each option shows estimated build time, hosting cost range, and complexity rating
- [ ] User can accept a recommendation or request a custom combination
- [ ] Selected stack is locked into the project config and drives all subsequent agent behavior
- [ ] A "Why this stack?" expandable section explains the rationale for each recommendation
