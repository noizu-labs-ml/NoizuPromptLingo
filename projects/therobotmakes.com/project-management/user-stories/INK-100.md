# INK-100: Mobile-Responsive Wizard and Dashboard

**As a** content creator who works primarily from my phone,
**I want** the wizard and dashboard to be fully usable on mobile devices,
**So that** I can start and check on projects from anywhere.

**Primary Persona:** Maya Jackson (#10)
**Phase:** Platform
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] All wizard steps are usable on screens 375px wide and above without horizontal scrolling
- [ ] Touch targets are at least 44x44px per WCAG 2.5.8
- [ ] The dashboard project list adapts to a card layout on mobile
- [ ] Navigation uses a mobile-friendly pattern (bottom nav or hamburger menu)
- [ ] Export and share actions are accessible from mobile without requiring desktop-only interactions
- [ ] Text remains readable without zooming (minimum 16px body text on mobile)
