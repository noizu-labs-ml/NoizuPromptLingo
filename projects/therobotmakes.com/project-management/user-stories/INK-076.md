# INK-076: Compute Overage Tracking and Alerts

**As an** indie hacker,
**I want to** see my current compute usage relative to my plan's included allocation and get alerts before overage charges hit,
**So that** I can manage costs and avoid surprise bills while building and deploying projects.

**Primary Persona:** Jules Okafor (#2)
**Phase:** Platform
**Priority:** P1-High

**Acceptance Criteria:**
- [ ] A usage meter is visible in account settings showing compute used vs. included allocation
- [ ] Usage is broken down by project (which projects are consuming compute)
- [ ] Email alert is sent at 80% and 100% of included compute allocation
- [ ] In-app banner warns when overage charges will apply on the next compute action
- [ ] Overage pricing is displayed clearly per unit (e.g., per build-minute or per deploy)
