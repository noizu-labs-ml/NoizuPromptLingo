03 — Spacing, Gutters & Whitespace

Whitespace is the brand. noizu.ink uses generous open space to convey calm authority — the confidence of a blank page before the first stroke. Sections breathe. Elements float. Nothing is cramped.

Section Spacing

Every major section is separated by a hairline rule and surrounded by 144px (5xl) vertical padding. This is intentionally extravagant — the empty space IS the design.

Context Vertical Padding Divider
Landing page hero 144px top & bottom 1px hairline below
Landing page sections 144px top & bottom 1px hairline between each
Wizard step content 32px None (contained in panel)
Dashboard content 48px None
Section heading → content 64–96px Heading floats high above content
Card grid gaps 24px —

Whitespace Principles

1. Empty space is intentional, not leftover. Every gap is a deliberate choice. If you're unsure whether something needs more space, it does.
2. Sections should feel like separate pages. A user scrolling through the landing page should feel like they're turning pages of a book, not reading a continuous feed.
3. Headings need room to land. 64–96px between a section heading and its first content element. The heading announces; the space lets it resonate.
4. Content width < container width. Body text and forms should be narrower (600–720px) than the page container (960px), creating visible side margins that frame the content like a printed page.
5. When in doubt, double the padding. The brand is calligraphy on open paper. If it looks like a SaaS dashboard, add more space.
