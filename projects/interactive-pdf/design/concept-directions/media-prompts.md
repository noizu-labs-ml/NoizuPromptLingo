# iPDF — Design Direction Media Prompts

> **Note:** These prompts produce *impressionistic* concept art for design direction exploration, not accurate UI previews. Generated images are mood references only — actual UI will be designed from the chosen direction.
>
> **Recommended tools:** Midjourney v6.1 (`/imagine`), Flux Pro 1.1, or DALL-E 3 via ChatGPT.  
> **Aspect ratio:** Use `--ar 16:9` for hero shots, `--ar 4:3` for UI detail.

---

## Direction 1: Scholar's Lantern

**Mood:** Warm, focused, intellectual. Reading by lamplight. A private study.  
**Design system:** Nocturne (80%) + Editorial (20%)  
**Signals:** Premium, intimate, literary, calm authority  
**Primary persona:** Bob (self-learner), Maya (researcher)

**Color palette:**
- Background: deep charcoal `#1c1917` + warm slate `#292524`
- Body text: warm cream `#fef3c7`
- Sentence highlight: amber glow `#f59e0b` at 30% opacity
- Accent: deep amber `#d97706`
- Sidebar: near-black `#0f0e0d`

**Typography:** EB Garamond (body), Inter (UI chrome), monospace footnotes

## Recommended Starting Point

**Scholar's Lantern + Clinical Focus** as the two finalists for A/B comparison.

- Scholar's Lantern suits the dominant use case (passive listening/reading) — warm, low-eye-strain over long sessions
- Clinical Focus suits power users (Q&A, professional doc work) — fast, precise, high trust
- Could implement both as light/dark themes with a toggle

**If only one direction:** Scholar's Lantern. It's the most distinct in the market (most PDF readers default to stark white) and signals that iPDF takes the *reading experience* seriously, not just the AI layer.

---

## Prompt Tips

- **Midjourney:** Add `--no text, --no UI elements` if output includes garbled fake text that's distracting
- **Flux Pro:** More literal interpretation; use `--guidance 4.0` for stylized results, lower for photorealism
- **DALL-E 3:** Tends to add fake readable text — add "no readable text on screen" to prompt
- **Upscale:** For marketing heroes, upscale 2x in MJ before using in layouts
- **Variations:** Run each prompt 4 times (`--repeat 4`) — pick the best composition, not the first result
