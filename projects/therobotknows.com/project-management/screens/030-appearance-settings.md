# Appearance Settings

| Field | Value |
|-------|-------|
| **ID** | appearance-settings |
| **Type** | Settings |
| **Category** | Settings |
| **User Stories** | US-081 |

## Description

Theme, font size, and appearance customization.

## Key Components

- **Theme Selector** — Light mode, Dark mode, System default (US-081)
- **Theme Preview** — Visual preview of selected theme (US-081)
- **Font Size Slider** — Range 12px–24px for editor text (US-081)
- **Font Size Preview** | Live preview of selected size (US-081)
- **Save Button** — Apply changes (US-081)

## Interactions

- Theme switches immediately without page reload
- System default follows OS preference via media query
- Font size applies in Canon Editor body text
- Preferences sync across browsers via account settings
- Default to system preference on first visit

## Navigation

- Accessible from: Account Settings (Appearance tab)
- Links to: None
