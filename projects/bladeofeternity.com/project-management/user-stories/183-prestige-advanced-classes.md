# US-183: Prestige & Advanced Classes

**Persona:** Tyler — MMO refugee seeking deep growth systems
**Priority:** P2
**Epic:** Character Progression & Classes

## Story
As Tyler, I want to evolve my character into a prestige advanced class at endgame that requires specific achievements and unlocks exclusive abilities and narrative flavor so that reaching the top of character progression feels earned and dramatically significant.

## Acceptance Criteria
- [ ] Prestige class unlock available at level 30 (endgame milestone); each specialization has one corresponding prestige class (e.g., Guardian → Paragon; Berserker → Warlord)
- [ ] Prestige unlock requires completing a dedicated prestige quest line specific to each class path, minimum three quest stages with narrative culmination
- [ ] Prerequisite checklist displayed in prestige quest introduction: level requirement, specialization, and any achievement prerequisites (e.g., "Defeat the Siege Golem in the Iron Citadel") read aloud in SR-navigable list
- [ ] Prestige quest completion triggers a dramatic multi-part assertive ARIA announcement sequence: first the quest completion fanfare, then a pause, then the prestige class declaration read in full
- [ ] Prestige class grants: retitling of class field ("Paragon"), access to a prestige-only skill branch (minimum 5 skills), a unique passive ability unavailable to non-prestige characters, and a cosmetic narrative marker in all NPC interactions
- [ ] Prestige abilities and skills function at full effectiveness with no penalty; prestige branch integrates visually and semantically into the existing skill tree UI
- [ ] Prestige status visible in player inspection panel (US-196), character sheet, and clan roster; SR reads prestige class name with distinction from specialization
- [ ] Prestige class cannot be changed or reversed; system enforces this with server-side lock and client-side explanation

## Notes
Prestige classes are the aspirational horizon Tyler needs to stay engaged for 30+ levels. The prestige quest line is not just a gating mechanism — it is the capstone narrative event of the character's story arc. Jamie (IF enthusiast) will care deeply about the quest writing quality. The dramatic announcement sequence is a calculated use of assertive ARIA: one of perhaps four or five moments in the entire game designed to interrupt whatever the player is doing because the moment demands it. The unique passive for prestige characters creates visible mechanical distinction from non-prestige players — Marcus will want to know immediately when he's fighting a Paragon vs a Guardian in PvP. Ship this post-launch with the first major content expansion; it requires endgame tuning data to balance correctly.
