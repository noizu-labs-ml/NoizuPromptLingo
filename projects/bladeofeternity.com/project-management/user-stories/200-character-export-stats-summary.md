# US-200: Character Export & Stats Summary

**Persona:** Raj — Content creator and streamer documenting gameplay
**Priority:** P2
**Epic:** Character Progression & Classes

## Story
As Raj, I want to export my character's stats, achievements, and history as a shareable text summary or image card so that I can share my progress with my audience and other players in an accessible format that works for screen reader users as well as visual media.

## Acceptance Criteria
- [ ] Export initiated via character profile settings: "Export Character Summary" generates a structured document containing character name, title, class/specialization/prestige, level, key attributes, top achievements (5), titles earned, faction standings, crafting mastery summary, and notable milestones
- [ ] Two export formats: Plain Text (fully SR-readable, pasteable into any chat or document, uses accessible formatting with labeled sections and no reliance on symbols or ASCII art) and Image Card (visual summary card with high-contrast design, game branding, and alt-text generated automatically for social sharing)
- [ ] Image card alt-text generated by LLM from the same structured data: alt text describes character name, class, level, and top three achievements in plain language ("Marcus, Guardian Warrior level 24, holder of the title 'the Unbroken,' has defeated 300 players in PvP combat and completed the Iron Citadel raid.")
- [ ] Export respects privacy settings: stats or sections the player has marked private (US-196) are excluded from export automatically; privacy exclusions noted in export ("Faction standings: private")
- [ ] Plain text export usable by screen reader users without modification: no ASCII decorations, tables use plain colon-separated labels, all numbers written in digits
- [ ] Social sharing integration: one-click copy of plain text, direct share to supported platforms via Web Share API; image card downloadable as PNG with embedded alt-text metadata
- [ ] Export history: last 5 exports stored and viewable in character profile; each export timestamped and re-downloadable without regeneration cost
- [ ] Export available via API endpoint for integration with third-party tools and fan sites; API returns structured JSON with all public character data

## Notes
Raj's audience is diverse — some viewers use screen readers, and an image card without alt-text excludes them. The automatic alt-text generation from structured character data is the right solution: it doesn't require Raj to manually write accessibility text, and the LLM-generated description is more natural than mechanical alt-text. The plain text format is equally a first-class citizen — for Marcus, the plain text export is the primary way he would share his character with other blind players. The API endpoint serves Dave's hacker instincts and the broader fan community: character stat-tracking sites, Discord bots, and leaderboard integrations are realistic downstream uses. The image card design must be high-contrast and readable without color alone — Raj's audience includes Sarah (low-vision) and similar players. This feature lands at US-200, a symbolic milestone — the character export is in some sense the game looking back at everything built in this epic and saying: here is what you have made.
