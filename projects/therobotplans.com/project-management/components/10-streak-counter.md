# Streak Counter

| Field | Value |
|-------|-------|
| **ID** | `streak-counter` |
| **Category** | Data Display |
| **Used In** | 09-Habit Overview, 04-Weekly Review |

## Description

Numeric display of consecutive completions with personal best indicator and break warning

## Size Variants

| Variant | Description |
|---------|-------------|
| **Inline** | Number with flame/streak icon |
| **Compact** | Counter with personal best badge |

## Props / Configuration

- `current` — number
- `personalBest` — number
- `gracePeriod` — number
- `atRisk` — boolean

## Interactions

- hover for streak details
- click for full history
