# Notification Badge

| Field | Value |
|-------|-------|
| **ID** | `notification-badge` |
| **Category** | Feedback & Indicators |
| **Used In** | 05-Inbox, 53-Agent Team Dashboard |

## Description

Numeric count badge overlaid on nav items or icons indicating unread/pending items

## Size Variants

| Variant | Description |
|---------|-------------|
| **Inline** | Red dot or number on icon |

## Props / Configuration

- `count` — number
- `max` — display cap (e.g., 99+)
- `visible` — boolean

## Interactions

- click parent to navigate and clear
