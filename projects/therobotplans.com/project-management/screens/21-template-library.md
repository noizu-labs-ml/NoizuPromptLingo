# Template Library

| Field | Value |
|-------|-------|
| **ID** | `template-library` |
| **Type** | Settings |
| **Category** | Project Management |
| **User Stories** | US-030, US-063, US-067 |

## Description

Workspace-level library for project templates, document templates, item templates, and workflow templates. Centralized management with versioning and usage tracking.

## Key Components

- **Template list** — All templates with name, type, usage count
- **Category tabs** — Project, Document, Item, Workflow, Checklist
- **Search/filter** — Find templates by name, tag, or type
- **Template detail panel** — Preview template structure and configuration
- **Version history** — Track template changes over time
- **Usage count** — How many times each template has been applied
- **Create from template action** — Apply template to create new entity

## Interactions

- Browse by category or search
- Preview template before applying
- Create new template from scratch or clone existing
- Edit template (creates new version)
- Delete unused templates (with confirmation)

## Navigation

- Accessible from: Settings nav, Project Creation Wizard, Document editor
- Links to: Project Creation, Document Creation, Checklist Library
