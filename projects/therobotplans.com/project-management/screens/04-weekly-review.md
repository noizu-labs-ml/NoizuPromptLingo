# Weekly Review

| Field | Value |
|-------|-------|
| **ID** | `weekly-review` |
| **Type** | Primary |
| **Category** | Today & Daily Planning |
| **User Stories** | US-019 |

## Description

AI-generated weekly summary presenting accomplishments, missed items, habit streak status, time allocation, insights, and actionable suggestions. Supports personal reflection annotations and archives for historical comparison.

## Key Components

- **Completion summary** — Items completed this week by project/category
- **Missed/deferred items** — What didn't get done and why
- **Habit streak status** — Weekly habit completion rates and streak health
- **Time allocation chart** — Pie/bar chart of time across projects and categories
- **AI insights panel** — Pattern observations and productivity insights
- **Suggestions list** — Actionable recommendations for next week
- **Personal reflection editor** — Free-text area for user annotations
- **Review archive browser** — Navigate to past weekly reviews

## Interactions

- Auto-generated on a configurable day (default: Sunday evening)
- User can add personal reflections
- Dismiss or accept AI suggestions (creates items for next week)
- Compare current week to previous weeks
- Export as PDF/markdown

## Navigation

- Accessible from: Main nav, notification prompt on review day
- Links to: Review archive, Today Dashboard, Habit Overview
