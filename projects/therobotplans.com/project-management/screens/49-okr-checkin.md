# OKR Check-In

| Field | Value |
|-------|-------|
| **ID** | `okr-checkin` |
| **Type** | Storyboard |
| **Category** | Goals & OKRs |
| **User Stories** | US-071 |

## Description

Agent-drafted check-in flow with pre-filled progress data, velocity trends, risk flags, confidence ratings, and accept/edit/discard workflow. Runs on configurable cadence (weekly/biweekly).

## Key Components

- **Progress vs target** — Current progress compared to expected trajectory
- **Velocity trend** — Rate of progress over recent periods
- **Blockers list** — Identified blockers affecting key results
- **Confidence rating** — Red/yellow/green confidence in hitting target
- **Edit draft action** — Modify AI-generated check-in before publishing
- **Check-in history timeline** — All past check-ins for this OKR

## Flow Steps

1. **Review AI draft** — Agent pre-fills progress, blockers, confidence
2. **Edit** — Adjust any section for accuracy
3. **Submit** — Publish check-in (notifies stakeholders)

## Navigation

- Triggered from: Scheduled cadence, OKR Hierarchy (check-in action)
- Links to: OKR Hierarchy, Check-in history, Blocker items
