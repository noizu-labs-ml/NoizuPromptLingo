# Client Report Generator

| Field | Value |
|-------|-------|
| **ID** | `client-report-generator` |
| **Type** | Storyboard |
| **Category** | Project Management |
| **User Stories** | US-032 |

## Description

AI-generated client-facing status report with template customization, editable draft sections, and export/send options. Pulls data from project status, milestones, and completed work.

## Key Components

- **Report template selector** — Choose from predefined or custom report formats
- **AI-generated draft** — Auto-filled sections from project data
- **Editable sections** — Rich text editing of each report section
- **Export PDF action** — Generate downloadable PDF
- **Email send action** — Send report directly to client contacts
- **Report history** — Browse previously generated reports

## Flow Steps

1. **Select template** — Choose report format and target audience
2. **Review draft** — AI generates report from project data
3. **Edit** — Modify any section for tone/accuracy
4. **Export/Send** — Deliver via PDF download or email

## Navigation

- Triggered from: Project nav, Portfolio Dashboard, Gantt View
- Outputs to: PDF export, email delivery
