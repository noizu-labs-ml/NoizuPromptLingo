# Prompt Tag & Categorize

| Field | Value |
|-------|-------|
| **ID** | `prompt-tagging` |
| **Type** | Primary |
| **Category** | Prompt Archival & Versioning |
| **User Stories** | US-088 |

## Description

Tag management for archived prompts with effectiveness labels, boolean search across prompt content and metadata, and bulk tagging operations.

## Key Components

- **Tag browser** — All tags with usage counts and hierarchy
- **Effectiveness labels** — Rate prompts as effective/neutral/ineffective
- **Search with boolean** — Full-text search with AND/OR/NOT operators
- **Bulk tag action** — Apply tags to multiple prompts at once
- **Filter panel** — Filter by tag, effectiveness, agent, date

## Interactions

- Browse prompts by tag
- Search with boolean operators
- Apply effectiveness labels to versions
- Bulk-tag multiple prompts
- Create/rename/merge tags

## Navigation

- Accessible from: Prompt management nav
- Links to: Prompt Timeline, Prompt Template Library
