## User Story

As an **Alex Russo (Productivity Enthusiast)**, I want to maintain personal goals alongside team OKRs with optional visibility control so that my life goals and work goals live in one system without oversharing.

## Acceptance Criteria

- [ ] Personal OKRs/goals use the same data model and UI as team OKRs (scale-free: no separate "personal goals" feature)
- [ ] Visibility control per goal: private (only me), shared (selected people), or public (workspace-visible)
- [ ] Personal goals appear in the unified "today" view and weekly review alongside work items
- [ ] Agent check-ins (US-071) cover both personal and team goals in a single review session
- [ ] Switching between personal and team goal views is instant, with a combined view option

## Notes

This is core to tobornalp' "operational life platform" identity. Alex tracks fitness goals, learning goals, and side project goals alongside work. The visibility model must be bulletproof: private goals must never leak into team views, search results, or agent reports shared with others. Consider "life domains" as an organizational layer (health, career, learning, relationships).
