# NOIZUAI-15: BookmarkFlow

**Domain:** bookmarkflow.com

## Project Idea

AI-native bookmarking system for humans and LLMs, enabling searchable personal notes and shared agent knowledge bases. BookmarkFlow reimagines bookmarking for the agentic era — users and AI agents can save, annotate, and organize web resources with AI-generated summaries, semantic search, and shared knowledge graphs that both humans and agents can query and build upon.
