# ExLlama.dev

**Domain:** [exllama.dev](http://exllama.dev)

## Project Idea

Quantized LLM inference toolkit — developer tools, benchmarks, and optimization guides around ExLlama/GPTQ for efficient local model serving. Includes performance profiling dashboards, quantization recipe comparisons, and deployment templates for running large models on consumer hardware.
