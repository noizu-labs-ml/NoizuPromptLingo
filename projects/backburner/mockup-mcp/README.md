# NOIZUAI-3: Mockup MCP

**Domain:** securamcp.com

## Project Idea

Product mockup generator using image AI and frameworks like PlantUML/SVG, with feedback collection website. Mockup MCP provides an MCP service for generating product mockups, wireframes, and architectural diagrams using AI image generation alongside structured diagramming tools (PlantUML, SVG, Mermaid). Includes a companion website for collecting stakeholder feedback on generated mockups.
