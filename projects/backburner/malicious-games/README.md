# Malicious Games Franchise

**Domains:** [malicious-gamers.com](http://malicious-gamers.com) | [malicious-mercenaries.com](http://malicious-mercenaries.com) | [malicious-mobbers.com](http://malicious-mobbers.com)

## Project Idea

Cybersecurity-themed multiplayer game franchise where players attack and defend AI systems in gamified red-team vs blue-team scenarios. Each title focuses on a different threat vector — social engineering (Gamers), targeted attacks (Mercenaries), and coordinated swarm exploits (Mobbers). Players learn real security concepts through competitive gameplay.
