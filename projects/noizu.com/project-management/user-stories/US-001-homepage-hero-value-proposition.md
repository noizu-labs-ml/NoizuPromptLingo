# US-001: Homepage Hero & Value Proposition

## User Story

**As a** non-technical CEO evaluating consulting options (P-003),
**I want to** immediately understand what Keith does, who he serves, and why I should trust him,
**So that** I can quickly decide whether to continue reading or reach out.

## Acceptance Criteria

- [ ] Given a visitor arrives at the root URL, when the page loads, then the hero section is visible above the fold on desktop (1280px) and mobile (375px) without scrolling.
- [ ] Given the hero is rendered, when a visitor reads it, then a clear headline, sub-headline, and primary CTA ("Let's Talk" or equivalent) are all present.
- [ ] Given a non-technical founder visits, when reading the hero, then the copy does not rely on unexplained acronyms or jargon.
- [ ] Given any viewport width, when the page loads, then the hero layout is responsive and no text is clipped or overflows.
- [ ] Given the CTA button is clicked, when the user is redirected, then they land on the contact/inquiry form (US-011).

## Notes

Copy should communicate the Fractional CTO / Principal Engineer positioning. Trust signals (years experience, notable clients or outcomes) should appear within the first scroll. Related: US-002 (services page), US-011 (contact form).
