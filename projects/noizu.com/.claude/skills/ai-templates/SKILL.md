# AI Templates

Build, launch, and scale AI-powered digital products from prompt libraries to MCP server packages.

## Overview

The AI Templates skill transforms technical expertise into revenue-generating digital products. From prompt libraries to custom MCP servers, this skill covers the full lifecycle: ideation, validation, development, launch, and iteration.

**Core Value Proposition:**
- Solve high-value problems in underserved niches
- Package as premium products ($27-497 price range)
- Deliver instantly (digital, no fulfillment)
- Achieve revenue with minimal ongoing support

## When to Use This Skill

- **Building a new product** — Scope, develop, and package an AI template product
- **Launching a product** — Optimize listings, pricing, and promotional copy
- **Iterating on a product** — Refine prompts, improve documentation, update pricing
- **Planning a product line** — Decide what to build next, bundle strategy, portfolio gaps
- **Optimizing sales** — A/B test headlines, improve conversions, reduce refunds

> For niche research and market validation, see **market-intelligence**. Use it before this skill to validate demand.

> For stream selection and portfolio-level strategy, see **monetization-strategy** and **conversion-engineer**.

## Revenue Model

- **One-time purchases:** $27-497 per sale
- **Subscription tier:** $9-49/month for platform access (after 3+ products)
- **Volume strategy:** High margin, relatively low volume (5-50 sales/month per product)

**Typical conversion funnel:**
- 5,000 impressions on landing page
- 500 click through (10% CTR)
- 50 purchase (10% conversion = 1% overall)
- **Result:** ~$2,350 revenue per product at $47 price

## Development Workflow

### Phase 1: Niche Research & Validation (3-5 hours)

1. Identify problem space (pain point, audience size, willingness to pay)
2. Estimate market size and competition
3. Find your angle (differentiation)
4. Validate via audience/community feedback

> Use **market-intelligence** skill for systematic niche discovery and scoring. Pre-researched niches are summarized below.

### Phase 2: Product Scoping (1-2 days)

1. Define product scope (what's included, what's out)
2. Create requirements document
3. Define competitive positioning
4. Map user journey from purchase to ongoing use

> See `references/agent-playbook.md` for scoping prompts and requirements templates.

### Phase 3: Development (1-4 weeks)

1. Create core material (prompts, workflows, code)
2. Build supporting assets (guide, examples, use cases)
3. Test all prompts (target 8+/10 average quality)
4. Polish and package

> See `references/agent-playbook.md` for draft creation and testing workflows.

### Phase 4: Launch (1-2 weeks)

1. Create sales page copy (headline, benefits, FAQ)
2. Choose platform (Gumroad recommended for V1)
3. Set pricing (test $47-97 for first product)
4. Build promotional materials (email sequence, social posts)
5. Execute launch day plan

> See `references/templates-reference.md` for launch copy frameworks and checklists.

### Phase 5: Iteration (Ongoing)

1. Monitor sales velocity and conversions
2. Track customer feedback and refund rate
3. Refine prompts based on usage data
4. Plan V2 improvements or new products

> Track everything in `assets/project-tracker.md`.

## Platform Strategy

### Primary Launch: Gumroad
- **Why:** Lowest friction, built-in discovery, payments handled
- **Audience:** Creators, makers, technical audience
- **Fees:** 10% + payment processing
- **Time to revenue:** Hours (after product is ready)

### Growth: Stan Store
- **Why:** Better for product bundles, higher price points
- **Fees:** $29-99/month + variable
- **When to move:** 3-5 products, $500+/month revenue

### Scale: Own Site (Lemonsqueezy or Stripe)
- **Why:** Full control, lower fees (5-8%), better unit economics
- **When to move:** $2,000+/month revenue threshold
- **Effort:** More technical setup, ongoing maintenance

## Quality Standards

All products must pass before launch:

**Content Quality:**
- Solves a specific, validated problem
- Beginner can use successfully within 10 minutes
- Includes 3+ concrete, realistic examples
- Clear language (no jargon without explanation)

**Technical Quality:**
- All prompts tested with target AI (average rating 8+/10)
- No broken links, references, or file paths
- File structure is logical and easy to navigate

**Business Quality:**
- Price point validated against 3+ competitors
- Refund policy clear and customer-friendly
- Support channel established

> See `references/templates-reference.md` for the full 16-item pre-launch checklist.

## Failure Points & Fixes

| Problem | Signal | Fix |
|---|---|---|
| No sales | 0 sales in first 2 weeks | Poor positioning or no audience — revisit niche |
| High refund rate | >20% refunds | Product not meeting expectations — revise promise |
| Stagnant traffic | No clicks despite promotion | Landing page not compelling — A/B test headlines |
| Low conversion | <3% click-to-purchase | Weak sales copy or unclear value — rewrite page |
| Community fatigue | Declining engagement | Over-promoting — space launches 2-3 weeks apart |
