# Stream Comparison & Selection

> Detailed comparison prompt for evaluating the three income streams against your specific situation. Use after the initial assessment to make your final stream selection.

## What to Provide

Your profile summary:
- Primary skill/strength
- Time available per week
- Budget for ads/testing
- Revenue timeline needs
- Current audience size
- Risk tolerance

---

## The Prompt

```markdown
I'm deciding between AI Templates, Content Publishing, and Print on Demand.
Help me compare them for my specific situation.

### My Profile:
- Primary skill/strength: [e.g., "excellent technical writer", "software engineer", "designer"]
- Time available per week: [hours]
- Budget for ads/testing: [amount or "none"]
- Need revenue by: [date or "flexible"]
- Audience size: [e.g., "none", "small email list", "1K Twitter followers"]
- Risk tolerance: [Conservative/Moderate/Aggressive]

### Compare:

1. **Effort & Timeline** — Which gets me to first revenue fastest? Least weekly
   effort long-term? Most upfront effort?

2. **Revenue Potential** — Realistic Y1 revenue for each? Time to meaningful
   income ($1-5K/month)? Highest ceiling long-term?

3. **Audience Requirements** — Which needs biggest audience? Which works with
   small niche? Do I need to build audience first?

4. **Ad Spend Worthiness** — Which makes sense for paid ads? Sustainable CAC?
   Fastest ad ROI?

5. **Sustainability** — Most passive? Requires ongoing maintenance? Longest
   shelf-life?

6. **Personalized Comparison Table:**

| Factor | AI Templates | Content Publishing | Print on Demand |
|--------|---|---|---|
| Time to first sale | | | |
| Effort to get started | | | |
| Weekly maintenance | | | |
| Audience needed | | | |
| Realistic Y1 revenue | | | |
| Ad spend ROI | | | |
| Best case scenario | | | |
| Worst case risk | | | |

7. **Specific Recommendation** — Primary stream with justification, why start
   here vs others, when to add secondary, test multiple or go deep.
```
