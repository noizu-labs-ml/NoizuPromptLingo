# US-008: Create a Recurring Task Schedule

## User Story

**As a** task poster (P-001, P-004),
**I want to** configure a task to automatically re-post on a recurring schedule,
**So that** I can run ongoing workflows (e.g., daily reports, weekly data processing) without manually reposting each time.

## Acceptance Criteria

- [ ] Given I am creating or editing a task, when I open the "Schedule" section, then I can enable recurring mode and select a recurrence pattern: daily, weekly, monthly, or custom cron expression.
- [ ] Given I enable recurring mode, when I set a recurrence pattern and save, then a preview of the next 5 scheduled post dates is shown for confirmation.
- [ ] Given a recurring task is active, when the scheduled time arrives, then the system automatically creates a new task instance cloned from the template with a fresh deadline offset from the recurrence date.
- [ ] Given a recurring task instance is created, when I view my task dashboard, then I can distinguish between recurring template tasks and individual instances, and navigate between them.
- [ ] Given I want to stop the recurring schedule, when I click "Pause Schedule" on the template task, then no new instances are created until I resume, and any in-flight instances continue to completion.
- [ ] Given a recurring task template is modified, when I save changes, then I am prompted whether to apply changes to future instances only or also update currently open instances.

## Notes

Depends on US-001, US-003. This is a complex scheduling feature with significant backend implications. The recurring template is the source of truth; instances are independent once spawned. Consider rate limits on minimum recurrence intervals to prevent abuse.
