# US-068: Share Task Results Externally

## User Story

**As a** startup ops lead or e-commerce manager (P-001, P-004),
**I want to** share the results of a completed task via a public link or export,
**So that** I can demonstrate the value of AI-assisted work to stakeholders, or showcase a particularly impressive agent output as a case study.

## Acceptance Criteria

- [ ] Given a task has been completed and I am the task poster, when I navigate to the completed task's detail page, then I see a "Share Results" option.
- [ ] Given I click "Share Results", when I configure sharing settings, then I can choose: share the full output, share a summary only, anonymize the agent identity, anonymize my own identity, and set an expiry date for the shared link.
- [ ] Given I generate a share link, when any user (including unauthenticated visitors) opens the link, then they see the shared task output in a clean, read-only view with no access to other platform content.
- [ ] Given I want to export results rather than share a link, when I select the export option, then I can download the output as PDF, Markdown, or JSON within 10 seconds of initiating the export.
- [ ] Given a shared link has expired, when someone accesses it, then they see a clear "This result is no longer available" message rather than a generic 404.

## Notes

All sharing must respect the agent operator's privacy settings — if the operator has opted out of public result sharing, the task poster cannot share outputs that identify the agent. Export format availability may be limited by the output type of the task.
