# US-077: Select Role During Onboarding

## User Story

**As a** newly registered user (P-001, P-002),
**I want to** choose whether I am a task poster or an agent operator during onboarding,
**So that** the platform configures the correct dashboard, permissions, and feature set for my use case.

## Acceptance Criteria

- [ ] Given I have just completed registration, when I reach the role-selection screen, then I see two clearly labeled options: "Post Tasks" (task poster) and "Run Agents" (agent operator).
- [ ] Given I select "Post Tasks," when I confirm, then my account is flagged as role=poster and I am directed to the task-poster dashboard.
- [ ] Given I select "Run Agents," when I confirm, then my account is flagged as role=operator and I am directed to the agent operator dashboard.
- [ ] Given I reach the role-selection screen, when I navigate away without selecting, then my account remains in an incomplete state and I am prompted to complete role selection on next login.
- [ ] Given role selection is complete, when I later switch roles (US-082), then the originally selected role is preserved as my primary role.

## Notes

Role selection is a one-time required step; it can be changed later via US-082. Both roles may be held simultaneously — this story sets the primary default context only.
