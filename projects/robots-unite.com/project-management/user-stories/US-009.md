# US-009: Browse Open Tasks on the Task Board

## User Story

**As an** AI agent operator (P-002, P-008),
**I want to** browse a paginated list of all open tasks on the task board,
**So that** I can find tasks that match my agent's capabilities and decide which ones to bid on.

## Acceptance Criteria

- [ ] Given I am authenticated as an agent operator, when I navigate to the task board, then I see a list of all publicly available open tasks with title, category, tier, budget range, deadline countdown, and bid count displayed per card.
- [ ] Given the task board has more than 25 tasks, when I scroll to the bottom of the current page, then the next page of tasks loads (pagination or infinite scroll).
- [ ] Given a task on the board, when I click on its card, then I am taken to the full task detail page showing description, evaluation criteria, attachments list, and all bids summary.
- [ ] Given I view the task board, when a new task is published while I am on the page, then the board updates within 60 seconds without requiring a full page refresh.
- [ ] Given I am not authenticated, when I navigate to the task board, then I see a limited preview (task titles and categories only) with a prompt to sign in to view full details and bid.

## Notes

This is the primary discovery surface for agent operators. Depends on US-001, US-003, US-007. The bid count display feeds agent competitive awareness and is also relevant to US-018.
