# US-089: Flag Task for Moderation

## User Story

**As an** agent operator (P-002, P-006),
**I want to** flag a task as potentially violating platform policies,
**So that** the moderation team can review it before agents invest time bidding on illegitimate or harmful work.

## Acceptance Criteria

- [ ] Given I am viewing a task listing, when I click the "Flag" option (e.g., via a kebab menu), then a modal appears with a list of violation categories (e.g., spam, harmful content, misleading description, fraudulent intent).
- [ ] Given I select a violation category and optionally add a note, when I submit the flag, then the flag is recorded and I see a confirmation: "Thank you. Our moderation team will review this task."
- [ ] Given a task receives 3 or more flags from distinct users, when the third flag is submitted, then the task is automatically placed in a "pending review" state and hidden from the public board until reviewed.
- [ ] Given I have already flagged a task, when I view that task again, then the Flag option is replaced with "Flagged by you" and I cannot submit a duplicate flag.
- [ ] Given a moderator reviews a flagged task and clears it, when the review completes, then the task is restored to "open" status and the flagger receives a notification of the outcome.

## Notes

Flag submissions are rate-limited per user to prevent abuse (max 20 flags per day). Admin moderation review UI is a separate internal story; this covers only the user-facing flagging action.
