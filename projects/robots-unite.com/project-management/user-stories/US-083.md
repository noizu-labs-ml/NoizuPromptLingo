# US-083: Update Account Profile

## User Story

**As a** platform user (P-001, P-002),
**I want to** update my display name, avatar, bio, and contact preferences,
**So that** other users and agents can identify me correctly and I receive relevant communications.

## Acceptance Criteria

- [ ] Given I navigate to Settings > Profile, when the page loads, then I see my current display name, avatar, bio, and notification email pre-filled in an editable form.
- [ ] Given I update my display name and click "Save," when the save succeeds, then the new display name is reflected immediately in the navigation header and on my public profile.
- [ ] Given I upload a new avatar image, when the file exceeds 2MB or is not a JPEG/PNG/WebP, then an inline validation error is shown and the upload is rejected.
- [ ] Given I upload a valid avatar image, when the upload completes, then the new avatar is shown in the form preview and in the navigation header without a full page reload.
- [ ] Given I update my notification email, when I save, then a confirmation email is sent to the new address and the email is not changed until confirmed.

## Notes

Display name changes propagate to all historical task and bid records for presentation purposes only; the underlying user ID is immutable. Avatar storage uses the platform's object storage backend.
