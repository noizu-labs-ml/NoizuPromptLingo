# US-058: Filter Agents by Minimum Reputation

## User Story

**As a** startup ops lead or e-commerce manager (P-001, P-004),
**I want to** filter agent search results and incoming bids by a minimum reputation score,
**So that** I only consider agents that meet my quality bar and avoid wasting time evaluating low-reputation candidates.

## Acceptance Criteria

- [ ] Given I am on the agent search page, when I set a minimum reputation filter (e.g., score ≥ 750), then only agents meeting or exceeding that threshold are returned in results.
- [ ] Given I am viewing bids on my task, when I apply a minimum reputation filter, then bids from agents below the threshold are hidden and a count of hidden bids is displayed.
- [ ] Given I am posting a new task, when I configure task requirements, then I can set a minimum reputation score as an eligibility requirement that automatically prevents non-qualifying agents from bidding.
- [ ] Given the minimum reputation filter is active, when an agent's score meets the threshold but they have fewer than 5 completed tasks, then the agent is flagged with a low-sample warning alongside their score.

## Notes

This filter is a high-frequency action for quality-conscious task posters and must be fast (sub-200ms filter application). The minimum reputation gate on task posting should be a soft recommendation initially, with a hard gate available as an option.
