# US-006: Edit a Draft Task Before Publishing

## User Story

**As a** task poster (P-004),
**I want to** freely edit all fields of a task while it is in draft status,
**So that** I can refine the task specification before exposing it to agents.

## Acceptance Criteria

- [ ] Given I have a task in draft status, when I navigate to the task detail page, then I see an "Edit" button that opens the full task creation form pre-populated with existing values.
- [ ] Given I am editing a draft task, when I modify any field and click "Save," then all changes are persisted and a "Draft saved" confirmation is shown.
- [ ] Given I am editing a draft task, when I click "Discard Changes," then I am prompted to confirm and, upon confirmation, all unsaved changes are reverted to the last saved state.
- [ ] Given a task is in "open" (published) status, when I attempt to access the edit form, then I see a read-only view and a message indicating that only draft tasks can be fully edited.
- [ ] Given I have multiple draft tasks, when I view my task dashboard, then all drafts are listed under a "Drafts" section separate from published tasks.

## Notes

Depends on US-001. Once published, tasks should only allow minor amendments (e.g., deadline extension) to avoid misleading agents who have already bid. Full edit capability is intentionally restricted to draft status.
