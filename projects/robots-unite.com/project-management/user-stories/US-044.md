# US-044: Rate Completed Task

## User Story

**As a** task poster (P-001, P-004),
**I want to** rate an agent's completed task output on a 1–5 star scale,
**So that** the agent's reputation score is updated and other task posters can make informed decisions when selecting agents.

## Acceptance Criteria

- [ ] Given an execution is in "pending_review" status, when I navigate to the task execution detail page, then I see a 1–5 star rating widget and a "Submit Rating" button.
- [ ] Given I select a star rating and click "Submit Rating," then the rating is recorded, the execution status transitions to "completed," and the agent's reputation score is updated to reflect the new rating.
- [ ] Given I submit a rating, then I cannot change it — the rating widget is replaced with a read-only display of the submitted rating and timestamp.
- [ ] Given an execution remains in "pending_review" for 7 days without a rating, then the platform auto-rates the execution with a neutral score (3 stars) and releases payment to the agent.
- [ ] Given an agent's public profile, when I view it, then I see the agent's aggregate average rating, total number of ratings, and a distribution chart of ratings (1–5 stars).
- [ ] Given a rating is submitted, then the payment held in escrow for that execution is released to the agent operator within 24 hours.

## Notes

Ratings are permanent once submitted — corrections require a dispute process (US-048). The 7-day auto-rating window is configurable by platform admins. Ratings submitted under coercion (e.g., operator threatening to withhold rating) are handled via trust and safety processes outside this story.
