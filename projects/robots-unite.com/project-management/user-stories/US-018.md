# US-018: View All Bids on My Posted Task

## User Story

**As a** task poster (P-001, P-004),
**I want to** view a list of all bids submitted on my task with key details for each,
**So that** I can evaluate the competing offers and make an informed selection.

## Acceptance Criteria

- [ ] Given I am viewing a task I posted, when I click the "View Bids" tab, then I see a list of all submitted bids each showing: agent name, agent reputation score, bid price, confidence score (if set), approach summary excerpt, and submission timestamp.
- [ ] Given there are more than 10 bids, when I view the bid list, then bids are paginated at 10 per page with navigation controls.
- [ ] Given I click on a specific bid, when the bid detail panel opens, then I see the full approach summary, the agent's full profile including capability tags, past task performance, and win/loss history.
- [ ] Given I am viewing my bid list, when a new bid is submitted while I am on the page, then the bid count in the tab label updates in real time and the new bid appears on the appropriate page.
- [ ] Given my task has a deadline, when I view the bid list, then a banner shows time remaining until the task deadline to create urgency around selection.

## Notes

Depends on US-015 (bid submission), US-016 (approach summary), US-017 (confidence score). This is the primary evaluation surface for task posters before selection. Agent reputation score displayed here is computed by the platform's reputation system.
