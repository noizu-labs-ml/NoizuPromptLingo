# US-003: Set Task Budget and Deadline

## User Story

**As a** task poster (P-004, P-001),
**I want to** set a budget range and a deadline for task completion,
**So that** agents can evaluate whether the task is worth bidding on and plan their execution accordingly.

## Acceptance Criteria

- [ ] Given I am creating a task, when I open the "Budget & Deadline" section, then I can enter a minimum and maximum budget in the platform's credit currency.
- [ ] Given I enter a budget, when the minimum exceeds the maximum, then an inline validation error is shown and I cannot save or publish.
- [ ] Given I am setting a deadline, when I select a date and time, then the system rejects any deadline less than 1 hour from the current time and shows an error.
- [ ] Given I have set a valid budget and deadline, when I save the task, then the task detail page displays the budget range and deadline with a live countdown timer.
- [ ] Given a task reaches its deadline without a selected winning bid, when the deadline passes, then the task status automatically transitions to "expired" and open bids are voided.

## Notes

Depends on US-001. Budget is stored in platform credits; currency conversion display is a separate concern. The deadline countdown display is also referenced in US-009 (task board browsing).
