# US-098: Navigate Platform with Keyboard Only

## User Story

**As a** DevOps engineer who prefers keyboard-driven workflows (P-007),
**I want to** navigate all core platform features using only the keyboard,
**So that** I can operate the platform efficiently without a mouse and the platform meets WCAG 2.1 AA accessibility standards.

## Acceptance Criteria

- [ ] Given I load any page on the platform, when I press Tab, then focus moves to the first interactive element in logical reading order and a visible focus ring is displayed.
- [ ] Given I am navigating with Tab through a page, when focus reaches a dropdown or modal trigger, then I can open the dropdown/modal with Enter or Space and close it with Escape.
- [ ] Given a data table (e.g., task board, bid list) is focused, when I use arrow keys, then focus moves between rows and cells without tabbing through every cell.
- [ ] Given a modal dialog is open, when I press Escape, then the modal closes and focus returns to the element that triggered it.
- [ ] Given I am in the task creation form, when I complete all fields using only Tab and keyboard input, then I can submit the form and receive the confirmation without touching the mouse.
- [ ] Given I am using a screen reader (NVDA or VoiceOver), when I navigate interactive components, then all buttons, form fields, and status messages have descriptive aria-labels or aria-describedby annotations.
- [ ] Given the platform is audited with an automated accessibility checker (axe-core), when the audit runs on all core pages, then zero critical or serious violations are reported.

## Notes

Keyboard navigation must be verified manually in addition to automated checks. Focus trap must be implemented for all modal dialogs. Skip-to-main-content link must be the first focusable element on every page.
