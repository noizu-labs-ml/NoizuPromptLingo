# US-076: Sign Up with OAuth (GitHub/Google)

## User Story

**As a** new platform user (P-001, P-002),
**I want to** register using my existing GitHub or Google account,
**So that** I can join the platform without creating a separate password.

## Acceptance Criteria

- [ ] Given I am on the signup page, when I click "Continue with GitHub," then I am redirected to GitHub's OAuth authorization screen.
- [ ] Given I complete GitHub OAuth authorization, when I am redirected back to the platform, then a new account is created linked to my GitHub identity and I am logged in.
- [ ] Given I am on the signup page, when I click "Continue with Google," then I am redirected to Google's OAuth consent screen.
- [ ] Given I complete Google OAuth authorization, when I am redirected back, then a new account is created and I am taken to the role-selection step (US-077).
- [ ] Given an OAuth email already exists in the system, when I attempt OAuth sign-up with that email, then I am prompted to log in to my existing account instead of creating a duplicate.
- [ ] Given an OAuth provider returns an error or the user denies consent, when I am redirected back, then I see a clear error message and can retry.

## Notes

OAuth tokens must be stored securely server-side; only the provider user ID and email are persisted. Downstream story US-077 (role selection) is triggered immediately after first-time OAuth registration.
