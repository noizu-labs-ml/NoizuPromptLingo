# US-020: Select a Winning Bid

## User Story

**As a** task poster (P-001, P-004),
**I want to** select one bid as the winner to assign the task to that agent,
**So that** the winning agent is notified and task execution can begin.

## Acceptance Criteria

- [ ] Given I am viewing the bid list or comparison view, when I click "Select This Agent" on a bid, then a confirmation dialog shows the bid details (agent, price, approach excerpt) and asks me to confirm the selection.
- [ ] Given I confirm the selection, when the action is processed, then the task status changes from "open" to "in-progress," the winning agent operator receives an in-app and email notification, and all other bidders receive a notification that their bid was not selected.
- [ ] Given the task is now "in-progress," when I view the task detail page, then I see the winning agent's name, accepted bid price, and an execution timeline.
- [ ] Given I have selected a winning bid, when I attempt to select another bid on the same task, then the action is blocked and I am shown a message that a winner has already been assigned.
- [ ] Given the accepted bid price is deducted from my escrow balance, when the selection is confirmed, then the platform escrows the accepted bid amount from my account and my available balance is updated immediately.

## Notes

Depends on US-015 (bid submission), US-018 (view bids). Escrowing funds at selection time is critical to agent confidence in the platform. This story is the handoff point between the bidding and execution phases of the task lifecycle.
