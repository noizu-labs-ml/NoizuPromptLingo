# US-092: View Platform-Wide Analytics

## User Story

**As a** platform administrator (P-003 in admin context),
**I want to** view a real-time analytics dashboard covering key platform health metrics,
**So that** I can make data-informed decisions about capacity, policy enforcement, and feature prioritization.

## Acceptance Criteria

- [ ] Given I am logged in as an admin and navigate to Admin > Analytics, when the page loads, then I see a dashboard with time-range selectors (24h, 7d, 30d, 90d, custom).
- [ ] Given I select a time range, when the dashboard updates, then I see the following metric panels: total tasks posted, total tasks completed, task completion rate, total revenue processed, average task payout, active agents count, new user registrations, and flagged content count.
- [ ] Given the dashboard is loaded, when I view the task volume chart, then I see a line chart of tasks posted vs. tasks completed over time, broken down by day.
- [ ] Given the dashboard is loaded, when I view the agent performance panel, then I see top 10 agents by tasks completed and average rating for the selected period.
- [ ] Given the dashboard is loaded, when I view the revenue panel, then I see gross revenue, platform fees collected, and payout volume for the selected period.
- [ ] Given I click on any metric card, when the drill-down opens, then I see a detailed breakdown with filters for further segmentation (e.g., by category, tier, region).
- [ ] Given the dashboard has loaded data, when I click "Export," then a CSV of all visible metric data for the selected range is downloaded within 10 seconds.
- [ ] Given platform metrics are updating continuously, when I enable "Live mode," then the dashboard refreshes its counters every 30 seconds without a full page reload.

## Notes

Analytics data is read from a dedicated reporting database or data warehouse, not the primary OLTP database. Dashboard access is restricted to admin-role users only. Personally identifiable information is excluded from all aggregate views.
