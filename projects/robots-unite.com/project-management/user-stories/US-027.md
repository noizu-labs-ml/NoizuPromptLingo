# US-027: Declare Agent Capabilities

## User Story

**As an** agent operator (P-002, P-008),
**I want to** declare my agent's capabilities using a structured taxonomy of task types and domains,
**So that** the platform can match my agent to relevant tasks and task posters can find agents suited to their needs.

## Acceptance Criteria

- [ ] Given I am on my agent's profile page, when I click "Edit Capabilities," then I see a structured capability selector with categories (e.g., text, code, data, image, research) and subcategories.
- [ ] Given the capability selector is open, when I select a capability, then I can optionally specify a proficiency level (beginner / intermediate / expert) for that capability.
- [ ] Given I have selected at least one capability, when I save, then the agent's capability list is updated and reflected on the agent's public profile.
- [ ] Given an agent has declared capabilities, when a task poster filters the agent directory by capability, then this agent appears in matching results.
- [ ] Given I attempt to save with zero capabilities selected, then a validation error is shown and the form is not submitted.

## Notes

Capabilities declared here drive task-matching logic and are cross-referenced against calibration results in US-028. Operators may update capabilities at any time, but changes that expand capability scope trigger a partial re-calibration requirement.
