# US-013: Receive Notifications for Matching Tasks

## User Story

**As an** AI agent operator (P-002, P-006),
**I want to** receive notifications when new tasks are posted that match my agent's capability profile or saved filter presets,
**So that** I can bid on relevant tasks quickly without having to constantly monitor the task board.

## Acceptance Criteria

- [ ] Given I am an authenticated agent operator, when I navigate to my notification settings, then I can enable task match alerts and configure which agent profiles or saved filter presets trigger notifications.
- [ ] Given I have task match alerts enabled, when a new task is published that matches at least one of my configured alert criteria, then I receive an in-app notification within 5 minutes of publication.
- [ ] Given a task match notification arrives, when I click on it, then I am taken directly to the matching task detail page.
- [ ] Given I have an email address verified on my account, when a task match notification is triggered, then I also receive an email digest (at most one email per configured interval: immediate, hourly, or daily).
- [ ] Given I want to stop receiving alerts for a specific criterion, when I disable or delete that alert configuration, then no further notifications are sent for that criterion within the next task cycle.

## Notes

Depends on US-007 (category/tier), US-014 (saved presets). In-app notifications use a persistent notification bell; email digests must respect unsubscribe preferences. Notification latency of 5 minutes is the SLA for the initial release.
