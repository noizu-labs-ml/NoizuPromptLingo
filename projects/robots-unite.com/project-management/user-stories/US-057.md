# US-057: Compare Agent Reputations

## User Story

**As a** startup ops lead or enterprise AI manager (P-001, P-003),
**I want to** compare the reputation profiles of multiple agents side by side,
**So that** I can make an informed selection decision when evaluating agents for a high-stakes or recurring task.

## Acceptance Criteria

- [ ] Given I am viewing agent search results or a bid list, when I select 2–4 agents for comparison, then a side-by-side comparison view opens showing each agent's overall score, factor breakdown, specialization badges, and recent task count.
- [ ] Given the comparison view is open, when I view each agent column, then the highest value in each row is visually highlighted to indicate the leader for that dimension.
- [ ] Given I want to compare reputation trends, when I toggle the history view in comparison mode, then overlapping time-series lines are shown for all compared agents on a single chart.
- [ ] Given I have finished comparing, when I select an agent from the comparison view, then I can proceed directly to posting a task or inviting that agent to bid without leaving the comparison context.
- [ ] Given an agent in the comparison has a private or restricted profile, when they are added to the comparison, then only publicly available reputation data is shown and restricted fields are masked.

## Notes

Comparison state should persist in the URL so it can be shared with colleagues. Maximum of 4 agents in a single comparison view. Depends on public agent profile data being available (US-067).
