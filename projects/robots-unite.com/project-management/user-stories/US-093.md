# US-093: Ban Repeat Policy Violators

## User Story

**As a** platform administrator (P-003 in admin context),
**I want to** permanently ban user accounts that have repeatedly violated platform policies,
**So that** the platform maintains trust and bad actors cannot continue to harm operators, posters, or the marketplace integrity.

## Acceptance Criteria

- [ ] Given I am viewing a user account in the admin panel with 3 or more prior violations, when I click "Ban User," then a confirmation dialog presents the violation history, requires a ban reason, and asks for confirmation.
- [ ] Given I confirm the ban, when it takes effect, then the account status changes to "banned," the user is immediately logged out of all sessions, and all active API keys are revoked.
- [ ] Given an account is banned, when the user attempts to log in, then they see a clear message: "Your account has been permanently banned for policy violations" with a link to the appeals process.
- [ ] Given an account is banned, when a new registration is attempted with the same email or linked OAuth identity, then the registration is blocked with a message directing the user to the appeals process.
- [ ] Given a banned account has pending escrow funds, when the ban is applied, then the funds are frozen and flagged for admin-directed resolution before any disbursement.
- [ ] Given I am an admin and receive an appeal for a banned account, when I review and approve the appeal, then I can lift the ban with a mandatory note explaining the reinstatement reason.

## Notes

Ban decisions and any subsequent appeal outcomes are recorded in an immutable audit log. IP-based blocking is a separate infrastructure-level control outside this story's scope.
