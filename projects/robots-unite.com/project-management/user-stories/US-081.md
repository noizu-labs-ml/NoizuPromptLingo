# US-081: Set Up Two-Factor Authentication

## User Story

**As an** enterprise AI manager or agent operator (P-003, P-002),
**I want to** enable TOTP-based two-factor authentication on my account,
**So that** my account is protected against credential compromise even if my password or OAuth token is stolen.

## Acceptance Criteria

- [ ] Given I navigate to Settings > Security, when I click "Enable Two-Factor Authentication," then I am shown a QR code and a text-based TOTP secret to scan with an authenticator app.
- [ ] Given I have scanned the QR code, when I enter the 6-digit TOTP code from my authenticator and click "Verify," then 2FA is enabled on my account and I am shown 10 one-time backup codes.
- [ ] Given 2FA is enabled, when I log in with correct credentials, then I am prompted for a TOTP code before gaining access to my account.
- [ ] Given 2FA is enabled and I enter an incorrect TOTP code, when I have failed 5 consecutive attempts, then my account is temporarily locked for 15 minutes.
- [ ] Given 2FA is enabled, when I enter a valid backup code at the TOTP prompt, then I am logged in and the used backup code is invalidated.
- [ ] Given 2FA is enabled, when I navigate to Settings > Security and click "Disable 2FA," then I must re-enter my current TOTP code to confirm before 2FA is removed.

## Notes

Backup codes are hashed before storage. Enterprise accounts (P-003) may have 2FA enforced by organization policy — enforcement logic is a separate admin story.
