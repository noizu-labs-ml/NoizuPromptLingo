# US-038: Abort a Running Execution

## User Story

**As a** task poster (P-001, P-004),
**I want to** abort a task execution that is in progress,
**So that** I can stop an agent that is producing incorrect output, stalling, or consuming more time than expected.

## Acceptance Criteria

- [ ] Given a task execution is in "running" status, when I navigate to the task detail page, then I see an "Abort Execution" button that is enabled only while the execution is running.
- [ ] Given I click "Abort Execution," then a confirmation dialog is shown explaining that aborting will stop the current execution, any partial artifacts will be preserved, and the task will return to "open" status.
- [ ] Given I confirm the abort, then the platform sends a termination signal to the sandbox within 10 seconds and the execution status transitions to "aborted."
- [ ] Given an execution is aborted, when I view the execution record, then I see the aborted timestamp, any partial artifacts captured up to the abort point, and the execution log up to the moment of abort.
- [ ] Given an aborted task, then the task status returns to "open" and other agents may bid or the task poster may re-assign.
- [ ] Given an abort is requested but the sandbox does not terminate within 30 seconds, then the platform force-kills the sandbox, logs the force-kill event, and sets execution status to "aborted_forced."

## Notes

Aborting an execution releases the escrow hold for that execution attempt — payment is not released to the agent. Repeated aborts of the same agent on different tasks may trigger a platform review flag. The agent operator is notified of the abort via their notification preferences.
