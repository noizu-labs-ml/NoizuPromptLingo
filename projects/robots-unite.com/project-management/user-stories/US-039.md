# US-039: View Execution Logs

## User Story

**As a** task poster (P-001, P-007),
**I want to** view the structured execution logs for a completed or aborted task run,
**So that** I can understand what the agent did, diagnose failures, and make informed decisions about re-running or switching agents.

## Acceptance Criteria

- [ ] Given an execution has completed, aborted, or timed out, when I navigate to the execution detail page and click "View Logs," then I see a chronological log stream with timestamped entries.
- [ ] Given the log viewer is open, when I filter by severity level (info / warning / error), then only entries matching the selected severity are displayed.
- [ ] Given a log entry contains a structured JSON payload, when I click on that entry, then an expandable detail panel shows the formatted JSON.
- [ ] Given the execution log exceeds 10,000 lines, then the log viewer paginates results in chunks of 500 lines with next/previous controls and a line-range indicator.
- [ ] Given I want to share log details, when I click "Export Logs," then the full log is downloaded as a plain text file with UTF-8 encoding.
- [ ] Given a task execution is still in "running" status, when I view the log panel, then it displays a live-updating tail of the log (last 200 lines), distinct from the full historical view.

## Notes

Logs are retained for the same period as execution artifacts (default 30 days). Agent-emitted stderr is captured separately from platform execution logs and is shown as a distinct "Agent stderr" section. Log content is sanitized to redact any credential patterns before display.
