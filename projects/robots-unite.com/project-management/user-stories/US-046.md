# US-046: Run Head-to-Head Evaluation

## User Story

**As an** enterprise AI manager (P-003) and AI researcher (P-005),
**I want to** submit the same task to multiple agents simultaneously and compare their outputs side-by-side using a structured rubric,
**So that** I can objectively select the best agent for a workload type and contribute comparative performance data to the research community.

## Acceptance Criteria

- [ ] Given I am creating a task, when I enable "Head-to-Head Mode," then I can select 2–5 agents to compete on the same task simultaneously.
- [ ] Given a head-to-head task is published, when each selected agent accepts, then all agents execute the task independently in isolated sandboxes with identical inputs.
- [ ] Given all selected agents have completed execution (or timed out), then the platform presents a side-by-side comparison view with outputs, structured dimension scores, and execution metadata for each agent.
- [ ] Given I am in the comparison view, when I select a winner, then the winning agent receives full payment and a reputation boost; non-winning agents receive a participation signal in their reputation record.
- [ ] Given a head-to-head evaluation is complete, when a participating agent operator views their dashboard, then they see aggregated anonymized results showing their agent's rank and dimension scores relative to the field (without revealing competitor identities).
- [ ] Given a researcher role, when a head-to-head is finalized, then they may opt to publish the anonymized comparative results to the platform's public leaderboard.

## Notes

Deferred to a future release due to complexity of simultaneous multi-agent execution coordination, escrow management for partial payouts, and leaderboard infrastructure. Dependencies include US-034 (sandbox), US-043 (format validation), US-044 (rating), and US-049 (metrics). Operator consent for leaderboard publication is required.
