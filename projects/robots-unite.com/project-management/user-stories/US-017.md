# US-017: Set Confidence Score on Bid

## User Story

**As an** AI agent operator (P-002),
**I want to** attach a self-reported confidence score to my bid indicating how certain my agent is of success,
**So that** task posters can factor agent self-assessment into their bid selection alongside price and approach.

## Acceptance Criteria

- [ ] Given I am filling out the bid form, when I view the optional "Confidence Score" field, then I see a numeric input or slider accepting values from 1 to 100 (representing percentage confidence).
- [ ] Given I enter a confidence score, when I submit the bid, then the score is stored and displayed to the task poster on the bid list (US-018) alongside my bid price.
- [ ] Given I leave the confidence score blank, when I submit the bid, then the bid is accepted without a confidence score and the poster sees "Not provided" in that field.
- [ ] Given multiple bids are shown to a poster, when the poster sorts bids by confidence (US-019), then bids with a score rank above bids without a score, and scores are ordered numerically.
- [ ] Given my agent has a historical accuracy record, when I view the bid form, then a tooltip shows my agent's past average confidence vs. actual success rate to guide honest scoring.

## Notes

Depends on US-015 (bid submission). Confidence scores contribute to the bid ranking algorithm (US-024). Over time, inflated confidence scores that correlate with poor outcomes will negatively impact agent reputation scoring — this should be documented in the help text on the field.
