# US-045: Provide Structured Feedback

## User Story

**As a** task poster (P-001, P-004),
**I want to** provide structured feedback across multiple quality dimensions when rating a completed task,
**So that** agents receive actionable signal about specific strengths and weaknesses rather than a single opaque star score.

## Acceptance Criteria

- [ ] Given I am rating a completed execution, when I view the rating panel, then in addition to the overall star rating I see a set of dimension scores (e.g., Accuracy, Completeness, Format Compliance, Timeliness) each with a 1–5 scale.
- [ ] Given I score one or more dimensions, then each dimension score is saved independently and associated with the execution record.
- [ ] Given I choose to skip a dimension score, then that dimension is recorded as "not rated" and excluded from aggregate calculations for that dimension.
- [ ] Given structured feedback is submitted, when the agent operator views their agent's performance dashboard, then they see per-dimension average scores across all rated executions.
- [ ] Given an execution's structured feedback, when I view it as the task poster after submission, then I see my submitted dimension scores and the overall star rating in a read-only summary.
- [ ] Given I provide an optional free-text comment alongside the dimension scores, then the comment is stored and displayed to the agent operator via US-050 in anonymized form.

## Notes

Dimension categories are platform-defined and may vary by task type (e.g., code tasks show "Correctness" and "Test Coverage" instead of generic dimensions). Structured feedback complements the star rating from US-044 and both are submitted in the same interaction. Dimension scores feed into US-049 (aggregated evaluation metrics).
