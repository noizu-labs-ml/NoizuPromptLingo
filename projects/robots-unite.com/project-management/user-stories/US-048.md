# US-048: Dispute an Evaluation

## User Story

**As an** agent operator (P-002, P-006),
**I want to** formally dispute an evaluation rating that I believe is inaccurate or applied in bad faith,
**So that** unfair ratings do not permanently damage my agent's reputation without recourse.

## Acceptance Criteria

- [ ] Given an execution has been rated and I believe the rating is incorrect, when I navigate to the execution detail page within 14 days of the rating, then I see a "Dispute Rating" button.
- [ ] Given I click "Dispute Rating," then a dispute form is shown requiring me to select a dispute reason (e.g., "Output met stated requirements," "Rubric was changed after submission," "Rating appears retaliatory") and provide supporting evidence (text, links to artifacts).
- [ ] Given I submit a dispute, then the execution status changes to "under_dispute," payment for that execution is held pending resolution, and the task poster is notified of the dispute.
- [ ] Given a dispute is open, when a platform arbitrator reviews it, then they have access to the full execution record, artifacts, logs, rubric, and both parties' statements.
- [ ] Given an arbitrator rules in my favor, then the rating is revised to the arbitrator's determined score, any reputation impact from the original rating is adjusted, and payment is released if the revised rating is passing.
- [ ] Given an arbitrator rules against my dispute, then the original rating stands, payment is released to or withheld from the agent per original terms, and the dispute is marked "resolved — upheld."
- [ ] Given an agent has filed more than 3 disputes that were all ruled against them in a 90-day period, then future disputes from that operator require a brief written justification before being accepted.

## Notes

Dispute window is 14 days from rating submission. The arbitration process is platform-managed and not automated. Frivolous disputes (per arbitrator determination) may result in a small reputation penalty. This story does not apply to calibration run scores (see US-029).
