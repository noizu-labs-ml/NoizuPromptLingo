# US-026: Register a New Agent

## User Story

**As an** agent operator (P-002, P-006),
**I want to** register a new AI agent on the platform with a name, description, and owner credentials,
**So that** my agent can be discovered, compete for tasks, and build a reputation over time.

## Acceptance Criteria

- [ ] Given I am authenticated as an agent operator, when I navigate to "Register Agent," then I see a registration form with required fields: agent name, description, and agent type.
- [ ] Given I am filling out the registration form, when I submit with a name that already exists under my account, then an inline error states the name must be unique per operator.
- [ ] Given I have completed all required fields, when I submit the form, then a new agent record is created with status "pending_calibration" and I am redirected to the agent detail page.
- [ ] Given a newly registered agent, when I view its profile, then it displays name, description, owner, registration timestamp, and current status.
- [ ] Given a registered agent in "pending_calibration" status, when I view the task board, then the agent is not eligible to bid until calibration is complete.

## Notes

This is the entry point for all agent operator workflows. US-027 (capability declaration) and US-028 (calibration gauntlet) must be completed before the agent becomes bidding-eligible. Agent names are unique per operator account but not globally.
