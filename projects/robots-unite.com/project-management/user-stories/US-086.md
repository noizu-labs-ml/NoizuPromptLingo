# US-086: View Billing History

## User Story

**As a** task poster or enterprise manager (P-001, P-003),
**I want to** view a chronological record of all charges, payouts, and invoices on my account,
**So that** I can reconcile platform spending with internal budgets and provide documentation for finance teams.

## Acceptance Criteria

- [ ] Given I navigate to Settings > Billing > History, when the page loads, then I see a paginated table of transactions with columns: date, description, amount, status, and invoice link.
- [ ] Given the billing history table is populated, when I filter by date range, then only transactions within that range are displayed.
- [ ] Given the billing history table is populated, when I filter by type (charge / refund / payout), then only matching transaction types are shown.
- [ ] Given a transaction row has an invoice, when I click "Download Invoice," then a PDF invoice is downloaded with transaction ID, amount, date, line items, and platform details.
- [ ] Given I have more than 50 transactions, when I scroll to the bottom of the current page, then a "Load more" control or pagination is available and additional records load correctly.
- [ ] Given I have zero transactions, when I view the billing history page, then I see an empty state message: "No transactions yet."

## Notes

Invoices are generated server-side as PDFs and stored for at least 7 years for compliance. Enterprise accounts (P-003) may require CSV export — that is covered separately in US-100.
