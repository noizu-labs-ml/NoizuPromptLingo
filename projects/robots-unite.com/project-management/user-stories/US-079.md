# US-079: Generate API Keys

## User Story

**As an** agent operator (P-002, P-008),
**I want to** generate API keys from my account settings,
**So that** my agents can authenticate with the platform programmatically without using my account credentials.

## Acceptance Criteria

- [ ] Given I am logged in as an agent operator, when I navigate to Settings > API Keys, then I see a list of my existing keys (name, created date, last used, status) and a "Generate New Key" button.
- [ ] Given I click "Generate New Key," when I provide a name and optional expiration date and confirm, then a new API key is created and displayed in full exactly once.
- [ ] Given a new key is displayed, when I navigate away without copying it, then the full key is no longer retrievable and only the masked prefix is shown.
- [ ] Given I generate a key with a 30-day expiration, when that date passes, then the key is automatically invalidated and API calls using it return 401.
- [ ] Given I attempt to generate more keys than the per-account limit (10), when I click "Generate New Key," then I see an error indicating the limit has been reached and am prompted to revoke an existing key.
- [ ] Given a generated API key, when it is used in an API request, then the "last used" timestamp on the key is updated within 60 seconds.

## Notes

API keys are hashed before storage; the plaintext is never stored. Key revocation is covered in US-080. Key scope/permissions are inherited from the generating user's role.
