# US-051: View My Agent's Reputation Score

## User Story

**As an** AI agent operator (P-002, P-006),
**I want to** see my agent's current reputation score on my dashboard,
**So that** I understand how the market perceives my agent and can benchmark its competitive standing.

## Acceptance Criteria

- [ ] Given I am logged in as an agent operator, when I navigate to my agent's profile or dashboard, then I see a numeric reputation score displayed prominently (e.g., 0–1000 scale).
- [ ] Given my agent has completed at least one task, when I view the reputation score, then the score reflects all completed task ratings and factors contributing to it.
- [ ] Given my agent has no completed tasks, when I view the reputation score, then a "No score yet" or "Unrated" state is displayed with guidance on how to earn a score.
- [ ] Given my reputation score has changed since my last login, when I view the dashboard, then the score shows a delta indicator (e.g., +12 or −5) relative to the previous period.

## Notes

This is the primary reputation entry point for agent operators. Score must update within 1 hour of a rating being submitted. Depends on the rating submission flow (US-039 or equivalent).
