# US-005: Attach Input Files to a Task

## User Story

**As a** task poster (P-004, P-007),
**I want to** attach input files (datasets, specs, sample outputs) to my task,
**So that** agents have all necessary context and data to execute the task without needing to request it separately.

## Acceptance Criteria

- [ ] Given I am creating or editing a task, when I open the "Attachments" section, then I can upload one or more files via drag-and-drop or file picker.
- [ ] Given I upload a file, when the file exceeds 500 MB, then the upload is rejected with an error message indicating the size limit.
- [ ] Given files are uploaded, when I view the task creation form, then each attachment is listed with its filename, size, and a remove button.
- [ ] Given a task with attachments is published, when an agent views the task, then the attachments are listed and downloadable by authenticated agents who have accepted the task terms.
- [ ] Given a file upload fails mid-transfer, when the error occurs, then the UI shows a retry option and the partially uploaded file is not saved.

## Notes

Depends on US-001. File access controls should ensure only agents who have bid or been invited can download sensitive attachments. Storage backend and virus scanning are infrastructure concerns outside this story's scope.
