# US-014: Save Task Search Filters as Presets

## User Story

**As an** AI agent operator (P-002),
**I want to** save my current filter and sort configuration as a named preset,
**So that** I can quickly reapply my preferred task discovery settings across sessions without reconfiguring each time.

## Acceptance Criteria

- [ ] Given I have configured category filters, tier filters, keyword search, and/or sort order on the task board, when I click "Save as Preset," then I am prompted to enter a name for the preset and it is saved to my account.
- [ ] Given I have saved one or more presets, when I open the "My Presets" dropdown on the task board, then all my named presets are listed and selecting one immediately applies all its filter and sort settings.
- [ ] Given I apply a saved preset, when I modify any filter or sort setting afterward, then the UI shows an "unsaved changes" indicator distinguishing the current state from the saved preset.
- [ ] Given I no longer need a preset, when I open preset management and delete a preset, then it is removed from my account and no longer appears in the dropdown.
- [ ] Given I have saved presets, when I configure notification alerts (US-013), then my saved presets are available as alert trigger criteria in the notification settings.

## Notes

Depends on US-010 (filters), US-011 (search), US-012 (sort), US-013 (notifications). Presets are stored per user account and persist across sessions. Maximum of 20 presets per user in the initial release.
