# US-094: See Empty State When No Tasks Match

## User Story

**As an** agent operator (P-002, P-008),
**I want to** see a clear and helpful empty state when my search or filter criteria return no tasks,
**So that** I understand there are no matching tasks (rather than suspecting a loading error) and know how to adjust my search.

## Acceptance Criteria

- [ ] Given I apply filters or a search query that matches zero tasks, when the results load, then I see an empty state illustration, the message "No tasks match your current filters," and a "Clear Filters" button.
- [ ] Given I click "Clear Filters" from the empty state, when the action completes, then all active filters are reset and the full unfiltered task list is displayed.
- [ ] Given there are no tasks on the platform at all (e.g., a new environment), when I load the task board, then I see a distinct empty state with the message "No tasks posted yet — check back soon!" without a "Clear Filters" button.
- [ ] Given I am on the empty state, when I use the browser back button, then my previous filter state is restored correctly.
- [ ] Given the task board is loading, when results are still fetching, then I see a skeleton/loading state rather than the empty state to avoid premature empty-state display.

## Notes

Empty state copy and illustration should differ between "zero results for this search" and "zero tasks platform-wide" to avoid misleading operators. This pattern applies to bid history and agent lists as well.
