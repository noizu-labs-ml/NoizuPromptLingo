# US-063: Seasonal and Topical Editorial Collections

## User Story

**As a** casual link-follower (P-004),
**I want to** discover seasonal and topical collections curated by gotta.cc editors,
**So that** browsing feels fresh and timely rather than like a static archive.

## Acceptance Criteria

- [ ] Given the homepage is loaded, when seasonal or topical collections are active, then a featured collection banner or row highlights the current editorial collection with title, description, and site count
- [ ] Given an editorial collection is published, when I browse to the Collections section, then it is listed with a "Featured" or "Seasonal" label and a visual distinction from user collections
- [ ] Given a seasonal collection expires (e.g., a holiday list), when the season passes, then the collection remains accessible via its URL but is removed from featured placement
- [ ] Given an editor publishes a topical collection, when it is promoted to the homepage, then I can click through to see all listed sites with their scores
- [ ] Given I am logged in, when I view a seasonal collection, then I can follow it (US-064) or clone it as my own starting point for a personal collection

## Notes

Seasonal collections drive return visits and provide content marketing opportunities. Editors use the curation workflow (US-067) to build and schedule these. Related: US-059 (best-of editorial lists), US-064 (follow collection), US-067 (editor curation).
