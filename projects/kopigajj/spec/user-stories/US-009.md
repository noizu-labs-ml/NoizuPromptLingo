# US-009: Configure Maximum History Size

As a developer,
I want to configure how many clipboard history items are kept,
so that I can balance between useful history and resource usage.

## Scenario: Set max history to 100 items
Given the application has a default max history of 50 items
When the user configures max history to 100 items
Then the application should keep up to 100 items in history

## Scenario: Prune old items when over limit
Given the user has configured max history to 50 items and has 50 items in history
When the user copies a new item
Then the oldest item should be removed from history and the new item added

## Scenario: Validate max history configuration
Given the user is configuring max history
When the user enters an invalid value (negative or unreasonably large)
Then the application should reject the invalid value or apply a reasonable maximum

## Notes
- **Persona**: developer
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: None significant
- **Dependencies**: US-008, US-062 (configuration system)
