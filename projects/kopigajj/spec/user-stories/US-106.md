# US-106: Keyboard-Only Navigation

As a developer,
I want to perform all operations using only the keyboard,
so that I can maintain high productivity flow without switching to the mouse.

## Scenario: Navigate entries with arrow keys
Given the history panel is open
When the user presses Arrow Up/Down keys
Then the selection should move to the previous/next entry
And the selection should wrap from top to bottom

## Scenario: Navigate sections with Tab
Given the history panel has multiple sections (Suggested, Recent, Favorites)
When the user presses Tab/Shift+Tab
Then focus should move to the next/previous section header
And the first/last entry in that section should be selected

## Scenario: Page up/down
Given many entries are displayed
When the user presses Page Up/Down
Then the view should scroll by one screen of entries
And selection should move to the top/bottom of the visible area

## Scenario: Quick jump with first letter
Given entries are being viewed
When the user presses a letter key (not a command key)
Then selection should jump to the first entry starting with that letter
And subsequent presses cycle through matches

## Scenario: Home/End to jump to first/last
Given the history panel is open
When the user presses Home/End
Then selection should jump to the first/last entry in the list
And the view should scroll to show the selection

## Scenario: Keyboard triggers all actions
Given any operation can be performed with mouse
When the equivalent keyboard shortcut exists
Then the operation should be fully accessible without touching the mouse
Including: open, select, paste, delete, tag, edit, macroize, favorite

## Notes
- **Persona**: developer
- **T-Shirt Size**: L
- **Complexity**: medium
- **Risks**: Key conflict resolution, accessibility consistency
- **Dependencies**: All panel-related user stories (US-002 through US-017)
