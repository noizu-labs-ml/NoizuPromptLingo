# US-088: LLM Snippet Library Panel

As a developer,
I want to press Cmd+Shift+T L to open the LLM Snippet Library,
so that I can browse, select, and invoke my AI-powered snippets.

## Scenario: Open LLM Snippet Library
Given the application is running
When the user presses Cmd+Shift+T L
Then the LLM Snippet Library panel should appear
And the search field should be focused

## Scenario: Display snippet list
Given the LLM Snippet Library is open
When browsing snippets
Then each snippet should show: icon (🤖), slug, display name, description, model, version, average score
And snippets should be sorted by most-recently-used or relevance

## Scenario: Search snippets by keyword
Given the LLM Snippet Library is open
When the user types in the search field
Then results should be filtered by slug, name, description, and tags
And filtering should be instant

## Scenario: Filter snippets by tag
Given the LLM Snippet Library is open
When the user selects a tag filter
Then only snippets matching that tag should be displayed
And the active filter should be visible

## Scenario: Dismiss snippet library
Given the LLM Snippet Library is open
When the user presses Escape
Then the panel should close without changes

## Notes
- **Persona**: both
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Hotkey conflicts, panel performance with many snippets
- **Dependencies**: US-087 (Create LLM Snippet)
