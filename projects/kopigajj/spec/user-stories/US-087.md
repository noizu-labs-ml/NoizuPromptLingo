# US-087: Create LLM Snippet

As a developer,
I want to create LLM-powered snippets with system prompts and variables,
so that I can reuse AI workflows like code review or commit message generation.

## Scenario: Open LLM snippet creation form
Given the user opens the LLM Snippet Library (Cmd+Shift+T L)
When the user selects "Create New Snippet"
Then a snippet creation form should appear

## Scenario: Define snippet properties
Given the snippet creation form is open
When the user fills in: slug, display name, description
Then these properties should be saved when the snippet is created

## Scenario: Configure LLM model and provider
Given the snippet creation form is open
When the user selects: model provider (OpenAI/Anthropic/Ollama) and model name
Then the configuration should be saved for this snippet
And future invocations should use this model

## Scenario: Write system prompt
Given the snippet creation form is open
When the user writes the system prompt (instruction for the LLM)
Then the prompt should be saved
And input variables can be referenced using {{variable_name}} syntax

## Scenario: Configure output format
Given the snippet creation form is open
When the user selects an output format (text, markdown, code, image)
Then the format should be saved
And the UI should provide appropriate preview for that format

## Scenario: Save new snippet
Given all required fields are populated (slug, name, system prompt)
When the user saves the snippet
Then it should be stored with version number 1
And the snippet should appear in the snippet library

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Prompt injection vulnerabilities, model configuration errors
- **Dependencies**: None
