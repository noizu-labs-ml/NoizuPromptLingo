# US-125: Text-to-Image Generation Macro

As a developer,
I want to generate images from text prompts using LLM image generation (DALL-E, Stable Diffusion),
so that I can create images on-demand from my clipboard workflow.

## Scenario: Create text-to-image snippet
Given the user creates an LLM snippet with output type "image"
When the user configures a prompt with variables
Then the snippet should generate images when invoked

## Scenario: Generate image from text prompt
Given a text-to-image snippet is invoked with a prompt
When the generation completes
Then the generated image should appear in preview
And the user can paste or save it

## Scenario: Select generation provider
Given multiple image providers are configured (OpenAI DALL-E, Stability AI)
When creating a text-to-image snippet
Then the user should select which provider to use
And provider-specific parameters should be available

## Scenario: Image generation progress
Given an image is being generated
When generation is in progress
Then a progress indicator should be displayed
And the user should be able to cancel

## Scenario: Save generated image to history
Given an image has been generated
When the user chooses to save
Then the image should be added to clipboard history
And it should be tagged with generation metadata

## Notes
- **Persona**: developer
- **T-Shirt Size**: L
- **Complexity**: high
- **Risks**: API costs, generation latency, content policy
- **Dependencies**: US-087 (Create LLM Snippet), US-119 (Image Type Support)
