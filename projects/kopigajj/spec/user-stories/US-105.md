# US-105: Add/Edit Description (D Key)

As a developer,
I want to press D on a highlighted entry to add or edit its description,
so that I can document clipboard entries for easy recall.

## Scenario: Press D to add description
Given a clipboard entry has no description
When the user presses the D key
Then a description input field should appear
And the cursor should focus in the input

## Scenario: Press D to edit description
Given a clipboard entry has an existing description
When the user presses the D key
Then the existing description should appear in the input field for editing
And all text should be selected for easy replacement

## Scenario: Save description
Given the description field is open
When the user presses Enter
Then the description should be saved
And the field should close

## Scenario: Long description multi-line support
Given the user wants a long description
When typing a description
Then multiple lines should be supported
And the field should expand to accommodate longer text

## Scenario: Description appears in entry list
Given an entry has a description
When the history panel displays the entry
Then the description should appear as subtitle under the preview
And the description should support multi-line display

## Scenario: Cancel description edit
Given the description field is open
When the user presses Escape
Then the field should close without saving
And the original description should be preserved

## Notes
- **Persona**: both
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Key conflict, multi-line display complexity
- **Dependencies**: US-004 (View Clipboard History), US-011 (Search Clipboard History) for descriptions in search
