# US-012: Case-Insensitive Search

As a knowledge worker,
I want search to be case-insensitive,
so that I don't have to worry about capitalization when searching.

## Scenario: Case-insensitive search with uppercase query
Given the clipboard contains "Hello World"
When the user searches for "hello"
Then "Hello World" should appear in the search results

## Scenario: Case-insensitive search with mixed case query
Given the clipboard contains "My API Key: ABC123"
When the user searches for "api key"
Then "My API Key: ABC123" should appear in the search results

## Scenario: Case-insensitive search with lowercase query
Given the clipboard contains "CONFIGURATION.json"
When the user searches for "configuration"
Then "CONFIGURATION.json" should appear in the search results

## Notes
- **Persona**: both
- **T-Shirt Size**: XS
- **Complexity**: low
- **Risks**: None significant
- **Dependencies**: US-011
