# US-047: English language support (base)

As a knowledge-worker,
I want the application to use English language as the default,
so that I can use the application with familiar terminology and phrasing.

## Scenario: Application uses English by default
Given I install and launch Smart Clipboard on a new macOS device
When the app starts for the first time
Then all UI elements and text should be in English

## Scenario: Menu bar items in English
Given the application is running with English selected
When I click the menu bar icon
Then the dropdown menu items should display in English

## Scenario: Settings in English
Given the application is running with English selected
When I open the settings window
Then all section names, labels, and descriptions should be in English

## Scenario: Clipboard popup in English
Given the application is running with English selected
When I open the clipboard history popup
Then all text labels, placeholder text, and interface elements should be in English

## Scenario: Notifications in English
Given the application is running with English selected
When the app sends a notification
Then the notification title and body text should be in English

## Notes
- **Persona**: knowledge-worker
- **T-Shirt Size**: XS
- **Complexity**: low
- **Risks**: None - this is the primary development language
- **Dependencies**: None
