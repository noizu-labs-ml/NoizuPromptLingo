# US-048: Detect and use system language

As a knowledge-worker,
I want the application to automatically use my system's language,
so that I don't need to manually configure language preferences.

## Scenario: App matches system language (supported)
Given my macOS system language is set to English
When I launch Smart Clipboard
Then the app should use English as the selected language

## Scenario: App detects new system language
Given I am using Smart Clipboard in English
When I change my macOS system language to a supported language
Then the app should use the new language on next restart

## Scenario: Prompt to restart for language change
Given I change my macOS system language
When the app detects the language change
Then I should be prompted to restart the app to apply the new language

## Scenario: Fallback to English for unsupported language
Given my macOS system language is set to a language not yet supported
When I launch Smart Clipboard
Then the app should use English as the language and display normally

## Scenario: Per-app language override
Given I want to use a different language than my system language
When I select a language in the app's Language setting
Then the app should use the selected language regardless of system language

## Scenario: Remember language selection
Given I have selected a language override
When I relaunch the application
Then the app should continue using the previously selected language

## Notes
- **Persona**: knowledge-worker
- **T-Shirt Size**: S
- **Complexity**: medium
- **Risks**: Needs localization framework from the start; adding languages later is harder
- **Dependencies**: US-047
