# US-095: LLM Snippet Eval Dashboard

As a developer,
I want a visual dashboard showing snippet performance metrics over time,
so that I can identify trends and make data-driven decisions about prompt improvements.

## Scenario: Open eval dashboard for snippet
Given a snippet is selected
When the user presses V
Then the eval dashboard should open for that snippet

## Scenario: Display version comparison table
Given the eval dashboard is open
When viewing the version comparison
Then a table should show for each version: version number, avg_score, sample_count, model_name, status (current/archived)

## Scenario: Score trend chart
Given the eval dashboard is open
When visualization is displayed
Then a chart should show average scores over time for all versions
And the x-axis should show time, y-axis should show score (1-5)

## Scenario: A/B Test results visualization
Given an A/B test has been run
When viewing the eval dashboard
Then a side-by-side comparison should display: version, avg_score, paired inputs, user preference
And the winning version should be highlighted

## Scenario: Export evaluation data
Given eval dashboard is open
When the user chooses to export
Then evaluation data should be available for download as CSV
And the CSV should include: version, timestamp, score, inputs, outputs, model

## Scenario: Confidence intervals
Given a version has multiple ratings
When displaying scores in the dashboard
Then confidence intervals should be calculated and displayed
And low-confidence metrics (few samples) should be visually indicated

## Scenario: Run new evaluation from dashboard
Given the eval dashboard is open
When the user selects an evaluation method (A/B test, batch re-eval, auto-eval)
Then the eval framework should launch
And results should be added to the dashboard

## Notes
- **Persona**: developer
- **T-Shirt Size**: L
- **Complexity**: high
- **Risks**: Visualization complexity, performance with large datasets
- **Dependencies**: US-093 (Eval Framework), US-094 (Regression Alerts)
