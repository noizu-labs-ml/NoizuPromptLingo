# US-101: Quick-Paste from Suggested Shortlist

As a developer,
I want to press Cmd+Shift+T 1-9 to quick-paste from the top suggested entries,
so that I can paste my most likely clipboard item without opening the full panel.

## Scenario: Quick-paste entry 1
Given the application is running in the background
When the user presses Cmd+Shift+T 1
Then the #1 suggested entry should be immediately pasted
And no panel should be shown

## Scenario: Quick-paste any suggested entry (1-9)
Given the suggestion algorithm has ranked at least 9 entries
When the user presses Cmd+Shift+T followed by 1-9
Then the corresponding numbered entry should be pasted
And the action should be instant without UI delay

## Scenario: Quick-paste exceeds available suggestions
Given fewer than N suggested entries exist
When the user presses Cmd+Shift+T N
Then the highest-numbered available entry should be pasted
Or a subtle beep should indicate no entry exists

## Scenario: Quick-paste uses suggestion algorithm
Given the suggestion scores have been calculated
When quick-paste is invoked
Then the suggested entries should include context: app affinity, recency, frequency, favorites

## Scenario: Quick-paste tracks usage
Given a quick-paste action completes
When the paste occurs
Then the target app, document, and timestamp should be logged like normal pastes
And the entry's usage count should be incremented

## Notes
- **Persona**: both
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Hotkey timing confusion, suggestion algorithm performance
- **Dependencies**: US-069 (Context-Aware Suggestions), US-006 (Paste Selected History Item)
