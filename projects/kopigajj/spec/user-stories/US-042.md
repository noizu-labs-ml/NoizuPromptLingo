# US-042: PIN or biometric unlock for popup

As a knowledge-worker,
I want to use a PIN or biometric authentication to unlock the clipboard popup,
so that I can quickly access clipboard history without compromising security when others are present.

## Scenario: Enable PIN unlock
Given the settings window is open in the "Security" section
When I enable "Require PIN to access history" and set a 4-6 digit PIN
Then PIN authentication should be active and required on each popup access

## Scenario: Prompt for PIN before showing popup
Given PIN unlock is enabled
When I press the global hotkey
Then a PIN entry prompt should appear instead of the popup and should only show the popup after correct PIN entry

## Scenario: Enable Touch ID unlock
Given the device supports Touch ID
When I enable "Use Touch ID to access history" in Security settings
Then Touch ID prompt should appear when pressing the hotkey and the popup should unlock upon successful biometric verification

## Scenario: Auto-lock after inactivity
Given PIN or biometric unlock is configured
When I configure "Auto-lock after X minutes of inactivity" and the timeout elapses without popup access
Then the next hotkey press should require PIN or biometric authentication again

## Scenario: Fallback to PIN when biometric fails
Given Touch ID is enabled and biometric verification fails or is declined
When I cannot authenticate with Touch ID after multiple attempts
Then the system should fall back to PIN entry prompt

## Scenario: Disable unlock requirement
Given PIN or biometric unlock is enabled
When I disable the unlock requirement
Then the popup should appear immediately upon hotkey press without any authentication

## Notes
- **Persona**: knowledge-worker
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Biometric API limitations; PIN must be stored securely; can slow down workflow
- **Dependencies**: US-018
