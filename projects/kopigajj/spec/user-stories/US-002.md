# US-002: Popup Display Current Clipboard

As a developer,
I want to see my current clipboard contents in the popup,
so that I can verify what's available to paste immediately.

## Scenario: Display text clipboard content
Given the user has text content in the clipboard
When the user presses Cmd+Shift+T to open the popup
Then the popup should display the current text clipboard content

## Scenario: Display image clipboard content
Given the user has an image in the clipboard
When the user presses Cmd+Shift+T to open the popup
Then the popup should display a preview of the clipboard image

## Scenario: Empty clipboard display
Given the user has an empty clipboard
When the user presses Cmd+Shift+T to open the popup
Then the popup should display a message indicating the clipboard is empty

## Notes
- **Persona**: both
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Large clipboard content may cause performance issues
- **Dependencies**: US-001
