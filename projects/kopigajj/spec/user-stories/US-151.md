# US-151: Scheduled Backups

As a developer,
I want automatic scheduled backups of clipboard history,
so that I don't lose data if something goes wrong.

## Scenario: Configure backup schedule
Given the user opens preferences
When they set a backup schedule (daily, weekly)
Then backups should run automatically at the specified interval

## Scenario: Automatic backup creation
Given backups are scheduled
When the scheduled time arrives
Then a .csa archive should be created
And the backup should be stored in the configured location

## Scenario: Configure backup retention
Given the user wants to limit backup storage
When they set retention count (e.g., keep last 10)
Then older backups should be deleted automatically
And retention should apply to local and cloud backups

## Scenario: Cloud backup destination
Given the user configures cloud backup
When they set a cloud path (iCloud, Dropbox)
Then backups should be uploaded to the cloud
And cloud backups should count toward retention

## Scenario: Restore from backup
Given a backup exists
When the user selects "Restore from Backup"
Then the backup should be imported
And the user should choose: replace or merge with existing

## Notes
- **Persona**: both
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Backup storage growth, cloud sync conflicts
- **Dependencies**: US-150 (Export Formats)
