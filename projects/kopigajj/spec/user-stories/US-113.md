# US-113: Color Value Conversion

As a designer,
I want to convert color values between different formats (hex, RGB, HSL, UIColor),
so that I can paste colors in the format required by my current application.

## Scenario: Detect color value in clipboard
Given clipboard content matches a color pattern (hex #RRGGBB, rgb(), rgba(), hsl())
When the content is analyzed
Then a color swatch preview should be displayed
And conversion options should be available

## Scenario: Convert hex to RGB
Given a hex color value (#FF5733) is in clipboard
When user chooses "Convert to RGB"
Then the pasted content should be "rgb(255, 87, 51)"

## Scenario: Convert hex to Swift UIColor
Given a hex color value (#FF5733) is in clipboard
When user chooses "Convert to UIColor"
Then the pasted content should be "UIColor(red: 1.0, green: 0.34, blue: 0.2, alpha: 1.0)"

## Scenario: Convert hex to HSL
Given a hex color value (#FF5733) is in clipboard
When user chooses "Convert to HSL"
Then the pasted content should be "hsl(11, 100%, 60%)"

## Scenario: Color swatch preview
Given a color is detected in clipboard content
When the entry is displayed
Then a color preview chip should appear
And clicking the chip should show conversion options

## Notes
- **Persona**: knowledge-worker (designer)
- **T-Shirt Size**: M
- **Complexity**: low
- **Risks**: Color format detection accuracy, alpha channel handling
- **Dependencies**: US-108 (Paste Format Options)
