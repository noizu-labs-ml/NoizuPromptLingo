# US-082: Macro Variants

As a developer,
I want to create multiple variants of a macro under the same slug,
so that I can access related templates with the same shortcut but different contexts.

## Scenario: Create macro variant with same slug
Given a macro with slug "sig" already exists
When the user creates a new macro with the same slug
Then it should be created as a variant under that slug group
And variants should have unique internal IDs

## Scenario: Select variant when invoking macro
Given a macro slug has multiple variants
When the user invokes that macro via quick-insert bar
Then a variant picker should appear showing all variants
And the user should select which variant to expand

## Scenario: Display variant names in picker
Given a variant picker is shown for a macro slug
When displaying the variants
Then each variant should show its display name and description
And the most-recently used variant should be highlighted by default

## Scenario: Auto-select only variant
Given a macro slug has only one variant
When the user invokes that macro
Then the variant picker should be skipped
And the single variant should expand directly

## Scenario: Macro variant usage tracking
Given a macro has multiple variants
When each variant is used
Then usage counts should be tracked separately per variant
And the default variant should be the most-used one

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Slug collision detection, variant selection UX
- **Dependencies**: US-072 (Macroize Clipboard Entry), US-074 (Macro Quick Insert Bar)
