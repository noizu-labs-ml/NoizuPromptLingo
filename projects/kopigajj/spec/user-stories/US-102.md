# US-102: Macroize Entry In-Panel (M Key)

As a developer,
I want to press M on a highlighted history entry to convert it to a macro,
so that I can quickly macroize frequently used snippets without leaving the panel.

## Scenario: Press M to macroize entry
Given a clipboard entry is highlighted in the history panel
When the user presses the M key
Then the macro creation form should open with the entry's content pre-populated as the template

## Scenario: Macroize with multi-line content
Given a multi-line clipboard entry is selected
When the user presses M
Then the entire content should be populated in the macro template
And line breaks should be preserved

## Scenario: Macroize with no selection
Given no entry is highlighted in the history panel
When the user presses M
Then no action should occur
Or a subtle invalid command feedback should be displayed

## Scenario: Cancel macroize with second M
Given the macro creation form is already open
When the user presses M again
Then the form should be dismissed without saving
And the history panel should regain focus

## Scenario: Already macroized entry
Given an entry is already linked to a macro
When the user presses M on that entry
Then the macro edit form should open instead of create form
And the user can modify the existing macro

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: low
- **Risks**: Key conflict with other actions, form state management
- **Dependencies**: US-072 (Macroize Clipboard Entry), US-004 (View Clipboard History)
