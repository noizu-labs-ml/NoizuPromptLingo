# US-080: Promote Nested Output to Clipboard History

As a developer,
I want to press Cmd+Shift+T P on a nested macro output to promote it to the main clipboard history,
so that I can preserve important macro expansions as standalone entries.

## Scenario: Promote nested output to main history
Given a nested macro output is selected in the history panel
When the user presses Cmd+Shift+T P
Then the nested output should be promoted to a top-level clipboard entry
And the promoted entry should create a copy in the main history

## Scenario: Promoted entry keeps original metadata
Given a nested output is being promoted
When the promotion completes
Then the new entry should preserve: timestamp of expansion, source app, used variables
And the entry should be marked with a "promoted" badge

## Scenario: Promoted entry becomes independently searchable
Given a nested output has been promoted to main history
When the user searches clipboard history
Then the promoted entry should appear in search results
And the entry should behave like any other top-level entry

## Scenario: Multiple promotions from same macro
Given a macro has multiple nested outputs
When the user promotes more than one output
Then each promoted output should have its own independent clipboard entry
And the originals should remain nested under the macro

## Scenario: Unpromote restored entry to nested
Given a promoted entry should return to being nested
When the user demotes a promoted entry
Then it should revert to nested status under the parent macro
And the top-level copy should be removed

## Notes
- **Persona**: both
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Hotkey conflict (Cmd+Shift+T P), database state consistency
- **Dependencies**: US-079 (Macro Generated Output Nesting)
