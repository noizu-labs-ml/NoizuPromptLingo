# US-046: Reduced motion animation option

As a user sensitive to motion or visual effects,
I want to disable animations in the clipboard popup,
so that I can use the application without discomfort.

## Scenario: Detect system reduce motion preference
Given macOS "Reduce motion" accessibility preference is enabled
When the application starts or the preference is changed
Then animations throughout the application should be disabled

## Scenario: Popup appears without animation
Given reduce motion is enabled
When I press the clipboard hotkey
Then the popup should appear instantly without any slide-in, fade, or scale animation

## Scenario: Item selection without animation
Given reduce motion is enabled
When I navigate between clipboard items
Then selection focus should change immediately without highlighting or selection transition animations

## Scenario: Settings UI respects reduced motion
Given reduce motion is enabled
When I navigate between settings sections
Then transitions should happen instantly without animation

## Scenario: Manual animation override
Given reduce motion is not enabled in the system
When I enable "Reduce animations" in the application settings
Then app-specific animations should be disabled independent of the system setting

## Scenario: Menu bar icon animations
Given reduce motion is enabled
When the app displays a menu bar icon animation or status indicator
Then the icon should be static without pulsing or rotating animations

## Notes
- **Persona**: knowledge-worker (with motion sensitivity)
- **T-Shirt Size**: XS
- **Complexity**: low
- **Risks**: Animations are core to the app feel; removing all may affect perceived polish
- **Dependencies**: US-018
