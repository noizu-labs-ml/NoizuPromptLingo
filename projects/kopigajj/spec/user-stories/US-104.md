# US-104: Inline Edit Entry (E Key)

As a developer,
I want to press E on a highlighted entry to edit it inline,
so that I can quickly fix typos or modify clipboard content.

## Scenario: Press E to edit text entry
Given a text clipboard entry is highlighted
When the user presses the E key
Then an inline editor should appear with the entry's content loaded
And syntax highlighting should be auto-detected for code

## Scenario: Press E to edit image entry
Given an image clipboard entry is highlighted
When the user presses the E key
Then a basic image editor should appear
And options for crop and annotate should be provided

## Scenario: Save edited entry
Given the inline editor is open
When the user presses Cmd+Shift+T Space or clicks Save
Then the edited content should replace the original entry
And a pencil icon should appear to indicate the entry was edited

## Scenario: Cancel edit
Given the inline editor is open
When the user presses Escape
Then the editor should close without saving
And the original content should be preserved

## Scenario: Edit preserves metadata
Given an entry is being edited
When the edit is saved
Then original metadata (source app, timestamp, tags, usage count) should be preserved
And edit version count should be incremented

## Scenario: Undo edit
Given an entry has been edited
When the user invokes an undo action
Then the entry should revert to its previous content
And edit version count should be decremented

## Notes
- **Persona**: both
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Undo/redo complexity, image editing complexity
- **Dependencies**: US-004 (View Clipboard History)
