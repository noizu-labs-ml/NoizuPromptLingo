# US-019: Hotkey customization

As a knowledge-worker,
I want to customize the global hotkey for accessing clipboard history,
so that I can avoid conflicts with other applications I use.

## Scenario: Change hotkey combination
Given the settings window is open in the "General" or "Hotkeys" section
When I click on the hotkey field and press a new key combination (e.g., Cmd+Option+V)
Then the new hotkey should be saved and registered globally

## Scenario: Validate hotkey availability
Given I am attempting to assign a new hotkey
When the key combination is already in use by the system or another application
Then a warning should appear indicating the conflict and suggesting an alternative

## Scenario: Clear hotkey assignment
Given a custom hotkey is configured
When I click the "Reset to Default" button
Then the hotkey should revert to Cmd+Shift+T

## Scenario: Prevent invalid key combinations
Given I am in the hotkey customization field
When I press a key combination that cannot be registered (e.g., single modifier key only)
Then the field should remain unchanged and display a brief error message

## Notes
- **Persona**: knowledge-worker
- **T-Shirt Size**: S
- **Complexity**: medium
- **Risks**: Must handle hotkey registration failures gracefully; some system keys cannot be overridden
- **Dependencies**: US-018
