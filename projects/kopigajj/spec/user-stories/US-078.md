# US-078: LLM Transform Variable Pipeline

As a developer,
I want llm_transform-type variables to run selected text through an LLM before insertion,
so that I can perform intelligent text transformations like code reviews or summaries.

## Scenario: Define llm_transform variable with system prompt
Given the user is creating a macro variable
When the variable type is set to "llm_transform"
Then the user should define a system prompt for the transformation

## Scenario: Transform selected text with LLM
Given a macro with an llm_transform variable is invoked
When text is selected when the macro is triggered
Then the selected text should be sent to the LLM with the system prompt
And the transformed output should be inserted into the template

## Scenario: Display transformation in preview
Given an llm_transform variable is being processed
When the LLM returns the transformed text
Then the macro preview should show the transformed result
And the user can see the prompt and output before pasting

## Scenario: Example code review transformation
Given a macro has an llm_transform variable for code review
When the user selects a code snippet and invokes the macro
Then the LLM should generate a brief code review comment
And the macro should wrap the original code with the review comment

## Scenario: Error handling for LLM transform failures
Given an LLM transform variable fails (API error, timeout, etc.)
When the transformation cannot be completed
Then the form should display an error message
And the user should be offered to retry or provide manual input

## Notes
- **Persona**: developer
- **T-Shirt Size**: L
- **Complexity**: high
- **Risks**: LLM latency, API failures, transformation quality
- **Dependencies**: US-073 (Macro Variable Types), US-077 (LLM-Assisted Variable Fill)
