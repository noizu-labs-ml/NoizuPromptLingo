# US-024: Manual sync trigger

As a knowledge-worker,
I want to manually trigger a sync when needed,
so that I can ensure the latest changes are immediately available on other devices.

## Scenario: Trigger sync via menu bar
Given sync is configured with active network connection
When I click the menu bar icon and select "Sync Now"
Then the app should immediately initiate a sync operation with the configured target

## Scenario: Show sync progress indicator
Given I have triggered a manual sync
When the sync is in progress
Then a spinning indicator or progress bar should appear in the menu or notification center

## Scenario: Sync completion notification
Given I have triggered a manual sync
When the sync completes successfully
Then a brief notification should appear confirming the sync completed with the timestamp

## Scenario: Disable sync during sync
Given a sync is currently in progress
When I attempt to click "Sync Now" again
Then the button should be disabled or show "Syncing in progress" to prevent duplicate syncs

## Scenario: Manual sync error handling
Given I have triggered a manual sync
When the sync fails due to a network or server error
Then an error notification should appear with a descriptive message and a "Retry" option

## Notes
- **Persona**: knowledge-worker
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Need to handle rapid sync requests; offline mode
- **Dependencies**: US-022, US-023
