# US-133: Preferences - Search Tab

As a developer,
I want a Search preferences tab,
so that I can configure search behavior and embedding models.

## Scenario: Open Search preferences
Given the menu bar dropdown is open
When the user selects Preferences > Search
Then the Search tab should display

## Scenario: Toggle semantic search
Given Search preferences is open
When the user toggles "Enable Semantic Search"
Then the setting should be saved
And semantic search should be enabled/disabled

## Scenario: Select embedding model
Given Search preferences is open
When the user selects an embedding model from the list
Then the model should be downloaded if needed
And future searches should use the selected model

## Scenario: Configure vector DB location
Given Search preferences is open
When the user sets a custom vector database path
Then the database should be moved or created at the new location
And existing embeddings should be migrated

## Scenario: Trigger re-index
Given Search preferences is open
When the user clicks "Re-index All"
Then all clipboard entries should be re-embedded
And progress should be displayed

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Model download size, re-index time
- **Dependencies**: US-068 (Semantic Search with Natural Language)
