# US-025: Encryption key setup and management

As a developer,
I want to manage encryption keys for sync data,
so that my clipboard history remains secure when synced across devices.

## Scenario: Create new encryption key
Given sync is configured for the first time
When I accept the suggested "Set up encryption" prompt
Then a new encryption key should be generated and stored in the macOS Keychain

## Scenario: Import existing encryption key
Given I have previously set up encryption on another device
When I select "Import Encryption Key" and paste or upload the key
Then the app should validate and store the key for decrypting synced data

## Scenario: Export encryption key backup
Given an encryption key is configured
When I click "Backup Encryption Key"
Then the key should be displayed or downloaded in a secure format for backup purposes

## Scenario: Change encryption key
Given an encryption key is already configured
When I click "Change Encryption Key"
Then a new key should be generated and existing data should be re-encrypted with the new key

## Scenario: Delete encryption key
Given an encryption key is configured
When I click "Delete Encryption Key" (with confirmation)
Then the key should be removed from the system and encrypted data should become inaccessible

## Notes
- **Persona**: developer
- **T-Shirt Size**: L
- **Complexity**: high
- **Risks**: Lost keys mean permanently lost data; key management must be bulletproof
- **Dependencies**: US-022, US-026
