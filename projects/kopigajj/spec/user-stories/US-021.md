# US-021: Exclude specific applications from clipboard monitoring

As a knowledge-worker,
I want to exclude certain applications from clipboard monitoring,
so that sensitive data from password managers or secure apps is not saved.

## Scenario: Add application to exclusion list
Given the settings window is open in the "Privacy" section
When I click "Add Application" and select an app from the file picker (or drag an app to the list)
Then the selected application bundle identifier should be added to the exclusion list

## Scenario: Clipboard change from excluded app
Given "1Password" is in the exclusion list
When I copy content while the 1Password application is frontmost
Then the clipboard content should not be saved to the history

## Scenario: Remove application from exclusion list
Given the settings window is open and shows an exclusion list with entries
When I click the remove button next to an application name
Then that application should be removed from the exclusion list and clipboard monitoring should resume for that app

## Scenario: Add currently active application
Given Smart Clipboard's settings window is open in the "Privacy" section
When I click "Exclude Current App" and another application is frontmost
Then the frontmost application should be immediately added to the exclusion list

## Notes
- **Persona**: knowledge-worker
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Must properly detect frontmost app; need to handle app bundle identifier changes
- **Dependencies**: US-018, US-032
