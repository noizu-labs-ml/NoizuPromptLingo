# US-079: Macro Generated Output Nesting

As a developer,
I want macro-generated outputs to be tracked as nested entries under their parent macro,
so that I can see the history of all expansions and promote important ones to the main history.

## Scenario: Track generated output under parent macro
Given a macro is expanded and pasted
When the paste action completes
Then a new clipboard entry should be created
And the entry should reference the parent macro_id
And the entry should store the variable values used for expansion

## Scenario: Display nested outputs in macro detail view
Given a macro has been used multiple times
When the user views the macro detail
Then all generated outputs should be listed chronologically
And each output should show timestamp and usage count

## Scenario: Show nested outputs indented under macro
Given the user is viewing clipboard history
When a macro output is displayed
Then it should be visually nested under the macro entry
And the nesting should indicate the parent-child relationship

## Scenario: Macro inherits parent macro tags
Given a macro has tags assigned
When a new output is generated from that macro
Then the new output entry should inherit all tags from the parent macro

## Scenario: Limit nested output history size
Given a macro has been used many times
When the number of nested outputs exceeds a configurable limit
Then older nested outputs beyond the limit should be pruned
And the most recent outputs should be retained

## Notes
- **Persona**: both
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Database schema changes, nesting display complexity
- **Dependencies**: US-072 (Macroize Clipboard Entry), US-075 (Macro Variable Form)
