# US-121: Image Full-Size Preview

As a developer,
I want to view full-size image previews via hover or Space key,
so that I can inspect image details before pasting.

## Scenario: Hover shows full-size preview
Given an image entry is highlighted in the history panel
When the user hovers over the entry for a short delay
Then a full-size preview popup should appear
And the preview should disappear when hover ends

## Scenario: Space key toggles full-size preview
Given an image entry is selected
When the user presses the Space key
Then a full-size preview panel should open
And pressing Space again should close the preview

## Scenario: Preview respects screen bounds
Given a full-size preview is displayed
When the image would extend beyond screen edges
Then the preview should be scaled or positioned to fit
And scrollbars should appear for very large images

## Scenario: Preview with zoom controls
Given a full-size preview is open
When the user uses pinch-to-zoom or scroll wheel
Then the preview should zoom in/out
And pan should work with drag

## Notes
- **Persona**: both
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Preview performance, memory for large images
- **Dependencies**: US-119 (Image Type Support), US-120 (Image Thumbnail Generation)
