# US-006: Paste Selected History Item

As a developer,
I want to press Enter to paste the selected history item,
so that I can quickly insert the desired content into my work.

## Scenario: Paste with Enter key
Given the clipboard popup is displaying history and an item is selected
When the user presses the Enter key
Then the selected item should be copied to the clipboard and the popup should be dismissed

## Scenario: Paste with number key
Given the clipboard popup is displaying history
When the user presses a number key (1-9)
Then the corresponding history item should be copied to the clipboard and the popup should be dismissed

## Notes
- **Persona**: both
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: None significant
- **Dependencies**: US-005
