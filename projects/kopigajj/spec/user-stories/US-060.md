# US-060: Quick Actions for Specific Content Types

As a developer,
I want context-aware actions available for different clipboard content types,
so that I can quickly perform common operations (open URL, format JSON, share text) without leaving the clipboard manager.

## Scenario: Open URL in browser
Given the clipboard popup displays a URL content type "https://api.example.com/users"
When the user presses the open URL shortcut (Cmd+O) or right-clicks and selects "Open URL"
Then the URL should open in the default web browser
And the clipboard popup should remain open or optionally dismiss based on user preference

## Scenario: Format JSON content
Given the clipboard popup displays JSON content (detected via curly braces or previous type detection)
When the user selects "Format JSON" from the right-click menu
Then the JSON should be pretty-formatted with 2-space indentation
And a "Copy Formatted" option should appear to paste the formatted version

## Scenario: Share text via share sheet
Given the clipboard popup displays text content
When the user clicks the share icon or selects "Share" from the right-click menu
Then the macOS share sheet should appear with the text content
And the user should be able to share to Messages, Mail, Notes, or other enabled share destinations

## Scenario: Encode/decode Base64
Given the clipboard popup displays text content
When the user selects "Base64 Encode" or "Base64 Decode" from the actions menu
Then the text should be transformed accordingly
And the result should be displayed in a preview panel with options to "Replace" or "Copy"

## Scenario: Show large image preview
Given the clipboard popup displays an image thumbnail
When the user double-clicks the image or selects "Preview" from the action menu
Then a full-size preview window should open
And the image should be zoomable with scroll and trackpad gestures

## Scenario: Validate and format CSV
Given the clipboard content is detected as CSV (comma-separated values with multiple lines)
When the user selects "Format as Table" from actions
Then a temporary table view should display the CSV with proper column alignment
And options should remain to copy the formatted version

## Scenario: Actions menu based on content type
Given the user selects any clipboard item
When the user opens the actions menu (Cmd+E or right-click)
Then only relevant actions for the detected content type should be shown
And irrelevant actions should be hidden or disabled

## Scenario: Copy file path from file URL
Given the clipboard contains a file URL starting with "file://"
When the user selects "Copy Path Only" from actions
Then only the file path portion (without "file://" prefix) should be copied to the clipboard

## Notes
- **Persona**: developer
- **T-Shirt Size**: L
- **Complexity**: medium
- **Risks**: Action performance impact on large content; content type detection accuracy; share sheet integration on background thread
- **Dependencies**: US-014 (content type detection), US-004 (clipboard history display)
