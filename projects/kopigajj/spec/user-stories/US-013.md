# US-013: Search Match Highlighting

As a developer,
I want to see search matches highlighted in the results,
so that I can quickly identify why an item matched my search.

## Scenario: Highlight single match
Given the clipboard contains "The quick brown fox"
When the user searches for "quick"
Then the word "quick" should be highlighted in the search results

## Scenario: Highlight multiple matches
Given the clipboard contains "error: system error occurred"
When the user searches for "error"
Then both occurrences of "error" should be highlighted

## Scenario: No match highlighting
Given the clipboard contains "Hello World"
When the user searches for "xyz"
Then no highlighting should be displayed (no matches)

## Notes
- **Persona**: developer
- **T-Shirt Size**: S
- **Complexity**: medium
- **Risks**: Performance overhead with highlighting
- **Dependencies**: US-011
