# US-089: Invoke LLM Snippet

As a developer,
I want to select a snippet, fill in variables, and generate AI output,
so that I can use my optimized prompts consistently across all my tasks.

## Scenario: Select snippet and open input form
Given a snippet is highlighted in the LLM Snippet Library
When the user presses Enter
Then a snippet invocation form should appear with all input variables

## Scenario: Display variable descriptions
Given the snippet invocation form is open
When displaying input fields
Then each field should show: variable name, type placeholder, and description
And text fields should show hints for expected input

## Scenario: Fill snippet variables
Given the snippet invocation form is open
When the user fills in all required variables
Then a "Generate" button should become active
And optional variables may be left blank

## Scenario: Send snippet to LLM
Given all required variables are filled
When the user presses Enter or clicks Generate
Then the system should send the system_prompt + input_values to the configured LLM
And the request should track the snippet_id and current version

## Scenario: Display LLM output preview
Given the LLM has returned a response
When the response is received
Then the output should be displayed in a preview panel
And the output should be formatted according to the snippet's output format

## Scenario: Output format-specific preview
Given a snippet's output format is "markdown"
When the LLM output is displayed
Then the preview should render markdown with proper formatting
And for "code" format, syntax highlighting should be applied

## Scenario: Paste generated output
Given the user is satisfied with the generated output
When the user presses Cmd+Shift+T Space
Then the output should be copied to the clipboard
And the panel should close

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: LLM API failures, rate limits, malformed output
- **Dependencies**: US-087 (Create LLM Snippet), US-088 (LLM Snippet Library Panel)
