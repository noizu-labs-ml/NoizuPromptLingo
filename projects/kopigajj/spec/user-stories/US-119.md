# US-119: Image Type Support

As a developer,
I want clipboard to support multiple image formats (PNG, JPEG, TIFF, GIF, SVG),
so that I can access image history regardless of source format.

## Scenario: Capture PNG image
Given a PNG image is copied to the system clipboard
When the clipboard monitor detects the change
Then the PNG image should be captured and stored
And the entry should be marked as type: image/png

## Scenario: Capture JPEG image
Given a JPEG image is copied to the system clipboard
When the clipboard monitor detects the change
Then the JPEG image should be captured and stored
And the entry should be marked as type: image/jpeg

## Scenario: Capture TIFF image
Given a TIFF image is copied to the system clipboard
When the clipboard monitor detects the change
Then the TIFF image should be captured and stored
And the entry should be marked as type: image/tiff

## Scenario: Capture GIF image
Given a GIF image is copied to the system clipboard
When the clipboard monitor detects the change
Then the GIF image should be captured and stored with animation preserved
And the entry should be marked as type: image/gif

## Scenario: Capture SVG image
Given an SVG image is copied to the system clipboard
When the clipboard monitor detects the change
Then the SVG content should be captured as text and rendered preview
And the entry should be marked as type: image/svg+xml

## Notes
- **Persona**: both
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Large image handling, SVG rendering
- **Dependencies**: US-002 (Popup Display Current Clipboard)
