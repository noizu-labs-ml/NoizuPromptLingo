# US-096: LLM Snippet Tags and Organization

As a developer,
I want to tag and organize my LLM snippets,
so that I can quickly find relevant snippets for different tasks.

## Scenario: Assign tags to snippet
Given a snippet is being edited or created
When the user adds tags (e.g., #git, #code, #docs)
Then those tags should be saved with the snippet
And tags should be indexable for search

## Scenario: Tag autocomplete
Given the user is adding tags to a snippet
When typing in the tag field
Then previously used tags should appear as suggestions
And selecting a suggestion adds the tag

## Scenario: Filter snippets by tag
Given the LLM Snippet Library is open
When the user selects a tag filter
Then only snippets with that tag should be displayed
And multiple tags can be selected for intersection filtering

## Scenario: Tag cloud view
Given the snippet library has many tags
When viewing the library
Then a tag cloud should show all tags sized by frequency
And clicking a tag applies it as a filter

## Scenario: Rename snippet tag
Given a tag needs to be renamed
When the user edits a snippet's tags
Then the tag can be renamed inline
And all snippets using the old tag should be updated

## Scenario: Delete tag from library
Given a tag is no longer needed
When the user deletes a tag
Then the tag should be removed from all snippets
And the tag should no longer appear in autocomplete or cloud

## Notes
- **Persona**: both
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Tag cleanup challenges, duplicate tags
- **Dependencies**: US-087 (Create LLM Snippet), US-088 (LLM Snippet Library Panel)
