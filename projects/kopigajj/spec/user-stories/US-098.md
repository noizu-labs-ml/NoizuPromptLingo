# US-098: LLM Provider Configuration

As a developer,
I want to configure multiple LLM providers (OpenAI, Anthropic, Ollama),
so that I can use different models for different snippet types and manage API keys.

## Scenario: Add LLM provider
Given the user opens LLM preferences
When the user adds a new provider
Then they should select: provider type (OpenAI/Anthropic/Ollama) and enter API key
And the API key should be stored securely in macOS Keychain

## Scenario: Configure per-snippet model
Given multiple LLM providers are configured
When editing a snippet
Then the user should select which provider/model combination to use for that snippet
And the selection should override the default model

## Scenario: Default model per task type
Given the user has preferences for different snippet types
When configuration contains default models for: code, text translation, image generation
Then newly created snippets should auto-select appropriate defaults based on output type

## Scenario: Token budget and cost tracking
Given LLM API calls consume tokens
When the user views cost tracking
Then they should see: total tokens used, estimated cost per provider, monthly budget vs usage
And budget alerts should trigger when approaching limits

## Scenario: Ollama local model configuration
Given Ollama is selected as a provider
When configuring Ollama
Then the server URL should be configurable (default: localhost:11434)
And available local models should be auto-discovered via API

## Scenario: Validate provider connection
Given an LLM provider is configured
When the user tests the connection
Then a minimal API call should be made to verify credentials
And success/failure should be reported

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Key security, API rate limits, provider service outages
- **Dependencies**: US-087 (Create LLM Snippet)
