# US-123: OCR Text Extraction from Images

As a developer,
I want to extract text from images using OCR,
so that I can search image content and copy text from screenshots.

## Scenario: Extract text on image capture
Given an image containing text is copied
When the entry is created
Then OCR should run in the background to extract text
And extracted text should be indexed for search

## Scenario: Search images by extracted text
Given images with OCR-extracted text exist
When the user searches for text that appears in an image
Then the matching image should appear in search results
And the matched text should be highlighted in the preview

## Scenario: Copy extracted text
Given an image with extracted text is selected
When the user chooses "Copy as Text"
Then the OCR-extracted text should be copied to clipboard
And the user can paste it as plain text

## Scenario: Display extracted text in detail view
Given an image has extracted text
When viewing the entry detail
Then the extracted text should be displayed in a collapsible section
And the user can select and copy portions of it

## Scenario: OCR accuracy indicator
Given OCR has been run on an image
When viewing the extracted text
Then a confidence score should be displayed
And low-confidence extractions should be flagged

## Notes
- **Persona**: both
- **T-Shirt Size**: L
- **Complexity**: medium
- **Risks**: OCR accuracy, processing time, Apple Vision framework integration
- **Dependencies**: US-119 (Image Type Support)
