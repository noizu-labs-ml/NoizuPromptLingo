# US-049: RTL (Right-to-Left) language support for Arabic/Hebrew

As a knowledge-worker speaking Arabic or Hebrew,
I want the application to support right-to-left text layout,
so that I can use the interface in my native reading direction.

## Scenario: Interface flips for RTL language
Given I have selected Arabic or Hebrew as the app language
When I open the clipboard history popup
Then the interface layout should be mirrored with content starting from the right side

## Scenario: Text alignment matches language direction
Given Arabic or Hebrew is selected as the language
When I view a clipboard item
Then the text should be right-aligned and characters should render in correct RTL order

## Scenario: Sidebar flips for RTL
Given RTL language is selected and the settings window is open
When I view the sidebar
Then the sidebar should appear on the right side of the interface with content flowing right-to-left

## Scenario: Search input respects RTL
Given RTL language is selected
When I type in the search field
Then the text should appear right-aligned with characters entering from the right

## Scenario: Menu items support RTL
Given RTL language is selected
When I view menu items
Then menu items should be right-aligned and text direction should match RTL conventions

## Scenario: Mixed LTR/RTL content
Given RTL language is selected
When I view a clipboard item containing English (LTR) text
Then the item should display with mixed bidirectional text handling

## Notes
- **Persona**: knowledge-worker (speaking Arabic, Hebrew, or other RTL languages)
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Bidirectional text rendering is complex; Swift's Text component needs RTL consideration
- **Dependencies**: US-047, US-048
