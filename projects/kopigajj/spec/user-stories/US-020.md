# US-020: Auto-start on login

As a knowledge-worker,
I want Smart Clipboard to automatically start when I log into macOS,
so that clipboard history is available immediately after I start working.

## Scenario: Enable auto-start
Given the settings window is open in the "General" section
When I toggle "Start at login" to ON
Then a helper helper application or launch agent should be registered to start Smart Clipboard at login

## Scenario: Verify auto-start status
Given "Start at login" is enabled
When I logout and login to macOS
Then Smart Clipboard should be running in the background and the menu bar icon should be visible

## Scenario: Disable auto-start
Given "Start at login" is enabled
When I toggle "Start at login" to OFF
Then the launch agent/helper should be deregistered and the app will not start on next login

## Notes
- **Persona**: knowledge-worker
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: macOS LaunchAgents can be tricky; may require helper app for proper background operation
- **Dependencies**: US-018
