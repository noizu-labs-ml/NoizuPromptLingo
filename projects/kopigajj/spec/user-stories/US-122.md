# US-122: Image Metadata Storage

As a developer,
I want image clipboard entries to store metadata (dimensions, size, source),
so that I can filter and search images by their properties.

## Scenario: Store image dimensions
Given an image is captured from clipboard
When the entry is created
Then width and height should be extracted and stored
And dimensions should be displayed in the entry detail

## Scenario: Store file size
Given an image is captured
When the entry is created
Then the file size in bytes should be stored
And a human-readable size (KB, MB) should be displayed

## Scenario: Store source application
Given an image is copied from an app
When the entry is created
Then the source app name should be captured via NSPasteboard
And the source should be displayed in entry metadata

## Scenario: Search images by dimensions
Given images with various dimensions exist
When the user searches for "width:>1000" or "size:>5MB"
Then matching images should be returned
And the search should use the stored metadata

## Scenario: Filter by image type
Given images of various formats exist
When the user filters by content type "image"
Then all image entries should be displayed
And sub-filters for PNG/JPEG/GIF should be available

## Notes
- **Persona**: both
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Metadata extraction accuracy
- **Dependencies**: US-119 (Image Type Support)
