# US-028: Sync activity log

As a developer,
I want to view a log of all sync activities,
so that I can diagnose sync issues and understand my sync history.

## Scenario: View sync activity in settings
Given the settings window is open in the "Sync" section
When I click "View Activity Log"
Then a dialog or section should appear showing a chronological list of sync events

## Scenario: Display sync event details
Given the sync activity log is displayed
When I examine a sync event entry
Then I should see the timestamp, direction (upload/download), status (success/failure), and item count

## Scenario: Filter sync activity
Given the sync activity log is displayed
When I apply a filter for "Failed operations only"
Then only sync events with a failure status should be displayed

## Scenario: Export sync activity log
Given the sync activity log is displayed
When I click "Export Log"
Then the sync activity should be exported to a CSV or JSON file for analysis

## Scenario: Clear sync activity log
Given the sync activity log contains entries
When I click "Clear Log" with confirmation
Then all log entries older than the configured retention period should be removed

## Scenario: Click event to view details
Given the sync activity log is displayed
When I click on a specific sync event
Then detailed information about that event, including any error messages or item IDs, should be displayed

## Notes
- **Persona**: developer
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Log retention must not grow unbounded; privacy concerns with detailed logs
- **Dependencies**: US-022, US-023
