# US-118: Default Paste Format Preference

As a developer,
I want to configure a default paste format,
so that frequent paste formats don't need to be selected each time.

## Scenario: Set default paste format
Given the user opens preferences
When they select a default format from: Plain Text, As-Is, Markdown, HTML
Then the default format should be saved to configuration
And all paste actions should use this format unless overridden

## Scenario: Override default for single paste
Given a default paste format is configured
When the user selects a different format from the_format picker
Then the selected format should be used for this paste only
And the default preference should remain unchanged

## Scenario: Reset to default format
Given the user has temporarily used a different format
When they close and reopen the panel
Then the default format should be active again
And no sticky format changes should persist beyond the session

## Notes
- **Persona**: both
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Preference persistence, UI feedback showing active format
- **Dependencies**: US-108 (Paste Format Options)
