# US-111: HTML to Markdown Conversion

As a developer,
I want to convert HTML clipboard content to Markdown,
so that I can paste web content into markdown editors without manual conversion.

## Scenario: Convert HTML to standard Markdown
Given an HTML clipboard entry is selected
When the user chooses "Paste as Markdown"
Then HTML tags should be converted to equivalent Markdown
Including: headings (#), bold (**), italic (*), lists (-/1.), links ([text](url)), images (![alt](url))

## Scenario: Preserve HTML tables as Markdown tables
Given HTML clipboard content contains tables
When converting to Markdown
Then tables should be converted to Markdown table syntax
And column alignment should be preserved

## Scenario: Handle HTML code blocks
Given HTML contains &lt;code&gt; or &lt;pre&gt; elements
When converting to Markdown
Then these should be converted to Markdown code blocks
And language should be inferred from class attributes if available

## Scenario: Strip inline styles during conversion
Given HTML contains inline CSS styles
When converting to Markdown
Then styles should be discarded
And only structural HTML should be converted

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: HTML parsing edge cases, complex table structures
- **Dependencies**: US-108 (Paste Format Options)
