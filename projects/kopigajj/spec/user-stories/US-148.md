# US-148: Webhook Support

As a developer,
I want HTTP webhooks triggered on clipboard events,
so that I can integrate clipboard activity with external services.

## Scenario: Configure webhook endpoint
Given the user opens developer preferences
When they add a webhook URL
Then clipboard events should be sent to that URL

## Scenario: Webhook on copy event
Given a webhook is configured
When content is copied to clipboard
Then an HTTP POST should be sent to the webhook
And the payload should include: event_type, content_preview, timestamp, source_app

## Scenario: Webhook on paste event
Given a webhook is configured
When content is pasted from ClipStash
Then an HTTP POST should be sent to the webhook
And the payload should include: entry_id, target_app, timestamp

## Scenario: Webhook authentication
Given the webhook requires authentication
When configuring the webhook
Then the user should be able to set: Authorization header, API key, or HMAC secret

## Scenario: Webhook retry on failure
Given a webhook request fails
When the endpoint returns non-2xx or times out
Then the request should be retried with exponential backoff
And failures should be logged

## Scenario: Filter webhooks by event type
Given the user only wants certain events
When configuring the webhook
Then they should be able to select: copy, paste, macro_invoke, etc.

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Webhook security, retry storms, privacy concerns
- **Dependencies**: None
