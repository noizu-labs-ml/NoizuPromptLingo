# US-058: Keyboard Shortcut Cheat Sheet and Learning Aids

As a developer,
I want a quick reference for all available keyboard shortcuts,
so that I can become more efficient without memorizing every command upfront.

## Scenario: Open cheat sheet from menu
Given the application is running
When the user clicks "Keyboard Shortcuts" from the menu bar or preferences
Then a cheat sheet panel should appear listing all available shortcuts organized by category

## Scenario: Display context-sensitive shortcuts
Given the clipboard popup is open and item is selected
When the user presses the help shortcut (Cmd+?)
Then a contextual overlay should show relevant shortcuts for the current state (navigation, selection, actions)

## Scenario: Cheat sheet dismisses on escape
Given the keyboard shortcuts cheat sheet is displayed
When the user presses the Escape key
Then the cheat sheet should dismiss and return focus to the previous element

## Scenario: Interactive shortcut practice mode
Given the user opens "Learn Shortcuts" from preferences
When the user enters practice mode
Then interactive prompts should walk through key shortcuts and wait for the user to execute them correctly

## Scenario: Keyboard shortcut reminders
Given the user has never used a particular feature (e.g., search)
When that feature becomes relevant (clipboard popup open, 10+ items)
Then a subtle hint should suggest the shortcut with option to dismiss permanently

## Scenario: Custom shortcuts shown in cheat sheet
Given the user has modified any keyboard shortcuts in preferences
When the user opens the keyboard shortcuts cheat sheet
Then all custom shortcuts should be displayed prominently with visual indicators distinguishing them from defaults

## Scenario: Quick tips on hover
Given the user is using the clipboard popup
When the user hovers over an actionable element for >1 second
Then a tooltip should display the keyboard shortcut for that action if one exists

## Notes
- **Persona**: developer
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Learning aids might clutter UI for experienced users; practice mode needs clear exit path
- **Dependencies**: US-001 (global hotkey), US-010 (keyboard navigation), US-012 (delete items)
