# US-022: Sync target configuration

As a developer,
I want to configure sync targets for clipboard history,
so that I can keep multiple devices in sync.

## Scenario: Add iCloud sync target
Given the settings window is open in the "Sync" section
When I select "iCloud" from a dropdown of available sync providers
When I click "Connect"
Then the app should request iCloud container access and, if granted, register iCloud as the sync target

## Scenario: Configure custom sync server
Given the settings window is open in the "Sync" section
When I select "Custom Server" from the dropdown
When I enter a valid server URL and authentication credentials
Then the app should validate the connection and save the configuration

## Scenario: Disable sync
Given sync is configured and active
When I toggle "Enable Sync" to OFF
Then sync should be disabled and no data should be sent to or retrieved from the configured target

## Scenario: Display current sync status
Given sync is configured
When I view the Sync section in settings
Then the status indicator should show "Connected" or "Not Connected" with the last sync timestamp

## Notes
- **Persona**: developer
- **T-Shirt Size**: L
- **Complexity**: high
- **Risks**: Multiple sync providers add complexity; offline mode needs consideration
- **Dependencies**: US-018, US-023
