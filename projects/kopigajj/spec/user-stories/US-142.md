# US-142: Per-Entry Usage Timeline

As a developer,
I want to see a timeline of when an entry was used,
so that I can understand usage patterns over time.

## Scenario: Open usage timeline
Given an entry is selected
When the user views entry details
Then a timeline section should show all paste events

## Scenario: Timeline entry details
Given the usage timeline is displayed
When viewing a timeline entry
Then it should show: timestamp, target app, target document (if available)

## Scenario: Timeline visualization
Given an entry has many usage events
When the timeline is displayed
Then events should be grouped by time period (today, this week, older)
And a sparkline should show usage over time

## Scenario: Filter timeline by date range
Given the usage timeline is displayed
When the user selects a date range
Then only events in that range should be shown

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Timeline performance with many events
- **Dependencies**: US-140 (Target App Tracking on Paste)
