# US-144: CLI Tool - clipstash

As a developer,
I want a CLI tool (`clipstash`) for clipboard operations,
so that I can script clipboard actions from the terminal.

## Scenario: Install CLI tool
Given the ClipStash app is installed
When the user runs the CLI installer or symlinks the binary
Then `clipstash` should be available in PATH

## Scenario: Query history from CLI
Given clipboard history exists
When the user runs `clipstash list --limit 10`
Then the 10 most recent entries should be printed
And output should be formatted as JSON or plain text

## Scenario: Copy entry from CLI
Given an entry exists with given ID
When the user runs `clipstash copy <id>`
Then the entry content should be copied to the system clipboard

## Scenario: Add entry from CLI
Given the user wants to add content
When the user runs `clipstash add "text content"`
Then the content should be added to clipboard history
And it should be available in the GUI

## Scenario: Search from CLI
Given clipboard history exists
When the user runs `clipstash search "query"`
Then matching entries should be printed
And results should be formatted consistently

## Scenario: Invoke macro from CLI
Given a macro exists with slug "sig"
When the user runs `clipstash macro sig --var name="John"`
Then the macro should be expanded with the variable
And output should be printed or copied to clipboard

## Notes
- **Persona**: developer
- **T-Shirt Size**: L
- **Complexity**: medium
- **Risks**: PATH configuration, shell compatibility
- **Dependencies**: US-004 (View Clipboard History), US-074 (Macro Quick Insert Bar)
