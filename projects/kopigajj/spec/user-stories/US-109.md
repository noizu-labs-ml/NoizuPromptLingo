# US-109: Option Key Strip Formatting

As a developer,
I want to hold Option key while pasting to automatically strip formatting,
so that I can quickly paste plain text without selecting a menu option.

## Scenario: Option key triggers plain text paste
Given a clipboard entry is selected
When the user holds Option and invokes paste (Cmd+Shift+T Space with ⌥)
Then the content should be pasted as plain text
And all formatting should be stripped

## Scenario: Visual feedback for Option modifier
Given the user is holding Option while preparing to paste
When the paste action is previewed
Then a subtle hint should indicate "Paste as Plain Text"
And the preview should show stripped formatting

## Scenario: Option key doesn't affect format picker
Given the user is using manual format selection
When Option key is held
Then the Option modifier should be ignored
And the selected format should be used

## Notes
- **Persona**: developer
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Modifier key detection across different input methods
- **Dependencies**: US-108 (Paste Format Options)
