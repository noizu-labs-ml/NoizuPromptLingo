# US-037: Import clipboard history from JSON

As a developer,
I want to import clipboard history from a JSON file,
so that I can restore or bring in history from another source.

## Scenario: Import from JSON file
Given I have a valid JSON export file from Smart Clipboard or a compatible format
When I click the menu bar icon and select "Import History" and choose the JSON file
Then the clipboard items should be added to my history with their original timestamps preserved

## Scenario: Validate import file format
Given I select an invalid or corrupted JSON file for import
When the import process begins
Then an error message should appear indicating the file format is invalid and no items should be added

## Scenario: Handle duplicate items during import
Given I am importing a JSON file containing items with the same content or timestamps as existing history
When the import is processed with the "Skip duplicates" option enabled
Then duplicate items should be skipped and only new items added

## Scenario: Merge import with existing history
Given I am importing a JSON file
When the import is processed
Then imported items should be merged with existing history, with new items added based on timestamp ordering

## Scenario: Import progress indicator
Given I am importing a large JSON file
When the import is in progress
Then a progress indicator should show the number of items imported or a percentage complete

## Scenario: Preview import before committing
Given I have selected a JSON file for import
When the preview dialog appears
Then I should see a summary of items to be imported (count, date range) with an option to cancel before committing

## Notes
- **Persona**: developer
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Malformed files could corrupt database; deduplication logic complexity
- **Dependencies**: US-036
