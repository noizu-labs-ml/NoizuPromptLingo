# US-117: Paste as Code Block with Language Detection

As a developer,
I want to paste clipboard content wrapped in a markdown code block with auto-detected language,
so that I can quickly paste code snippets into markdown editors with proper formatting.

## Scenario: Auto-detect programming language
Given a code clipboard entry is selected
When the user chooses "Paste as Code Block"
Then the code language should be auto-detected
And the code block syntax should be ```language``` with the detected language

## Scenario: Manually override language
Given language detection is incorrect
When the user edits the language in the preview
Then the corrected language should be used in the final paste

## Scenario: Language detection from file extensions
Given clipboard content was copied from a file (e.g., .swift, .py, .js)
When code block paste is selected
Then the language should default to the file extension's associated language

## Scenario: Language detection from syntax patterns
Given clipboard content contains language-specific patterns
When code block paste is selected
Then common keywords, comment styles, and punctuation should be used to infer language
Including: Python (def/import), JavaScript (function/var), Swift (func/var/let)

## Scenario: No language detected
Given clipboard content doesn't match any known language
When code block paste is selected
Then the code block should use ``` (no language specified)
Or a generic ```text``` should be used

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Language detection accuracy, false positives
- **Dependencies**: US-108 (Paste Format Options)
