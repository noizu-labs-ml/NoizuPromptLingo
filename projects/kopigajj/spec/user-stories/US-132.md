# US-132: Preferences - Keyboard Tab

As a developer,
I want a Keyboard preferences tab,
so that I can customize chord bindings and hotkeys.

## Scenario: Open Keyboard preferences
Given the menu bar dropdown is open
When the user selects Preferences > Keyboard
Then the Keyboard tab should display with all customizable shortcuts

## Scenario: Customize main hotkey
Given Keyboard preferences is open
When the user clicks the main hotkey field and presses a new key combination
Then the new hotkey should be saved
And the hotkey should be registered system-wide

## Scenario: Customize chord bindings
Given Keyboard preferences is open
When the user modifies a chord binding (e.g., Cmd+Shift+T M for macros)
Then the new binding should be saved
And the chord should work with the new key

## Scenario: Detect hotkey conflicts
Given the user sets a hotkey
When the hotkey is already registered by another app
Then a warning should be displayed
And the user should be prompted to resolve the conflict

## Scenario: Reset to default shortcuts
Given Keyboard preferences is open
When the user clicks "Reset to Defaults"
Then all shortcuts should revert to their default values
And the changes should take effect immediately

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: medium
- **Risks**: Hotkey conflicts, system accessibility permissions
- **Dependencies**: US-001 (Global Hotkey Activation), US-019 (Hotkey customization)
