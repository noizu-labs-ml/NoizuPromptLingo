# US-092: LLM Snippet Invocation History

As a developer,
I want to view all invocations of a snippet with input and output,
so that I can review past results and understand how prompts performed.

## Scenario: Open invocation history
Given the LLM Snippet Library is open
When the user presses H on a snippet
Then the invocation history panel should appear for that snippet

## Scenario: Display invocation list
Given the invocation history is open
When browsing history
Then each entry should show: timestamp, score, truncated input (50 chars), truncated output (50 chars)
And entries should be sorted by most recent

## Scenario: View invocation details
Given an invocation is selected in the history
When the user presses Enter
Then full details should display: input values, output content, model used, version number, rating, notes

## Scenario: Copy invocation output
Given an invocation is being viewed
When the user chooses to copy the output
Then the output should be copied to clipboard
And the panel should remain open

## Scenario: Re-run invocation with inputs
Given an invocation is being viewed
When the user selects "Re-run"
Then the snippet should be re-invoked with the same inputs
And the new result should appear alongside the original

## Scenario: Filter history by version
Given a snippet has multiple versions
When viewing invocation history
Then an option to filter by version should be available
And the list should show only invocations from the selected version

## Scenario: Clear invocation history
Given the snippet has invocation history
When the user chooses to clear history
Then all invocations for that snippet should be deleted
And a confirmation prompt should be required

## Notes
- **Persona**: developer
- **T-Shirt Size**: M
- **Complexity**: low
- **Risks**: Privacy concerns with stored prompts, storage growth over time
- **Dependencies**: US-089 (Invoke LLM Snippet), US-090 (Rate LLM Snippet Output)
