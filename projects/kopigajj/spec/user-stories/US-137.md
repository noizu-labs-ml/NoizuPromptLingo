# US-137: Preferences - Appearance Tab

As a developer,
I want an Appearance preferences tab,
so that I can customize the visual style of ClipStash.

## Scenario: Open Appearance preferences
Given the menu bar dropdown is open
When the user selects Preferences > Appearance
Then the Appearance tab should display

## Scenario: Set theme
Given Appearance preferences is open
When the user selects theme: System, Light, or Dark
Then the app UI should update immediately
And the theme should persist across launches

## Scenario: Configure font size
Given Appearance preferences is open
When the user adjusts the font size slider
Then all text in the app should scale accordingly
And the setting should be saved

## Scenario: Set density (compact/comfortable)
Given Appearance preferences is open
When the user selects density mode
Then entry list spacing should adjust
And the panel height should accommodate more/fewer entries

## Scenario: Configure panel dimensions
Given Appearance preferences is open
When the user sets panel width and max height
Then the panel should respect these dimensions
And the settings should be saved

## Scenario: Animation speed
Given Appearance preferences is open
When the user adjusts animation speed or enables "Reduce Motion"
Then animations should scale or be disabled
And the setting should match macOS accessibility preferences

## Notes
- **Persona**: both
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Theme consistency, accessibility compliance
- **Dependencies**: US-046 (Reduced motion animation option)
