# US-017: Delete Single History Item

As a privacy-conscious user,
I want to delete individual items from clipboard history,
so that I can remove specific sensitive information without clearing the entire history.

## Scenario: Delete selected item with keyboard shortcut
Given the clipboard popup is displaying history and an item is selected
When the user presses the Delete key
Then the selected item should be removed from history

## Scenario: Delete item with context menu
Given the clipboard popup is displaying history
When the user right-clicks on an item and selects "Delete"
Then that item should be removed from history

## Scenario: Delete item confirmation (optional)
Given the user attempts to delete a history item
When the item is a sensitive type (large text, large image, etc.)
Then a confirmation dialog may be shown before deletion

## Notes
- **Persona**: both
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Accidental deletion
- **Dependencies**: US-004
