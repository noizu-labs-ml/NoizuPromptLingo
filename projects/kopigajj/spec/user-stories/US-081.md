# US-081: Macro Usage Tracking and Statistics

As a developer,
I want to see usage statistics for each macro,
so that I can identify my most-used macros and optimize my snippet library.

## Scenario: Track macro usage count
Given a macro is invoked and expanded successfully
When the paste action completes
Then the macro's usage count should be incremented
And the count should be stored persistently

## Scenario: Display macro usage count in macro list
Given the user is browsing macros in the quick-insert bar
When looking at macro search results
Then each macro should display its usage count (e.g., "×14 uses")
And more-used macros should optionally be ranked higher in search

## Scenario: Per-macro usage timeline
Given a macro has been used multiple times
When the user opens the macro detail view
Then a timeline of all usage events should be displayed
And each event should show: timestamp, target app, variables used

## Scenario: Most-used macros in suggestions
Given the user opens the macro quick-insert bar
When suggestions are calculated
Then macros with higher usage counts should be weighted more heavily in the suggestion algorithm

## Notes
- **Persona**: both
- **T-Shirt Size**: S
- **Complexity**: low
- **Risks**: Performance impact on each paste, query optimization for usage stats
- **Dependencies**: US-074 (Macro Quick Insert Bar), US-079 (Macro Generated Output Nesting)
