# Persona Marketplace

| Field | Value |
|-------|-------|
| **ID** | `persona-marketplace` |
| **Type** | Primary |
| **Category** | Persona Management |
| **User Stories** | US-116 |

## Description

Community marketplace for browsing and importing publicly-shared personas from other organizations. Shows ratings, descriptions, download counts, and sample runs.

## Key Components

- **Marketplace grid** — Persona cards with title, author, downloads, average rating, last updated
- **Import action** — Deep-copies into caller's org
- **Detail panel** — Full persona description, sample system preamble, sample run results

## Interactions

- Browse community personas
- Filter by domain/tone
- Import selected personas
- View ratings and download counts

## Navigation

- Accessible from: Persona List (Marketplace button)
- Links to: Persona Detail (after import)
