Serif Accessibility

Source Serif 4 at 16px, #EDEDF0 on #141418 = 13.3:1 contrast ratio. Exceeds WCAG AAA.

Conversation Transcript 20% Editorial

This is the core 20% Editorial surface. Agent responses render in serif; prompts stay mono. Turn spacing is 28px (vs 16px in Direction A). Max width 72ch prevents ultra-wide line lengths.

Standard Transcript

Script
"Design a website for learning a second language"
Agent

That's an interesting project. Before I start designing, I'd like to understand a few things about the target audience and scope.

What age group are we targeting? Are we building for adults learning conversationally, or students in a formal education setting? And should the platform support multiple source languages, or is it primarily English-to-X?

Multi-Turn Example

Good call. Collaboration changes the architecture significantly. We'll need real-time sync, user authentication, and shared list permissions. Let me revise the approach.

I'll use WebSockets for live updates and add a simple invite system so users can share lists by email.

Mixing Notes

Three elements carry the 20% Editorial accent. Everything else is pure Minimal Tech.

What Changed (3 Elements)

ElementChangeWhy
Agent response typography Mono 13px → Serif 16px, line-height 1.5 → 1.75 Agent responses are prose you read and judge. Serif reduces fatigue during long review sessions.
Turn spacing 16px → 28px between turns Each turn is a distinct evaluative moment. Clear visual separation without scanning.
Agent highlight (pull-quote) New: italic serif + accent border-left Engineers flag specific responses for team discussion. Editorial pull-quote provides a "this is important" marker.

What Was Rejected

CandidateWhy Rejected
Serif for script promptsPrompts are authored input, closer to code. Mono preserves "I wrote this / agent wrote that" distinction.
Drop caps on first responseToo magazine-like for a testing tool. Signals "editorial publication," not "test results."
Serif for graph node labelsBreaks consistency with graph editor. Nodes are functional UI, not reading content.
Warm cream backgroundConflicts with dark mode palette. Creates jarring context switch.

Implementation Checklist

  • Geist (sans) for all UI, navigation, graph, dashboard
  • Source Serif 4 (serif) for agent response text and transcript body only
  • Geist Mono for prompts, YAML, expectations, code
  • Serif appears ONLY in .transcript and .agent-response containers
  • Transcript max-width: 72ch
  • Turn spacing: 28px (not 16px)
  • Agent response padding: 16px 20px
  • All other components unchanged from Direction A
  • Agent highlight uses italic + accent border-left
  • Dark mode only
  • Accessible contrast: serif text on dark bg meets AA (13.3:1)
