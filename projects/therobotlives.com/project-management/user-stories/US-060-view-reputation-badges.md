# US-060: View Reputation Score and Badges

## User Story

**As a** Prompt Engineer Power User (P-001), AI/ML Engineer (P-002), Engineering Team Lead (P-003), or MCP Server Developer (P-005),
**I want to** see my reputation score and earned badges,
**So that** I can understand my standing in the community and work toward earning specific achievements.

## Acceptance Criteria

- [ ] Given I am logged in, when I view my profile, then I see a prominent reputation badge with numeric score and percentile rank (e.g., "in top 5%")
- [ ] Given badges exist, when I click the reputation score, then I see a detailed breakdown showing score components (contributions, votes received, helpful answers) and all earned badges
- [ ] Given badges are earned, when I view badges, then each badge shows icon, name, description, date earned, and progress toward next tier (if applicable)
- [ ] Given another user's profile, when I view it, then I see their reputation score and badges (if public per their privacy settings)
- [ ] Given reputation changes, when I receive new badges or score increases, then I receive an in-app notification with celebration animation

## Notes

Reputation system must be transparent—users should understand how scores are calculated. Badges should include "First Prompt", "100 Helpful Answers", "Top Contributor", "MCP Publisher", etc. Avoid pay-to-win or spam-incentivizing metrics.
