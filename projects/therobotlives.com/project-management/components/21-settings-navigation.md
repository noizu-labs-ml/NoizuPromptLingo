# Settings Navigation

| Field | Value |
|-------|-------|
| **ID** | `settings-navigation` |
| **Category** | Navigation & Layout |
| **Used In** | 41-Settings Hub |

## Description

Sidebar navigation for settings categories. Highlights active category and preserves scroll position on refresh.

## Size Variants

| Variant | Description |
|---------|-------------|
| **Compact** — Icon-only sidebar |
| **Expanded** | Full sidebar with category labels |

## Props / Configuration

- `categories` — Account, Profile, Notifications, Privacy, API Keys, Danger Zone
- `activeCategory` — Currently selected

## Interactions

- Click category → navigate to section; active state highlights
