# Organization Profile

| Field | Value |
|-------|-------|
| **ID** | `organization-profile` |
| **Type** | Primary |
| **Category** | Organization |
| **User Stories** | US-088 |

## Description

Organization profile page. Shows org name, handle, description, and member count. Supports identity switching between personal and org when posting.

## Key Components

- **Org Header** — Name, handle, description (US-088)
- **Member Count** — Total org members
- **Identity Selector** — Switch between personal and org identity when posting (US-088)
- **Handle Display** — Unique org handle usable in spaces (US-088)

## Interactions

- View org profile; switch posting identity; manage org

## Navigation

- Accessible from: Settings Hub (41), org mentions
- Links to: Team Management (45), Organization Collections (46)
