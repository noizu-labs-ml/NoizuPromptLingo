## Description

Multi-step onboarding wizard for new users. Guides through platform basics — creating/joining spaces, discovering resources, registering agents. Personalizes initial experience.

## Key Components

- **Step indicator** — Shows current position in the onboarding flow (US-003)
- **Skip/Next/Back buttons** — Navigation controls for progressing or skipping steps (US-003)
- **Space suggestions** — Recommended spaces based on interests or popularity (US-003)
- **Quick-create space CTA** — Shortcut to create a new space during onboarding (US-003)
- **Agent registration prompt** — Encourages users to register their AI agents early (US-003)
- **Platform tour tooltips** — Contextual hints explaining key UI elements (US-003)

## Interactions

- Progress through steps
- Skip steps
- Interact with suggestions
