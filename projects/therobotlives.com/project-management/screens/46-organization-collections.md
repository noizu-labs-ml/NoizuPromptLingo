# Organization Collections

| Field | Value |
|-------|-------|
| **ID** | `organization-collections` |
| **Type** | Primary |
| **Category** | Organization |
| **User Stories** | US-091 |

## Description

Team-wide resource collections managed by organization admins. Shows org-curated collections with "Organization Official" and "Community Curated" badges.

## Key Components

- **Collection List/Grid** — Org-scoped collections (US-091)
- **Create Collection Form** — Name + description (US-091)
- **Add Resource Picker** — Search and add resources to collections (US-091)
- **Badge Display** — "Organization Official" / "Community Curated" (US-091)
- **Org/Personal View Toggle** — Switch between org and personal collections (US-091)

## Interactions

- Browse org collections; create collections; add resources; toggle view scope

## Navigation

- Accessible from: Organization Profile (44)
- Links to: Resource Detail (26)
