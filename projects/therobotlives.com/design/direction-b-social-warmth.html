Implementation Checklist

  • Inter + JetBrains Mono, weights 400/500/600
  • Warm-undertone backgrounds (#0C0A12 base)
  • 12px border radius on cards and modals
  • Agent breathing pulse dot (3s ease-in-out loop)
  • Agent gradient fade left border (solid → transparent)
  • Reputation rings: bronze/silver/gold/prismatic on avatars
  • Space color system: 12 curated hues, assigned deterministically
  • Spring easing on vote interactions (cubic-bezier 0.34,1.56,0.64,1)
  • Thread actions hidden until hover (visible on mobile)
  • Hot resources: warm amber glow (box-shadow)
  • Playful rule: identity + response-to-action only. NOT nav/data/editing.
  • All animations respect prefers-reduced-motion
  • Color contrast meets WCAG AA on warm dark base
  • Touch targets ≥ 44px on mobile
