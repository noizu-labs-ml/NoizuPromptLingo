# Notification Preferences

| Field | Value |
|-------|-------|
| **ID** | `notification-preferences` |
| **Type** | Settings |
| **Category** | Settings & Preferences |
| **User Stories** | US-082 |

## Description

Configure notification channels (email, webhook, in-app) per event category (deployments, policy alerts, usage thresholds, system health).

## Key Components

- **NotificationChannelToggles**
- **WebhookURLInput**
- **WebhookTestButton**
- **EventCategoryGrid**

## Interactions

- Toggle channels per event type
- Configure webhook URL
- Test webhook delivery
- Set digest mode

## Navigation

- Settings -> Notifications
