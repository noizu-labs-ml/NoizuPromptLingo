# Organization Setup & Management

| Field | Value |
|-------|-------|
| **ID** | `organization-management` |
| **Type** | Primary |
| **Category** | Organization Management |
| **User Stories** | US-061, US-062, US-065, US-067 |

## Description

Create org, invite members, assign roles (admin/developer/viewer/auditor), manage team activity feed, transfer server ownership.

## Key Components

- **OrgCreationForm**
- **TeamMemberList**
- **InviteMemberDialog**
- **RoleSelector**
- **ActivityFeed**
- **OwnershipTransferDialog**
- **OrgProfileCard**

## Interactions

- Create organization
- Invite members by email
- Assign/change roles
- Revoke invitations
- View activity feed
- Transfer server ownership
- Switch between organizations

## Navigation

- Dashboard -> Organization Management
