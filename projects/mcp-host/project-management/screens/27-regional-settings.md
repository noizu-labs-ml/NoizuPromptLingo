# Regional Settings

| Field | Value |
|-------|-------|
| **ID** | `regional-settings` |
| **Type** | Settings |
| **Category** | Settings & Preferences |
| **User Stories** | US-086, US-098 |

## Description

Configure timezone, date format, and display language.

## Key Components

- **TimezoneSelector**
- **DateFormatSelector**
- **LanguageSelector**

## Interactions

- Search and select timezone
- Choose date format
- Switch language

- Settings -> Regional
