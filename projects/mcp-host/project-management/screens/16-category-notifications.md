# Category Notifications

| Field | Value |
|-------|-------|
| **ID** | `category-notifications` |
| **Type** | Settings |
| **Category** | Registry & Discovery |
| **User Stories** | US-059 |

## Description

Manage watched categories and notification preferences for new tool publications and deprecations.

## Key Components

- **WatchedCategoryList**
- **NotificationChannelToggles**
- **DigestFrequencySelector**

## Interactions

- Watch/unwatch categories
- Set email digest frequency
- Configure channels per category

## Navigation

- Settings -> Notifications -> Category Watches
