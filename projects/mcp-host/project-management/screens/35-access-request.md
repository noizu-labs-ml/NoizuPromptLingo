# Access Request Flow

| Field | Value |
|-------|-------|
| **ID** | `access-request` |
| **Type** | Modal |
| **Category** | Social & Publishing |
| **User Stories** | US-073 |

## Description

Request access to a private MCP server with optional message. Owner sees approval queue.

## Key Components

- **AccessRequestForm**
- **RequestStatusIndicator**
- **ApprovalQueue**

## Interactions

- Submit access request with message
- View pending status
- Withdraw request
- Owner approves/rejects

## Navigation

- Registry Server Detail -> Access Request Modal
