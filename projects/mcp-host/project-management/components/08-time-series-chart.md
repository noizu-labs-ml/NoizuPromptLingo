# Time Series Chart

| Field | Value |
|-------|-------|
| **ID** | `time-series-chart` |
| **Category** | Data Display |
| **Used In** | 12-Server Detail |

## Description

Interactive line/area chart for metrics over time (invocations, latency, error rates, health probes). Supports zoom, hover tooltips, and time range selection.

| Variant | Description |
|---------|-------------|

## Props / Configuration

- `data`
- `timeRange`
- `series`
- `onTimeRangeChange`
- `anomalyMarkers`
- `thresholdLines`

## Interactions

- Hover for tooltip
- Select time range
- Zoom into area
- Click anomaly spike for drill-down
