# Infinite Scroll Loader

| Field | Value |
|-------|-------|
| **ID** | `infinite-scroll-loader` |
| **Category** | Navigation & Layout |
| **Used In** | 14-Registry Search & Browse |

## Description

Intersection observer-based loader that fetches next page of results when user scrolls near bottom.

## Size Variants

| Variant | Description |
|---------|-------------|

## Props / Configuration

- `hasMore`
- `isLoading`
- `onLoadMore`

## Interactions

- Auto-loads on scroll
- Shows loading spinner
