# Global Search Bar

| Field | Value |
|-------|-------|
| **ID** | `global-search-bar` |
| **Category** | Navigation & Layout |
| **Used In** | 04-Main Dashboard, 14-Registry Search & Browse |

## Description

Platform-wide search input with autocomplete for MCP servers, tools, and commands. Appears in the global navigation header.

- Autocomplete suggestions
