# Faceted Filter Panel

| Field | Value |
|-------|-------|
| **ID** | `faceted-filter-panel` |
| **Category** | Navigation & Layout |
| **Used In** | 14-Registry Search & Browse |

## Description

Sidebar or collapsible panel with filter groups (checkboxes, sliders, dropdowns) that narrow results. Shows active filter count and clear-all action.

## Size Variants

| Variant | Description |
|---------|-------------|

## Props / Configuration

- `filterGroups`
- `activeFilters`
- `onFilterChange`
- `onClear`

## Interactions

- Toggle filter values
- Adjust slider
- Clear all filters
- See result count update
