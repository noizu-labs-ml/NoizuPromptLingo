# Void Walker

**RPG / Roguelike**

## Core Loop
Manifest luminous artifacts from void dimensions to transcend floating island realms while hunting ethereal krakens that devour light.

## Features
- **Transcendent Skill System**: Chain teleport bursts and void-manifestation combos that create emergent, rhythm-based combat flows
- **Procedural Void Realms**: Each floating island generates unique architecture, creature ecosystems, and artifact layouts based on obsidian runes you collect
- **Artifact Evolution**: Combine elemental essences into luminous artifacts that reshape your abilities and the environments you traverse

## Why This Is Awesome
**Flow State** - Combat rewards precise teleport timing, combo chaining, and moment-to-moment decision density that pushes you into focused, rhythmic execution. Void-manifestation mechanics create skill ceilings that feel earned through practice rather than grind.

**Emergent Sandbox** - Void artifact combinations, creature interactions, and island terrain properties generate unpredictable emergent scenarios. Kraken behaviors evolve based on light pollution you create, forcing adaptive strategies rather than scripted solutions.

**Aesthetic Purist** - Obsidian voidscapes punctuated by luminous artifact glows create striking visual contrast. Combat animations emphasize elegance over gore—teleport trails crystallizing momentarily, artifacts pulsing with collected light, kraken movements rendered as fluid void-distortions.
