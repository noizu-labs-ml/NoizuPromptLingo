# Rift Katana Eternity

**Character Action Hack-and-Slash**

## Core Loop

You play as a nameless swordswoman wielding a katana forged from a fractured dimensional rift. The blade phases between three combat stances -- Void (slow, heavy, area denial), Flux (fast, evasive, counter-focused), and Pulse (ranged energy slashes). You fight through procedurally arranged combat arenas connected by rift corridors, building combo meters that unlock stance-specific finishers. Death sends you back to the hub, but the katana retains partial combo memory, making each run incrementally more powerful.

## Features
- **Stance Dance Combo System**: Switching stances mid-combo at specific timing windows triggers Rift Finishers -- cinematic attacks that deal 3x damage and freeze time for 1.5 seconds. The timing is tight (6-frame window) but the payoff is enormous.
- **Rift Corridor Exploration**: Between combat arenas, you traverse rift corridors where the environment shifts between parallel dimensions. In one dimension, a path is blocked; in the other, it's open but guarded. You can dimension-shift at will, creating spatial puzzles within traversal.
- **Memory Forge**: Spend combo memory currency at the hub to permanently engrave new ability runes onto the katana. Each rune changes a stance's behavior -- a Void rune might add a vacuum pull on heavy attacks, while a Flux rune adds a dash-cancel to every move.

## Why This Is Awesome
**Challenge Seeker** players will chase S-rank clears on every arena, mastering the 6-frame stance-dance timing and discovering that the true depth is in animation-canceling Flux attacks into Void finishers for sustained damage windows. The skill ceiling is measured in frame data.

**Flow State** enthusiasts will find the combat loop hypnotic once stance-switching becomes muscle memory -- the rhythm of attack, stance-switch, finisher, dash, attack creates a dance that feels like playing a musical instrument with violence.

**Aesthetic Purist** fans will be captivated by the dimension-shift visual design: one world is ink-wash black and white with crimson slash effects, the other is neon wireframe with gold particle trails. The katana's rift energy bleeds between both visual languages.
