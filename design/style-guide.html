Scenario

AI Fighter is a mobile game where players build neural-net powered fighters through a visual graph editor, train them in simulated gyms, and compete in async PvP arenas. The interface has two modes: spectacle (battles, replays, home, seasonal events) and precision (graph editor, training analytics, stats).

Bold Expressive delivers the energy a competitive game demands — neon accents on black, dramatic type, glowing particle motifs. Minimal Tech provides structural discipline for the graph editor and analytics screens — clean lines, readable labels, systematic spacing.

Brand personality: Electric. Competitive. Intelligent. Visceral.

Mixing Notes

5 elements carry the 20% Minimal Tech accent. Bold Expressive owns the visual layer; Minimal Tech owns the functional layer.

Elements Carrying 20% MT

ElementWhat ChangedWhy
Graph Editor BE chaos → MT 8px grid with systematic node spacing Precision tool needs clear spatial relationships for wiring perception→decision→action nodes
Form Inputs BE (undefined) → MT input patterns with mono type, 4px radius, focus rings Node parameter editing needs accessible, functional controls that feel "technical"
Data Readouts Display type → Mono for all numerical data Win rate, ELO, confidence % must be instantly parseable. Fixed-width numbers align in columns.
Functional Transitions BE 500ms+ → MT 150ms for functional interactions Dragging nodes, tapping tabs, focusing inputs need instant feedback. Drama reserved for battles.
Navigation BE hidden/experimental → MT systematic bottom tab bar Mobile game needs thumb-reachable, legible navigation. MT tab bar + mono labels + mint active state.

Considered & Rejected

CandidateWhy Rejected
MT's single accentFour neon accents are load-bearing — each maps to a game concept (mint/pink/blue/amber)
MT's type scale"ARENA" at 48px uppercase = title screen. At 36px sentence case = settings page.
Rounded corners everywhereWould soften the aesthetic. Radius reserved for pills and bento tiles.
Light modeNeon on dark IS the identity. Light mode would require redesigning every glow effect.

Implementation Checklist

Verify all items before shipping.

  • Space Grotesk (display, 600-700) + DM Sans (body, 400) + JetBrains Mono (data, 400-500)
  • All four neon accents rendered correctly against #0A0A0F background
  • Primary CTA buttons have neon glow on hover (box-shadow with accent color)
  • Graph editor uses MT spacing (8px grid, systematic node alignment)
  • All inputs have visible focus rings (--focus-ring token)
  • All numerical data (ELO, win rate, confidence %) uses JetBrains Mono
  • Health bars animate width with color transitions (green → amber → red)
  • Rank badges use correct tier colors with muted backgrounds
  • Bottom tab bar: 64px height, mono labels, mint active indicator dot
  • Spectacle animations: 200-800ms, spring easing, dramatic
  • Precision animations: 150ms ease, subtle, functional
  • prefers-reduced-motion: all animations disabled, instant state changes
  • Screen reader: semantic HTML, aria-labels on game controls, alt text on fighter renders
  • Touch targets: minimum 44px for all interactive elements
  • Dark mode only — no theme toggle
  • Contrast ratios: all text meets WCAG AA minimum (verified in Color section above)
