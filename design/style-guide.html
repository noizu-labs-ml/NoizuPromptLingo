Contrast Ratios

All text combinations against bg-primary (#0A0A0A). Targeting WCAG AAA (7:1) for game narrative. This game is designed for blind users — maximum legibility for sighted users who may also play.

Foreground Background Ratio AA (4.5:1) AAA (7:1) Use
text-primary bg-primary 15.5:1 Pass Pass Narrative body text
gold-primary bg-primary 8.2:1 Pass Pass Headings, section titles
text-secondary bg-primary 7.3:1 Pass Pass Labels, captions
accent-green bg-void 7.5:1 Pass Pass Command input text
text-muted bg-primary 3.8:1 Fail Fail Decorative only (no essential info)

Narrative Block

The core content display for game narrative. Left gold border, editorial line height, measured line length. NPC speech in gold italic, system messages in green mono.

You wake up. It's dark with only a lantern flickering faintly near your head.

You're not sure where you are. You remember something about a festival. People gave you a drink and then everything went black.

The room doesn't look familiar, and there are no indications of where you are now.

But you hear someone saying, "Where's Amanda," over and over again. You're not sure if that's in your head or if it's an echo from somewhere deeper down the hall.

Layout Grid

Game interface uses a main + aside layout. Main holds the narrative and command input (max-width: 65ch for reading comfort). Aside holds character stats. Below 768px, aside collapses into main.
