Implementation Checklist

  • Monospace default: Space Mono on body, all UI elements
  • Space Grotesk ONLY for display numbers (56px hero stats)
  • Two font weights: 400 (regular) and 700 (bold). No semibold. No italic.
  • border-radius: 0 on everything. Buttons, cards, inputs, badges, swatches.
  • 2px borders everywhere. No 1px. No hairline.
  • Pure black #000000 background. Not near-black. Black.
  • Electric green #00E676 accent. Green = operational. Not "success."
  • Transitions: 100ms linear or 0ms instant. Nothing else.
  • No smooth scrolling. scroll-behavior: auto.
  • Uppercase labels with 0.05-0.08em letter-spacing
  • No gradients. No shadows. No blur. No rounded shapes.
  • Status indicators are SQUARES (border-radius: 0), never circles
  • Text badges use literal brackets: [ONLINE] [CRITICAL] [OFFLINE]
  • Critical alerts pulse (1s cycle). Only looping animation in the system.
  • Color is signal, never decoration. Every hue maps to a system state.
  • No SVG icons. Text symbols only: > ■ ▲ ● ◆ ▸ ✕ + -
  • Visible grid lines everywhere. 2px borders between grid cells.
  • Dense spacing. 8px default gap. 16px card padding.
  • No sidebar navigation. Top tabs only. tmux-style.
  • WCAG AA contrast on all essential text (primary 14.7:1, secondary 5.7:1)
  • prefers-reduced-motion kills all animation and transitions
  • Touch targets ≥ 44px on mobile
  • Dark mode only. There is no light version. The brand lives in the dark.
