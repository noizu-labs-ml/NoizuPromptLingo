1from noizurpg import World, Character, NarrativeEngine 2from noizurpg.providers import Anthropic 3 4# Build your world 5world = World("The Ashward Chronicles") 6world.add_location("Thornwall", type="city", traits=["coastal"]) 7 8# Create a character 9kael = Character("Kael Ashward") 10kael.stats.set(str=12, dex=14, int=16) 11 12# Wire in any LLM 13engine = NarrativeEngine( 14 llm=Anthropic("claude-sonnet-4-5-20250514"), 15 world=world 16) 17 18# Play 19response = engine.turn( 20 character=kael, 21 action="Enter the guild hall and greet Master Venn" 22)

Alerts & Callouts

Documentation callouts for tips, notes, warnings, and danger.

Tip
Use noizurpg init to scaffold a new project with sensible defaults — SQLite storage, Ollama provider, and a sample world.
Note
The Narrative Engine requires at least one LLM provider configured. See the Providers guide for setup instructions.
Warning
Context windows have hard limits. For sessions longer than 50 turns, enable memory compression: engine.memory.compress_every = 10
Danger
Never expose your LLM API keys in client-side code. Use environment variables or a secrets manager.
