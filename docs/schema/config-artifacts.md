# Config & Persistence Artifacts (non-SQL)

Covers configuration files, env/secret structure, deployment values, and file formats the project defines. Companion to PROJ-SCHEMA.md.

## Environment / Secrets

| File | Role |
|------|------|
| `.env.example` | Template. Keys: `PROJECT_SLUG`, `REGISTRY`, `DATABASE_URL`, `REDIS_URL`, `REDIS_KEY_PREFIX`, `SECRET_KEY_BASE`, `GUARDIAN_SECRET_KEY`, `PHX_HOST`, `NEXT_PUBLIC_API_URL`, `PORT` |
| `.env` (root), `backend/.env`, `frontend/.env` | Generated by `make init` (scripts/gen-env.sh); **gitignored** |
| `.envrc` | direnv — hydrated from Infisical at the monorepo layer (`hydrate-envrc`); gitignored |
| `liquibase/liquibase.properties` (+ `.example`) | Liquibase DB connection for the Python-side schema; gitignored |
| `backend/db/liquibase.properties` | Backend schema connection |

Secret layering (monorepo convention): `dc:` direnv-config → `override:` env vars → `auto:` generated → `default:` fallback. Values sourced from the Infisical server; never committed.

## Backend runtime config (`backend/config/`)

| File | Role |
|------|------|
| `config.exs` | Compile-time base (ecto repo, endpoint, guardian, oban) |
| `runtime.exs` | Env-driven: `redis` (REDIS_URL, REDIS_KEY_PREFIX), `api_key_auth` (keys, NPL_SERVICE_USER_ID), `mock_mcp` (provider/model/timeout), `embeddings` (OPENAI_API_KEY/BASE, EMBEDDING_MODEL), `memory_weaviate` (WEAVIATE_ENABLED/CLASS, WEAVIATE_API_KEY), `session_inactivity_hours` |
| `dev.exs` / `prod.exs` / `test.exs` | Per-Mix-env overrides |

## Deployment values

**`helm/npl-mcp/values.yaml`** (MCP platform chart): `replicas`, `domain`, `deployment`, `backend`, `liquibase`, `frontend`, `ingress`, `tls`, `autoscaling`, `podDisruptionBudget`. Sandbox variant not used here; see `values-sandbox.yaml` in start-app.

**`helm/start-app/values.yaml`** (scaffold chart): `replicas`, `domain`, `backend`, `frontend`, `migrate`, `database`, `redis`, `secrets`, `mail`, `sso`, `extraEnv`, `configMap`, `imagePullSecrets`, `analytics`, `ingress`, `tls`, `otel`, `storage`, `autoscaling`, `podDisruptionBudget`, `sandbox` (+ `values-sandbox.yaml`).

**Compose stacks** (root): `docker-compose.yaml` (base; PostgreSQL at localhost:5111), `docker-compose.dev.yaml` + `.override.yaml` (hot reload), `docker-compose.ci.yaml`, `docker-compose.sandbox.yaml`. Legacy chart location: `charts/npl-mcp/`.

## Ecto migrations (`backend/priv/repo/migrations/`)

Minimal set only — schema is Liquibase-owned. Present: smart_token + seed helper setup (2024), oban tables + v14 upgrade, mcp_custom_scopes, SSO claim codes + scope packaging, mcp_account_default, mcp_endpoint_templates, mcp_key_toolsets, org_slug_uniqueness, oauth_client_toolsets, mcp_entities, clients. Also `priv/w8_export_definitions.exs` / `w8_import_definitions.exs` (TRP interop definitions).

## Runtime state stores

| Store | Use |
|-------|-----|
| PostgreSQL (backend) | Primary relational store — see [backend-domains.md](backend-domains.md) |
| PostgreSQL (Python MCP) | `liquibase/changelogs/` schema — `npl_*` tables, see PROJ-SCHEMA.md |
| Redis | Cache + PubSub; key prefix via `REDIS_KEY_PREFIX` (default `starter:`) |
| Weaviate (optional) | Memory embeddings; class `NplMemory` via `WEAVIATE_*` env |
| Oban | Job queue tables in backend Postgres |

## File formats defined by this project

| Format | Location | Notes |
|--------|----------|-------|
| NPL convention YAML | `conventions/*.yaml` (syntax, declarations, directives, prefixes, prompt-sections, special-sections, pumps, npl) | Source of truth for NPLSpec/NPLLoad; `npl/npl-full.md` is generated from it |
| Theme YAML | `design/theme*/theme-npl-*/` (8 themes) | Compiled to design-system CSS via `make regen` |
| PM index YAML | `project-management/{user-stories,personas,PRDs}/index.yaml` | Relationship metadata (yq v3.4.3 — no `-i` flag) |
| Liquibase changelog YAML | `backend/db/changelog/`, `liquibase/changelogs/` | Schema migrations, both trees |
| W8 export/import `.exs` | `backend/priv/w8_*_definitions.exs` | TRP interop shape definitions |
| Sandbox service config | `sandbox/{supervisord.conf,smb.conf,sandbox-entrypoint.sh}` | Sandbox image runtime |
