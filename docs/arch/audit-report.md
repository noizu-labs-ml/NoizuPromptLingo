### Agent Health Fields (3 missing columns)

### Review Status Enum

Backend: `pending|claimed|approved|rejected|promoted`. Frontend: `pending|claimed|resolved`. Frontend collapses terminal states.

### Webhook Event Values

Backend: `run.created`, `run.started`, `run.completed`, `run.errored`, etc. Frontend: `run.completed`, `run.failed`, `review.approved`, `review.rejected`, `dataset.published`. Only `run.completed` overlaps.
