# design/

Visual design assets and style guide explorations for IoTGo.

```
design/
├── logos/                              # SVG logo suite
│   ├── iotgo-combo-color.svg           #   Full logo (mark + logotype), color
│   ├── iotgo-combo-reversed.svg        #   Full logo, light-on-dark
│   ├── iotgo-favicon.svg               #   Favicon-optimized mark
│   ├── iotgo-logotype-color.svg        #   Logotype only (text), color
│   ├── iotgo-mark-color.svg            #   Logomark only, color
│   ├── iotgo-mark-mono.svg             #   Logomark only, monochrome
│   ├── iotgo-mark-reversed.svg         #   Logomark only, light-on-dark
│   └── preview.html                    #   Visual preview of all variants
├── direction-a-dark-ops.md             # Style guide A: Dark Ops Console
├── direction-a-dark-ops.html           #   Interactive HTML preview
├── direction-b-trust-precision.md      # Style guide B: Trust + Precision
├── direction-b-trust-precision.html    #   Interactive HTML preview
├── direction-c-signal-mesh.md          # Style guide C: Signal Mesh
├── direction-c-signal-mesh.html        #   Interactive HTML preview
└── README.md                           # Comparison table + decision framework
```

Three competing visual directions — see `README.md` for the decision framework. Each direction has a markdown spec and an interactive HTML preview.
