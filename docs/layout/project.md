    ├── 001–040                         # Accessibility, combat, navigation, physics

    ├── 081–100                         # Onboarding, settings, mobile, moderation

User stories are numbered sequentially (001–100) and cover:

| Range | Domain |
|-------|--------|
| 001–020 | Accessibility fundamentals (ARIA, keyboard, screen reader) |
| 021–040 | Combat, physics narration, dungeon crawling |
| 041–060 | World exploration, AI narrative, NPC behavior, events |
| 061–080 | Crafting, economy, clans, housing, social systems |
| 081–100 | Onboarding, settings, mobile, moderation, analytics |
